07. k 최근접 이웃 — 학습하지 않는 분류기, 그리고 AI의 ‘설명’

3~6주차 모델은 모두 훈련 데이터로 가중치를 학습해 두고 새 데이터에는 그 함수만 적용했다. 이번 주의 kNN은 정반대다. 모델을 만들지 않고 훈련 데이터를 통째로 들고 있다가, 새 데이터가 오면 가장 가까운 k개의 라벨로 다수결을 낸다. 뒤이은 XAI 강의는 시선을 넓혀, 이렇게 만든 AI의 판단을 사람에게 어떻게 설명하고 설득할 것인가를 다룬다.

7.1

모델 기반 학습과 사례 기반 학습K-NN 교안 1~4p · 학습 목표 두 가지

교안 슬라이드 모아보기 3 · 4p

교안학습 목표 (2p)

① 모델 기반 학습과 사례 기반 학습을 구분한다. ② K 최근접 이웃(kNN)을 이해한다.

모델 기반 학습 (Model-based Learning) · 3p사례 기반 학습 (Instance-based Learning) · 4p
학습 단계훈련 데이터로부터 모델 f의 파라미터를 최적화해 최적의 함수 f^* 생성별도의 모델을 생성하지 않는다
예측 단계한 번 모델 생성을 완료하면 테스트 데이터에는 단순히 f^*의 연산으로 예측값 도출테스트 데이터가 들어올 때마다 훈련 데이터를 기반으로 예측값 연산
〈그림〉의 흐름모델(적절한 함수 f 선정) → 학습 단계(파라미터 최적화로 f^*) → 테스트 단계(f^*(x_i')와 y_i' 일치율 비교)훈련 데이터 + 테스트 데이터 → 훈련 데이터로 특징벡터 x_i'에 대한 \hat y_i' 연산 → y_i'와 \hat y_i'의 일치율 비교
예선형 회귀 · 로지스틱 회귀 · 퍼셉트론 · 다층 퍼셉트론 — 앞서 배운 모델 전부k 최근접 이웃이 대표적

보충설명‘게으른 학습’ — 비용이 어디로 옮겨 가나

사례 기반 학습을 흔히 게으른 학습(lazy learning), 모델 기반을 열성 학습(eager learning)이라고 부른다. kNN은 훈련 단계에서 아무것도 계산하지 않고 데이터를 저장만 한다. 대신 예측할 때마다 훈련 데이터 N개 전부와의 거리를 계산해야 한다.

훈련 비용예측 1건 비용저장해야 할 것
로지스틱 회귀(4주차)경사하강 반복 — 큼내적 한 번 — O(d)가중치 d+1개
kNN0 (저장만)거리 N번 + 정렬 — O(Nd)훈련 데이터 전체

그래서 데이터가 수백만 건이면 kNN은 예측이 느려진다 — 컴퓨터비전 7주차의 FLANN(근사 최근접 이웃 탐색)이 바로 이 문제를 푸는 도구다. 특징점 매칭도 결국 ‘가장 가까운 기술자 찾기’, 즉 1-NN이다.

7.2

k 최근접 이웃 — K는 ‘몇 명에게 물어볼까’K-NN 교안 5~7p

교안 슬라이드 모아보기 5 · 6 · 7p

교안k = 1과 k = 3 (5 · 6p)

〈그림3〉은 키(x_{i2})와 몸무게(x_{i1})로 저체중(빨강) · 정상(초록) · 비만(파랑)을 나눈 분류 데이터다.

  • 1 최근접 이웃(k = 1) — 새 관측치에 대해 기존 데이터 중 가장 유사한 데이터는? 그 데이터와 동일한 라벨로 설정한다. New Data에서 가장 가까운 점이 초록 1번이므로 정상으로 분류
  • 3 최근접 이웃(k = 3) — 주변 데이터의 라벨에 따라 다수결로 새 라벨을 결정한다. 가까운 3개가 초록 1 · 파랑 2 · 파랑 3이므로 비만으로 분류

K는 근접해 있는 데이터 중 몇 개를 확인할 것인지를 의미한다. 같은 New Data가 k에 따라 정상 → 비만으로 바뀐다 — k 선택이 결과를 좌우한다는 7.5절의 예고다.

7.3

거리측도 — 유클리디안 거리와 맨하탄 거리K-NN 교안 8 · 9p

교안 슬라이드 모아보기 8 · 9p

유클리디안 거리 (8p) — 가장 많이 사용하는 거리측도, 고등수학의 직선거리

\text{Euclidean}(\mathbf x_1,\mathbf x_2)=\sqrt{\sum_{j=1}^{p}(x_{1j}-x_{2j})^2},\qquad p=\text{특징벡터 성분의 수}
\text{Euclidean}(\mathbf x_7,\mathbf x_3)=\sqrt{(9-3)^2+(2-3)^2}=\sqrt{37}\approx6.08

점과 점 사이의 거리 — 대응되는 관측치의 특징 벡터 간 차이 제곱 합의 제곱근. 생도7(9, 2)과 생도3(3, 3) 사이를 대각선으로 곧장 잇는다.

맨하탄 거리 (9p) — 축을 따라 걷는 거리

\text{Manhattan}(\mathbf x_1,\mathbf x_2)=\sum_{j=1}^{p}|x_{1j}-x_{2j}|,\qquad\text{Manhattan}(\mathbf x_7,\mathbf x_3)=|9-3|+|2-3|=7

일상에서는 잘 쓰지 않지만 머신러닝 · 프로그래밍에서 쓰이는 경우가 있다. 실제 뉴욕의 맨하탄 같은 구획에서 이동할 때는 건물을 뚫고 갈 수 없으니 가로 · 세로로만 이동해야 한다 — 그림의 꺾인 경로.

두 거리는 항상 맨하탄 ≥ 유클리디안이다 — 직각삼각형에서 빗변(유클리디안)은 두 변의 합(맨하탄)보다 짧다. 생도7-3도 6.08 < 7. 같은 값이 되는 경우는 한 축에서만 차이가 날 때뿐이다(예: (3,3)과 (3,4)는 둘 다 1). 그리고 거리 종류를 바꾸면 최근접 이웃의 순서가 바뀔 수 있다 — 아래 7.4의 표에서 생도4(유클리디안 2.83)와 생도2 · 생도6(3.16)은 맨하탄으로 재면 모두 4로 동점이 된다.

보충설명거리를 쓰기 전에 ‘단위’를 맞춰야 한다

교안의 예는 몸무게 · 키를 모두 1~9 등급으로 바꿔 놓아서 문제가 드러나지 않는다. 실제 값으로 키(cm, 150~190)와 몸무게(kg, 40~100)를 그대로 쓰면, 거리에서 숫자 범위가 큰 특징이 결과를 독차지한다. 그래서 kNN 전에는 보통 표준화(평균 0 · 표준편차 1) 또는 최소-최대 정규화(0~1)로 특징의 스케일을 맞춘다 — 6주차 MNIST 입력을 표준화한 것과 같은 이유다. 실습의 농구 데이터(3점슛 0~3개, 블록 0~2개)는 범위가 비슷해 그대로 쓴다.

이 거리들은 자연어처리 5주차의 텍스트 유사도(유클리디언 · 맨해튼 · 코사인)와 같은 식이다.

생도6(6, 5)13.165th
생도7(9, 2)16.327th

가까운 3명의 라벨은 0 · 1 · 1 → 다수결로 \hat y_1'=1(비만).

생도4의 거리는 정확히 \sqrt{2^2+2^2}=\sqrt8=2.828\ldots이라 반올림하면 2.83이다(교안은 2.82로 버림). 순서에는 영향이 없다. 또 생도2와 생도6은 둘 다 √10 = 3.16으로 동점인데 교안은 표 순서대로 4th · 5th를 매겼다 — k = 4였다면 어느 쪽을 넣느냐로 결과가 갈릴 수 있다.

보충설명왜 k는 보통 홀수로 고르나

클래스가 둘일 때 k가 짝수면 동표가 생길 수 있다(k = 2에서 정상 1 · 확진 1). 그래서 이진 분류에서는 k를 1, 3, 5, 7, … 홀수로 고르는 것이 관례다 — 실습 노트북도 range(1, 10, 2)로 홀수만 시험한다. 클래스가 셋 이상이면 홀수여도 동표가 날 수 있어(k = 3에서 1 · 1 · 1), 거리가 더 가까운 쪽을 우선하거나 거리에 반비례하는 가중치(7.5)를 준다.

교안kNN 회귀 (17p)

  • y_i의 값이 범주형이 아닌 연속형이면 회귀를 수행한다
  • 알고리즘의 동작은 동일하나, k개 데이터의 값의 평균을 회귀값으로 반환한다
  • 거리에 비례하여 가중치를 주는 방법도 존재한다

〈그림4〉는 인공지능 입문 중간고사 점수(x_{i1})와 수시 점수(x_{i2})로 기말고사 점수를 예측한다. New Data 주변 3명의 기말 점수가 72 · 87 · 69이므로

특징 5개짜리 유클리디안 거리로 가까운 순서는 F(1.12) · E(1.87) · C(2.12). k = 1이면 F의 점수 9.0을 그대로, k = 3이면 세 점수의 평균 9.17을 예측한다.

보충설명거리 가중 평균으로 다시 계산해 보면

‘거리에 비례하여 가중치를 주는 방법’은 실제로는 거리에 반비례하는 가중치 w_i=1/d_i를 쓴다 — 가까울수록 더 크게 반영해야 하기 때문이다.

\hat y=\frac{\sum w_iy_i}{\sum w_i}=\frac{\frac{9.0}{1.12}+\frac{10.0}{1.87}+\frac{8.5}{2.12}}{\frac{1}{1.12}+\frac{1}{1.87}+\frac{1}{2.12}}=\frac{8.04+5.35+4.01}{0.893+0.535+0.472}=\frac{17.40}{1.900}\approx9.16

단순 평균 9.17과 거의 같다 — 세 이웃의 거리가 비슷해서다. 이웃 하나가 아주 멀리 있으면 차이가 커진다. sklearn에서는 KNeighborsRegressor(n_neighbors=3, weights='distance')(기본값은 'uniform', 단순 평균).

교안k 선택 방법 (22p)

일정 범위 내에서 k를 조정해 가장 좋은 예측 결과를 보이는 k를 고른다. 예) k를 1부터 15까지 실험해 성능이 가장 좋을 때의 값을 설정한다. 학습 데이터를 기준으로 설정하는 것이 아니라, 테스트 데이터(새로운 관측치)에 대한 결과가 중요하다.

‘Classification result’ 그래프 — 가로축은 k(왼쪽 15 = underfitting → 오른쪽 1 = overfitting), 세로축은 오분류율. 파란 Train error는 k가 작아질수록 계속 줄어 k = 1에서 0%가 된다. 빨간 Test error는 U자를 그리며 k = 5에서 최소(Best k = 5)가 된다.

k = 1의 훈련 오차는 왜 반드시 0인가 — 훈련 데이터의 점 하나를 예측할 때, 그 점에서 가장 가까운 훈련 데이터는 거리 0인 자기 자신이다. 그러니 항상 자기 라벨을 그대로 맞힌다(같은 좌표에 라벨이 다른 점이 없다면). 훈련 오차 0%는 잘 배웠다는 뜻이 아니라 외웠다는 뜻이다. 그래서 22p의 결론처럼 k는 테스트(또는 검증) 오차로 골라야 한다 — NLP 7주차에서 ‘학습 PPL이 가장 낮은 3-gram MLE가 테스트 PPL은 inf’였던 것과 같은 구조다. 엄밀히는 테스트 데이터는 마지막 보고용이고 k 선택은 검증 데이터나 교차검증으로 하는 것이 맞다(6주차 개정판 · 데이터 분할).

교안AI 보급과 새로운 요구 사항 (3 · 4p)

AI는 학습 데이터에 맞춰 다양한 학습 방법을 구현할 수 있다. 같은 기법이라도 데이터만 바꾸면 광고 추천에도, 설비 이상 탐지에도, 의료 영상 판독에도 쓸 수 있으니 활용 범위가 계속 넓어진다. 그만큼 AI의 판단이 사람과 사회에 미치는 무게도 커져서, ‘잘 맞히는가’ 말고도 요구하는 것이 늘었다 — 아래 두 그림이 그 변화다.

〈그림 1.1〉 AI 활용 영역의 확대 — 세로축은 AI 기여도(의사결정 지원 ↔ 완전 자동화), 가로축은 사고 심각도(영향도 경미 → 운영에 영향 → 인명에 영향)다. 왼쪽 아래(광고 · 키오스크 · 이상 탐지 · 라인 자동화)는 틀려도 피해가 작다. 오른쪽 위로 갈수록 ‘AI의 판단에 높은 신뢰성이 필요한 영역’으로 묶인다 — 자동 운전 · 자동 거래 · 융자 심사 · 인프라 보수 · 의료 진단. 광고는 이 묶음 바깥이다.

〈그림 1.2〉 AI 활용에 요구되는 시점의 변화 — 왼쪽의 사회적 배경은 AI 악용, AI에 의한 차별, AI의 테스트 부족으로 인한 사고, 학습용 데이터의 편향이나 부족에 의한 AI 오작동, AI의 성능 향상이다. 그 결과 요구되는 시점이 아래에서 위로 확대되었다.

① 기계학습적 시점정확도 — 잘 맞히는가
② 시스템적 시점가용성 · 운용 · 보수성 · 성능 · 확장성 · 보안 — 시스템으로 안정적으로 돌아가는가
③ 사회적 시점공평성 · 책임성 · 투명성 — 사회가 받아들일 수 있는가
④ 윤리적 시점가장 바깥 — 옳은가

교안AI의 공평성 · 책임성 · 투명성 (5p)

AI는 데이터에서 규칙을 배우므로, 학습할 때 입력 데이터에 편향이 있으면 그 편향까지 그대로 배운다. 그래서 AI 시스템은 사용자의 속성(성별 · 나이 · 인종 · 출신 지역 등)이 달라도 결과가 그 차이 때문에 갈리지 않도록, 불공평한 바이어스를 제거해야 한다. 이것이 공평성(fairness)의 요구다.

〈그림 1.3〉 불공평한 예측 결과를 초래하는 바이어스의 예 — 바이어스는 네 단계로 쌓인다.

실제 데이터역사적 바이어스(과거 사회의 차별이 데이터에 남음) · 샘플링 바이어스(특정 집단이 덜 수집됨)
학습 데이터가공 바이어스 — 정제 · 라벨링 과정에서 생김
AI학습 바이어스 — 모델이 그 편향을 그대로 배움
불공평한 예측저울이 기운다

그리고 두 단어를 영어와 함께 기억하라 — AI의 책임성(Accountability): 판단의 결과에 대해 누가 어떻게 책임지는가, AI의 투명성(Transparency): 판단 과정을 밖에서 들여다볼 수 있는가.

‘성별 칸을 지우면 공평해진다’는 틀렸다 — 민감한 속성을 입력에서 빼기만 하는 방식을 무지를 통한 공평성이라 부른다. 그런데 거주지 우편번호 · 출신 학교 · 구매 품목처럼 민감 속성과 상관된 다른 변수(대리 변수, proxy)가 남아 있으면, 모델은 그 변수로 성별이나 인종을 사실상 다시 알아내고 같은 차별을 재현한다. 그래서 실무에서는 속성을 지우는 데서 멈추지 않고, 집단별 결과(예: 남녀 승인율, 집단별 오류율)를 직접 측정해 차이를 점검한다. 또 ‘공평하다’의 수학적 정의 여러 개(집단별 양성 비율을 같게, 집단별 오류율을 같게 등)는 기저 비율이 다르면 동시에 만족할 수 없다는 결과도 알려져 있어, 어떤 공평성을 택할지가 결국 사회적 · 윤리적 판단이 된다 — 〈그림 1.2〉의 ③ · ④ 시점이다.

〈그림 1.6〉 얕은 트리 vs 깊은 트리
  • 루트에서 잎까지의 경로가 곧 예측 근거다(“이용금액이 3만 원을 넘고, 쿠폰은 안 썼지만 월 5회 넘게 왔으니 회원일 확률이 높다”).
  • 각 마디에 조건으로 나타나는 항목은 예측값에 큰 영향을 준다. 트리는 예측에 쓸모 있는 항목만 골라 마디에 올리기 때문이다.

def distance(data1, data2):
    dist = 0
    for i in range(len(data1)):
        dist += math.pow(data1[i] - data2[i], 2)   # 성분별 차이의 제곱을 더한다
    return math.sqrt(dist)                          # 제곱근 → 유클리디안 거리 (7.3)

        dist_list.sort()                            # 거리가 가까운 순서로 정렬
        cnt = 0
        for j in range(k):                          # 가까운 k개 중 C의 수를 센다
            if dist_list[j][1] == "C": cnt += 1
        if cnt > (k / 2): result.append(["C"])      # 과반이면 C, 아니면 SG (Step 3, 다수결)
        else:             result.append(["SG"])
    return result

k = 1에서 sklearn은 0.80인데 직접 구현은 왜 0.75인가 — 노트북에는 설명이 없어서 데이터를 직접 돌려 원인을 찾았다. 테스트 16번째 선수(3P 1.7, BLK 0.8, 정답 SG)에서 가장 가까운 훈련 선수가 두 명이고, 거리가 똑같이 0.3606인데 한 명은 C, 한 명은 SG다.
  • 직접 구현 — dist_list.sort()는 [거리, 라벨] 리스트를 정렬하므로, 거리가 같으면 두 번째 원소(라벨 문자열)를 알파벳순으로 비교한다. 'C' < 'SG'이므로 C가 1등이 되어 C로 오분류
  • sklearn — 거리가 같으면 훈련 데이터에 먼저 나온 쪽을 고르는데, 이 경우 SG가 먼저라 정답
즉 성능 차이가 아니라 동점 처리(tie-breaking) 방식의 차이다. 20명 중 한 명이라 정확도가 0.05 차이 난다. 정렬 키를 거리만으로 두려면 dist_list.sort(key=lambda d: d[0])로 바꾸면 된다(파이썬 정렬은 안정 정렬이라 같은 거리면 원래 순서를 지킨다) — 그러면 sklearn과 같은 0.80이 나온다. 7.4절 생도2 · 생도6의 동점과 같은 문제다.
(5-3) 결과 시각화는 훈련 데이터 SG(파랑) · C(빨강) 위에 테스트 예측 SG(하늘색) · C(주황)를 찍는다. 그림에서 SG는 오른쪽 아래(3점슛 많고 블록 적음), C는 왼쪽 위(3점슛 거의 0, 블록 많음)에 모여 있어 두 특징만으로도 꽤 잘 갈린다 — 정확도 0.9가 나오는 이유다.

핵심 정리중간고사 전에 이것만은

모델 기반 vs 사례 기반

파라미터를 최적화해 f^*를 만들어 두기(회귀 · 퍼셉트론 · MLP) vs 모델 없이 새 데이터가 올 때마다 훈련 데이터로 연산(kNN).

kNN 3단계

새 관측치 → 거리로 가까운 k개 → 다수결(분류) / 평균(회귀). k = 1이면 가장 가까운 하나의 라벨.

거리

유클리디안 \sqrt{\sum(x_{1j}-x_{2j})^2} · 맨하탄 \sum|x_{1j}-x_{2j}|. 생도7-3은 √37 ≈ 6.08 vs 7.

초매개변수

k와 거리 측도. k 작음 → 과대적합, k 큼 → 과소적합. k는 테스트(새 관측치) 성능으로 고른다(예: Best k = 5).
