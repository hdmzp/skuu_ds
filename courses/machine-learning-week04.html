4.1

선형회귀 복습과 분류의 정의로지스틱 1부 앞부분 — 모델 · 손실 · 경사하강 → 분류로

선형회귀 핵심 복습

\hat y_i=w_0+w_1x_i,\qquad L(\mathbf w)=\frac1N\sum_{i=1}^{N}(\hat y_i-y_i)^2,\qquad w_0\leftarrow w_0-\alpha\frac{\partial L(\mathbf w)}{\partial w_0},\qquad \hat y_i=\mathbf w^{\mathsf T}\mathbf x_i

\mathbf w^*=\operatorname{argmin}L(\mathbf w) 를 반복 갱신으로 찾는 방법이 경사하강법. \hat y_i=\mathbf w^{\mathsf T}\mathbf x_i 로 간결하게 쓸 수 있는 것은 바이어스 성분을 1로 둔 \mathbf x_i=[1\;x_{i1}\cdots x_{id}]^{\mathsf T} 표기 덕분 → 3주차 3.6

분류(Classification) — 특성 값의 집합으로 설명되는 개체의 소속 클래스 / 카테고리를 예측하는 작업.
  • 클래스는 사전에 식별되어 있고, 모든 개체는 어느 한 클래스에 속한다고 가정
  • 학습 데이터 \mathcal D=\{(\mathbf x_i,y_i)\}_{i=1}^N,\;y_i\in\{C_1,\dots,C_K\} — 회귀와 달리 y_i는 실수 전체가 아니라 정해진 레이블 중 하나
  • 2클래스면 C_1=1,\;C_2=0 — 예) “스팸메일” = 1, “스팸 아닌 메일” = 0. 숫자로 쓰는 이유는 데이터를 표기·관리하기 편하기 때문(크기에 의미가 있는 것은 아님)
4.2

특징 벡터와 특징 공간개체 하나 = 공간의 점 하나

  • 특징 벡터 — 모든 개체를 동일한 특징으로 설명할 때 개별 관측 값을 표현하는 벡터
  • 학과를 숫자로 부호화(인공지능학과 1, 기계공학과 2, 수학과 3, 물리학과 4) — 컴퓨터의 동작 편의를 위한 것
  • 홍길동(인공지능학과, 평점 3.8) = [1\;\;3.8]^{\mathsf T} · 성춘향(수학과, 4.0) = [3\;\;4.0]^{\mathsf T}
  • 특징 공간 — 성분이 d개면 d차원 공간의 한 점. 학년까지 관측하면 3차원이 된다
주의 — 숫자로 바꾼 범주 — 학과 1·2·3·4는 이름표를 숫자로 적은 것이지 “수학과(3)가 인공지능학과(1)의 3배”라는 뜻이 아니다. 교안은 편의상 이렇게 쓰지만, 실무에서는 이런 범주형 특징을 원-핫 인코딩으로 바꿔 거리·크기 관계가 생기지 않게 하는 경우가 많다 (보충).
4.3

분류 규칙과 확률 분포 기반 분류구분선 · 사후 확률 · 베이즈 규칙

확률 분포로 분류하기 — 체조 동아리 회원(C_1)과 비회원(C_2)의 몸무게 분포를 알 때, 52kg 학생은 어느 쪽인가? 사후 확률 P(C_1\mid x) = x를 관찰했을 때 소속이 C_1일 가능성을 수치로 표현한 조건부 확률.

베이즈 규칙 (2주차 확률 복습)

P(C_1\mid x)=\frac{P(C_1,x)}{P(x)}=\frac{P(x\mid C_1)P(C_1)}{P(x\mid C_1)P(C_1)+P(x\mid C_2)P(C_2)},\qquad P(x)=P(C_1,x)+P(C_2,x)

분류 규칙 — P(C_1\mid x)>P(C_2\mid x) 이면 C_1. 두 확률의 합이 1이므로 이것은 P(C_1\mid x)>0.5 와 같은 조건이다. 계산에 필요한 정보는 P(C_1),P(C_2),P(x\mid C_1),P(x\mid C_2) (학습률 같은 것은 필요 없다).

로지스틱 회귀로 가는 다리 — 위 식은 각 클래스의 분포 P(x\mid C_k) 를 먼저 알아야 쓸 수 있다. 로지스틱 회귀는 이 분포를 추정하지 않고 사후 확률 P(C_1\mid\mathbf x) 자체를 바로 모델링한다(4.6).
4.4

선형 판별 함수와 선형 구분 가능성g(x) = wᵀx 의 부호로 분류

선형 판별 함수 (Linear discriminant function)

g(\mathbf x)=\mathbf w\cdot\mathbf x=\mathbf w^{\mathsf T}\mathbf x=w_0+w_1x_1+\cdots+w_dx_d\qquad(x_0=1)

\mathbf x 와 \mathbf w 는 둘 다 d+1개 성분. 식 모양은 다중 선형 회귀와 똑같고, 쓰임이 다르다 — 회귀는 값 자체가 예측, 판별은 부호가 예측.
결정 규칙: g(\mathbf x)>0 이면 C_1, 그 외에는 C_2. 학습이 결정하는 것은 가중치 벡터 \mathbf w

교안 예제 g(\mathbf x)=20x_1+3x_2-36, 즉 \mathbf w=[-36\;\;20\;\;3]^{\mathsf T} (x_1 학과, x_2 학점)

①
\mathbf x_2=[1\;\;3.8]^{\mathsf T}: 20+11.4-36=-4.6<0 → 미수강
②
\mathbf x_4=[3\;\;2.2]^{\mathsf T}: 60+6.6-36=30.6>0 → 수강
③
나머지도 확인: [1\;2.2]\to-9.4,\;[1\;3.9]\to-4.3,\;[3\;4.0]\to36,\;[3\;3.2]\to33.6 — 6명 모두 맞게 갈린다
정리 — g(\mathbf x)=0 이 경계선이고, 이 데이터는 선형 구분 가능하다: 한 클래스는 모두 g>0, 다른 클래스는 모두 g<0

4.5

로지스틱 함수와 로그 오드σ(x) · 미분 형태 · Odds · Log-odds(logit)

로지스틱(시그모이드) 함수와 미분

\sigma(x)=\frac{1}{1+e^{-x}}=\frac{e^x}{1+e^x},\qquad \frac{d}{dx}\sigma(x)=\frac{e^x}{(1+e^x)^2}=\frac{e^x}{1+e^x}\cdot\frac{1}{1+e^x}=\sigma(x)\bigl(1-\sigma(x)\bigr)

(1) 정의역 전체를 0과 1 사이로 사상하고 (2) 미분 가능. \sigma(0)=0.5. 미분이 자기 자신만으로 표현되는 점이 4.6의 기울기 계산을 간단하게 만든다.
활용 1 — 특정 사건·카테고리가 발생할 확률 표현(로지스틱 회귀) · 활용 2 — 인공신경망의 활성화 함수

오드와 로그 오드

오드(Odds)와 로그 오드(Log-odds, logit)

\text{odds}=\frac{p}{1-p},\qquad \text{logit}(p)=\ln\frac{p}{1-p}

· 공정한 주사위에서 3의 배수가 아닌 눈: p=2/3 → 오드 \frac{2/3}{1/3}=2 (“일어날 확률이 안 일어날 확률의 2배”)
· p=0.5 이면 오드 1, 로그 오드 0
· 로그 오드의 정의역은 확률 (0, 1), 치역은 실수 전체 (−∞, ∞)

왜 로그 오드인가 — 확률은 0~1에 갇혀 있어 선형식 \mathbf w^{\mathsf T}\mathbf x(−∞~∞)로 바로 근사할 수 없다. 로그 오드는 치역이 실수 전체라 선형 함수로 근사하기에 딱 맞다. 그래서 로지스틱 회귀는 “로그 오드를 선형 함수 표현으로 근사”한다. 그리고 로지스틱 함수는 로그 오드의 역함수다: \text{logit}(\sigma(z))=z.
4.6

로지스틱 회귀 모델과 학습모델 유도 · 베르누이 · 우도 · 크로스 엔트로피 · 경사하강법 I / II

이진 분류의 두 접근 — 접근법 1: 두 클래스를 구분하도록 특징 공간을 분할(4.4) · 접근법 2: P(C_1\mid\mathbf x) 와 P(C_2\mid\mathbf x)=1-P(C_1\mid\mathbf x) 를 비교해 레이블 결정. 로지스틱 회귀는 접근법 2다. 예) “스팸메일 여부”, “대학생 여부”

모델 유도 — 로그 오드 = 선형 함수

교안 전개 \ln\dfrac{P(C_1\mid\mathbf x)}{1-P(C_1\mid\mathbf x)}=\mathbf w^{\mathsf T}\mathbf x 를 P(C_1\mid\mathbf x) 에 대해 풀면?

①
양변에 지수: \dfrac{P}{1-P}=e^{\mathbf w^{\mathsf T}\mathbf x}
②
P=e^{\mathbf w^{\mathsf T}\mathbf x}(1-P)\;\Rightarrow\;P(1+e^{\mathbf w^{\mathsf T}\mathbf x})=e^{\mathbf w^{\mathsf T}\mathbf x}
③
P(C_1\mid\mathbf x)=\dfrac{e^{\mathbf w^{\mathsf T}\mathbf x}}{1+e^{\mathbf w^{\mathsf T}\mathbf x}}=\dfrac{1}{1+e^{-\mathbf w^{\mathsf T}\mathbf x}}=\sigma(\mathbf w^{\mathsf T}\mathbf x)
결과 — P(C_1\mid\mathbf x)=\sigma(\mathbf w^{\mathsf T}\mathbf x),\quad P(C_2\mid\mathbf x)=1-\sigma(\mathbf w^{\mathsf T}\mathbf x)=\dfrac{e^{-\mathbf w^{\mathsf T}\mathbf x}}{1+e^{-\mathbf w^{\mathsf T}\mathbf x}}. 특징 벡터는 바이어스를 포함한 [1\;x_1\cdots x_d]^{\mathsf T}

베르누이 분포로 레이블 확률을 한 줄에

베르누이 분포 → 레이블의 조건부 확률

P(X=x)=p^{x}(1-p)^{1-x},\;x\in\{0,1\}\qquad\Longrightarrow\qquad P(y_i\mid\mathbf x_i)=\sigma(\mathbf w^{\mathsf T}\mathbf x_i)^{y_i}\bigl(1-\sigma(\mathbf w^{\mathsf T}\mathbf x_i)\bigr)^{1-y_i}

지수 트릭 — y_i=1 이면 뒤 항이 (\cdot)^0=1 이 되어 \sigma(\cdot) 만 남고, y_i=0 이면 앞 항이 사라져 1-\sigma(\cdot) 만 남는다. 두 경우를 if문 없이 한 식으로 쓴 것.

우도 → 음의 로그 우도 → 손실함수

학습 데이터의 우도 (단순 로지스틱, x_i는 실수 하나)

\ell(w_0,w_1)=\prod_{i=1}^{N}P(y_i\mid x_i)=\prod_{i=1}^{N}\sigma(w_0+w_1x_i)^{y_i}\bigl(1-\sigma(w_0+w_1x_i)\bigr)^{1-y_i}

① P(y_i\mid x_i) = 현재 인자 w_0,w_1 로 계산한 사후 확률로 x_i의 클래스를 정확하게 추정할 확률 ② 우도는 그 곱이므로 클수록 좋다 ③ -\ln\ell 은 작을수록 좋다 — “우도 최대화”와 “-\ln\ell 최소화”는 같은 뜻

손실함수 L=-\frac1N\ln\ell

L(w_0,w_1)=-\frac1N\sum_{i=1}^{N}\Bigl\{y_i\ln\sigma(w_0+w_1x_i)+(1-y_i)\ln\bigl(1-\sigma(w_0+w_1x_i)\bigr)\Bigr\}

왜 곱이 아니라 로그를 쓰나 (보충) — 0~1 사이 확률을 수백 번 곱하면 컴퓨터에서 0으로 뭉개진다(underflow). 로그를 취하면 곱이 합이 되어 계산도 안정되고 미분도 쉬워진다. 로그는 증가함수라 최대화하는 위치는 그대로다.

바이너리 크로스 엔트로피 (Binary cross-entropy)

CE(y_i,\hat y_i)=-y_i\ln P(C_1\mid\mathbf x_i)-(1-y_i)\ln\bigl(1-P(C_1\mid\mathbf x_i)\bigr),\qquad \mathbf w^*=\underset{\mathbf w}{\operatorname{argmin}}\frac1N\sum_{i=1}^{N}CE(y_i,\hat y_i)

위 손실함수를 한 개 데이터 단위로 쓴 것이 CE이고, 그 평균이 곧 L(\mathbf w)=-\frac1N\ln\ell(\mathbf w). 일반화된 표기에서 \mathbf x_i=[1\;x_{i1}\cdots x_{id}]^{\mathsf T},\;P(C_1\mid\mathbf x_i)=\sigma(\mathbf w^{\mathsf T}\mathbf x_i)

인자 갱신 — 기울기 유도

보충 유도 한 데이터의 CE를 w_k 로 미분하면 왜 -(y_i-\sigma)x_{ik} 가 되나? (z=\mathbf w^{\mathsf T}\mathbf x_i,\;\sigma=\sigma(z))

①
\dfrac{\partial CE}{\partial\sigma}=-\dfrac{y_i}{\sigma}+\dfrac{1-y_i}{1-\sigma}=\dfrac{\sigma-y_i}{\sigma(1-\sigma)}
②
\dfrac{\partial\sigma}{\partial z}=\sigma(1-\sigma) (4.5의 미분 형태), \dfrac{\partial z}{\partial w_k}=x_{ik}
③
연쇄법칙으로 곱하면 \sigma(1-\sigma) 가 깔끔하게 약분: \dfrac{\partial CE}{\partial w_k}=(\sigma-y_i)\,x_{ik}=-(y_i-\sigma(\mathbf w^{\mathsf T}\mathbf x_i))\,x_{ik}
결과 — \dfrac{\partial}{\partial w_k}\dfrac1N\sum_i CE=-\dfrac1N\sum_{i=1}^{N}\bigl(y_i-\sigma(\mathbf w^{\mathsf T}\mathbf x_i)\bigr)x_{ik}, x_{i0}=1. 시그모이드와 CE를 짝지으면 기울기가 (정답 − 예측) × 입력이라는 선형 회귀와 같은 모양이 된다

dataset = pd.read_csv('Social_Network_Ads.csv')
X = dataset.iloc[:, [2, 3]].values        # Age, EstimatedSalary — 대괄호 안에 열 번호 목록
y = dataset.iloc[:, 4].values             # Purchased

from sklearn.preprocessing import StandardScaler
sc = StandardScaler()
X = sc.fit_transform(X)                   # 나이(수십)와 급여(수만)의 단위 차이를 없앤다

X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.25, random_state=1)

from sklearn.linear_model import LogisticRegression
classifier = LogisticRegression()
classifier.fit(X_train, y_train)          # 판별함수·시그모이드·손실·경사하강 전부 fit() 하나로
print(classifier.coef_)                   # [[w1, w2]] — Age, Salary의 가중치
print(classifier.intercept_)              # [w0]

y_pred = classifier.predict(X_test)       # 확률이 0.5 넘으면 1 — 손실·갱신 없이 예측만
print(sklearn.metrics.accuracy_score(y_test, y_pred))
print(sklearn.metrics.f1_score(y_test, y_pred))
스케일링 순서 — 노트북이 직접 짚은 함정
정석은 분할 먼저, 그다음 X_train = sc.fit_transform(X_train) · X_test = sc.transform(X_test)다. fit_transform은 훈련 데이터의 평균·분산을 구해 변환하고, transform은 그 값을 테스트에 그대로 적용한다 — 두 데이터에 같은 기준을 써야 하기 때문. 그런데 실습 코드는 편의상 분할 전에 전체 X에 fit_transform을 했다. 이러면 테스트 데이터의 통계가 학습에 섞이는 데이터 누수가 생긴다(개정판 3주차에서 본 Pipeline 이야기와 같은 문제). 노트북 주석도 “비교하려면 split을 먼저 실행한 후 StandardScaler를 실행해야 한다”고 적어 두었다.
분류 성능 지표 — Positive(1)/Negative(0) 이진 분류 기준
  • Accuracy — 테스트 데이터에서 레이블을 정확히 맞힌 비율
  • Precision — 모델이 Positive라고 한 것 중 실제 Positive 비율 (“산다고 예측한 사람 중 진짜 산 사람”)
  • Recall — 실제 Positive 중 모델이 Positive라고 맞힌 비율 (“실제 구매자 중 놓치지 않은 비율”)
  • F1 score — 2\cdot\frac{\text{Precision}\cdot\text{Recall}}{\text{Precision}+\text{Recall}}. 클래스 비율이 한쪽으로 쏠렸을 때 정확도만 보면 속기 쉬워 함께 본다

실습 ② — NumPy로 직접 구현sigmoid · loss · gradients · train · predict

먼저 알아 둘 NumPy 함수
  • np.mean(x) — 평균 · np.exp(x) — e^x · np.log(x) — 자연로그 ln(밑이 e). 셋 다 리스트를 받으면 원소마다 계산
  • np.dot — 벡터·벡터면 내적, 행렬·벡터면 행렬곱. 노트북 예: np.dot([2,3,4], [1,2,3]) = 20, np.dot(x2.T, w)는 (2,3)×(3,) → (2,)
def sigmoid(x):
    return 1.0 / (1 + np.exp(-x))

def loss(y, y_hat):                                   # y_hat = σ(Xw) = P(C1|x)
    loss = np.mean(y*np.log(y_hat) + (1-y)*np.log(1-y_hat))
    return -loss                                      # 평균 바이너리 크로스 엔트로피

def gradients(X, y, y_hat):
    dw = np.dot(X.T, (y - y_hat))                     # Σ (y_i − ŷ_i) x_ik 를 행렬곱 한 번으로
    return dw

def train(X_train, y_train, bs, epochs, lr):
    m, n = X_train.shape                              # m = 300(데이터 수), n = 2(특징 수)
    w = np.zeros((n, 1))                              # 가중치 0으로 초기화, 모양 (2,1)
    y_train = y_train.reshape(m, 1)                   # (300,) → (300,1) 로 맞춤
    for epoch in range(epochs):
        for i in range((m-1)//bs + 1):                # 미니배치 개수 (// = 몫)
            xb = X_train[i*bs : i*bs+bs]              # i번째 묶음
            yb = y_train[i*bs : i*bs+bs]
            y_hat = sigmoid(np.dot(xb, w))            # 예측 확률
            dw = gradients(xb, yb, y_hat)
            w += lr * dw                              # w ← w + α Σ(y−ŷ)x
        ...                                           # 에폭마다 loss·정확도 기록, 10에폭마다 출력
    return w, losses, train_acc, test_acc

def predict(X, w):
    preds = sigmoid(np.dot(X, w))
    return np.array([1 if p > 0.5 else 0 for p in preds])   # 사후 확률 0.5 기준 결정 규칙

w, l, train_acc, test_acc = train(X_train, y_train, bs=100, epochs=100, lr=0.1/len(X_train))

코드 속 질문 풀이

①
(m-1)//bs + 1 은? — //는 몫. m=300, bs=100이면 299//100+1 = 3 → 한 에폭에 100개씩 3번 갱신. m이 bs로 나눠떨어지지 않아도 마지막 자투리 묶음까지 포함되게 하는 계산이다
②
행렬 모양 — xb (100,2), w (2,1) → np.dot(xb, w) (100,1). gradients에서 X.T (2,100) × (y−ŷ) (100,1) = (2,1) — 교안의 Σ 합이 행렬곱 한 번으로 표현됐다
③
lr = 0.1/len(X_train) 인 이유 — gradients가 평균이 아니라 합을 돌려주므로, 학습률에 \frac1N 을 미리 넣어 교안의 \frac{\alpha}{N}\sum 과 맞춘 것
④
loss 함수는 갱신에 안 쓰인다? — 맞다. 노트북도 “loss는 BCE 평균을 계산해 줄어드는 것을 보여주기 위한 것이고, 갱신은 log likelihood 기울기로 하는 다소 복잡한 구현”이라고 밝힌다. 두 식은 부호만 반대인 같은 양이라 결과는 일관된다
바이어스가 없다 (보충) — 이 직접 구현의 w는 (2,1)로 Age·Salary 가중치만 있고 w_0(절편)이 없다. 표준화로 평균이 0이 된 데이터라 어느 정도 동작하지만, 경계가 원점을 지나야 한다는 제약이 생긴다. X 앞에 1로 된 열을 붙이면(np.c_[np.ones(m), X]) 교안의 x_{i0}=1 표기와 같아진다
