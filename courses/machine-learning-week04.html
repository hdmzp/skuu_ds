4.1

선형회귀 복습과 분류의 정의로지스틱 1부 3 · 4p · 2부 3p

교안 슬라이드 모아보기 1부 3 · 4p · 2부 3p (3장)

개념 정리

교안3주차에서 가져오는 것

선형회귀 핵심 복습

\hat y_i=w_0+w_1x_i,\qquad L(\mathbf w)=\frac1N\sum_{i=1}^{N}(\hat y_i-y_i)^2,\qquad w_0\leftarrow w_0-\alpha\frac{\partial L(\mathbf w)}{\partial w_0},\qquad \hat y_i=\mathbf w^{\mathsf T}\mathbf x_i

\mathbf w^*=\operatorname{argmin}L(\mathbf w) 를 반복 갱신으로 찾는 방법이 경사하강법이다. \hat y_i=\mathbf w^{\mathsf T}\mathbf x_i 처럼 간결하게 쓸 수 있는 것은 바이어스 자리를 1로 둔 \mathbf x_i=[1\;x_{i1}\cdots x_{id}]^{\mathsf T} 표기 덕분이다 → 3주차 3.6

교안분류(Classification)란

특성 값의 집합으로 설명되는 개체의 소속 클래스 / 카테고리를 예측하는 작업이다. 클래스는 미리 정해져 있고, 모든 개체는 그중 하나에 속한다고 본다.

  • 학습 데이터 \mathcal D=\{(\mathbf x_i,y_i)\}_{i=1}^N,\;y_i\in\{C_1,\dots,C_K\} — 회귀와 달리 y_i 는 실수 전체가 아니라 정해진 레이블 중 하나
  • 2클래스면 C_1=1,\;C_2=0 으로 적는다. 숫자로 쓰는 이유는 데이터를 다루기 편해서일 뿐, 크기에 의미가 있는 것은 아니다

플립러닝이번 주 내내 다루는 것은 ‘이진(바이너리) 분류’

모든 개체가 C_1 아니면 C_2 둘 중 하나에 속하는 상황만 다룬다. 스팸메일 여부, 대학생 여부, 구매 여부처럼 예 / 아니오로 답이 갈리는 문제다. 레이블은 \{C_1=1,\;C_2=0\} 으로 적는다.

그래서 확률 하나만 구하면 끝난다. P(C_1\mid\mathbf x) 를 알면 나머지는 P(C_2\mid\mathbf x)=1-P(C_1\mid\mathbf x) 로 자동으로 정해지기 때문이다. 0.5보다 크면 C_1 이 기본 결정 규칙이 된다.

4.2

특징 벡터와 특징 공간로지스틱 1부 5 · 6p · 개체 하나 = 공간의 점 하나

교안 슬라이드 모아보기 1부 5 · 6p (2장)

개념 정리

교안개체 하나를 숫자 벡터로

  • 특징 벡터 — 모든 개체를 같은 특징으로 설명할 때, 개별 관측값을 늘어놓은 벡터
  • 학과를 숫자로 부호화(인공지능학과 1, 기계공학과 2, 수학과 3, 물리학과 4)한 뒤, 홍길동(인공지능학과, 평점 3.8) = [1\;\;3.8]^{\mathsf T}, 성춘향(수학과, 4.0) = [3\;\;4.0]^{\mathsf T}
  • 특징 공간 — 성분이 d 개면 d 차원 공간이고, 개체 하나는 그 공간의 점 하나다. 학년까지 관측하면 3차원이 된다

보충설명범주를 숫자로 바꿀 때의 함정

학과 1 · 2 · 3 · 4는 이름표를 숫자로 적은 것이지 “수학과(3)가 인공지능학과(1)의 3배”라는 뜻이 아니다. 교안은 설명 편의로 이렇게 쓰지만, 이대로 모델에 넣으면 학과 사이에 없던 거리와 순서가 생긴다. 실무에서는 이런 범주형 특징을 원-핫 인코딩(학과마다 0/1 칸을 따로 두는 방식)으로 바꿔 그 문제를 없앤다.

4.3

분류 규칙과 확률 분포 기반 분류로지스틱 1부 7~9p · 구분선 · 사후 확률 · 베이즈 규칙

교안 슬라이드 모아보기 1부 7 · 8 · 9p (3장)

개념 정리

교안구분선은 하나로 정해지지 않는다

‘정수론’ 수강 여부 예제에서 인공지능학과 3명 [1\;2.2],[1\;3.8],[1\;3.9] 은 미수강(0), 수학과 3명 [3\;2.2],[3\;4.0],[3\;3.2] 는 수강(1)이다. 이 여섯 점을 가르는 선은 하나가 아니라 여러 개가 가능하다(교안의 구분선 1, 2). 그래서 “어떤 선이 더 나은가”를 정하는 기준이 필요해진다.

교안확률로 분류하기 — 사후 확률과 베이즈 규칙

체조 동아리 회원(C_1)과 비회원(C_2)의 몸무게 분포를 안다면, 52kg인 학생은 어느 쪽일까? 이때 쓰는 것이 사후 확률 P(C_1\mid x) — x 를 관찰한 뒤 소속이 C_1 일 가능성을 나타내는 조건부 확률이다.

베이즈 규칙 (2주차 확률 복습)

P(C_1\mid x)=\frac{P(C_1,x)}{P(x)}=\frac{P(x\mid C_1)P(C_1)}{P(x\mid C_1)P(C_1)+P(x\mid C_2)P(C_2)}

분류 규칙 — P(C_1\mid x)>P(C_2\mid x) 이면 C_1. 두 확률의 합이 1이므로 이것은 P(C_1\mid x)>0.5 와 같은 조건이다. 계산에 필요한 것은 P(C_1),P(C_2),P(x\mid C_1),P(x\mid C_2) 네 가지뿐이다.

보충설명로지스틱 회귀로 가는 다리

베이즈 규칙을 쓰려면 각 클래스의 분포 P(x\mid C_k) 를 먼저 알아야 한다. 현실에서는 그 분포를 모르는 경우가 대부분이다. 그래서 로지스틱 회귀는 분포를 추정하는 대신 사후 확률 P(C_1\mid\mathbf x) 자체를 바로 모델링한다. 이것이 4.5 · 4.6에서 할 일이다.

4.4

선형 판별 함수와 선형 구분 가능성로지스틱 1부 10~15p · g(x)의 부호로 분류

교안 슬라이드 모아보기 1부 10 · 11 · 12 · 13 · 14 · 15p (6장)

① 정의와 내적

② 공간 분할과 예제

③ 예측 절차와 선형 구분 가능성

개념 정리

교안선형 판별 함수 — 값이 아니라 부호를 본다

Linear discriminant function

g(\mathbf x)=\mathbf w\cdot\mathbf x=\mathbf w^{\mathsf T}\mathbf x=w_0+w_1x_1+\cdots+w_dx_d\qquad(x_0=1)

\mathbf x 와 \mathbf w 는 둘 다 d+1 개 성분이다. 식 모양은 다중 선형 회귀와 똑같고 쓰임만 다르다 — 회귀는 값 자체가 예측이고, 판별은 부호가 예측이다.
결정 규칙: g(\mathbf x)>0 이면 C_1, 그 외에는 C_2. 학습이 정하는 것은 가중치 벡터 \mathbf w 하나뿐이다.

경계가 생기는 모양은 차원에 따라 달라진다 — 1차원이면 점, 2차원이면 선, 3차원이면 평면, 4차원 이상이면 초평면이 특징 공간을 둘로 나눈다.

교안예제로 확인 — 정수론 수강생

교안 13p g(\mathbf x)=20x_1+3x_2-36, 즉 \mathbf w=[-36\;\;20\;\;3]^{\mathsf T} (x_1 학과, x_2 학점)

①
\mathbf x_2=[1\;\;3.8]^{\mathsf T}: 20+11.4-36=-4.6<0 → 미수강
②
\mathbf x_4=[3\;\;2.2]^{\mathsf T}: 60+6.6-36=30.6>0 → 수강
③
나머지도 같은 방법으로: [1\;2.2]\to-9.4,\;[1\;3.9]\to-4.3,\;[3\;4.0]\to36,\;[3\;3.2]\to33.6 — 6명 모두 맞게 갈린다
정리 — g(\mathbf x)=0 이 경계선이고, 이 데이터는 선형 구분 가능하다. 한 클래스는 모두 g>0, 다른 클래스는 모두 g<0 이기 때문이다

쓰는 순서는 두 단계다. ① 학습 — 학습 데이터로 \mathbf w^* 를 정한다. ② 예측 — 레이블을 모르는 \mathbf x' 에 대해 g(\mathbf x') 의 부호로 클래스를 정한다.

보충설명부호만으로는 부족하다 — 다음 절로 가는 이유

g(\mathbf x)=0.1 도 C_1, g(\mathbf x)=50 도 C_1 이다. 부호만 보면 간신히 맞힌 것과 확실한 것을 구별할 수 없고, 구분선도 여러 개가 가능하다. 그래서 g(\mathbf x) 를 0~1 사이 확률로 바꿔 주는 함수가 필요하다. 그 함수가 4.5의 로지스틱 함수다.

4.5

로지스틱 함수와 오드 · 로그 오드로지스틱 1부 16 · 17p · 2부 4p

교안 슬라이드 모아보기 1부 16 · 17p · 2부 4p (3장)

개념 정리

교안로지스틱(시그모이드) 함수

정의와 미분

\sigma(x)=\frac{1}{1+e^{-x}}=\frac{e^x}{1+e^x},\qquad \frac{d}{dx}\sigma(x)=\sigma(x)\bigl(1-\sigma(x)\bigr)

① 정의역 전체(−∞~∞)를 0과 1 사이로 눌러 담고 ② 어디서나 미분 가능하며 ③ \sigma(0)=0.5 다. 미분이 자기 자신만으로 표현된다는 점이 4.6의 기울기 계산을 아주 간단하게 만든다.
활용 1 — 사건이 일어날 확률을 표현(로지스틱 회귀) · 활용 2 — 인공신경망의 활성화 함수(5주차 퍼셉트론)

교안오드(Odds)와 로그 오드(Log-odds)

\text{odds}=\frac{p}{1-p},\qquad \text{logit}(p)=\ln\frac{p}{1-p}

· 공정한 주사위에서 3의 배수가 아닌 눈이 나올 확률은 p=2/3 → 오드는 \frac{2/3}{1/3}=2. “일어날 가능성이 안 일어날 가능성의 2배”라는 뜻이다
· p=0.5 면 오드 1, 로그 오드 0 · 로그 오드의 정의역은 확률 (0, 1), 치역은 실수 전체다

왜 로그 오드인가 — 확률은 0~1에 갇혀 있어 선형식 \mathbf w^{\mathsf T}\mathbf x(−∞~∞)로 바로 근사할 수 없다. 로그 오드는 치역이 실수 전체라서 선형 함수로 근사하기에 딱 맞다. 그래서 로지스틱 회귀는 “로그 오드를 선형 함수로 표현”한다.

보충설명로짓 변환이란 — 확률 축을 실수 축으로 펴는 일

로짓 변환은 확률 p 를 \ln\frac{p}{1-p} 로 바꾸는 것이다. 0과 1 사이에 눌려 있던 값이 −∞부터 ∞까지 쭉 펴진다. p=0.5 가 0, p 가 1에 가까우면 +∞, 0에 가까우면 −∞로 간다.

  • 시그모이드와 정확히 반대다 — 로짓은 확률 → 실수, 시그모이드는 실수 → 확률. 즉 \text{logit}(\sigma(z))=z 로 서로 역함수다
  • 왜 하필 로그를 씌우나 — 오드만 쓰면 범위가 (0,\infty) 라 음수 쪽이 비어 있고, 1을 기준으로 위아래가 비대칭이다(2배는 2, 절반은 0.5). 로그를 씌우면 0을 기준으로 대칭이 되고(+0.69와 −0.69) 음수까지 쓸 수 있다

보충설명오드비(Odds ratio)와 해석하는 법

오드비는 두 상황의 오드를 나눈 값이다 — \text{OR}=\dfrac{\text{odds}_A}{\text{odds}_B}. “A 쪽이 B 쪽보다 그 일이 일어날 오드가 몇 배인가”를 하나의 숫자로 말해 준다.

구해 보고 해석까지 흡연자는 60%, 비흡연자는 20%가 어떤 증상을 보인다면?

①
흡연자 오드 =\dfrac{0.6}{0.4}=1.5 · 비흡연자 오드 =\dfrac{0.2}{0.8}=0.25
②
오드비 =\dfrac{1.5}{0.25}=6
해석 — “흡연자에서 증상이 나타날 오드가 비흡연자의 6배”다. 확률이 6배라는 뜻이 아니다(실제 확률은 3배). \text{OR}=1 이면 차이 없음, >1 이면 그쪽에서 더 잘 일어남, <1 이면 덜 일어남으로 읽는다

로지스틱 회귀 계수가 바로 오드비다 — \ln(\text{odds})=w_0+w_1x 에서 x 가 1 늘면 로그 오드가 w_1 만큼 커지므로, 오드는 e^{w_1} 배가 된다. 예를 들어 w_1=0.7 이면 e^{0.7}\approx2 — “그 특징이 1 늘 때마다 오드가 약 2배”. 이래서 의학 · 사회과학 논문이 로지스틱 회귀 결과를 오드비 표로 싣는다.

보충설명헷갈리는 기호 — σ · Σ · Π

\sigma(\cdot) 소문자 시그마로지스틱(시그모이드) 함수. \sigma(z)=\frac1{1+e^{-z}} — 실수를 확률로 바꾼다. (통계에서 표준편차 기호로도 쓰이니 문맥으로 구분)
\sum_{i=1}^{N} 대문자 시그마합. \sum_{i=1}^{N}a_i=a_1+a_2+\cdots+a_N — “i를 1부터 N까지 바꿔 가며 전부 더해라”. 손실함수와 기울기의 \frac1N\sum 은 데이터 N개에 대한 평균이라는 뜻
\prod_{i=1}^{N} 대문자 파이곱. 우도가 “각 데이터 확률의 곱”이라 4.6에서 등장한다. 로그를 씌우면 \ln\prod=\sum\ln 으로 곱이 합으로 바뀐다

개념 정리

교안모델 유도 — 로그 오드를 선형으로 놓으면 시그모이드가 나온다

이진 분류에는 두 갈래가 있다. 접근법 1은 두 클래스를 구분하도록 특징 공간을 자르는 것(4.4), 접근법 2는 P(C_1\mid\mathbf x) 와 P(C_2\mid\mathbf x) 를 비교해 레이블을 정하는 것이다. 로지스틱 회귀는 접근법 2를 쓰되, 그 확률을 직접 만들어 낸다.

교안 6p 전개 \ln\dfrac{P(C_1\mid\mathbf x)}{1-P(C_1\mid\mathbf x)}=\mathbf w^{\mathsf T}\mathbf x 를 P(C_1\mid\mathbf x) 에 대해 풀면?

①
양변에 지수를 취한다: \dfrac{P}{1-P}=e^{\mathbf w^{\mathsf T}\mathbf x}
②
정리하면 P(1+e^{\mathbf w^{\mathsf T}\mathbf x})=e^{\mathbf w^{\mathsf T}\mathbf x}
③
P(C_1\mid\mathbf x)=\dfrac{e^{\mathbf w^{\mathsf T}\mathbf x}}{1+e^{\mathbf w^{\mathsf T}\mathbf x}}=\dfrac{1}{1+e^{-\mathbf w^{\mathsf T}\mathbf x}}=\sigma(\mathbf w^{\mathsf T}\mathbf x)
결과 — P(C_1\mid\mathbf x)=\sigma(\mathbf w^{\mathsf T}\mathbf x),\quad P(C_2\mid\mathbf x)=1-\sigma(\mathbf w^{\mathsf T}\mathbf x). 4.4의 선형 판별 \mathbf w^{\mathsf T}\mathbf x 가 그대로 확률이 된 셈이다

플립러닝“로지스틱 회귀에서는 로그 오드를 선형 함수로 표현한다”

이 한 문장이 모델 전체다. 확률을 바로 선형식으로 쓰려 하면 0~1을 벗어나 버리니까, 확률 → 로그 오드로 한 번 바꿔서 선형식과 크기를 맞춘 것이다. 그리고 그 식을 확률로 되돌리면 자동으로 시그모이드가 튀어나온다.

정리하면 로그 오드 = \mathbf w^{\mathsf T}\mathbf x ⟺ 확률 = \sigma(\mathbf w^{\mathsf T}\mathbf x) 로, 같은 말을 두 방향으로 쓴 것뿐이다.

교안베르누이 분포로 레이블 확률을 한 줄에

베르누이 분포 → 레이블의 조건부 확률

P(X=x)=p^{x}(1-p)^{1-x},\;x\in\{0,1\}\qquad\Longrightarrow\qquad P(y_i\mid\mathbf x_i)=\sigma(\mathbf w^{\mathsf T}\mathbf x_i)^{y_i}\bigl(1-\sigma(\mathbf w^{\mathsf T}\mathbf x_i)\bigr)^{1-y_i}

지수 트릭 — y_i=1 이면 뒤 항이 (\cdot)^0=1 이 되어 \sigma(\cdot) 만 남고, y_i=0 이면 앞 항이 사라져 1-\sigma(\cdot) 만 남는다. 두 경우를 if문 없이 한 식으로 쓴 것이다.

보충설명베르누이 분포는 어떤 상황에서 쓰나

결과가 두 가지뿐인 시행을 한 번 했을 때의 분포다. 앞/뒤(동전), 합격/불합격, 클릭/비클릭, 스팸/정상, 구매/비구매 — 예 · 아니오로 답이 갈리는 모든 관측이 여기에 해당한다. 값이 1일 확률 p 하나로 분포가 완전히 정해진다.

  • 이진 분류와 맞닿는 지점 — 개체 \mathbf x_i 의 정답 y_i 를 “성공 확률이 \sigma(\mathbf w^{\mathsf T}\mathbf x_i) 인 베르누이 시행의 결과”로 본다. 개체마다 확률 p 가 다른 베르누이라는 점이 핵심이다
  • 이항 분포와의 관계 — 같은 베르누이 시행을 n 번 독립으로 반복해 성공 횟수를 세면 이항 분포가 된다. 베르누이는 그 n=1 짜리다
  • 이 가정 덕분에 뒤의 우도가 곱으로 쓰이고, 로그를 씌우면 크로스 엔트로피가 나온다

교안우도(Likelihood)와 음의 로그 우도

학습 데이터 전체의 우도 (단순 로지스틱 — x_i 가 실수 하나인 경우)

\ell(w_0,w_1)=\prod_{i=1}^{N}P(y_i\mid x_i)=\prod_{i=1}^{N}\sigma(w_0+w_1x_i)^{y_i}\bigl(1-\sigma(w_0+w_1x_i)\bigr)^{1-y_i}

P(y_i\mid x_i) 는 “지금의 w_0,w_1 로 계산한 확률로 x_i 의 클래스를 정확히 맞힐 확률”이다. 우도는 그것들을 전부 곱한 값이다.

플립러닝클수록 좋은 것과 작을수록 좋은 것

  • 우도는 각 조건부 확률의 곱이므로, 값이 클수록 데이터를 잘 설명하는 모델이다 → 선호
  • Negative log likelihood -\ln\ell(w_0,w_1) 는 우도 로그값의 음수이므로, 작을수록 좋다 → 선호
  • 즉 우도의 최대화와 NLL의 최소화는 완전히 같은 말이고, 그렇게 되는 w_0,w_1 을 찾아 가는 것이 모델 학습의 목표다

보충설명왜 곱을 그대로 두지 않고 로그를 씌우나

0~1 사이 확률을 수백 번 곱하면 값이 0에 가깝게 뭉개져 컴퓨터가 구분하지 못한다(언더플로). 로그를 취하면 곱이 합으로 바뀌어(\ln\prod=\sum\ln) 계산이 안정되고 미분도 훨씬 쉬워진다. 로그는 증가함수라서 최대가 되는 위치는 바뀌지 않는다 — 그래서 마음 놓고 씌울 수 있다.

교안손실함수 — 평균 NLL이 곧 크로스 엔트로피

손실함수 L=-\frac1N\ln\ell (교안 9p)

L(w_0,w_1)=-\frac1N\sum_{i=1}^{N}\Bigl\{y_i\ln\sigma(w_0+w_1x_i)+(1-y_i)\ln\bigl(1-\sigma(w_0+w_1x_i)\bigr)\Bigr\}

관측값이 N 개이므로 NLL을 N 으로 나눠 한 개당 평균으로 쓴다. 곱이 로그를 만나 합이 되었고, 지수 y_i 는 앞으로 내려와 곱셈이 되었다.

바이너리 크로스 엔트로피 (교안 12p)

CE(y_i,\hat y_i)=-y_i\ln P(C_1\mid\mathbf x_i)-(1-y_i)\ln\bigl(1-P(C_1\mid\mathbf x_i)\bigr),\qquad \mathbf w^*=\underset{\mathbf w}{\operatorname{argmin}}\frac1N\sum_{i=1}^{N}CE(y_i,\hat y_i)

위 손실함수를 데이터 한 개 단위로 쓴 것이 CE이고, 그 평균이 곧 L(\mathbf w)=-\frac1N\ln\ell(\mathbf w) 다. 이름이 바이너리인 것은 정답이 0 아니면 1인 이진 분류용이기 때문이다.

보충설명argmin이 무슨 뜻인가 — 값이 아니라 ‘자리’

\min_{\mathbf w}L(\mathbf w) 는 손실의 가장 작은 값이고, \operatorname*{argmin}_{\mathbf w}L(\mathbf w) 는 그 값을 만드는 \mathbf w 자체다. 산에서 가장 낮은 지점의 높이가 min이라면, 그 지점의 좌표가 argmin이다.

  • 왜 쓰나 — 우리가 원하는 것은 손실 수치가 아니라 그 손실을 내는 가중치다. 그래서 학습 목표를 \mathbf w^*=\operatorname*{argmin}_{\mathbf w}L(\mathbf w) 한 줄로 적는다
  • 언제 나오나 — 목표를 정의할 때 쓰고, 실제로 그 자리를 찾아가는 방법이 경사하강법이다. 식은 목표, 경사하강법은 수단이다
  • argmax와의 관계 — 우도는 최대화이므로 \mathbf w^*=\operatorname*{argmax}\ell(\mathbf w)=\operatorname*{argmin}\bigl(-\ln\ell(\mathbf w)\bigr). 부호만 뒤집으면 서로 오간다

보충설명편미분이 무엇이고, 왜 · 언제 쓰나

편미분은 변수가 여러 개인 함수에서 나머지는 상수로 붙잡아 두고 한 변수로만 미분하는 것이다. 기호는 \partial(라운드 디)를 쓴다. 뜻은 “그 변수만 아주 조금 늘렸을 때 함수값이 얼마나 변하는가”, 즉 그 방향의 기울기다.

  • 왜 하나 — 손실 L(w_0,w_1,\dots) 은 여러 인자에 동시에 달려 있다. 각 인자를 어느 쪽으로 얼마나 움직여야 손실이 줄어드는지 알려면 인자별로 따로 봐야 한다
  • 언제 쓰나 — 경사하강법의 매 걸음마다. 편미분을 모두 모아 벡터로 쓴 것이 그래디언트 \nabla L=\bigl[\frac{\partial L}{\partial w_0},\dots,\frac{\partial L}{\partial w_d}\bigr]^{\mathsf T} 이고, 그 반대 방향이 손실이 가장 빨리 줄어드는 쪽이다
  • 연습 — f(w_0,w_1)=w_0^2+3w_0w_1 이면 \frac{\partial f}{\partial w_0}=2w_0+3w_1(w_1 은 상수 취급), \frac{\partial f}{\partial w_1}=3w_0

교안외워 둘 수식꼴 — 편미분 결과와 갱신식

교안 10p — 단순 로지스틱의 편미분과 갱신

\frac{\partial L}{\partial w_0}=-\frac1N\sum_{i=1}^{N}\bigl\{y_i-\sigma(w_0+w_1x_i)\bigr\},\qquad \frac{\partial L}{\partial w_1}=-\frac1N\sum_{i=1}^{N}x_i\bigl(y_i-\sigma(w_0+w_1x_i)\bigr)
w_0\leftarrow w_0-\alpha\frac{\partial L}{\partial w_0},\qquad w_1\leftarrow w_1-\alpha\frac{\partial L}{\partial w_1}

모양을 외우는 요령 — 괄호 안은 언제나 (정답 − 예측), 그 앞에 붙는 것은 그 인자에 곱해져 있던 입력이다. w_0 의 입력은 1이라 아무것도 안 붙고, w_1 의 입력은 x_i 라 x_i 가 붙는다. 전체 앞에 -\frac1N.

교안 13p — 일반형 (특징이 여러 개일 때)

\frac{\partial}{\partial w_k}\frac1N\sum_{i=1}^{N}CE(y_i,\hat y_i)=-\frac1N\sum_{i=1}^{N}\bigl(y_i-\sigma(\mathbf w^{\mathsf T}\mathbf x_i)\bigr)x_{ik},\qquad x_{i0}=1

x_{ik} 는 i 번째 개체의 k 번째 성분이다. 위의 두 식이 이 한 줄에 모두 들어 있다 — k=0 이면 x_{i0}=1 이므로 첫 번째 식이 된다.

보충설명왜 저런 모양이 나오는가 — 한 줄씩 유도

연쇄법칙 한 데이터의 CE를 w_k 로 미분하면 왜 -(y_i-\sigma)x_{ik} 인가? (z=\mathbf w^{\mathsf T}\mathbf x_i,\;\sigma=\sigma(z))

①
\dfrac{\partial CE}{\partial\sigma}=-\dfrac{y_i}{\sigma}+\dfrac{1-y_i}{1-\sigma}=\dfrac{\sigma-y_i}{\sigma(1-\sigma)}
②
\dfrac{\partial\sigma}{\partial z}=\sigma(1-\sigma) (4.5의 미분), \dfrac{\partial z}{\partial w_k}=x_{ik}
③
셋을 곱하면 \sigma(1-\sigma) 가 깔끔하게 약분된다: \dfrac{\partial CE}{\partial w_k}=(\sigma-y_i)\,x_{ik}=-(y_i-\sigma)\,x_{ik}
왜 중요한가 — 시그모이드와 크로스 엔트로피를 짝지으면 기울기가 (정답 − 예측) × 입력이라는 선형 회귀와 똑같은 모양이 된다. 손실을 다른 것으로 골랐다면 이렇게 깔끔하게 약분되지 않는다

인자마다 \frac{\partial L}{\partial w_k} 를 구한다 — 그 인자를 조금 움직였을 때 손실이 어느 쪽으로 얼마나 변하는지

3

그래디언트를 얻는다

편미분을 모두 모은 것이 그래디언트다. 지금 위치에서 손실이 가장 가파르게 늘어나는 방향을 가리킨다

4

w_k 를 갱신한다 — 계속해서

그래디언트의 반대쪽으로 학습률 \alpha 만큼 이동한다. 종료조건(정해진 반복 수, 손실이 거의 안 줄어듦)까지 2~4를 반복한다

SUM

핵심 정리시험 전에 이것만은

1

분류 = 레이블 예측, 개체 = 특징 공간의 점

2클래스는 1/0으로 표기. 규칙: P(C_1\mid\mathbf x)>0.5 이면 C_1 → 4.1 4.2 4.3

2

선형 판별 g(\mathbf x)=\mathbf w^{\mathsf T}\mathbf x

부호로 분류, g=0 이 경계(점·선·평면·초평면). 정확히 갈리면 선형 구분 가능 → 4.4

3

로그 오드를 선형으로

\ln\frac{P}{1-P}=\mathbf w^{\mathsf T}\mathbf x\iff P(C_1\mid\mathbf x)=\sigma(\mathbf w^{\mathsf T}\mathbf x), \sigma'=\sigma(1-\sigma) → 4.5

4

학습 = 우도 최대화 = CE 최소화

베르누이 \sigma^{y}(1-\sigma)^{1-y} → 우도 곱 → -\frac1N\ln\ell = 평균 CE → 기울기 -\frac1N\sum(y_i-\sigma)x_{ik} → w_k\leftarrow w_k+\frac{\alpha}{N}\sum(y_i-\sigma)x_{ik} → 4.6

dataset = pd.read_csv('Social_Network_Ads.csv')
X = dataset.iloc[:, [2, 3]].values        # Age, EstimatedSalary — 대괄호 안에 열 번호 목록
y = dataset.iloc[:, 4].values             # Purchased

from sklearn.preprocessing import StandardScaler
sc = StandardScaler()
X = sc.fit_transform(X)                   # 나이(수십)와 급여(수만)의 단위 차이를 없앤다

X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.25, random_state=1)

from sklearn.linear_model import LogisticRegression
classifier = LogisticRegression()
classifier.fit(X_train, y_train)          # 판별함수·시그모이드·손실·경사하강 전부 fit() 하나로
print(classifier.coef_)                   # [[w1, w2]] — Age, Salary의 가중치
print(classifier.intercept_)              # [w0]

y_pred = classifier.predict(X_test)       # 확률이 0.5 넘으면 1 — 손실·갱신 없이 예측만
print(sklearn.metrics.accuracy_score(y_test, y_pred))
print(sklearn.metrics.f1_score(y_test, y_pred))
스케일링 순서 — 노트북이 직접 짚은 함정
정석은 분할 먼저, 그다음 X_train = sc.fit_transform(X_train) · X_test = sc.transform(X_test)다. fit_transform은 훈련 데이터의 평균·분산을 구해 변환하고, transform은 그 값을 테스트에 그대로 적용한다 — 두 데이터에 같은 기준을 써야 하기 때문. 그런데 실습 코드는 편의상 분할 전에 전체 X에 fit_transform을 했다. 이러면 테스트 데이터의 통계가 학습에 섞이는 데이터 누수가 생긴다(개정판 3주차에서 본 Pipeline 이야기와 같은 문제). 노트북 주석도 “비교하려면 split을 먼저 실행한 후 StandardScaler를 실행해야 한다”고 적어 두었다.
분류 성능 지표 — Positive(1)/Negative(0) 이진 분류 기준
  • Accuracy — 테스트 데이터에서 레이블을 정확히 맞힌 비율
  • Precision — 모델이 Positive라고 한 것 중 실제 Positive 비율 (“산다고 예측한 사람 중 진짜 산 사람”)
  • Recall — 실제 Positive 중 모델이 Positive라고 맞힌 비율 (“실제 구매자 중 놓치지 않은 비율”)
  • F1 score — 2\cdot\frac{\text{Precision}\cdot\text{Recall}}{\text{Precision}+\text{Recall}}. 클래스 비율이 한쪽으로 쏠렸을 때 정확도만 보면 속기 쉬워 함께 본다

실습 ② — NumPy로 직접 구현sigmoid · loss · gradients · train · predict

먼저 알아 둘 NumPy 함수
  • np.mean(x) — 평균 · np.exp(x) — e^x · np.log(x) — 자연로그 ln(밑이 e). 셋 다 리스트를 받으면 원소마다 계산
  • np.dot — 벡터·벡터면 내적, 행렬·벡터면 행렬곱. 노트북 예: np.dot([2,3,4], [1,2,3]) = 20, np.dot(x2.T, w)는 (2,3)×(3,) → (2,)
def sigmoid(x):
    return 1.0 / (1 + np.exp(-x))

def loss(y, y_hat):                                   # y_hat = σ(Xw) = P(C1|x)
    loss = np.mean(y*np.log(y_hat) + (1-y)*np.log(1-y_hat))
    return -loss                                      # 평균 바이너리 크로스 엔트로피

def gradients(X, y, y_hat):
    dw = np.dot(X.T, (y - y_hat))                     # Σ (y_i − ŷ_i) x_ik 를 행렬곱 한 번으로
    return dw

def train(X_train, y_train, bs, epochs, lr):
    m, n = X_train.shape                              # m = 300(데이터 수), n = 2(특징 수)
    w = np.zeros((n, 1))                              # 가중치 0으로 초기화, 모양 (2,1)
    y_train = y_train.reshape(m, 1)                   # (300,) → (300,1) 로 맞춤
    for epoch in range(epochs):
        for i in range((m-1)//bs + 1):                # 미니배치 개수 (// = 몫)
            xb = X_train[i*bs : i*bs+bs]              # i번째 묶음
            yb = y_train[i*bs : i*bs+bs]
            y_hat = sigmoid(np.dot(xb, w))            # 예측 확률
            dw = gradients(xb, yb, y_hat)
            w += lr * dw                              # w ← w + α Σ(y−ŷ)x
        ...                                           # 에폭마다 loss·정확도 기록, 10에폭마다 출력
    return w, losses, train_acc, test_acc

def predict(X, w):
    preds = sigmoid(np.dot(X, w))
    return np.array([1 if p > 0.5 else 0 for p in preds])   # 사후 확률 0.5 기준 결정 규칙

w, l, train_acc, test_acc = train(X_train, y_train, bs=100, epochs=100, lr=0.1/len(X_train))

코드 속 질문 풀이

①
(m-1)//bs + 1 은? — //는 몫. m=300, bs=100이면 299//100+1 = 3 → 한 에폭에 100개씩 3번 갱신. m이 bs로 나눠떨어지지 않아도 마지막 자투리 묶음까지 포함되게 하는 계산이다
②
행렬 모양 — xb (100,2), w (2,1) → np.dot(xb, w) (100,1). gradients에서 X.T (2,100) × (y−ŷ) (100,1) = (2,1) — 교안의 Σ 합이 행렬곱 한 번으로 표현됐다
③
lr = 0.1/len(X_train) 인 이유 — gradients가 평균이 아니라 합을 돌려주므로, 학습률에 \frac1N 을 미리 넣어 교안의 \frac{\alpha}{N}\sum 과 맞춘 것
④
loss 함수는 갱신에 안 쓰인다? — 맞다. 노트북도 “loss는 BCE 평균을 계산해 줄어드는 것을 보여주기 위한 것이고, 갱신은 log likelihood 기울기로 하는 다소 복잡한 구현”이라고 밝힌다. 두 식은 부호만 반대인 같은 양이라 결과는 일관된다
바이어스가 없다 (보충) — 이 직접 구현의 w는 (2,1)로 Age·Salary 가중치만 있고 w_0(절편)이 없다. 표준화로 평균이 0이 된 데이터라 어느 정도 동작하지만, 경계가 원점을 지나야 한다는 제약이 생긴다. X 앞에 1로 된 열을 붙이면(np.c_[np.ones(m), X]) 교안의 x_{i0}=1 표기와 같아진다
