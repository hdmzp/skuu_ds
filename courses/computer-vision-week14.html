  • 생성 모델의 목표: p_{model}(x)\approx p_{data}(x)를 배우고 거기서 새 x를 뽑는다. 밀도를 명시적으로(PixelCNN · VAE · 확산) 또는 암묵적으로(GAN)

  • 오토인코더: X → 인코더 → 작은 Z → 디코더 → X̂, 재구성 손실. 그런데 Z 공간을 몰라 생성은 못 한다
  • VAE: z를 확률 분포로 · q_\phi(z|x)로 사후 분포 근사 · ELBO = 재구성 − KL 최대화 · 재매개변수화 트릭. 잠재 공간이 해석 가능 / 흐릿한 샘플
  • GAN: 밀도를 포기하고 노이즈 → 영상 변환만 배운다. 판별자(진짜/가짜)와 생성자의 minimax 게임. DCGAN · CGAN · CycleGAN · StyleGAN · SRGAN
  • 확산 모델: 전방(가우시안 노이즈를 T단계 추가, 고정 마르코프 연쇄) → 역방(신경망이 노이즈 \epsilon을 예측해 단계별 제거). 품질 최고 · Stable Diffusion · DALL-E 2 · Imagen

생성 모델 — 개요교안 3~7p

개념 정리

교안지도 vs 비지도, 판별 vs 생성 (4 · 5p)

내용
지도 학습사람 ‘선생님’이 문제와 답을 짝지은 레이블 데이터를 준다
비지도 학습레이블도 지시도 없이, 컴퓨터가 데이터의 바탕 구조 · 패턴을 스스로 찾는다
판별 모델대부분 지도 학습에 쓴다. 확률 추정 · 최대 가능도로 데이터를 클래스로 나누는 경계를 배운다 — p(y|x)
생성 모델이름대로 새 데이터 점을 만들 수 있다. 보통 비지도 문제에 쓴다 — p(x)

교안생성 모델링의 목표와 분류 체계 (6 · 7p)

학습 데이터가 주어지면, 같은 분포에서 새 표본을 생성한다. 목표는 두 가지다 — ① p_{data}(x)를 근사하는 p_{model}(x)를 배운다 ② p_{model}(x)에서 새 x를 뽑는다. 이것을 밀도 추정 문제로 세운다.

  • 명시적 밀도 추정 — p_{model}(x)를 명시적으로 정의하고 푼다
  • 암묵적 밀도 추정 — 명시적으로 정의하지 않고, p_{model}(x)에서 표본을 뽑을 수 있는 모델만 배운다
갈래 (7p)모델
명시적 밀도계산 가능한(tractable) 밀도Fully Visible Belief Net · PixelRNN / PixelCNN
근사 밀도 — 변분VAE
근사 밀도 — 확산DDPM · LDM · SD

02

PixelCNN — 픽셀을 하나씩 조건부로교안 8~11p · CVPR 2016

교안 슬라이드 모아보기 9p · 10p · 11p

개념 정리

교안자기회귀 모델과 마스크 합성곱 (9 · 10p)

PixelCNN의 목적은 픽셀 분포 p(x)를 모델링하는 것이다(x=(x_0,\dots,x_n)은 영상의 픽셀 값 벡터). 이를 위해 자기회귀 모델을 쓴다 — 결합 분포에 평범한 연쇄 법칙을 적용한다.

p(\mathbf x)=p(x_0)\prod_{i=1}^{n}p(x_i\,|\,x_{<i}),\qquad p(x_{i,R}|x_{<i})\,p(x_{i,G}|x_{<i},x_{i,R})\,p(x_{i,B}|x_{<i},x_{i,R},x_{i,G})

왼쪽 위부터 래스터 순서로, 앞서 생성된 픽셀들(context)을 조건으로 다음 픽셀의 256단계 분포를 예측한다. 한 픽셀 안에서도 R → G → B 순서다.

  • RNN 대신 합성곱 층을 쌓는다 — 이미 생성된 근처 픽셀로 목표 픽셀을 생성한다
  • 합성곱은 병렬화가 쉬워 PixelRNN보다 학습이 훨씬 빠르다
  • 마스크 A — 앞서 생성된 픽셀(context)과 목표 픽셀에서 이미 생성된 채널에만 의존한다. 맨 첫 층에 쓴다(자기 자신을 보면 안 되므로)
  • 마스크 B — 마스크 A에서 같은 채널로의 연결을 허용하도록 완화한 것. 둘째 층부터 쓴다

교안장단점 (11p)

장점

가능도 p(x)를 명시적으로 계산할 수 있다 · 최적화가 쉽다(그냥 픽셀별 분류의 교차 엔트로피)

단점

순차 생성이라 느리다 — 32×32×3 영상이면 3,072번 차례로 예측해야 한다

03

오토인코더 — 줄였다가 되살린다교안 12~19p

교안 슬라이드 모아보기 13p · 14p · 15p · 16p · 17p · 18p · 19p

개념 정리

교안왜 잠재 변수인가 · 차원 축소 (13 · 14p)

PixelRNN/CNN은 계산 가능한 밀도를 정의하고 학습 데이터의 가능도를 최적화한다. VAE는 잠재 변수 z를 둔 계산 불가능한 밀도 p_\theta(x)=\int p_\theta(z)p_\theta(x|z)dz를 정의한다 — 픽셀 사이에 의존성이 없어 모든 픽셀을 동시에 생성할 수 있지만, 직접 최적화할 수 없어 가능도의 하한을 유도해 최적화한다.

14p — 가장 중요한 특징을 찾는 차원 축소. MNIST 데이터를 2D 다양체로 펼치면 엉킨 다양체가 숫자별로 풀린다(스위스 롤 예). 선형(PCA · LDA)과 비선형(오토인코더 · t-SNE · Isomap · LLE)으로 나뉜다.

교안오토인코더의 구조와 손실 (15 · 16p)

레이블 없는 학습 데이터에서 저차원 특징 표현을 배우는 비지도 방법이다. 재구성 손실로 학습한다 — 특징이 원래 데이터(입력 자기 자신)를 재구성하도록 훈련된다. 입력은 무엇이든 될 수 있다(데이터에 대한 가정이 없다). Z는 보통 X보다 작다 — 데이터 변이의 의미 있는 요인을 잡게 하려고.

L=\sum_{X\in D}\lVert X-g(h(X))\rVert^2=\lVert X-\hat X\rVert^2

인코더 h(X): 임베딩 · 다양체 학습 · 특징 추출. 지도 모델의 초기화에 쓸 수 있다. 디코더 g(Z): 학습이 끝나면 더 쓰지 않는다. 손실은 L2(소프트맥스 등도 가능).

교안변형 · 응용 · 한계 (17~19p)

변형 — 기본 오토인코더, 입력에 무작위 노이즈 · 드롭아웃을 넣고 깨끗한 원본을 복원하게 하는 잡음 제거(denoising) 오토인코더, 여러 겹 쌓은 적층(stacked) 오토인코더. 응용 — 이상 탐지 · 영상 채색 · 영상 잡음 제거.

한계(19p) — 오토인코더는 데이터를 재구성하고, 지도 모델 초기화용 특징을 배울 수 있으며, 그 특징은 학습 데이터의 변이 요인을 잡는다. 하지만 Z의 공간을 모르기 때문에 새 영상을 생성할 수는 없다. 오토인코더를 생성 모델로 만들 수 있을까? → VAE.

보충설명‘Z 공간을 모른다’는 말의 뜻 · 이상 탐지 원리

학습된 오토인코더의 Z들은 공간 여기저기 불규칙하게 흩어져 있고 사이사이에 빈 곳이 많다. 아무 Z나 골라 디코더에 넣으면 그 Z가 학습 때 본 적 없는 빈 곳일 가능성이 커서 의미 없는 영상이 나온다. VAE는 Z가 표준 정규 분포 근처에 모이도록 KL 항으로 강제해, N(0,I)에서 뽑기만 하면 되게 만든다.

이상 탐지: 정상 데이터로만 학습하면 정상은 잘 재구성되고, 본 적 없는 이상 데이터는 재구성 오차 \lVert X-\hat X\rVert^2가 크다. 오차가 임곗값을 넘으면 이상으로 판정한다(공장 불량 · 의료 영상).

04

변분 오토인코더 VAE — 잠재 공간을 확률로교안 20~26p · ICLR 2014

교안 슬라이드 모아보기 20p · 21p · 22p · 23p · 24p · 25p · 26p

개념 정리

교안오토인코더에 확률을 입히기 (20 · 21p)

오토인코더에 확률적 해석을 더해 모델에서 표본을 뽑아 데이터를 생성하게 한다. 학습 데이터가 관측되지 않은(잠재) 표현 z의 분포에서 생성되었다고 가정한다 — x는 영상, z는 x를 만드는 잠재 요인(속성 · 방향 등)이다. VAE는 잠재 속성을 확률로 기술하고, 학습 데이터 x가 주어졌을 때 생성 모델의 진짜 모수 \theta^*를 추정한다 — 학습 데이터의 가능도를 최대화하도록 모수를 배운다.

교안근사 사후 분포와 재매개변수화 트릭 (22p)

데이터 가능도 p_\theta(x)=\int p_\theta(z)p_\theta(x|z)dz는 모든 z에 대해 p(x|z)를 계산해야 해서 계산할 수 없다. 해법: p_\theta(x|z)와 함께, 진짜 사후 분포 p_\theta(z|x)를 근사하는 q_\phi(z|x)(인코더)를 배운다. 이 근사 사후 분포 덕분에 계산 가능한 가능도 하한을 유도해 최적화할 수 있다. 변분 추론은 관측 데이터 X만으로 모르는 사후 분포를 근사하는 것이다.

인코더 q_\phi(z|x)평균 \mu_{z|x}와 공분산 \Sigma_{z|x}를 출력
재매개변수화 트릭\epsilon\sim N(0,I)를 뽑아 z=\mu+\Sigma^{1/2}\epsilon
디코더 g_\theta(z)z에서 영상 \hat x 생성
교안 22p 표기 오타 — 그림의 노이즈 분포가 N(1,0)으로 적혀 있지만 표준 정규 분포 N(0,1)(평균 0, 분산 1)이어야 한다. 분산이 0이면 노이즈가 아니다. 또 본문 첫 줄의 q_\theta(Z|X)는 그림 · 다음 쪽 표기대로 q_\phi(Z|X)(인코더 모수는 φ)다.

교안ELBO 유도 (23p)

\begin{aligned}\log p_\theta(x^{(i)})&=\mathbf E_{z\sim q_\phi(z|x^{(i)})}\big[\log p_\theta(x^{(i)})\big]\qquad(\text{z와 무관})\\&=\mathbf E_z\Big[\log\frac{p_\theta(x^{(i)}|z)p_\theta(z)}{p_\theta(z|x^{(i)})}\cdot\frac{q_\phi(z|x^{(i)})}{q_\phi(z|x^{(i)})}\Big]\qquad(\text{베이즈 규칙 , 1 곱하기})\\&=\underbrace{\mathbf E_z\big[\log p_\theta(x^{(i)}|z)\big]}_{\text{재구성 오차}}-\underbrace{D_{KL}\big(q_\phi(z|x^{(i)})\,\|\,p_\theta(z)\big)}_{\text{정규화 오차}}+\underbrace{D_{KL}\big(q_\phi(z|x^{(i)})\,\|\,p_\theta(z|x^{(i)})\big)}_{\ge0}\end{aligned}

마지막 KL 항은 계산할 수 없지만 항상 0 이상이다. 그래서 앞의 두 항 \mathcal L(x^{(i)},\theta,\phi)는 로그 가능도의 하한(ELBO, Evidence Lower BOund)이고, 이것을 최대화한다. 첫 항은 디코더가 z에서 x를 잘 되살리게(재구성), 둘째 항은 인코더 분포를 사전 분포 N(0,I)에 가깝게(정규화) 만든다.

교안학습된 잠재 공간과 장단점 (24~26p)

해석 가능한 변이 요인(24p) — MNIST에서 z_1,z_2를 바꾸면 숫자 모양이 연속적으로 변하고, 얼굴에서는 z_1이 표정(미소), z_2가 고개 방향을 맡는다. 25p는 CIFAR-10 · LFW 얼굴 생성 예다.

장점

생성 모델에 대한 원리적 접근 · 해석 가능한 잠재 공간 · q(z|x) 추론이 가능해 다른 과제의 특징 표현으로 쓸 수 있다

단점

가능도의 하한(근사)을 최대화한다 · 실제 가능도를 쓰는 PixelRNN/CNN만큼 평가가 좋지 않다 · 최신 GAN보다 샘플이 흐릿하고 품질이 낮다

보충설명재매개변수화가 왜 필요한가 · KL 항의 닫힌 식

z를 N(\mu,\sigma^2)에서 그냥 ‘뽑으면’ 뽑기 연산에는 기울기가 없어 인코더까지 역전파가 끊긴다. z=\mu+\sigma\odot\epsilon,\;\epsilon\sim N(0,I)로 쓰면 무작위성은 입력 쪽 ε로 빠지고, z는 μ · σ에 대해 미분 가능한 식이 된다.

인코더가 대각 가우시안을 내고 사전 분포가 N(0,I)이면 KL 항은 닫힌 식이다: D_{KL}=\frac12\sum_j\big(\mu_j^2+\sigma_j^2-\log\sigma_j^2-1\big). μ = 0, σ = 1이면 0이 된다 — 인코더 출력이 표준 정규 분포에서 벗어날수록 벌점이 커진다.

GAN — 판별자와 겨루며 배운다교안 27~35p · NeurIPS 2014

교안 슬라이드 모아보기 28p · 29p · 30p · 31p · 32p · 33p · 34p · 35p

개념 정리

교안밀도를 포기하고 표본만 (28 · 29p)

PixelRNN/CNN은 계산 가능한 밀도, VAE는 잠재 z를 둔 계산 불가능한 밀도(하한 최적화)를 다뤘다. 밀도를 명시적으로 모델링하는 것을 포기하고 표본을 뽑는 능력만 원한다면? — 쉽게 뽑을 수 있는 단순한 분포(무작위 노이즈)에서 뽑고, 그것을 학습 분포로 바꾸는 변환을 배운다.

그런데 어떤 z가 어떤 학습 영상으로 가야 하는지 모르므로 재구성으로 학습할 수 없다. 사람이 모든 출력을 검사할 수도 없다. 해법 — 생성한 영상이 데이터 분포 안(‘진짜’)인지 아닌지 가려내는 판별자 네트워크를 쓴다. 진짜/가짜 학습 신호에는 사람의 레이블이 필요 없다(비지도).

교안두 사람의 게임 · minimax 목적 함수 (30 · 31p)

판별자 D

진짜 영상과 가짜 영상을 가려내려 한다. 입력은 학습 데이터의 진짜 영상이거나 생성자가 만든 가짜, 출력은 입력이 진짜일 확률(시그모이드), 목적은 진짜 vs 가짜 이진 분류(교차 엔트로피)

생성자 G

진짜처럼 보이는 영상을 만들어 판별자를 통과하려 한다

\min_{\theta_g}\max_{\theta_d}\Big[\mathbb E_{x\sim p_{data}}\log D_{\theta_d}(x)+\mathbb E_{z\sim p(z)}\log\big(1-D_{\theta_d}(G_{\theta_g}(z))\big)\Big]

번갈아 푼다 — 판별자는 이 식에 대해 경사 상승(\max_{\theta_d}: 진짜에 1, 가짜에 0), 생성자는 \min_{\theta_g}\mathbb E_z\log(1-D(G(z)))로 경사 하강(판별자를 속여 D(G(z))\to1). 한쪽은 최대화, 다른 쪽은 최소화하는 minimax 게임으로 함께 학습한다.

교안DCGAN과 벡터 연산 (32~34p)

DCGAN(ICLR 2016) — 생성자는 100차원 z를 4×4×512에서 시작해 5×5 전치 합성곱(stride 2) 네 번으로 8×8×256 → 16×16×128 → 32×32×64 → 64×64×3까지 키운다. 판별자는 그 반대의 합성곱 네트워크다. 원래 GAN 논문은 대부분 완전 연결 층을 썼는데, CIFAR-10에서 전치 합성곱(G) + 합성곱(D) 조합이 훨씬 선명한 표본을 냈다(33p).

해석 가능한 벡터 연산(34p) — 왼쪽을 보는 얼굴 네 장과 오른쪽을 보는 얼굴 네 장의 z 평균 차이로 ‘돌리기(turn)’ 벡터를 만들고, 무작위 표본에 이 축을 따라 보간해 더하면 얼굴이 돌아간다. 잠재 공간에서 의미가 선형으로 정렬된다.

교안GAN의 발전 (35p)

모델특징
Vanilla GAN생성자 · 판별자 모두 다층 퍼셉트론
Conditional GAN두 네트워크에 클래스 레이블 같은 추가 정보 → 조건에 맞는 데이터 생성
DCGANCNN 사용 — 영상 데이터에 효과적, 고품질 · 고해상도
CycleGAN짝이 없는 영상 대 영상 변환(여름 풍경 → 겨울)
Text to Image GAN문장 설명으로 영상 생성 — 언어와 시각을 잇는다
StyleGAN고품질 · 사실적, 생성 영상의 스타일 제어(얼굴 특징 바꾸기)
SRGAN저해상도 → 고해상도, 세부를 잃지 않는 초해상도

보충설명최적의 판별자 · 실제로 쓰는 생성자 손실 · 모드 붕괴

G를 고정하면 최적 판별자는 D^*(x)=\frac{p_{data}(x)}{p_{data}(x)+p_g(x)}이고, 이때 목적 함수는 -\log4+2\,JSD(p_{data}\|p_g)가 된다 — 생성자는 두 분포의 젠슨-섀넌 발산을 줄이는 셈이고, p_g=p_{data}에서 D^*=0.5(구별 불가)다.

학습 초반에는 가짜가 형편없어 D(G(z))\approx0이고, 그 근처에서 \log(1-D)는 평평해 생성자 기울기가 거의 없다. 그래서 실제로는 \max_{\theta_g}\mathbb E_z\log D(G(z))(비포화 손실)로 바꿔 쓴다. 또 생성자가 판별자를 속이기 쉬운 몇 가지 영상만 반복해 만드는 모드 붕괴가 GAN의 대표적 불안정성이다 — 44p 비교에서 GAN이 ‘다양성(mode coverage)’을 놓치는 이유다.

확산 모델 — 노이즈를 단계별로 걷어 낸다교안 36~44p · DDPM, NeurIPS 2020

교안 슬라이드 모아보기 37p · 38p · 39p · 40p · 41p · 43p · 44p

개념 정리

교안한마디로 (37p)

확산 모델은 학습 데이터에 가우시안 노이즈를 더해 망가뜨리고(확산 과정), 그 노이즈 과정을 한 단계씩 거꾸로 되돌려 원래 정보를 복원하는 법을 배운다(역 · 잡음 제거 과정). 학습이 끝나면 무작위 가우시안 노이즈를 뽑아 학습한 잡음 제거 과정에 통과시켜 새 데이터를 만든다.

교안전방 확산과 역방 확산 (38 · 39p)

q(\mathbf x_t|\mathbf x_{t-1})=\mathcal N\big(\mathbf x_t;\sqrt{1-\beta_t}\,\mathbf x_{t-1},\,\beta_t\mathbf I\big),\qquad q(\mathbf x_t|\mathbf x_0)=\mathcal N\big(\mathbf x_t;\sqrt{\bar\alpha_t}\,\mathbf x_0,\,(1-\bar\alpha_t)\mathbf I\big)

전방 과정 — 입력 영상에 가우시안 노이즈를 총 T단계에 걸쳐 조금씩 더한다(조건부 가우시안). t 시점의 영상이 t+1 시점으로 가는 고정된 마르코프 연쇄로 본다. \bar\alpha_t=\prod_{s\le t}(1-\beta_s)라서 한 번에 t단계로 건너뛸 수 있다. 38p 아래는 선형 · 시그모이드 · 이차 노이즈 일정(scheduling)이다.

p_\theta(\mathbf x_{0:T})=p(\mathbf x_T)\prod_{t=1}^{T}p_\theta(\mathbf x_{t-1}|\mathbf x_t),\qquad p_\theta(\mathbf x_{t-1}|\mathbf x_t)=\mathcal N\big(\mathbf x_{t-1};\boldsymbol\mu_\theta(\mathbf x_t,t),\boldsymbol\Sigma_\theta(\mathbf x_t,t)\big)

역방 과정 — 진짜 q(\mathbf x_{t-1}|\mathbf x_t)는 계산할 수 없으므로 신경망 p_\theta로 근사한다(변분 하한 사용). 신경망의 역할은 일반적으로 t 시점 영상에 들어 있는 노이즈 전체를 예측하는 것이고, 그 예측을 실제로 더한 노이즈와 비교해 학습한다. 39p 오른쪽은 2D 스위스 롤 데이터에서 노이즈가 다시 롤 모양으로 모이는 예다.

교안잡음 제거 신경망과 손실 (40p)

L_{simple}(\theta)=\mathbb E_{t,\mathbf x_0,\boldsymbol\epsilon}\Big[\big\lVert\boldsymbol\epsilon-\boldsymbol\epsilon_\theta\big(\sqrt{\bar\alpha_t}\,\mathbf x_0+\sqrt{1-\bar\alpha_t}\,\boldsymbol\epsilon,\;t\big)\big\rVert^2\Big]

잡음 제거 신경망은 U-Net(13주차)이고, 시간 t는 시간 표현 → 완전 연결 층을 거쳐 각 층에 들어간다. 원래 손실은 정규화(KL) · 잡음 제거 과정(단계별 KL 합) · 재구성 세 항이지만, DDPM은 이를 ‘더한 노이즈 ε를 맞히는 제곱 오차’로 단순화했다. 생성은 t=T=1000의 \mathbf x_{1000}\sim N(0,I)에서 시작해 U-Net으로 노이즈를 예측하고 빼기를 반복한다.

교안활용 · 대표 모델 · 요점 (41~43p)

  • 활용 — 프롬프트(문장 · 조건)로 영상 생성 · 초해상도 · 도메인 적응과 스타일 전이 · 인페인팅(빠지거나 망가진 부분 채우기) · 아웃페인팅(테두리 밖으로 영상 확장)
  • 대표 모델 — GLIDE · Stable Diffusion · DALL-E 2 · Midjourney · Deep Dream Generator · Imagen · Firefly
  • 요점 — 단순한 시작 분포를 일련의 가역 연산으로 원하는 복잡한 분포로 바꿔 데이터가 만들어지는 과정을 흉내 낸다. 전통적 생성 모델보다 영상 품질이 좋고, 잠재 공간이 해석 가능하며, 과적합에 강하다. 텍스트 → 비디오, 영상 → 영상 변환, 영상 검색 등에 쓰인다

교안네 생성 모델 한눈에 (44p)

모델학습 방식세 가지 바람 중
자기회귀 (PixelCNN)앞의 변수가 주어졌을 때 각 변수의 조건부 분포를 배운다—
VAE변분 하한을 최대화빠른 샘플링 · 다양성 / 품질이 약하다
GAN적대적 학습고품질 · 빠른 샘플링 / 다양성이 약하다
확산 모델가우시안 노이즈를 점점 더한 뒤 거꾸로고품질 · 다양성 / 샘플링이 느리다

44p의 세 원(고품질 샘플 · 빠른 샘플링 · 다양성)은 생성 모델의 삼중고(trilemma)라 불린다 — 셋을 모두 갖춘 모델은 없다.

보충설명숫자로 보는 전방 과정 · 왜 노이즈를 예측하나

\bar\alpha_t=0.25인 시점이라면 \mathbf x_t=0.5\,\mathbf x_0+\sqrt{0.75}\,\boldsymbol\epsilon\approx0.5\,\mathbf x_0+0.87\,\boldsymbol\epsilon — 원본은 절반만, 노이즈가 더 크게 섞여 있다. t\to T이면 \bar\alpha_T\approx0이라 \mathbf x_T\approx\boldsymbol\epsilon, 순수한 노이즈다. 학습은 아무 t나 골라 이 식으로 한 번에 \mathbf x_t를 만들고, 신경망이 섞인 ε를 맞히게 하면 된다 — T단계를 다 돌 필요가 없어 학습이 단순하다.

노이즈 ε를 알면 \mathbf x_0=(\mathbf x_t-\sqrt{1-\bar\alpha_t}\,\boldsymbol\epsilon)/\sqrt{\bar\alpha_t}로 원본을 추정할 수 있으므로 ‘노이즈 예측’과 ‘원본 예측’은 같은 일이다. 다만 노이즈는 늘 표준 정규 분포라 크기가 일정해 학습이 안정적이다. 생성이 느린 것(수백~1,000단계)이 단점이라 DDIM 같은 빠른 샘플러, 잠재 공간에서 확산하는 LDM(Stable Diffusion)이 나왔다.
