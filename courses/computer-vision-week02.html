이미지 형성의 네 가지 요소Factors in image formation — 교안 3p

Geometry기하학

3D 세계의 점과 이미지에 맺힌 점 사이의 관계. 이번 주차의 주제인 카메라 모델이 바로 이 관계를 수식으로 쓴 것이다.

Radiometry복사량

표면에서 나오는 빛의 양과 이미지에 도달하는 빛의 양의 관계. 자외선·가시광선·적외선을 포함한 광학 복사의 측정.

Photometry측광

빛의 세기(intensity)를 재는 방법. 그중에서도 사람 눈이 감지할 수 있는 빛을 다룬다.

Digitization디지털화

연속 신호를 디지털 근사값으로 바꾸는 과정.

  • Geometry(기하학) — 3차원 세계에서 점과 점 간의 관계는 결국 기하학적인 위치 관계로 나타난다.
  • Radiometry(복사량) — 물체에 반사된 빛의 방향이나 양을 측정. 광학적으로 적외선·자외선까지 포함.
  • Photometry — 한마디로 빛의 강도를 재는 것.
  • Digitization — 실세계에서 접하는 것은 아날로그 신호(연속적인 변화)다. 컴퓨터가 연산할 수 있게 이산적인 디지털 값(digit)으로 바꿔 주는 과정.
01

Image Transformation필터링은 값(range)을, 워핑은 좌표(domain)를 바꾼다

Image Filteringg(x) = h( f(x) )

화소의 값을 바꾼다. 한 화소를 정하기 위해 주변 화소를 함께 본다. 블러·샤프닝·에지 검출이 여기에 속한다.

Image Warpingg(x) = f( h(x) )

화소의 위치를 바꾼다. 변환 함수 h로 좌표를 옮겨 다른 위치·다른 형태의 이미지를 만든다.

  • 이미지 필터링 — 이미지의 range를 변화시킨다. 실제로 이미지가 받아들이는 빛의 양을 조절하는 셈이며, 화소 하나를 파악하기 위해 주변을 다 파악한다.
  • Image warping — 변환 함수를 활용해 다른 형태로 바꾼다. 다른 위치, 다른 형태로의 변환.
  • 각 화소들의 기하학적인 관계를 잘 파악해서 알맞게 바꿔 주는 것 = 기하학적 변환.

기하학적 요소 — 무엇을 변환하는가

차원대상표기
2D점 (point)x = (x, y) ∈ ℝ²
직선 (line)l = (a, b, c), 점이 직선 위에 있으면 ax + by + c = 0
3D점 (point)x = (x, y, z), 동차 표현은 (x̄, ȳ, z̄, w̄)
평면 (plane)m = (a, b, c, d), ax + by + cz + d = 0
3D에서는 점이 모여 선이 되고, 선이 모여 평면이 된다. 그래서 (x, y)가 (x′, y′)로 변환될 때 p′ = T(p) — 즉 하나의 변환 매트릭스를 만드는 과정이 이번 절의 목표다.

선형 변환 — 2×2 행렬로 표현되는 것들

선형 변환(Linear transformation)은 좌표를 바꾸는 기계 p′ = T(p) 중에서 2×2 행렬 하나로 쓸 수 있는 것들이다.
① 균일 스케일링 (Uniform scaling by s)
x′y′ = s00s · xy
② 회전 행렬 (Rotation by θ, 원점 기준)
x′y′ = cos θ−sin θsin θcos θ · xy
  • 역변환은 −θ 회전이며, 회전 행렬의 역행렬 = 전치행렬 (Rᵀ = R⁻¹)
③ 그 밖의 2×2 변환
  • Mirror (Y축 대칭) — [[−1, 0], [0, 1]] · y = x 대칭 — [[0, 1], [1, 0]]
  • Shear(전단) — [[1, k], [0, 1]] 형태로 한쪽 축을 밀어 기울인다
평행이동(Translation)은 선형 연산이 아니다 — 2D 좌표만으로는 (x′, y′) = (x + tx, y + ty) 를 2×2 행렬 곱으로 쓸 수 없다. 덧셈이 따로 남기 때문이다.
  • 좌표의 평행이동은 구할 수 있지만, 엄격하게 보면 선형 연산이 아니다.
  • Composition(변환의 합성)은 곱의 형태로 표현되어야 한다 — 영상에서 아주 강력한 요소이며, 대부분의 연산은 곱의 형태가 효율적이다.
선형 변환의 성질
  • 원점은 원점으로 간다 (origin maps to origin)
  • 직선은 직선으로, 평행성은 유지된다
  • 길이의 비가 보존되고, 변환을 곱으로 합칠 수 있다 (closed under composition)
02

동차 좌표Homogeneous Coordinates — 평행이동까지 곱으로 묶는 트릭

아이디어 — 좌표를 하나 더 붙인다. Heterogeneous (x, y) → 동차 좌표 (x, y, 1). 되돌릴 때는 w로 나눈다: (x, y, w) → (x/w, y/w).
xy → 3×3 행렬 곱 → x′y′1
이렇게 하면 평행이동도 행렬 곱이 되어, 회전·스케일과 같은 방식으로 합성할 수 있다.
x′y′1 = 10tx01ty001 · xy1
  • 동차 행렬·동차 벡터 — 컴퓨터비전에서 동차는 주로 perspective(원근)에서 강력하게 쓰이고, 컴퓨터 그래픽스에서는 아주 기본적으로 활용한다.
  • 핵심 질문: 평행이동을 덧셈이 아닌 곱의 표현으로 바꾸려면? → heterogeneous coordinates를 homogeneous coordinates로 표현하면 된다.
  • 앞으로 좌표계를 쓸 때는 동차 좌표로 바꿔서, 1을 붙여 곱의 형식으로 표현하자. 그래야 다른 변환과 함께 연산할 수 있다.

본격적인 이미지 변환 4가지Rigid → Similarity → Affine → Perspective · 자유도가 커지는 순서

1-① Rigid(강체) 변환 — Translation

평행이동DoF 2

원래 영상을 이동시켜 새로운 위치에 놓는다. 모양·크기·방향은 전혀 바뀌지 않는다.

x′y′1 = 10tx01ty001 · xy1
보존 — 방향(orientation) · 길이 · 각도 · 평행성 · 직선

1-② 강체 변환 — Euclidean

이동 + 회전DoF 3

이동도 하고, θ만큼 각도 이동(회전)도 한 변환. 회전 1 + 이동 2 = 자유도 3.

x′y′1 = cos θ−sin θtxsin θcos θty001 · xy1
보존 — 길이(lengths) · 각도 · 평행성 · 직선 (방향은 회전한 만큼 달라진다)

2) 동질 변환 — Similarity(유사 변환)

이동 + 회전 + 크기DoF 4

앞선 강체 변환에 크기 변화까지 추가한다. (T, R) + S — 성질은 그대로 유지하면서 이동·회전·크기만 달라진다. 아래에서 a = s·cos θ, b = s·sin θ 이므로 매개변수는 a, b, e, f 네 개다.

x′y′1 = a−bebaf001 · xy1
보존 — 각도(angles) · 모양 · 평행성 · 직선 · 길이의 비

3) Affine 변환

Affine TransformationDoF 6

직선의 평행 관계를 유지하면서, 거리와 거리의 비는 보존되도록 변환한다. 유사 변환 + 직선/길이의 비 — 가로·세로가 서로 다르게 늘어나거나 기울어질 수 있어 매개변수가 여섯 개(a, b, c, d, e, f)다.

x′y′1 = abecdf001 · xy1
보존 — 평행성(parallelism) · 직선 · 같은 직선 위 길이의 비 (각도와 길이 자체는 변한다)
affine의 특징 — 선형 변환의 특성을 가지면서 변화하고, 여기에 덧붙이자면 앞선 선형 변환에 비해 원점과 매핑시킬 필요가 없다는 특징이 하나 더 있다. (선형 변환 + 평행이동 = 아핀 변환)

4) Perspective(투영) 변환 — 원근

= Projective = HomographyDoF 8

3D 공간을 2D 공간으로 투영할 때 주로 쓰는 변환 — 원근법을 생각하면 된다. 서로 다른 두 이미지를 합성(파노라마)할 때도 사용한다. 3×3 행렬 9개 원소 중 전체 스케일은 의미가 없어 자유도는 8이고, 대응점 4쌍이면 구할 수 있다.

x′y′1 = abecdfghi · xy1
보존 — 직선(straight lines)만 — 평행선은 소실점(vanishing point)에서 만난다
  • perspective = projective = homography 라고도 부른다.
  • 2개의 서로 다른 이미지를 합성할 때도 사용 — 모아지거나, 벌어지거나.
  • affine에 projective warps가 더해진 것. 라인은 라인으로 된다(lines map to lines). 평행도는 바뀐다(일부는 유지되겠지만). 자유도 8.

04

카메라 파라미터란 무엇인가How can we model the geometry of a camera?

카메라 모델을 안다는 것은 그 사진이 찍힐 당시의 상황을 복원할 수 있다는 뜻이다. 카메라가 어디에 어떤 자세로 있었고(외부), 어떤 렌즈와 센서로 빛을 받았는지(내부)를 알면 이미지의 한 점이 3D 공간의 어느 광선에서 왔는지 되짚을 수 있다.

Intrinsic내부 파라미터

초점거리 f · 주점(principal point) (ox, oy) · 픽셀 크기 · skew(비대칭). 카메라를 어디에 두든 변하지 않는다. 이번 주차의 대부분이 여기에 해당한다.

Extrinsic외부 파라미터

세계 좌표계에 대한 카메라의 회전 R과 이동 t. 카메라를 옮기거나 돌리면 바뀐다.

"이걸 다 모아서 카메라 행렬로 만든다"가 무슨 뜻인가
3D 점을 2D로 옮기는 과정은 실제로는 세 단계다 — ① 세계 좌표 → 카메라 좌표(위치·자세 보정) ② 카메라 좌표 → 센서 평면(초점거리로 나누는 투영) ③ 센서 평면 → 픽셀 좌표(원점 이동·픽셀 크기). 그런데 동차 좌표를 쓰면 세 단계가 모두 행렬 곱이므로, 미리 곱해서 단 하나의 3×4 행렬 카메라 행렬 P로 합쳐 둘 수 있다. 그러면 어떤 3D 점이든 x = P·X 한 번의 곱셈으로 이미지 위치가 나온다. "카메라 매트릭스로 만들어 둔다"는 말은 이 뜻이다.
  • 카메라의 모델을 알고, 이 카메라가 이미지를 획득했을 당시의 상황을 이해해야 한다 — 카메라가 상황을 어떻게 받아들였고 어떻게 처리했는지.
  • 실제 카메라 자체도 3차원에 있다. 카메라가 실제 위치에서 가져온 3차원 정보가 2차원으로 투영되는 그 복잡한 과정을 다룬다.
  • 실세계 좌표를 2차원으로 가져오기 위한 내용들 — 이를 모두 모아 camera matrix로 만들어 놓는다.
  • 외부적인 요소 extrinsic, 내부적인 요소 intrinsic 을 모두 다룬 것이 카메라 파라미터. 이 시간에 설명할 내용은 카메라의 내부 요소가 대부분.
카메라 캘리브레이션(Camera calibration) — 반대로, 사진들로부터 이 파라미터들을 역으로 구하는 작업. 좌표를 아는 물체(체스보드 등)를 여러 각도에서 찍어 K와 [R|t]를 추정한다.
05

투영(Projection)의 성질3D → 2D 로 갈 때 무엇을 잃고 무엇을 지키는가

차원 축소 기계 (3D → 2D)
잃는 것 — 각도(angles) · 거리(길이) · 깊이 정보
지키는 것 — 직선(straight lines) · 결합 관계(incidence, 점이 선 위에 있다는 사실)
투영의 속성
  • Many-to-one — 같은 광선 위의 점들은 모두 같은 이미지 점으로 간다
  • 점 → 점, 직선 → 직선 (단, 광학 중심을 지나는 직선은 한 점으로 투영된다)
  • 평면 → 평면, 또는 소실선을 경계로 한 반평면(half-plane)
  • 소실점(vanishing point) — 평행선은 더 이상 평행하지 않고 한 점에서 만난다. 방향마다 자기 소실점이 있다
  • 소실선(horizon line) — 같은 평면 위 여러 방향의 소실점들이 모여 만드는 직선
  • 단, 이미지 평면과 평행한 직선들은 투영 후에도 평행을 유지한다
  • 카메라의 센서에 담는 것(3차원 → 2차원)이 곧 projection, 앞서 배운 개념이다.
  • (x, y, 1) = (2x, 2y, 2) — 스케일에 대한 의미는 없다. x, y에서의 투영이라는 공통점만 남는다.
  • 소실점(vanishing point)을 중심으로 펼쳐 나가는 모습 — 평행했던 것들이 더 이상 평행하지 않다. 하지만 straight lines는 유지된다.
  • 속성 정리 — many-to-one, 점은 점으로, 라인은 라인으로, 면은 면으로 혹은 half-planes로.
  • 또 하나의 가장 중요한 특징 — 카메라의 시선들이 모이는 vanishing point, 그리고 horizon line.
"(x, y, 1) = (2x, 2y, 2), 스케일은 의미가 없다"의 뜻 — 동차 좌표의 스케일 불변성
투영식 (x, y, z) → (f·x/z, f·y/z) 에는 z로 나누는 연산이 들어 있는데, 동차 좌표로 쓰면 (f·x, f·y, z) 라고만 적어 두고 마지막에 w로 나누기만 하면 된다. 그래서 투영이 행렬 곱 하나로 표현된다.
06

핀홀 카메라 모델Pinhole camera model — 가장 단순한 카메라

1

문제 — 그냥 필름만 두면 흐려진다

물체의 한 점에서 나온 빛은 사방으로 방사되므로 필름 여러 곳에 동시에 닿는다. 모든 점의 빛이 겹쳐 아무 상도 맺히지 않는다.

2

해결 — barrier(장벽)를 세운다

대부분의 빛은 장벽에서 차단되고, 구멍을 지나는 하나의 광선만 필름에 도달한다. 물체의 한 점 ↔ 필름의 한 점이 대응되어 상이 맺힌다.

3

결과 — 역상(倒立)

구멍을 지나며 광선이 교차하므로 위는 아래로, 좌우도 뒤집혀 맺힌다. 이 구멍이 곧 조리개(aperture) 역할을 한다.

4

정리 — Virtual image(가상 이미지)

계산할 때는 이미지 평면을 핀홀 앞쪽 f 위치로 옮겨 상이 바로 서게 둔다. 기하 관계는 같고 부호만 정리된다.

구멍 크기의 딜레마
  • 구멍이 크면 — 여러 방향의 빛이 한 점에 섞여 들어와 평균되어 흐려진다
  • 구멍이 너무 작으면 — 회절(diffraction) 때문에 다시 흐려지고, 들어오는 빛의 양이 부족해진다
  • 그래서 빛이 모자라면 노출 시간을 길게 가져간다 — 야경 촬영에서 셔터를 오래 열어 두는 것과 같은 이치
  • 하나의 객체에서 나오는 여러 빛은 방사하기 때문에 film의 여러 곳에 닿는다 → 그래서 barrier를 설치한다. 대부분의 빛은 차단되고 어떤 하나의 빛 정도만 통과해 film에 맺힌다.
  • 위는 아래로 역상으로 맺히며, 핀홀이 곧 조리개(aperture) 역할을 하게 된다.
  • 중국의 철학자 Mozi(묵자)가 원리를 이야기했고, 아리스토텔레스도 언급했으며, 레오나르도 다 빈치가 이를 그림에 활용했다.
  • 핀홀 카메라는 결국 박스 안에 조그만 구멍을 뚫은 것. 맺히는 상은 역상이고, virtual image는 상이 바뀌지 않도록 앞쪽에 세워 둔 것이다.
  • 구멍이 크면 많은 빛이 들어와 흐려지니 가능하면 작게, 근데 너무 작으면 빛의 양이 적어 또 흐려진다. 그래서 장시간 조리개를 열어 두는 작업이 필요할 수도 있다 — 야경 촬영처럼.
07

렌즈와 초점Cameras with lenses — 빛을 더 많이, 그러나 선명하게

  • 렌즈를 넣는 이유 — 구멍을 키워 빛을 많이 받으면서도 상을 선명하게 유지하기 위해서. 렌즈가 퍼지는 빛을 한 점으로 모아 주기 때문이다
  • 초점(focal point) — 평행하게 들어온 광선들이 렌즈를 지나 모이는 점. 렌즈에서 그 점까지의 거리가 초점거리 f
  • 핀홀 모델은 그대로 성립 — 렌즈 중심을 지나는 광선은 꺾이지 않기 때문에, 앞에서 세운 투영식을 그대로 쓸 수 있다
  • 착란원(circle of confusion) — 초점이 어긋난 점은 원으로 번져 맺힌다. 이 원이 충분히 작으면 "초점이 맞았다"고 본다
Thin Lens Formula — 얇은 렌즈 공식
1 / D′+1 / D=1 / f
  • D — 물체까지의 거리 (object distance) · D′ — 상이 맺히는 거리 (focus distance) · f — 초점거리
  • 이 식을 만족하는 점만 정확히 초점이 맞는다. 초점면 D′를 앞뒤로 움직이면 초점이 맞는 물체 거리 D도 함께 달라진다 — 카메라의 포커싱이 바로 이 조작이다
  • 빛이 들어올 때 굴절(꺾임)의 문제가 있다. 렌즈의 어떤 구간에서는 빛이 꺾인다.
  • 렌즈를 통해 더 많은 빛으로 표현할 수 있게 한다 — a lens focuses light onto the film.
  • 굴절 문제를 처리하려고 렌즈의 모양·두께를 바꿔 가며 거리를 맞춘다. 우리 눈이 하는 일과 같다.
  • 사람의 눈도 결국 렌즈 — iris(홍채, 빛의 양 조절) · retina(망막, 센서) · fovea(중심와, 가장 조밀한 센서).
  • 결국 object distance D · focal length f · focus distance D′ 라는 모델이 나오고, 도형화하면 1/D′ + 1/D = 1/f 공식이 된다.
08

피사계 심도Depth of Field — "초점이 잘 맞는 구간"의 정체

필기의 "같은 거리에 있는 부분… 일치하는 부분" 이 무슨 뜻인가
얇은 렌즈 공식을 정확히 만족하는 거리는 딱 하나다. 하지만 그 거리에서 조금 벗어난 점도 착란원(circle of confusion)이 센서 화소(또는 눈의 분해능)보다 작으면 사람 눈에는 여전히 점으로 보인다. 그래서 실제 렌즈에서는 초점이 맞는 거리의 범위가 생기고, 이 범위를 피사계 심도(Depth of Field)라고 부른다.
어떻게 조절하는가 — 조리개
  • 조리개를 조이면(작게) — 렌즈 가장자리를 지나는 광선이 잘려 착란원이 작아진다 → 심도가 깊어져 앞뒤로 넓은 범위가 선명해진다. 대신 어두워진다
  • 조리개를 열면(크게) — 빛은 많이 들어오지만 착란원이 커져 심도가 얕아진다 → 배경이 흐려지는 아웃포커스
  • 물체 거리 D가 멀어질수록 심도는 대체로 깊어진다
가장 잘 나오는 부분을 컨트롤하려면 결국 조리개 사이즈를 조절해서 얻을 수 있다. 조리개를 크게 열었을 때와 작게 열었을 때 — 작게 조일수록 선명하게 커버하는 거리 범위가 길어진다.
09

화각Field of View — 초점거리가 결정하는 시야

  • 화각(FOV)는 초점거리 f와 센서(필름) 크기로 결정된다. 카메라가 보는 3D 공간의 각도 범위
  • f가 작아지면 → 더 넓은 각도가 유한한 이미지 평면 안에 들어온다 = 광각(wide angle), 더 많은 세계 점이 담긴다
  • f가 커지면 → 화각이 좁아진다 = 망원(telephoto), 좁은 영역이 크게 확대된다
  • 수식으로는 대략 FOV = 2·arctan( (센서 크기 / 2) / f ) 의 형태 — f가 분모에 있으므로 반비례
  • 시야각은 focal length(렌즈의 초점거리)로 정해지고, 교안에 식도 제시되어 있다.
  • 초점거리 vs viewpoint — 멀리서 망원으로 당겨 찍을수록 화각이 좁아지고, 배경을 크롭시키는 효과가 생긴다. 그래서 망원은 배경을 고르기가 쉽다 (시점을 조금만 옮겨도 배경이 크게 바뀐다).
10

카메라 행렬 P 만들기What is the camera matrix P? — 단계별로 쌓아 올리기

출발점 — Rearranged Pinhole Camera Model
역상으로 맺힌 이미지 평면을 광학축(optical axis) 위 초점거리 f 위치로 당겨 놓으면(가상 이미지) 닮은꼴 삼각형에서 곧바로
(x, y, z)→( f·x / z ,  f·y / z )
z로 나누는 이 연산 때문에 엄밀히 말하면 선형 변환이 아니다. 그래서 동차 좌표의 스케일 불변성 덕분에 동차 좌표로 적어 두고, 나눗셈은 맨 마지막 w로 미룬다 — 그러면 전체가 x = P·X 라는 행렬 곱 하나가 된다.

① 카메라 좌표 → 센서 평면

투영과 카메라 파라미터를 분리해서 쓴다. 앞의 3×3이 카메라(초점거리), 뒤의 3×4가 순수한 투영이다.
x′y′1 = (1/z) f000f0001 · 100001000010 · xyz1

② 센서 평면 → 이미지(픽셀) 좌표

센서 좌표의 원점은 광학축이 지나는 가운데지만, 이미지 픽셀의 원점은 보통 왼쪽 위 모서리다. 그래서 주점(principal point) (ox, oy) 만큼 평행이동을 더한다.
K = f0ox0foy001

③ 세계 좌표 → 카메라 좌표 (외부 파라미터)

카메라가 세계 어디에 어떤 자세로 있는지를 회전 R(3×3)과 이동 t(3×1)로 붙인다.
Rt01×31

④ Complete Camera Model

세 단계를 모두 곱하면 완성이다. 앞쪽이 Intrinsic parameters, 뒤쪽이 Extrinsic parameters.
x′y′1 = f0ox0foy001 · 100001000010 · Rt01×31 · xyz1
즉,  x = P · X ,  P = K [ R | t ]  (3×4)

⑤ More General Camera Model

실제 센서는 픽셀이 정사각형이 아닐 수도 있고(픽셀 종횡비), 축이 살짝 비틀려 있을 수도 있다(skew(비대칭)). 이를 보정하는 항을 넣으면 내부 행렬의 자유도가 늘어난다.
K = f sxf sθox0f syoy001
  • f·sx, f·sy — 가로/세로 방향의 배율 (픽셀 크기 차이 반영)
  • f·sθ — skew 보정 항. 픽셀 축이 직교하면 0이다
  • 내부 파라미터 자유도 5(fx, fy, sθ, ox, oy) + 외부 6(R 3 + t 3) = 총 11, 이는 3×4 행렬 12개 원소에서 전체 스케일 1을 뺀 값과 정확히 일치한다
  • rearrange할 때, 역상으로 맺힌 걸 당겨서 optical axis 위 가상의 평면에 맺히게 한다 — rearranged pinhole camera model.
  • 선형 변환이라고 말할 수는 없고, homogeneous하게 표현한다. 그래서 x = PX. 앞으로 이 P에 대해 알아보게 된다.
  • camera frame과 sensor plane의 관계 → 초점거리만큼의 배율을 도입. 이어서 sensor plane과 image의 관계(주점 이동). 여기까지가 카메라 내부.
  • 카메라 외부에서는 world frame과 image의 관계 — 실세계 좌표와 카메라의 이동성(R, t)까지.
  • 결국 intrinsic·extrinsic parameters를 다 합쳐 complete camera model을 만든다. 다르게 scaling해야 할 수도 있어 자유도가 증가할 수 있고, 뒤틀려 있을 수도 있어 skew 보정값을 포함해 more general camera model을 구축한다.

응용 — 왜곡과 보정Applications · 교안 60~62p

1) Perspective distortion

원근 왜곡 · converging verticals

건축 사진의 고질적인 문제 — 높은 건물을 담으려고 카메라를 위로 기울이면 이미지 평면이 건물 벽과 평행하지 않게 되어, 수직선들이 위로 갈수록 모인다(아래는 넓고 위는 좁게). 카메라를 수평으로 유지하면 왜곡은 없지만 건물 아랫부분만 담긴다.

해결 ① 하드웨어 — 렌즈를 위로 평행 이동시킨다(lens shift / 시프트 렌즈). 카메라는 수평인 채로 건물 전체가 담긴다
해결 ② 소프트웨어 — Perspective rectification. 우리가 배운 호모그래피로 모여 버린 평행선을 다시 평행하게 되돌린다

2) Radial distortion

방사 왜곡 · barrel / pin cushion

렌즈의 불완전함에서 오는 왜곡으로, 렌즈 가장자리를 지나는 광선일수록 편차가 크게 나타난다. 중심에서 멀어질수록 직선이 휘어 보인다.

유형모습흔한 경우
No distortion직선이 직선으로이상적인 렌즈
Pin cushion (핀쿠션)가장자리가 안으로 오목하게 당겨짐 — 바늘꽂이 모양망원 쪽
Barrel (배럴)가장자리가 밖으로 볼록하게 부풀음 — 술통 모양광각 · 어안렌즈
보정 — 반지름 방향으로 늘이고 줄이는 왜곡 계수를 추정해 되돌린다. 직선이 다시 직선이 되는지가 판단 기준이며, 호모그래피와 함께 카메라 캘리브레이션의 일부로 다룬다
  • perspective distortion — 카메라로 찍을 때 위는 좁게, 아래는 넓게 왜곡되는 것. 하드웨어적 solution은 camera lens가 shifting, 우리가 배운 방법은 perspective rectification (modeling distortion) — 왜곡된 평행선을 평행하게 바꿔 주는 것.
  • radial distortion — 어안렌즈처럼 가장자리가 왜곡된 것. pin cushion처럼, 또는 barrel처럼.
  • 이것도 평행선을 유지하게끔 당기고 늘리고 줄여서 맞춰 주는 것이며, homography와도 같이 고려한다. 결국 이미지에 대한 transformation을 진행하는 것이고, 왜곡 효과는 카메라의 파라미터를 활용해 보정한다.
