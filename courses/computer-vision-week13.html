13. 검출과 분할 — 어디에, 어떤 모양으로 있나

12주차의 CNN은 영상 한 장에 레이블 하나를 붙였다. 이번 주는 질문을 넓힌다 — 검출(detection)은 ‘무엇이 어디에 있나’(분류 + 상자 회귀), 분할(segmentation)은 ‘각 물체의 정확한 모양은 무엇인가’(픽셀마다 레이블)다. 검출은 후보 영역을 먼저 뽑는 2단계(R-CNN → Fast → Faster R-CNN)와 한 번에 예측하는 1단계(YOLO · SSD)로 나뉘고, 분할은 줄였다 키우는 인코더-디코더(FCN · U-Net)와 검출에 마스크 가지를 단 Mask R-CNN으로 이어진다. 마지막으로 데이터셋과 IoU · 정밀도 · 재현율 · mAP · ROC 같은 평가 지표를 정리한다.

교안발전사와 1단계 vs 2단계 (6~8p)

2단계 검출기 7p

① 전통 비전 방법이나 심층 신경망으로 물체 영역을 제안하고, ② 제안된 영역에서 뽑은 특징으로 물체를 분류하며 상자를 회귀한다. RCNN · Faster R-CNN · Mask R-CNN · G-RCNN.

1단계 검출기 8p

영역 제안 단계 없이 영상 위에서 상자를 바로 예측한다. 시간이 덜 걸려 실시간 응용에 쓴다. 추론 속도를 우선해 매우 빠르지만 모양이 불규칙한 물체나 작은 물체 무리는 덜 잘 잡는다. YOLO 계열 · SSD · RetinaNet.

02

R-CNN 계열 — 영역을 제안하고 분류한다교안 12~21p

교안 슬라이드 모아보기 13p · 14p · 15p · 16p · 17p · 18p · 19p · 20p · 21p

개념 정리

교안왜 영역 제안이 필요한가 (13 · 14p)

물체가 하나면 분류 + 상자 좌표 4개를 뽑는 회귀 문제다. 물체가 여러 개면 몇 개인지 모르므로, 엄청나게 많은 위치 · 크기 · 종횡비에 CNN을 적용해야 해 계산이 너무 비싸다.

영역 제안 — 선택적 탐색(Selective Search): 물체를 담고 있을 것 같은 ‘뭉툭한(blobby)’ 영역을 찾는다. 비교적 빨라서 CPU에서 몇 초 만에 영역 제안 2,000개를 낸다. 물체는 여러 크기로 있고, 한 물체가 다른 물체 안에 들어 있기도 하다(TV 안의 소녀).

교안R-CNN과 상자 회귀 (15 · 16p)

R-CNN(Regions with CNN) — 선택적 탐색으로 물체 후보 상자(관심 영역, RoI)를 여럿 찾고, 영역마다 따로 특징을 뽑아 분류한다(잘라 크기를 맞춘 뒤 CNN → SVM 분류 + 상자 회귀).

\hat g_x=p_wd_x(\mathbf p)+p_x,\;\;\hat g_y=p_hd_y(\mathbf p)+p_y,\;\;\hat g_w=p_w\exp(d_w(\mathbf p)),\;\;\hat g_h=p_h\exp(d_h(\mathbf p))

상자 회귀 — 제안 상자 \mathbf p=(p_x,p_y,p_w,p_h)를 정답 상자 g 쪽으로 보정한다. 학습 목표는 t_x=(g_x-p_x)/p_w,\;t_y=(g_y-p_y)/p_h,\;t_w=\log(g_w/p_w),\;t_h=\log(g_h/p_h)이고, 손실은 \mathcal L_{reg}=\sum_{i\in\{x,y,w,h\}}(t_i-d_i(\mathbf p))^2+\lambda\lVert\mathbf w\rVert^2이다.

보충설명왜 상자 크기로 나누고 로그를 쓰나

중심 이동을 상자 너비 · 높이로 나누면 크기에 무관한 목표가 된다 — 큰 상자에서 10픽셀 어긋남과 작은 상자에서 1픽셀 어긋남을 같은 비율로 다룬다. 크기는 비율의 로그라서 2배 커지는 것과 절반이 되는 것이 \pm\log2로 대칭이고, 예측을 exp로 되돌리면 너비가 늘 양수다. 예: p=(100,100,50,40), g=(110,96,60,40)이면 t=(0.2,\,-0.1,\,\log1.2\approx0.18,\,0).

교안Fast R-CNN과 RoI Pool (17 · 18p)

R-CNN의 계산 비효율을 고친다 — RoI마다 CNN을 돌리지 않고, 영상 전체에 CNN을 한 번 돌린 특징 지도에서 RoI를 잘라 낸다.

RoI Pool(특징 자르기) — ① 제안 영역을 특징 지도의 격자 칸에 맞춰 붙인다(snap) ② 대략 같은 크기의 2×2(실제로는 7×7) 하위 영역으로 나눈다 ③ 하위 영역마다 최대 풀링. 입력 영역의 크기가 달라도 영역 특징은 늘 같은 크기가 되어 완전 연결 층에 넣을 수 있다. 문제: 격자에 맞춰 붙이면서 영역 특징이 조금 어긋난다 — 05절의 RoI Align이 해결한다.

교안Faster R-CNN — 영역 제안 네트워크 (19~21p)

Fast R-CNN에도 남은 병목(CPU의 선택적 탐색)을 영역 제안 네트워크(RPN)로 바꿔, 제안까지 신경망이 만든다. Faster R-CNN은 2단계 검출기다.

1단계: 영상마다 한 번

백본 네트워크 · 영역 제안 네트워크

2단계: 영역마다 한 번

특징 자르기(RoI pool / align) · 물체 클래스 예측 · 상자 오프셋 예측

RPN과 앵커 상자(20p) — 800×800 영상을 CNN에 넣어 8×8 특징 지도를 얻고, 특징 지도의 각 칸에 미리 정한 크기 · 종횡비의 앵커 상자 k개를 놓는다. 앵커마다 ‘물체인가(object O / X)’와 상자 보정값 (t_x,t_y,t_w,t_h)를 예측한다.

교안 슬라이드 모아보기 22p · 23p · 24p · 25p · 26p · 27p · 28p · 29p · 30p

개념 정리

교안YOLO 모델과 구조 (22 · 23p)

YOLO(You Only Look Once) — 입력을 S×S 격자로 나누고, 칸마다 상자 B개 + 신뢰도와 클래스 확률 지도를 한꺼번에 예측한 뒤 NMS로 정리한다. 클래스별 신뢰도는 \Pr(\text{Class}_i|\text{Object})\cdot\Pr(\text{Object})\cdot\text{IoU}^{truth}_{pred}=\Pr(\text{Class}_i)\cdot\text{IoU}^{truth}_{pred}다. YOLOv1은 GoogLeNet을 본떠 합성곱 층 24개 + 완전 연결 층 2개다(Redmon 등 2015).

교안손실 함수 세 부분 (24p)

\underbrace{\lambda_{coord}\sum_{i=0}^{S^2}\sum_{j=0}^{B}\mathbb 1^{obj}_{ij}\Big[(x_i-\hat x_i)^2+(y_i-\hat y_i)^2+(\sqrt{w_i}-\sqrt{\hat w_i})^2+(\sqrt{h_i}-\sqrt{\hat h_i})^2\Big]}_{\text{위치 손실}}\\+\underbrace{\sum_{i,j}\mathbb 1^{obj}_{ij}(C_i-\hat C_i)^2+\lambda_{noobj}\sum_{i,j}\mathbb 1^{noobj}_{ij}(C_i-\hat C_i)^2}_{\text{신뢰도 손실}}+\underbrace{\sum_{i=0}^{S^2}\mathbb 1^{obj}_i\sum_{c\in\text{classes}}(p_i(c)-\hat p_i(c))^2}_{\text{분류 손실}}

\mathbb 1^{obj}_{ij}는 칸 i의 j번째 상자가 그 물체를 맡았을 때 1이다. 원 논문은 \lambda_{coord}=5,\;\lambda_{noobj}=0.5를 썼다 — 대부분의 칸에는 물체가 없으므로, 빈 칸의 신뢰도 항이 학습을 압도하지 않게 줄이고 위치 항은 키운다. 너비 · 높이에 제곱근을 씌운 것은 큰 상자의 작은 오차보다 작은 상자의 같은 오차를 더 무겁게 보려는 것이다.

교안IoU · 신뢰도 · NMS (25 · 26p)

IoU 임곗값 = 0.5일 때 IoU ≈ 0.3인 예측은 거짓 양성(FP), IoU ≈ 0.7은 참 양성(TP)이다. 같은 IoU 0.3도 임곗값이 0.2면 TP가 된다. 신뢰도 임곗값을 올리면 정밀도가 오르고 재현율이 내려간다(25p 곡선).

1. 물체 점수가 가장 높은 상자를 고른다
2. 이 상자와 나머지 상자의 겹침(IoU)을 비교한다
3. IoU가 50%보다 큰 상자를 지운다같은 물체를 가리키는 중복
4. 다음으로 점수가 높은 상자로 간다
5. 2~4를 반복한다NMS(Non-Maximum Suppression)

27p — YOLO 계보: v1(2015) · v2(2016) · v3(2018) · v4 · v5(2020) · … · v8(2023) · v9(2024).

교안SSD — 여러 크기의 특징 지도에서 (28~30p)

SSD(Single Shot MultiBox Detector)는 CNN의 피라미드형 특징 계층을 써서 여러 크기의 물체를 효율적으로 검출하려 한 첫 시도 중 하나다. VGG-16 뒤에 크기가 점점 작아지는 추가 특징 층(38×38 → 19×19 → 10×10 → 5×5 → 3×3 → 1×1)을 붙이고, 층마다 기본 상자(default box, 앵커)에서 위치 보정 \Delta(cx,cy,w,h)와 클래스 신뢰도 (c_1,\dots,c_p)를 예측한다.

s_k=s_{min}+\frac{s_{max}-s_{min}}{m-1}(k-1),\qquad k\in[1,m]

k번째 특징 지도의 기본 상자 크기. 29p — 8×8 지도(촘촘, 작은 상자)는 작은 고양이를, 4×4 지도(성김, 큰 상자)는 큰 개를 맡는다.

보충설명NMS 손으로 돌려 보기 · sk 숫자 예

상자 A(0.9), B(0.8), C(0.7)가 있고 IoU(A,B)=0.7, IoU(A,C)=0.1, IoU(B,C)=0.2라면 — A를 남기고 A와 0.5 넘게 겹친 B를 지운다 → 남은 C는 A와 거의 안 겹치므로 남는다. 결과 {A, C}: 두 물체다.

Long · Shelhamer · Darrell, “Fully Convolutional Networks for Semantic Segmentation”(CVPR 2015) · Noh 등, “Learning Deconvolution Network”(ICCV 2015).

교안올리는 방법 — 언풀링과 전치 합성곱 (36 · 37p)

방법2×2 [1 2; 3 4] → 4×4
최근접 이웃 언풀링값을 2×2로 복사: [1 1 2 2; 1 1 2 2; 3 3 4 4; 3 3 4 4]
‘Bed of Nails’왼쪽 위에만 두고 나머지 0: [1 0 2 0; 0 0 0 0; 3 0 4 0; 0 0 0 0]
최대 언풀링 (max unpooling)앞에서 최대 풀링할 때 최댓값이 있던 자리를 기억해 두고, 짝을 이룬 업샘플링 층에서 그 자리에 값을 되돌려 놓는다
전치 합성곱 (transpose conv) — 학습 가능보통 합성곱은 커널로 입력 원소들을 모아 줄이지만, 전치 합성곱은 입력 원소 하나를 커널로 퍼뜨려 입력보다 큰 출력을 만든다. 겹치는 곳은 더한다

정리(38p) — 내려가기는 풀링 · strided 합성곱, 올라오기는 언풀링 · strided 전치 합성곱. 대표 구조가 U-Net(MICCAI 2015, 의료 영상 분할)이다.

보충설명전치 합성곱 손계산 · U-Net의 ‘U’와 건너뛰기 연결

37p 기본 연산: 입력 [0 1; 2 3], 커널 [0 1; 2 3], stride 1. 입력 값마다 커널을 곱해 그 자리에 놓고 더한다 — 0·K는 전부 0, 1·K = [0 1; 2 3]은 오른쪽으로 한 칸, 2·K = [0 2; 4 6]은 아래로 한 칸, 3·K = [0 3; 6 9]는 대각선으로 한 칸. 합하면 [0 0 1; 0 4 6; 4 12 9](3×3). 출력 크기는 (w_{in}-1)s+k=(2-1)\cdot1+2=3, stride 2면 (2-1)\cdot2+2=4.

U-Net은 인코더가 줄이며 잃은 세밀한 위치 정보를, 같은 해상도의 인코더 특징을 디코더에 이어 붙여(skip connection) 되살린다. 그림을 그리면 U자다. 12주차 ResNet의 건너뛰기가 ‘더하기’였다면 U-Net은 ‘이어 붙이기’다.

개념 정리

교안Faster R-CNN + 마스크 가지 (39 · 40p)

He 등, “Mask R-CNN”(ICCV 2017). 분류 · 상자에 마스크 예측을 더한다 — RoI마다 동작하는 작은 마스크 네트워크를 붙여 28×28 이진 마스크를 예측한다.

  • Faster R-CNN + FCN(마스크 가지) — CNN + RPN → RoI Align → 256×14×14 → 합성곱 → 합성곱
  • 출력: 분류 점수 C, 클래스별 상자 좌표 4·C, 클래스마다 마스크 C×28×28
  • RoI Pooling → RoI Align
  • 클래스와 마스크 예측을 분리 — 마스크는 클래스마다 따로 예측하고, 분류 가지가 고른 클래스의 마스크만 쓴다
  • 다중 과제 손실 L=L_{cls}+L_{box}+L_{mask}(42p)

교안RoI Align (41p)

RoI Pool과 비교하면 — ① 격자에 맞춰 붙이지 않는다(no snap) ② 각 하위 영역 안의 규칙적인 점에서 쌍선형 보간으로 값을 뽑는다 ③ 하위 영역마다 최대 풀링. 소수점 위치를 반올림하지 않으므로 특징이 원래 영역과 정확히 정렬된다.

보충설명왜 분할에는 RoI Align이 꼭 필요한가

특징 지도가 영상보다 32배 작다고 하자. 영상 좌표 x = 100인 경계는 특징 지도에서 100/32 = 3.125다. RoI Pool은 이를 3으로 반올림한다 — 영상으로 되돌리면 4픽셀 어긋난다. 상자 분류에는 별 문제가 없지만, 픽셀 단위 마스크에서는 경계가 통째로 밀린다. RoI Align은 3.125 위치의 값을 이웃 네 칸으로 쌍선형 보간해 읽으므로 어긋남이 없다. 원 논문에서 이것만으로 마스크 AP가 크게 올랐다.

평가 지표교안 50~58p

교안 슬라이드 모아보기 50p · 51p · 54p · 55p · 57p · 58p

개념 정리

교안혼동 행렬과 네 지표 (50~53 · 56p)

칸뜻 (암 진단 예)
TP실제 양성을 양성으로 — 암 환자를 암으로 맞힘
TN실제 음성을 음성으로 — 건강한 사람을 건강하다고 맞힘
FP음성인데 양성으로 — 건강한 사람에게 암이라고 함
FN양성인데 음성으로 — 암 환자를 놓침
  • 정확도 = (TP + TN) / 전체 — 직관적이지만 클래스가 불균형하면 오해를 부른다
  • 정밀도 = TP / (TP + FP) — 양성 예측 중 진짜 양성의 비율. 거짓 양성의 비용이 클 때 중요
  • 재현율 = TP / (TP + FN) — 실제 양성 중 찾아낸 비율. 양성을 놓치는 비용이 클 때 중요. 민감도 · 참 양성률(TPR)이라고도 한다
  • F1 = 정밀도와 재현율의 조화 평균. F1을 최대화하면 둘을 동시에 최대화하는 셈이라 정확도와 함께 많이 쓴다

보충설명교안의 두 병원 예를 직접 계산하면

실제는 두 병원 모두 [건강, 건강, 건강, 건강, 암] — 암 환자 1명.

예측TP · FP · FN · TN정확도정밀도재현율
병원 A건강 · 건강 · 건강 · 암 · 건강0 · 1 · 1 · 30.60 / 1 = 00 / 1 = 0
병원 B건강 · 건강 · 암 · 암 · 암1 · 2 · 0 · 20.61 / 3 ≈ 0.331 / 1 = 1

정확도는 둘 다 0.6으로 같지만, A는 암 환자를 놓쳤고 B는 찾아냈다(대신 건강한 두 명을 재검사로 보낸다). 암 진단처럼 놓치는 비용이 크면 재현율로 보면 B가 훨씬 낫다 — 정확도만 보면 안 되는 이유다.

교안PR 곡선 · AP · mAP (54 · 55p)

정밀도-재현율은 클래스가 매우 불균형할 때 예측 성공을 재는 유용한 척도다. 정보 검색에서 정밀도는 결과의 적합성, 재현율은 진짜 적합한 결과를 얼마나 많이 돌려주는지다. PR 곡선은 확률 임곗값을 바꿔 가며 참 양성률(재현율)과 양성 예측도(정밀도)의 맞바꿈을 요약한다.

AP=\int_{r=0}^{1}p(r)\,dr,\qquad mAP=\frac1{N_{cls}}\sum_{c}AP_c

AP는 PR 곡선 아래 넓이로, 곡선을 값 하나(0~1)로 요약한다. 여러 신뢰도 임곗값에 걸쳐 정밀도와 재현율이 모두 높을 때 높고, 어느 하나라도 낮으면 낮다. mAP는 클래스별 AP의 평균이다 — 검출 논문의 ‘mAP 66.9%’(21p)가 이것이다.

교안ROC 곡선과 IoU (57 · 58p)

ROC 곡선 — 모든 분류 임곗값에서의 성능을 보여 주는 그래프로, 가로축 FPR = FP / (FP + TN)(위양성률, fall-out), 세로축 TPR = TP / (TP + FN)(= 재현율)이다. 왼쪽 위(0, 1)가 완벽한 분류기, 대각선이 무작위 분류기다. AUC(곡선 아래 넓이)는 ROC 곡선 전체의 ‘전반적인’ 위치를 1차원 지표 하나로 요약한다.

\text{IoU}=\frac{\text{Area of Overlap}}{\text{Area of Union}}\qquad(\text{58p 예}:\;21{,}600/35{,}000=0.618)

IoU는 정답 상자와 예측 상자가 얼마나 가까운지를 0~1로 잰다. 두 상자가 완전히 겹치면 1(완벽한 예측)이다. 검출의 TP · FP 판정은 IoU 임곗값(보통 0.5)으로 한다.

보충설명IoU 손계산 · PR과 ROC는 언제 무엇을

정답 상자 (0, 0)~(4, 4), 예측 상자 (2, 2)~(6, 6)이면 겹친 넓이 2×2 = 4, 합친 넓이 16 + 16 − 4 = 28 → IoU = 4 / 28 ≈ 0.14. 한 변 길이의 절반만 밀려도 IoU는 0.5 아래로 크게 떨어진다 — 0.5가 생각보다 엄격한 기준인 이유다.

ROC는 TN을 쓰므로, 음성(배경)이 압도적으로 많은 검출 문제에서는 FPR이 늘 작게 나와 곡선이 좋아 보인다. 그래서 검출 · 검색처럼 음성이 너무 많은 과제는 TN을 쓰지 않는 PR 곡선 · AP로 평가한다. NLP 10주차 감성 분석의 정밀도 · 재현율 · F1과 같은 식이다(NLP 10.2.5).
