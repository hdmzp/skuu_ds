10. 합성곱 신경망 — 이미지를 펴지 않고 그대로 본다

6주차의 다층 퍼셉트론(MLP)으로도 손글씨 숫자를 분류할 수 있었다. 그런데 이미지를 한 줄로 펴서(Flatten) 넣다 보니 파라미터가 수십만 개로 불어나고, 가까이 붙어 있던 픽셀끼리의 관계가 사라진다. 이번 주의 합성곱 신경망(CNN)은 이미지를 2차원 그대로 받아 작은 필터(커널)를 미끄러뜨리며 특징을 찾는다. 같은 필터를 이미지 전체에 재사용하므로 파라미터가 적고, 층을 쌓을수록 모서리 → 모양 → 물체의 부분으로 특징이 깊어진다. 실습은 이 CNN을 PyTorch로 짜서 뇌 MRI 종양 4종을 분류하고, 데이터 누수 · 불균형 · 캘리브레이션 · Grad-CAM까지 다룬다.

이번 주 한 줄 요약

  • MLP와 CNN은 학습 원리가 같다 — 순전파 → 손실 → 경사하강법으로 가중치 · 편향을 고친다. 다른 것은 층의 모양이다
  • MLP는 28×28 이미지를 784칸짜리 한 줄로 편다(Flatten). 그 결과 작은 망도 파라미터가 669,706개이고, 이웃 픽셀 관계(공간 정보)가 사라진다
  • CNN은 합성곱층(특징 추출) → 풀링층(크기 축소) → 전결합층(분류)으로 이루어진다. 커널 값이 곧 가중치이고, 학습으로 정해진다
  • 합성곱층을 지나면 크기는 유지(same 패딩) · 깊이는 필터 수, 풀링층을 지나면 깊이는 유지 · 크기는 절반이다. 그래서 층을 쌓을수록 작아지고 깊어진다
  • 교안의 케라스 CNN은 파라미터가 220,234개로 MLP의 약 1/3이면서 공간 정보를 지킨다

교안MLP와 CNN은 학습 원리가 같다 (3p)

신경망이 학습하고 파라미터를 최적화하는 기본 원리는 CNN과 MLP 모두 동일하다. 교안이 드는 공통점은 네 가지다.

공통점내용이번 주에 달라지는 것
1. 신경망 구조뉴런층이 겹겹이 쌓인 구조층의 종류 — Dense 대신 합성곱층 · 풀링층
2. 가중치와 편향예측이 같은 방식으로 작동하고, 둘 다 무작위 값으로 초기화된 가중치 · 편향을 학습한다CNN에서는 커널(필터) 값이 가중치다(10.5)
3. 하이퍼파라미터오차 함수 · 활성화 함수 · 최적화 알고리즘을 정해야 한다필터 수 · 커널 크기 · 스트라이드 · 패딩이 더해진다(10.6)
4. 학습순방향 계산 → 손실 함수 계산(예측과 실제 레이블) → 경사하강법으로 파라미터 최적화같다 — 6주차 학습 절차 그대로

그러니 이번 주에 새로 배울 것은 ‘학습하는 법’이 아니라 ‘이미지를 받는 층을 어떻게 생기게 만드느냐’다.

10.2

다층 퍼셉트론 구조와 이미지 벡터 변환교안 4~9p · 2차원 이미지를 한 줄로 편다

교안 슬라이드 모아보기 4 · 5 · 6 · 7 · 8 · 9p

교안MLP의 구조 (4p)

뉴런이 층 모양으로 모여 있고, 인접한 층과 층 사이의 모든 뉴런이 가중치가 있는 연결을 갖는다(완전 연결). 구조는 입력층 하나 + 은닉층 하나 이상 + 출력층 하나다.

교안입력층 — 이미지를 벡터로 편다 (5 · 6 · 7p)

컴퓨터에게 28×28 이미지는 28×28 행렬이고, 각 원소는 0~255의 밝기 값이다. 그런데 MLP는 모양이 (1, n)인 1차원 벡터만 입력받는다. 그래서 (x, y) 모양의 행렬을 (1, n) 벡터로 바꾸는 이미지 벡터 변환(image flattening)이 필요하다.

\underbrace{28\times28}_{\text{행렬}}\;\longrightarrow\;\underbrace{(1\times784)}_{\text{벡터}},\qquad \mathbf x=[\text{row}_1,\text{row}_2,\ldots,\text{row}_{28}]

1행 28개, 그 뒤에 2행 28개, … 28행까지 행을 차례로 이어 붙인다. 그래서 입력층 노드는 784개다. 케라스에서는 Flatten(input_shape=(28, 28))이 이 일을 하고, 입력 이미지 크기를 반드시 인수로 지정해야 한다(첫 층이라 앞에서 모양을 알려 줄 층이 없다).

교안은닉층 · 출력층 (8 · 9p)

  • 은닉층 — 이론적으로 원하는 수만큼 둘 수 있고, 각 층의 뉴런 수도 원하는 만큼 정한다. 모델 설계의 일이 곧 층을 설계하는 것이다. 교안은 Dense(512, activation='relu')를 두 번 쌓는다
  • 출력층 — 분류 문제의 출력 노드 수는 분류 대상 클래스 수와 같다. 숫자 0~9면 Dense(10, activation='softmax')
from keras.models import Sequential
from keras.layers import Flatten, Dense
model = Sequential()
model.add(Flatten(input_shape=(28, 28)))        # 28×28 → 784 (파라미터 0)
model.add(Dense(512, activation='relu'))        # 은닉층 1
model.add(Dense(512, activation='relu'))        # 은닉층 2
model.add(Dense(10, activation='softmax'))      # 출력층: 클래스 10개의 확률
model.summary()
PyTorch로 옮기면 출력층의 softmax를 빼야 한다 — 케라스는 Dense(10, activation='softmax') + categorical_crossentropy로 확률을 내보내지만, PyTorch의 nn.CrossEntropyLoss는 소프트맥스 이전의 로짓을 받아 안에서 소프트맥스를 계산한다. 이번 주 실습의 SimpleCNN도 마지막이 nn.Linear(c_prev, 4)로 끝나고, 정답 README가 “마지막에 nn.Softmax를 붙이는 것이 가장 흔한 오답”이라고 짚는다(6주차 개정① 17p와 같은 이야기).
10.3

MLP의 파라미터 수 계산과 한계교안 10~13p

교안 슬라이드 모아보기 10 · 11 · 12 · 13p

교안Param # 를 손으로 맞춰 보기 (10~12p)

model.summary()의 Param #는 그 층의 파라미터(가중치) 수이고, 학습은 이 가중치들이 조정되는 과정이다.

층출력 모양계산Param #
Flatten(None, 784)모양만 바꾼다 — 행렬을 벡터로 펴는 역할뿐0
dense_1(None, 512)784\times512+512 — 입력 노드 784 × 이 층 노드 512 + 편향 512401,920
dense_2(None, 512)512\times512+512262,656
dense_3 (출력)(None, 10)512\times10+105,130
전체669,706

규칙은 하나다 — (\text{앞 층 노드 수}\times\text{이 층 노드 수})+\text{이 층 노드 수(편향)}. 노드마다 편향이 하나씩이라 뒤에 더하는 수는 이 층의 노드 수다. 100문제의 응용 예처럼 512 → 5클래스면 512\times5+5=2{,}565. 교안 11 · 12p는 층 이름을 ‘Dense_1층과 Dense_2층을 잇는’ 식으로 쓰는데, summary 표에서는 이것이 각각 dense_1 · dense_2 · dense_3의 Param #다.

교안MLP의 두 가지 단점 (13p)

① 파라미터가 너무 많다

크지 않은 망도 669,706개를 학습해야 한다. 입력이 커지면 첫 Dense 층이 폭발한다(아래 보충설명).

② 공간적 특징이 사라진다

2차원 이미지를 1차원 벡터로 펴면 서로 가까이 있던 픽셀 간의 관계를 알 수 없게 된다. 이것을 해결하는 방법이 CNN이다.

보충설명펴면 왜 ‘이웃 관계’가 사라지나 — 그리고 이미지가 커지면

28×28을 펴면 (0, 0) 픽셀은 벡터의 0번, 그 바로 아래 (1, 0) 픽셀은 28번 자리에 간다. 위아래로 붙어 있던 두 픽셀이 벡터에서는 28칸 떨어진다. Dense 층은 784개 입력을 모두 순서와 무관하게 똑같이 취급하므로, 784칸의 순서를 어떻게 섞어도 학습 결과가 같다 — ‘누가 누구 옆이었는지’라는 정보를 쓰지 못한다는 뜻이다. 또 숫자가 오른쪽으로 2칸만 옮겨 가도 벡터의 거의 모든 칸이 바뀌어, 같은 숫자를 처음 보는 입력처럼 다시 배워야 한다.

크기 문제도 숫자로 보면 분명하다. 실습의 MRI 입력 224×224×3을 펴면 150{,}528칸이고, 첫 은닉층을 512개로만 해도 150{,}528\times512\approx7{,}700만 개의 가중치가 한 층에만 필요하다. 같은 실습의 SimpleCNN 전체 파라미터가 1,174,244개인 것과 비교하면 약 65배다.

10.4

합성곱 신경망의 등장 배경과 전체 구조교안 14~19p · 특징 추출 / 분류 / 예측

교안 슬라이드 모아보기 14 · 15 · 16 · 17 · 18 · 19p

교안CNN은 왜 생겼나 (14p)

이미지를 1차원 벡터로 변환하면서 손실되는 정보와 전결합층(Fully-connected layer)의 계산 복잡도를 고려해 이미지 입력을 다루려고 CNN이 탄생했다. CNN은 2차원 이미지 행렬을 그대로 입력받으므로 픽셀 값에 숨어 있는 패턴을 이해할 수 있다 — 10.3의 두 단점에 대한 정확한 답이다.

교안층마다 배우는 특징이 깊어진다 (15p)

첫 번째 층기본적인 특징 — 모서리, 직선
그다음 층좀 더 복잡한 패턴 — 원, 정사각형
이어지는 층훨씬 복잡한 패턴 — 얼굴의 일부, 자동차 바퀴, 개의 수염
Flatten → 전결합층추출한 특징을 1차원 벡터로 만들어 분류 — 10.2의 MLP와 같은 과정

15p 고양이 그림 — 아래층이 귀 · 코 · 수염의 선과 곡선을 찾고, 위층이 그것을 조합해 ‘고양이’를 판정한다. 19p의 사진(구체적인 특징 → 약간 추상적인 특징 → 추상적인 특징)은 실제 CNN이 추출한 특징 맵이 층을 거치며 점 · 선 → 눈 · 코 → 얼굴 전체로 바뀌는 모습이다.

교안전체 구조와 숫자 3 · 7 예시 (16 · 17p)

CNN은 입력층 / 특징 추출을 담당하는 합성곱층 / 분류를 담당하는 전결합층 / 예측 결과 출력으로 이루어진다. 줄이면 특징 추출 / 분류 / 예측의 구조다.

1. 이미지를 합성곱층에 입력숫자 3이 쓰인 흑백 이미지
2. 패턴이 특징 맵(Feature map)으로 추출층을 지날 때마다 이미지 크기는 줄고, 특징 맵 수는 는다
3. 1차원 특징 벡터로 변환 → 전결합층이미지를 분류한다
4. 출력층 노드가 발화예측 결과에 해당하는 노드 — 여기서는 3과 7 중 하나

교안특징 추출과 분류를 들여다보기 (18 · 19p)

특징 추출은 비유하면 “큰 이미지를 여러 개의 작은 특징 맵으로 나눈 뒤 쌓아 벡터로 만드는 과정”이다. 숫자 3 흑백 이미지는 깊이 1로 들어와, 특징이 네 가지면 깊이 4가 된다. 합성곱층을 차례로 지나면 크기는 작아지고 특징 가짓수가 늘어 깊이가 깊어진다.

‘조각으로 나눈다’는 비유일 뿐이다 — 교안이 굵게 강조한 문장: CNN은 실제로 이미지를 여러 조각으로 분할하지 않는다. 다른 사물이 찍힌 이미지와 구분되는 의미 있는 특징을 추출해 다른 특징과 함께 쌓아 둔다. 100문제에서 “입력 이미지를 실제로 잘라 따로 저장한다”가 오답 보기로 나온다.

분류는 전결합층이 맡는다. “첫 번째 특징을 보니 모서리가 있어 3, 7 또는 2일 것이다 → 두 번째 특징에 곡선이 있으니 7은 확실히 아니다 → 3이다”처럼 특징을 근거로 후보를 좁혀 간다.

교안합성곱이란 — 이미지 위를 오가는 확대경 (21 · 22p)

합성곱층은 CNN의 핵심이다. 이미지 위를 픽셀 단위로 오가며 특징을 찾는 확대경처럼, 이미지에 찍힌 사물을 구분 짓는 특징을 추출한다. 수학의 합성곱은 두 함수를 인수로 새 함수를 만드는 연산이고, CNN에서는 첫 번째 인수가 입력 이미지, 두 번째 인수가 합성곱 필터다. 필터를 입력 이미지 위로 옮기며 필터가 놓인 작은 조각을 처리하고, 그 결과를 모아 새 이미지 — 특징 맵 — 을 만든다.

교안커널 · 수용 영역 · 커널 값 = 가중치 (23 · 24p)

  • 가운데 놓인 3×3 행렬이 합성곱 필터 = 커널(kernel)이다. 커널은 입력 위를 픽셀 단위로 움직이며 각 위치에서 값을 계산하고, 그 값들을 모아 ‘합성곱 연산을 거친’ 새 이미지를 다음 층으로 넘긴다
  • 수용 영역(receptive field) — 필터가 놓인 입력 이미지 위의 범위, 즉 합성곱이 한 번 수행되는 영역이다
  • 커널 값은 무엇인가? — 합성곱 신경망에서는 합성곱 행렬이 바로 가중치다. 무작위 값으로 초기화된 뒤 신경망이 학습한다
  • 계산 방법 — 수용 영역과 필터의 겹치는 픽셀 값을 각각 곱하고, 결과를 모두 더해 필터 중심에 해당하는 픽셀 값으로 삼는다

보충설명교안 22p의 −3을 직접 계산해 보기

22p 그림의 수용 영역 3×3과 필터 3×3을 칸끼리 곱해 모두 더한다(100문제 71번).

수용 영역 (입력)필터 (가중치)칸끼리 곱행 합
1행3 · 0 · 1−1 · 0 · 1−3 · 0 · 1−2
2행2 · 6 · 2−2 · 0 · 2−4 · 0 · 40
3행2 · 4 · 1−1 · 0 · 1−2 · 0 · 1−1
모두 더하면 → 결과 특징 맵의 그 칸−3

이 필터는 왼쪽 열에 −, 오른쪽 열에 +를 준다(컴퓨터비전 3주차의 소벨 필터와 같은 모양). 그래서 오른쪽이 왼쪽보다 밝으면 양수, 어두우면 음수 — 세로 경계를 찾는 필터다. 이 수용 영역은 왼쪽(3, 2, 2)이 오른쪽(1, 2, 1)보다 약간 밝아서 −3이 나왔다. 24p의 243도 같은 필터로 같은 계산을 한 결과다. CNN은 이런 필터 값을 사람이 정하지 않고 데이터로 학습한다 — 그래서 학습된 첫 층 필터가 실제로 경계 검출기 모양이 된다(15p ‘모서리 · 직선’).

교안특징 맵과 필터 수 (25 · 26p)

필터는 이미지 위를 이동하며 입력 전체를 덮는다. 한 번 움직일 때마다 가중합이 계산되어 필터 중심 픽셀의 새 값이 정해지고, 이렇게 만든 이미지를 특징 맵(feature map) 또는 활성화 맵(activation map)이라고 한다. 합성곱층에는 필터가 하나 이상 있고, 필터 수만큼 특징 맵이 출력되므로 필터 수가 다음 층의 깊이를 결정한다.

from keras.layers import Conv2D
model.add(Conv2D(filters=16, kernel_size=2, strides=1, padding='same', activation='relu'))
# filters     : 합성곱 필터 수 → 출력의 깊이
# kernel_size : 커널(필터 행렬)의 크기
# strides     : 스트라이드   padding : 패딩 (10.6)
정정 · 주의 — 26p 코드는 strides='1'로 숫자를 따옴표로 감쌌다. 케라스의 strides는 정수(또는 정수 튜플)여야 하므로 문자열을 넣으면 오류가 난다. 위 코드는 strides=1로 고쳐 적었다.

보충설명CNN의 파라미터가 적은 진짜 이유 — 가중치 공유

3×3 필터 하나는 가중치 9개(+편향 1개)뿐인데, 이 같은 10개를 이미지의 모든 위치에서 재사용한다. 28×28이든 224×224든 필터 파라미터 수는 그대로다. Dense 층은 입력 칸마다 따로 가중치를 두는 것과 정반대다. 그래서 합성곱층의 파라미터 수는 이미지 크기와 무관하고 k\cdot k\cdot C_{in}\cdot C_{out}+C_{out}로만 정해진다 — 실습 TODO(5) conv_params가 이 식이고, 정답 README가 “위치(H · W)는 곱하지 않는다 — 가중치 공유의 핵심”이라고 짚는다. 같은 필터가 어디서든 같은 모양을 찾으므로, 숫자가 옆으로 옮겨 가도 같은 특징이 옮겨 간 자리에서 똑같이 검출된다(10.3 보충설명의 MLP 약점에 대한 답).

교안 슬라이드 모아보기 27 · 28 · 29 · 30 · 31 · 32p

교안커널 크기와 스트라이드 (27 · 28p)

  • 커널은 가중치가 담긴 행렬로, 입력 위를 이동하며 특징을 추출한다. 커널 크기는 필터의 너비 × 높이(3×3, 5×5 …)이고 합성곱층을 만들 때 필요한 파라미터 중 하나다
  • 직관적으로 필터가 작을수록 세세한 부분까지 잡아내고, 클수록 놓치는 세세한 부분이 많다
  • 스트라이드(stride) — 필터가 입력 위를 한 번에 이동하는 픽셀 수. 한 칸씩이면 1, 두 칸씩이면 2. (필터 개수를 정하는 것은 filters다 — 100문제의 오답 보기)

교안제로 패딩 (29p)

제로 패딩(zero-padding)은 이미지 둘레에 픽셀 값이 0인 추가 픽셀을 덧붙이는 것이다. 주목적은 합성곱을 거친 출력 이미지의 크기를 입력과 같게 유지하는 것이다. 패딩 값이 2면 둘레에 두 픽셀씩 덧붙인다(29p 그림: 4×4 이미지 → 8×8).

보충설명출력 크기 공식 — 커널 · 스트라이드 · 패딩을 한 줄로

n_{out}=\left\lfloor\frac{n+2p-k}{s}\right\rfloor+1\qquad(n:\text{입력 한 변},\;k:\text{커널},\;p:\text{패딩},\;s:\text{스트라이드})

실습 TODO(4) conv_out_size는 확장(dilation) d까지 넣은 일반형 \lfloor(n+2p-d(k-1)-1)/s\rfloor+1이고, d = 1이면 위 식과 같다.

경우계산출력
28, 3×3, 패딩 0, 스트라이드 1(28+0-3)/1+126 — 둘레 1칸씩 줄어든다(valid)
28, 3×3, 패딩 1, 스트라이드 1(28+2-3)/1+128 — 그대로(same) · 10.7의 ‘스트라이드 · 패딩 1’
28, 3×3, 패딩 1, 스트라이드 2\lfloor(28+2-3)/2\rfloor+114 — 스트라이드가 크기를 반으로
4, 최대 풀링 2×2, 스트라이드 2(4-2)/2+12 — 31p의 4×4 → 2×2
224, [3×3 same 두 번 + 풀링 2] × 4 (실습 SimpleCNN)224 → 112 → 56 → 28 → 1414 — 실습 3-2절 assert n == 14

패딩 없이 3×3을 쌓으면 층마다 둘레가 1칸씩 깎여, 깊게 쌓을수록 이미지가 빨리 사라지고 가장자리 픽셀이 계산에 덜 참여한다. 그래서 대부분의 CNN은 ‘same’ 패딩으로 크기를 지키고, 크기를 줄이는 일은 풀링(또는 스트라이드 2)에 맡긴다.

교안풀링층과 최대 풀링 (30~32p)

풀링(pooling)은 최대 · 평균 같은 통계 함수로 입력 크기를 줄여 다음 층에 넘긴다. 목적은 합성곱층이 만든 특징 맵을 다운샘플링해 계산 복잡도를 낮추는 것이고, 보통 합성곱층 사이에 끼워 넣는다.

최대 풀링(max pooling) — 앞 합성곱층의 특징 맵 위로 창을 옮기며 창 안의 최댓값을 출력 픽셀로 삼는다. 스트라이드 2인 2×2 풀링은 4×4를 2×2로 줄인다. 31p 예:

4×4 특징 맵을 2×2 창 네 개로 나누면창의 값최댓값
왼쪽 위1, 9, 5, 49
오른쪽 위6, 4, 7, 88
왼쪽 아래5, 1, 6, 77
오른쪽 아래2, 9, 6, 09

풀링을 쓰는 이유(32p) — 그대로 두면 신경망 전체의 파라미터가 어마어마하게 늘어나는데, 풀링층을 쓰면 중요한 특징을 잃지 않으면서 이미지 크기를 줄여 넘길 수 있다. 케라스: MaxPooling2D(pool_size=(2, 2), strides=2).

정정 · 주의 — ‘파라미터 수를 줄인다’의 정확한 뜻 — 풀링층 자체에는 학습할 가중치가 하나도 없다(10.7 summary에서 Param # 0). 줄어드는 것은 다음 층으로 넘어가는 특징 맵의 크기(값의 개수)이고, 그 결과 뒤에 오는 전결합층의 파라미터가 줄어든다. 예를 들어 10.7 모델에서 풀링을 모두 빼면 Flatten 출력이 7×7×64 = 3,136이 아니라 28×28×64 = 50,176이 되어, Dense(64)의 파라미터가 200,768에서 약 321만 개로 16배 늘어난다.

교안전결합층 — 분류는 결국 MLP가 한다 (36 · 37p)

추출한 특징으로 실제 분류를 하려면 MLP를 쓴다 — MLP는 분류에 효과적이기 때문이다. 구성은 ① (1, n) 1차원 벡터 입력(Flatten) ② 은닉층 하나 이상 ③ 출력층(활성화 함수 소프트맥스)이다. 37p 그림: 5×5×40 특징 맵을 1차원(1, 1000)으로 펴고 → 전결합층 64 → 소프트맥스 10개가 P_0\ldots P_9를 낸다.

교안케라스 CNN 모델과 summary (38~40p)

from keras.models import Sequential
from keras.layers import Conv2D, MaxPooling2D, Flatten, Dense, Dropout
model = Sequential()
model.add(Conv2D(32, kernel_size=(3, 3), strides=1, padding='same',
                 activation='relu', input_shape=(28, 28, 1)))   # input_shape 는 첫 층에만
model.add(MaxPooling2D(pool_size=(2, 2)))
model.add(Conv2D(64, (3, 3), strides=1, padding='same', activation='relu'))
model.add(MaxPooling2D(pool_size=(2, 2)))
model.add(Flatten())
model.add(Dense(64, activation='relu'))
model.add(Dense(10, activation='softmax'))
model.summary()

  • 합성곱층 · 풀링층의 출력은 (None, height, width, channels) 3차원 텐서다. channels = 출력의 깊이 = 특징 맵 수, 맨 앞 None은 한 번에 처리하는 이미지 수로, None이면 batch_size를 자유롭게 정할 수 있다
  • Output Shape를 보면 층이 거듭될수록 이미지 크기가 작아진다(28 → 14 → 7)
Param # 가 몰려 있는 곳 — 합성곱층이 아니라 전결합층이다 — 220,234개 중 200,768개(91%)가 Flatten 바로 뒤 Dense_1 한 층에 있다. 합성곱층 두 개는 합쳐도 18,816개뿐이다. 그래서 요즘 CNN은 Flatten + 큰 Dense 대신 전역 평균 풀링(GAP)으로 특징 맵을 채널마다 숫자 하나로 줄인 뒤 바로 출력층에 연결한다 — 실습 SimpleCNN의 AdaptiveAvgPool2d(1) → Flatten → Dropout → Linear(256, 4)가 그 방식이고, 정답 README는 이 헤드를 Flatten → Linear(256·14·14, 4)로 만들면 “파라미터가 200배로 늘고 입력 크기에 고정된다”고 감점한다.

보충설명컬러 이미지의 합성곱 — 학습 목표 ③

흑백 이미지는 깊이(채널) 1이지만 컬러 이미지는 R · G · B 세 장이 겹친 깊이 3이다. 이때 필터도 입력과 같은 깊이를 가져야 한다 — 3×3 필터는 사실 3×3×3 = 27칸짜리 정육면체다.

① 채널마다 따로 곱해 더한다R 채널 × 필터의 R 면, G × G 면, B × B 면 — 각각 10.5의 ‘곱해서 더하기’
② 세 결과를 다시 모두 더하고 편향을 더한다필터 하나가 특징 맵 한 장을 만든다(깊이 3 → 1)
③ 필터를 여러 개 두면필터 수만큼 특징 맵이 쌓인다 — 출력 깊이 = 필터 수(10.5)
\text{파라미터}=(k\cdot k\cdot C_{in}+1)\times C_{out}\qquad\text{예: 컬러 입력, 3×3 필터 32개}\;\Rightarrow\;(3\cdot3\cdot3+1)\times32=896

흑백이었던 CONV_1이 320개였던 것과 비교하면, 입력 채널이 3배가 된 만큼 필터의 깊이가 늘었다. 같은 원리로 CONV_2의 필터는 3×3×32짜리다 — 앞 층의 특징 맵 32장 전체를 한꺼번에 본다(그래서 18,496). 실습의 MRI는 원래 흑백이지만 .convert('RGB')로 3채널로 복제해 넣는다 — ImageNet으로 사전학습된 모델의 첫 층이 3채널 입력을 기대하기 때문이다.

공통 기초

MLP와 CNN은 학습 원리가 같다 — 무작위 초기화 → 순전파 → 손실 → 경사하강법. 다른 것은 층의 모양.

Flatten

28×28 → (1, 784), 행을 이어 붙인다. 파라미터 0. 입력층 노드 784개.

Dense 파라미터

\text{앞}\times\text{뒤}+\text{뒤}. 784·512+512 = 401,920 / 512·512+512 = 262,656 / 512·10+10 = 5,130 → 669,706.

MLP의 단점

① 파라미터가 너무 많다 ② 공간 정보 손실(이웃 픽셀 관계) → CNN.

CNN 구조

특징 추출(합성곱) / 분류(전결합) / 예측. 층마다 모서리 → 모양 → 부분. 크기 ↓ · 깊이 ↑.

합성곱

커널 = 가중치(무작위 초기화 → 학습). 수용 영역 × 필터를 칸끼리 곱해 합 → 특징 맵 한 칸. 예: −3.

크기 공식

\lfloor(n+2p-k)/s\rfloor+1. same 패딩(3×3이면 p = 1)은 크기 유지, 2×2 풀링 · 스트라이드 2는 절반.

풀링

최댓값 · 평균으로 다운샘플링. 깊이 유지 · 크기 축소, 자체 파라미터 0. 4×4 → 2×2.

케라스 CNN

28×28×1 → 28×28×32 → 14×14×32 → 14×14×64 → 7×7×64 → 3,136 → 64 → 10. 220,234. input_shape는 첫 층만.

Conv 파라미터

(k\cdot k\cdot C_{in}+1)\cdot C_{out} — 이미지 크기와 무관(가중치 공유). 320 · 18,496 · 컬러면 896.
