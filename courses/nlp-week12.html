12.1.1

순차 데이터교안 3~5p · 순서를 바꾸면 의미가 바뀐다

순차 데이터란 (교안 3p)

순차 데이터(Sequential data) = 관측 값이 순서(order)를 가지고 나열된 데이터. t번째 관측 값을 x(t)로, 전체를 x(1), x(2), …, x(T)로 쓴다(h(t)는 은닉 상태, y(t)는 출력의 표기다). 가장 큰 특징은 순서를 바꾸면 데이터의 의미 자체가 달라진다는 점이다. 텍스트(단어의 순차열) · 시계열(주가 · 센서 값) · 음성(파형)이 대표적이고, 자연어처리가 다루는 데이터는 대부분 순차 데이터다.

순차 데이터의 세 가지 특성 (교안 4p)

① 순서 의존성

“개가 사람을 물었다” vs “사람이 개를 물었다” — 단어 구성은 같은데 의미가 다르다. (BoW는 이 둘을 구분하지 못했다.)

② 가변 길이

어떤 문장은 3단어, 다른 문장은 40단어 → 입력의 크기를 고정할 수 없다.

③ 장기 의존성

현재 출력이 아주 먼 과거 입력에 의해 결정된다 — “프랑스에서 자란 그는 … 유창한 ( 프랑스어 ) 를 말한다”.

세 특성 목록에 없는 것 — ‘차원 불변성’ 같은 그럴듯한 이름이 오답 보기로 나온다. 교안의 세 가지는 순서 의존성 · 가변 길이 · 장기 의존성뿐이다.

기존 신경망(MLP)의 한계 (교안 5p)

  • 입력을 한 덩어리의 고정 길이 벡터로 밀어 넣어야 한다 → 순서 정보가 사라진다
  • 문장 길이가 달라지면 입력 노드 수가 달라져 같은 모형을 쓸 수 없다
  • 시점마다 별도의 가중치를 두면 파라미터 수가 시점 수에 비례해 폭증한다

RNN은 세 문제를 한꺼번에 푼다 — 한 시점씩 차례로 읽어 순서를 지키고(①), 같은 셀을 몇 번이든 반복해 길이에 상관없이 처리하며(②), 모든 시점이 같은 가중치를 공유해 파라미터가 늘지 않는다(③). 교안 32p의 생각해 볼 문제 ① “가중치를 시점마다 다르게 두면?”의 답이 바로 세 번째 줄이다.

12.1.2

RNN 구조 · 순전파교안 6~10p · 기억을 가진 신경망

핵심 아이디어 — 은닉 상태 (교안 6p)

순환 신경망(RNN, Recurrent Neural Network) — 순차 데이터를 처리하려고 설계된 구조. 핵심 아이디어는 이전 시점의 은닉 상태를 현재 시점의 입력과 함께 사용하는 것이다.
  • 은닉 상태(hidden state) h(t) — t 시점까지의 입력 x(1) … x(t)를 요약해 담고 있는 고정 크기 벡터
  • 매 시점 갱신되어 다음 시점으로 전달된다 → “기억(memory)”의 역할
  • 출력만 내보내는 MLP와 달리, RNN은 자기 자신에게도 값을 다시 흘려보낸다(순환 구조, folded)

순전파 수식 (교안 7 · 8p)

h(t)=\tanh\big(W_x\,x(t)+W_h\,h(t-1)+b\big),\qquad y(t)=\mathrm{softmax}\big(W_y\,h(t)+c\big)

W_x = 입력 → 은닉, W_h = 은닉 → 은닉(순환 가중치), b, c = 편향. 셀 안에서는 현재 입력과 직전 은닉 상태를 각각 선형 변환해 더한 뒤 tanh를 씌운다. tanh는 출력 범위를 (−1, 1)로 제한해 은닉 상태가 발산하지 않게 한다(합을 1로 만드는 건 softmax의 일).

초기 은닉 상태 — h(0)은 보통 영벡터로 둔다. 그러면 W_h\,h(0)=0이라 첫 시점의 은닉 상태는 x(1)만으로 결정된다.

펼친 구조와 가중치 공유 (교안 9p)

  • 순환 구조를 시간축으로 펼치면 시점 수만큼 층이 쌓인 깊은 신경망과 같아진다(그래서 12.1.4에서 ‘깊은 신경망의 기울기 문제’가 그대로 나타난다)
  • 가중치 공유(weight sharing) — 모든 시점이 동일한 W_x, W_h를 쓴다 → 문장 길이가 달라져도 같은 파라미터로 처리(가변 길이 대응)
  • 파라미터 수가 시점 수 T와 무관하게 일정하다 — 11주차 CNN의 ‘같은 커널을 모든 위치에’와 같은 발상을 시간축에 적용한 것이다

간단한 수치 예시 — 은닉 차원 1 (교안 10p)

W_x=0.5,\ W_h=0.8,\ b=0,\ h(0)=0, 입력 x=(1,1,0). 교안 표를 다시 계산해 확인했다.

tx(t)W_x·x(t) + W_h·h(t−1)h(t) = tanh(·)
11.00.5 × 1.0 + 0.8 × 0.000 = 0.5000.462
21.00.5 × 1.0 + 0.8 × 0.462 = 0.8700.701
30.00.5 × 0.0 + 0.8 × 0.701 = 0.5610.509
🔎 표에서 읽어야 할 두 가지 — ① t = 3에서 입력이 0인데 h(3)은 0이 아니다(0.509) → 과거 정보가 W_h\,h(2)=0.561을 통해 은닉 상태에 남아 있다. ② 같은 입력 1.0이 들어와도 h(1)=0.462, h(2)=0.701로 다르다 → 같은 단어라도 앞 문맥에 따라 표현이 달라진다. 함정 보기는 tanh를 씌우기 전 값(0.500 · 0.870 · 0.561)을 h로 내놓는다. 한 번 더 이어 x(4) = 0이면 0.8 × 0.509 = 0.407 → tanh = 0.386 — 입력이 끊기면 기억이 매 시점 약 0.8배씩 희석된다(12.1.4 장기 의존성의 씨앗).
12.1.3

입출력 구조 · RNN의 입력 만들기교안 11~13p

입력 · 출력 길이에 따른 네 가지 구조 (교안 11p)

구조무엇을대표 응용
one-to-many하나의 입력 → 순차열 출력이미지 캡셔닝
many-to-one순차열 입력 → 하나의 출력감정 분류, 스팸 판별
many-to-many (동기)매 시점 입력과 출력이 대응품사 태깅, 개체명 인식 (7주차)
many-to-many (비동기)입력을 모두 읽은 뒤 출력 생성기계 번역 → 12-2의 Seq2Seq
구조와 응용 짝 바꾸기 — “many-to-one : 이미지 캡셔닝”은 틀렸다. 캡셔닝은 이미지 하나에서 문장(순차열)을 만드는 one-to-many다. 동기와 비동기는 ‘출력이 입력과 같은 박자로 나오는가’로 가른다 — 품사 태깅은 단어마다 태그 하나(같은 길이), 번역은 다 읽고 나서 다른 길이로.

텍스트를 RNN 입력으로 (교안 12p)

토큰화문장을 단어 · 형태소로
단어 사전 구축단어마다 번호
정수 인코딩문장 → 정수 순차열
임베딩V × d 행렬에서 행 조회 → 밀집 벡터 (d ≪ V)

원-핫 벡터는 차원이 어휘 크기 V만큼 커지고 단어 간 유사도를 담지 못한다(11주차 원핫의 한계). 임베딩 층은 V × d 행렬을 학습해 각 단어를 밀집 벡터로 바꾼다(11주차 Embedding 계층).

패딩과 마스킹 (교안 13p)

  • 미니배치 학습을 위해 한 배치 안의 문장 길이를 같게 맞춰야 한다
  • 짧은 문장 뒤에 0(PAD)을 채워 최대 길이에 맞춘다(post-padding) → 입력은 (batch, timesteps, dim) 3차원 텐서
  • PAD 위치는 마스킹으로 연산에서 제외한다 → Keras에서는 Embedding(..., mask_zero=True)
🔎 왜 RNN에는 마스킹이 꼭 필요한가 — many-to-one RNN은 마지막 시점의 h(T)를 분류기로 넘긴다. post-padding된 짧은 리뷰(예: 실제 50단어, maxlen 200)는 뒤 150칸이 전부 PAD라, 마스킹이 없으면 RNN이 의미 없는 0을 150번 더 읽으며 기억을 희석시킨 뒤의 h(200)을 넘기게 된다. mask_zero=True면 Keras는 PAD 시점에서 은닉 상태를 갱신하지 않고 그대로 넘겨, 실제 마지막 단어의 은닉 상태가 분류기로 간다. 11주차 Text-CNN은 전역 최대 풀링이 위치와 무관해 pre-padding으로도 충분했던 것과 대비된다.
12.1.4

BPTT · 기울기 소실과 폭주교안 14~18p

시간을 거슬러 가는 역전파 BPTT (교안 14p)

BPTT(Backpropagation Through Time) = 펼친 구조에 통상적인 오차 역전파를 그대로 적용하는 방법. 전체 손실은 각 시점 손실의 합 L=L(1)+L(2)+\cdots+L(T)이고, 기울기가 시간 역방향으로 전파된다. W_h는 모든 시점에서 공유되므로 그 기울기는 모든 시점의 기여를 더해서 계산된다.

계산 비용과 잘라낸 BPTT (교안 15p)

  • 문장이 길어지면 펼친 층 수가 늘어 메모리 · 연산량이 함께 증가 — 역전파를 위해 T에 비례하는 순전파 결과를 저장해야 한다
  • 잘라낸 BPTT(Truncated BPTT) — 역전파 구간을 일정 길이 k로 잘라서 수행하고 순전파는 계속 이어 간다. 장점: 메모리 절약 · 학습 속도 향상 / 단점: k보다 먼 과거의 의존 관계는 학습되지 않는다
실무 관점 (15p) — 대부분의 프레임워크는 입력 순차열 길이만큼만 펼쳐서 학습한다. 따라서 maxlen(자를 문장 길이)이 곧 학습 가능한 의존 거리의 상한이 된다.

기울기 소실 · 폭주 (교안 16 · 17p)

\frac{\partial h(t)}{\partial h(t-k)}=\prod_{j=1}^{k}W_h^{\top}\,\mathrm{diag}\big(\tanh'(\cdot)\big)\quad\Rightarrow\quad\text{대략 }|W_h|^{k}\text{ 에 비례}

k 시점 이전으로 기울기를 보내려면 야코비 행렬을 k번 곱해야 한다. 같은 수를 반복해 곱하면 1보다 작을 땐 지수적으로 0으로, 1보다 클 땐 지수적으로 무한대로 간다.

경우무슨 일이증상대표 해결
|W_h| < 1기울기가 지수적으로 0에 수렴 = 기울기 소실먼 과거를 학습하지 못함게이트 구조 (LSTM, GRU)
|W_h| > 1기울기가 지수적으로 발산 = 기울기 폭주손실 발산 / NaN기울기 클리핑 (gradient clipping)

tanh의 미분값은 최대 1이고(z = 0에서), 포화 구간(|z|가 큰 곳)에서는 거의 0이다 → 곱해질수록 기울기를 더 작게 만드는 방향으로 작용한다. 그래서 RNN은 폭주보다 소실이 더 흔하다.

🔎 숫자로 보는 반복 곱 — tanh' = 0.9로 두면 한 시점마다 |W_h|\times0.9가 곱해진다. k = 10이면 |W_h| = 0.6 → 0.54¹⁰ = 0.0021, 0.9 → 0.81¹⁰ = 0.12, 1.3 → 1.17¹⁰ = 4.8. k = 50이면 각각 4 × 10⁻¹⁴, 2.6 × 10⁻⁵, 2.6 × 10³. 0.9배짜리 셀도 50단어 전에는 10만분의 1로 줄어든다 — 200단어 리뷰의 앞부분은 사실상 학습에 기여하지 못한다. 교안 16p 그래프 범례는 폭주 곡선을 |W_h| = 1.2로, 17p 본문은 1.3으로 그렸다 — 둘 다 ‘1보다 크면 폭주’의 예일 뿐이다.
클리핑은 소실을 못 고친다 — 기울기 클리핑은 \lVert g\rVert가 기준을 넘을 때만 크기를 줄인다. 너무 작은 기울기(소실)는 건드리지 않으므로 폭주만 해결한다. 소실은 게이트 구조로 완화한다(교안 32p 생각해 볼 문제 ②).

장기 의존성 문제 (교안 18p)

정답에 필요한 정보가 아주 먼 과거 입력에 있는 상황. 기본 RNN은 은닉 상태가 매 시점 tanh로 덮어써지면서 과거 정보가 희석된다. 실험적으로 대략 10 시점 이상(Bengio et al., 1994) 떨어진 의존 관계는 학습이 매우 어렵다. 교안 그림: ‘프랑스 에서 자란 그는 … (중략) … 유창한 ___ 를 말한다’ — 빈칸을 채우려면 맨 앞 ‘프랑스’를 기억해야 한다.

12.1.5

게이트와 LSTM교안 19~26p · 학습되는 정보 밸브와 덧셈 갱신

게이트의 아이디어 (교안 19p)

게이트(gate) = 정보를 “얼마나 통과시킬지”를 학습하는 밸브. 시그모이드 출력 g\in(0,1)을 정보 벡터에 원소별로 곱해 통과량을 조절한다 — g ≈ 0이면 차단, g ≈ 1이면 그대로 통과. 핵심은 게이트 값 자체도 학습되는 가중치로 결정된다는 점이다(현재 입력과 직전 은닉 상태를 보고 그때그때 밸브를 연다).

LSTM — 두 개의 상태와 세 개의 게이트 (교안 20p)

  • LSTM(Long Short-Term Memory) — Hochreiter & Schmidhuber (1997)가 제안한 게이트 기반 순환 구조. 망각 게이트는 Gers et al. (2000)이 추가해 오늘날의 3-게이트 표준 구조가 되었다
  • 셀 상태 C(t) = 장기 기억 — 컨베이어 벨트처럼 곧게 흐른다 / 은닉 상태 h(t) = 단기 기억 및 현재 시점의 출력
  • 세 게이트 — 망각 f(t) · 입력 i(t) · 출력 o(t) (리셋 · 업데이트는 GRU의 게이트다)

① 망각 게이트 (교안 21p)

f(t)=\sigma\big(W_f\cdot[h(t-1),\,x(t)]+b_f\big),\qquad f(t)\in(0,1)

직전 셀 상태 C(t-1)에서 무엇을 버릴지 결정한다. f(t)\odot C(t-1)로 원소별로 곱해 필요 없는 기억을 지운다 — 예: 새 주어가 나오면 이전 주어의 성 · 수 정보를 잊는다. [h(t-1),x(t)]는 두 벡터를 이어 붙인(concatenate) 것이다.

② 입력 게이트와 후보값 (교안 22p)

i(t)=\sigma\big(W_i\cdot[h(t-1),x(t)]+b_i\big),\qquad\tilde C(t)=\tanh\big(W_C\cdot[h(t-1),x(t)]+b_C\big)

현재 입력에서 무엇을 새로 저장할지. i(t)는 저장 비율이라 시그모이드(0~1), C̃(t)는 저장할 내용이라 tanh(−1~1)다. 실제로 셀에 더해지는 새 정보는 i(t)\odot\tilde C(t).

③ 셀 상태 갱신 — 덧셈 (교안 23p)

C(t)=\underbrace{f(t)\odot C(t-1)}_{\text{남길 과거 기억}}+\underbrace{i(t)\odot\tilde C(t)}_{\text{추가할 새 기억}}

곱이 아니라 덧셈으로 갱신된다는 점이 기울기 소실 완화의 핵심이다. 게이트를 상수로 본 직접 경로 기준 \partial C(t)/\partial C(t-1)\approx f(t)이므로 f(t) ≈ 1이면 기울기가 그대로 보존된다.

④ 출력 게이트 (교안 24p)

o(t)=\sigma\big(W_o\cdot[h(t-1),x(t)]+b_o\big),\qquad h(t)=o(t)\odot\tanh\big(C(t)\big)

갱신된 셀 상태 중 무엇을 이번 시점의 출력으로 내보낼지. 장기 기억 C(t)는 그대로 유지하면서 필요한 부분만 골라 h(t)로 낸다.

🔎 한 시점을 숫자로 — 스칼라 셀에서 C(t-1)=1.0, 게이트가 f = 0.9 · i = 0.2 · o = 0.8, 후보값 C̃ = 0.5로 나왔다고 하자. C(t)=0.9\times1.0+0.2\times0.5=0.9+0.1=1.0, h(t)=0.8\times\tanh(1.0)=0.8\times0.762=0.609. 기억(C)은 1.0 그대로 다음 시점으로 넘어가고, 바깥으로는 0.609만 내보낸다. 기본 RNN이었다면 매 시점 tanh(W_h·h + …)로 덮어써졌을 값이, LSTM에서는 ‘90% 남기고 10% 보태는’ 덧셈으로 이어진다.

LSTM 수식 정리 · 파라미터 수 (교안 25p)

구성 요소수식활성역할
망각 게이트f(t)=\sigma(W_f[h(t-1),x(t)]+b_f)σ과거 기억 삭제 비율
입력 게이트i(t)=\sigma(W_i[h(t-1),x(t)]+b_i)σ새 정보 저장 비율

게이트 3개 + 후보값 1개 = 선형 변환 4개 → 같은 은닉 차원의 기본 RNN 대비 약 4배. 입력(임베딩) d = 64, 은닉 u = 64면 SimpleRNN = 128 × 64 + 64 = 8,256, LSTM = 4 × 8,256 = 33,024로 정확히 4배다.

LSTM이 기울기 소실을 완화하는 이유 (교안 26p)

  • 셀 상태는 게이트를 통한 덧셈으로 갱신되므로 기울기가 곧게 흐른다(constant error carousel)
  • \partial C(t)/\partial C(t-1)=f(t) — 반복 곱해지는 항이 고정된 W_h가 아니라 학습되는 값 f(t)로 대체된다
  • 망각 게이트가 열려 있으면(f(t) ≈ 1) 먼 과거까지 기울기가 전달된다 — f = 0.99면 50시점 뒤에도 0.99⁵⁰ = 0.61, f = 0.95면 0.077이다(기본 RNN 0.81⁵⁰ = 2.6 × 10⁻⁵와 비교)
원리를 뒤집은 보기 — “셀 상태가 매 시점 tanh로 덮어써져 과거 정보를 새로 갱신하기 때문”은 기본 RNN의 문제점을 그대로 옮긴 오답이다. 교안 32p 생각해 볼 문제 ③(망각 게이트 편향 b_f를 크게 초기화하면?) — 학습 초기부터 f(t) ≈ 1이 되어 ‘기본값이 기억 유지’가 되므로, 기울기가 처음부터 먼 과거까지 흐른다. Keras LSTM의 unit_forget_bias=True(기본값)가 바로 b_f를 1로 초기화하는 설정이다.
12.1.6

GRU · RNN의 확장 · Keras 구현교안 27~32p

GRU (교안 27p)

  • GRU(Gated Recurrent Unit) — Cho et al. (2014)가 제안한 LSTM의 경량화 구조
  • 셀 상태를 없애고 은닉 상태 h(t) 하나만 유지 / 게이트를 2개로 축소 — 리셋 게이트 r(t), 업데이트 게이트 z(t)
h(t)=\big(1-z(t)\big)\odot h(t-1)+z(t)\odot\tilde h(t)

삭제와 추가를 한 게이트가 담당한다 — z와 1 − z가 짝이라, LSTM에서 망각 · 입력 두 게이트가 나눠 하던 일을 업데이트 게이트 하나가 한다. 리셋 게이트 r(t)는 후보값 \tilde h(t)=\tanh(W_hx(t)+U_h(r(t)\odot h(t-1))+b_h)을 만들 때 과거를 얼마나 쓸지 정한다.

z와 1 − z의 위치는 표기마다 반대다 — 교안 식은 Chung et al. (2014) 표기다. Keras · PyTorch 구현과 Cho et al. (2014) 원 논문은 h(t)=z\odot h(t-1)+(1-z)\odot\tilde h(t)로, z가 ‘과거를 남길 비율’이다. Keras로 직접 검증할 때는 Keras 표기를 따라야 결과가 일치한다. 어느 쪽이든 ‘한 게이트로 삭제와 추가를 함께 한다’는 뜻은 같다.

실험적 결론 — 데이터셋에 따라 LSTM과 GRU의 우열이 갈리므로 두 구조를 모두 시도하는 것이 일반적이다. 다만 둘 다 SimpleRNN보다는 대체로 우수하다.

RNN의 확장 — 심층 · 양방향 (교안 29p)

심층(다층) RNN

은닉층을 위로 쌓아 표현력을 높인다. Keras에서는 아래쪽 층에 return_sequences=True를 지정해 매 시점 출력을 위층에 넘긴다(기본값 False면 마지막 h(T) 하나만 나간다).

양방향(bidirectional) RNN

정방향 · 역방향 RNN을 함께 써서 현재 시점에서 과거와 미래 문맥을 모두 참조 → 품사 태깅 · 개체명 인식에 유리. 단, 미래 입력을 알 수 없는 실시간 생성 과제에는 쓸 수 없다(32p 문제 ④ — 실시간 음성 인식은 아직 오지 않은 소리를 볼 수 없다).

Keras 구현 (교안 30p)

from tensorflow.keras import Sequential
from tensorflow.keras.layers import Embedding, SimpleRNN, LSTM, Dense
model = Sequential([
    Embedding(input_dim=10001, output_dim=64, mask_zero=True),   # 교안 주석 : 0은 PAD 전용이므로 input_dim = 어휘 수 + 1
    LSTM(64),                                                    # SimpleRNN(64)으로 바꿔 비교
    Dense(1, activation='sigmoid'),                              # 이진 감정 분류
])
model.compile(optimizer='adam', loss='binary_crossentropy', metrics=['accuracy'])
input_dim은 ‘가장 큰 정수 인덱스 + 1’이다 — 교안은 10001을 쓰고 100문제(54번)는 10000을 쓴다. Keras IMDB를 num_words=10000으로 불러오면 0(PAD) · 1(시작) · 2(OOV)까지 포함해 인덱스가 0~9999이므로 10000이면 충분하다. 10001로 두어도 쓰이지 않는 행이 하나 생길 뿐 오류는 없다. 직접 만든 사전이 1~V 번호를 쓰고 0을 PAD로 비워 두었다면 그때 V + 1이 필요하다.

대화 시스템사용자 발화 → 응답 문장
음성 인식음성 파형 → 텍스트

12-1까지의 구조(many-to-one, 동기 many-to-many)는 입력 시점과 출력 시점이 대응되는 경우만 다뤘다 → 길이가 다른 문장을 생성하는 번역을 다루기 어려웠다. 9주차 기계번역의 신경망 번역(seq2seq)을 이번에 구조부터 본다.

응용 짝 바꾸기 — “대화 시스템 : 음성 파형 → 텍스트”는 음성 인식이다. 이미지 분류는 출력이 순차열이 아니므로 Seq2Seq 응용이 아니다.
12.2.2

인코더-디코더100문제 61~67번 기준

구조 — 두 개의 RNN을 이어 붙인다

인코더-디코더(Encoder-Decoder) 구조는 Sutskever et al. (2014)와 Cho et al. (2014)가 제안했다. 두 개의 RNN(보통 LSTM)을 이어 붙여, 인코더는 입력 순차열을 하나의 문맥 벡터로 압축하고 디코더는 그 벡터로 출력을 한 단어씩 생성한다.

  • 문맥 벡터 c — 인코더가 입력을 순서대로 읽으며 은닉 상태를 갱신하고, 마지막 시점의 은닉(과 셀) 상태를 입력 전체의 요약으로 쓴다: c=h(T)
  • 디코더 — 문맥 벡터를 초기 상태로 삼아, 직전 출력 단어를 입력으로 받으며 상태를 갱신하는 언어 모형: s(t)=\mathrm{LSTM}(y(t-1),s(t-1)),\ s(0)=c
  • 단어 예측 — P(y(t)\mid y(1..t-1),x)=\mathrm{softmax}(W\cdot s(t)+b)
  • <sos> = 디코더 첫 시점의 입력(생성 시작 신호), <eos> = 이것이 생성되면 문장 생성 종료
# 인코더의 마지막 상태를 디코더에 넘기는 Keras 방식 (100문제 64번)
enc_out, state_h, state_c = LSTM(units, return_state=True)(enc_emb)    # 마지막 은닉 · 셀 상태
dec_out = LSTM(units, return_sequences=True)(dec_emb,
                                             initial_state=[state_h, state_c])   # s(0) = c
return_state와 return_sequences — return_state=True는 마지막 은닉 · 셀 상태를 따로 돌려준다(문맥 벡터용). return_sequences=True는 모든 시점의 출력을 돌려준다(심층 RNN의 아래층, 그리고 12.2.5 어텐션에서 인코더 출력 전체가 필요할 때).
12.2.3

학습 · 디코딩100문제 68~74번 기준

Teacher forcing과 노출 편향

  • Teacher forcing(교사 강요) — 학습 시 디코더 입력으로 이전 시점의 ‘예측’ 대신 ‘정답’을 넣는다. 초반에 한 번 틀린 단어가 뒤를 다 망치지 않아 학습이 빠르고 안정적이며, 디코더 입력이 미리 확정되므로 한 번의 순전파로 전체 시점의 손실을 계산할 수 있다 — 다만 시점 축 자체의 병렬화는 Transformer에서 가능하다(RNN은 여전히 한 시점씩 계산)
  • 노출 편향(exposure bias) — 학습 때는 정답이 입력되지만 추론 때는 자기 예측을 입력해야 해 두 환경이 달라진다 → 한 번 틀리면 오류가 뒤로 누적된다. Teacher forcing의 대표적 부작용이다
  • Scheduled sampling — 학습 중 정답과 예측을 확률적으로 섞어 넣되, 학습이 진행될수록 예측 입력 비율을 높인다
장점과 부작용 바꾸기 — “teacher forcing으로 학습과 추론 환경이 완전히 같아져 노출 편향이 생기지 않는다”는 정반대다. 노출 편향의 원인이 teacher forcing이다.

디코딩 — 그리디와 빔 서치

그리디 디코딩

매 시점 확률이 가장 높은 단어 하나만 골라 이어 간다. 가장 단순하지만, 지금 1등인 단어가 문장 전체로는 최선이 아닐 수 있다.

빔 서치 (beam search)

상위 k개(beam size)의 후보 순차열을 함께 유지하며 확장하고, 누적 로그 확률로 후보를 평가한다. 필요하면 길이 정규화를 적용한다(9주차 디코딩 · 빔 탐색).

🔎 왜 로그 확률의 합인가 · 왜 길이 정규화인가 — 문장 확률은 단어 확률의 곱 \prod_t P(y_t\mid\cdot)이다. 0.5짜리 단어 20개만 곱해도 10⁻⁶이라 컴퓨터에서 아주 작은 수가 되므로, 로그를 씌워 \sum_t\log P(합)로 바꾼다. 그런데 로그 확률은 항상 음수라 단어가 많을수록 합이 더 작아진다 → 그대로 비교하면 짧은 문장이 유리하다. 그래서 길이로 나눠(길이 정규화) 공정하게 비교한다.
12.2.4

문맥 벡터 병목100문제 75~79번 기준

고정 길이 문맥 벡터의 병목

입력 문장의 길이와 무관하게 항상 같은 크기의 벡터 하나로 압축해야 한다 → 문장이 길어질수록 정보 손실이 커진다. 교안 그래프: 문맥 벡터 1개짜리 Seq2Seq는 원문이 길어질수록 BLEU가 급격히 떨어지지만, 주의 메커니즘을 더하면 길이에 강건하다(거의 평평).

기존 Seq2Seq의 문제내용
① 고정 길이 병목긴 문장도 벡터 하나에 담아야 한다
② 출력 시점과 무관한 같은 c“school”을 낼 때는 ‘학교’를, “go”를 낼 때는 ‘간다’를 봐야 하는데 디코더는 늘 같은 c만 쓴다
③ 장기 의존성문장 앞쪽 정보는 인코더 끝까지 가는 동안 희석된다(12.1.4)

해결 방향 — 문장 전체를 하나로 압축하지 말고, 인코더의 모든 시점 은닉 상태를 남겨 두고 출력 시점마다 필요한 것을 골라 쓴다 → 주의 메커니즘의 출발점.

해결책을 문제로 바꾼 보기 — “디코더가 시점마다 다른 문맥 벡터를 계산해 계산량이 폭증한다”는 기존 Seq2Seq의 문제가 아니라 주의 메커니즘의 특징이다(실제로 계산량은 12.2.6처럼 늘어난다).
12.2.5

주의 메커니즘100문제 80~89번 기준 · Bahdanau et al. (2015)

핵심 아이디어와 세 단계

주의 메커니즘(Attention mechanism)은 Bahdanau et al. (2015)가 기계 번역을 위해 제안했다(Vaswani et al. 2017은 Transformer). 디코더가 매 시점 인코더의 모든 은닉 상태를 다시 참조하되 관련도가 높은 곳에 큰 가중치를 주어, 시점마다 다른 문맥 벡터 c(t)를 만든다.

① 스코어 계산e(t,i)=\mathrm{score}(s(t),h(i)) — 디코더 상태와 각 인코더 상태의 관련도
② 정렬 가중치a(t,i)=\frac{\exp(e(t,i))}{\sum_j\exp(e(t,j))} — softmax라 모두 양수, \sum_i a(t,i)=1
③ 문맥 벡터c(t)=\sum_i a(t,i)\,h(i) — 인코더 상태의 가중합, 시점 t마다 다르다
④ 결합\tilde s(t)=\tanh(W[c(t);s(t)]) — 문맥 벡터와 디코더 상태를 이어 붙여 tanh
⑤ 예측\hat y(t)=\mathrm{softmax}(W_o\,\tilde s(t))

스코어 함수 세 가지

이름식특징
dots^{\top}h가장 단순, 추가 파라미터 없음 (Luong)
generals^{\top}Wh학습되는 W를 사이에 두어 인코더와 디코더 차원이 다를 때도 사용 (Luong)
concatv^{\top}\tanh(W[s;h])작은 신경망으로 관련도 계산 (Bahdanau, additive)

수치 예시 — 인코더 상태 셋

100문제 88 · 89번의 수치: 인코더 상태 h_1=(1,0),\ h_2=(0,1),\ h_3=(1,1), 스코어의 exp 값이 7.389 · 1.000 · 7.389 — 즉 스코어가 (2, 0, 2)다(dot이라면 디코더 상태 s = (2, 0)일 때 s·h = 2, 0, 2가 된다).

a=\frac{(7.389,\ 1.000,\ 7.389)}{15.778}=(0.468,\ 0.063,\ 0.468)
c=0.468(1,0)+0.063(0,1)+0.468(1,1)=(0.937,\ 0.532)

직접 계산해 확인했다(0.4683 + 0.4683 = 0.9366 → 0.937, 0.0634 + 0.4683 = 0.5317 → 0.532). 스코어가 0인 h₂도 가중치가 0이 아니라 0.063이다 — softmax는 어떤 칸도 완전히 0으로 만들지 않는다. 가중치 합 0.468 + 0.063 + 0.468 = 0.999는 반올림 탓이고 정확히는 1이다.

12.2.6

정렬 행렬 · Query-Key-Value · 확장100문제 90~100번 기준

정렬 행렬 히트맵 읽기

행 = 디코더 시점(출력 단어), 열 = 인코더 시점(원문 단어). softmax가 디코더 시점별로 적용되므로 각 행의 합은 1이고, 진한 칸일수록 높은 가중치다. 한국어 → 영어 예시 — I – 나는 0.82, school – 학교 0.80, go – 간다 0.75. 어순이 다른 두 언어에서 단어 대응이 대각선이 아니라 엇갈려 나타나는 것을 모형이 스스로 배운다(9주차 단어 정렬을 정답 없이 학습하는 셈).

Query · Key · Value와 scaled dot-product

역할Seq2Seq 어텐션에서비유
Query디코더 상태 s(t)찾는 쪽 — “지금 무엇이 필요한가”
Key인코더 상태 h(i)비교 대상 — 색인
Value인코더 상태 h(i)가져올 값 — 내용
\mathrm{Attention}(Q,K,V)=\mathrm{softmax}\!\left(\frac{QK^{\top}}{\sqrt d}\right)V

Q와 K의 내적을 차원의 제곱근 √d로 나눠 스케일한 뒤 softmax, 그 가중치로 V를 가중합한다. 차원이 크면 내적값이 커져 softmax가 한 칸에 쏠리므로(기울기가 거의 0) √d로 눌러 준다. 셀프 어텐션(self-attention) = Q, K, V를 모두 같은 문장에서 뽑는 경우 — Transformer의 핵심 구성 요소다.

score   = tf.matmul(query, enc_outputs, transpose_b=True)   # ① 스코어 (dot)
weights = tf.nn.softmax(score, axis=-1)                     # ② 정렬 가중치 (행마다 합 1)
context = tf.matmul(weights, enc_outputs)                   # ③ 문맥 벡터 (가중합)

Transformer — Vaswani et al. (2017), “Attention Is All You Need”. “RNN 없이 어텐션만 쓰면 어떨까”라는 질문에서 출발해 순환 구조를 제거하고 셀프 어텐션만으로 문맥을 학습 → 시점을 하나씩 기다릴 필요가 없어 완전한 병렬 처리가 가능해졌다(14주차).

계산량 방향 바꾸기 — “Attention을 더하면 계산량이 O(T + T′)로 줄어든다”는 틀렸다. 어텐션은 성능 · 해석을 얻는 대신 계산량을 O(T × T′)로 늘린다.
