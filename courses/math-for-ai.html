선형변환Linear Transformation · 7.1 선형변환 / 7.2 부분공간과 계수

선형변환은 벡터공간 사이의 구조를 보존하는 함수 L: V→W다. 핵심 조건은 두 가지 — 덧셈 보존, 스칼라배 보존. 이를 만족하면 행렬 A로 표현할 수 있고, 그 행렬을 표준행렬이라 한다.

변환을 거치면 공간이 어떻게 바뀌는지가 7.2의 주제다.열공간 Col(A): Ax 꼴로 나타낼 수 있는 모든 벡터의 집합 → 치역(image)영공간 Nul(A): Ax=0의 해 집합 → 핵(kernel)계수(rank) = dim Col(A), 퇴화차수(nullity) = dim Nul(A). 이 둘의 합 = n (열 개수)

기말에서 증명으로 출제되는 핵심: L(x)=Ax는 선형변환임을 보이는 것. 덧셈·스칼라배 각각 보존됨을 보이면 끝.

핵심 개념

선형변환 조건
① L(u+v) = L(u)+L(v)   ② L(cu) = cL(u). 동치: L(cu+dv) = cL(u)+dL(v)
표준행렬
L(eᵢ)를 열벡터로 하는 행렬 A. L(x) = Ax로 표현됨.
열공간 Col(A)
{ y | y = Ax, x∈ℝⁿ }. RREF에서 pivot열에 해당하는 원래 A의 열벡터들이 기저.
영공간 Nul(A)
{ x | Ax=0 }. RREF → free variable에 1/0 대입해 기저 추출.
계수 정리
rank(A) + nullity(A) = n (A의 열 개수)
직교연산자
‖L(x)‖ = ‖x‖ ↔ AᵀA = I (열벡터가 정규직교). 내적 보존.

주요 정리 ★★ 기말 증명 출제

정리 · L(x) = Ax는 선형변환이다
m×n 실수행렬 A와 ℝⁿ의 벡터 x에 대하여, 사상 L(x) = Ax는 ℝⁿ에서 ℝᵐ으로의 선형변환이다.
증명: 임의의 u, v∈ℝⁿ, 스칼라 c에 대해
① L(u+v) = A(u+v) = Au + Av = L(u)+L(v) ✓
② L(cu) = A(cu) = c(Au) = cL(u) ✓
따라서 L은 선형변환이다. ∎
정리 7-5 · 가역 선형변환은 전단사
선형변환 L: V→W이 가역 선형변환이면 L은 전단사(bijection)이다.
정리 7-15 · 퇴화차수 0 → 가역행렬
n×n 행렬 A의 퇴화차수(nullity)가 0이면, A의 모든 열벡터가 선형독립이고 A는 가역행렬이다.
정리 7-22 · 행렬 곱의 계수
rank(AB) ≤ min(rank(A), rank(B)). 가역행렬 B, C에 대해 rank(BAC) = rank(A).

열공간 · 영공간 기저 구하는 법 ★★ 반드시

1A를 RREF(행 축소)로 변환
2열공간: pivot열 위치 확인 → 원래 A에서 그 열벡터 가져옴 (RREF 열벡터 쓰면 틀림)
3영공간: RREF를 Ax=0 연립방정식으로 읽기 → pivot variable을 free variable로 표현
4free variable 하나씩 1로, 나머지 0으로 놓아 기저 벡터 추출 (free 개수 = 기저 벡터 개수)

고윳값과 고유벡터Eigenvalues & Eigenvectors · PCA

행렬 A를 곱해도 방향이 변하지 않고 크기만 바뀌는 벡터가 고유벡터, 그 배율이 고윳값이다: Av = λv.

계산 순서: det(λI−A)=0으로 특성방정식 → λ 구하기 → 각 λ에 대해 (λI−A)x=0 풀어 고유벡터 구하기.

기말 응용 파트인 PCA는 여기서 나온다. 공분산행렬 C의 최대 고윳값에 대응하는 고유벡터가 주성분 방향이다.

핵심 개념

고유벡터/고윳값
Av = λv (v ≠ 0). v: 고유벡터, λ: 고윳값. (λI−A)v=0의 비자명해.
특성방정식
det(λI−A) = 0. n차 다항식 → 복소수 범위에서 n개의 근(고윳값) 존재.
고유공간
고윳값 λ에 대한 고유벡터 전체 집합 + {0}. = Nul(λI−A).
대각행렬 고윳값
삼각행렬·대각행렬의 고윳값 = 주대각 원소들.

고윳값/고유벡터 계산 순서 ★★ 반드시

1det(λI−A) = 0 세우기 (특성방정식)
2λ에 대해 풀기 → 고윳값 λ₁, λ₂, … 구하기
3각 λᵢ에 대해 (λᵢI−A)x = 0 풀기 → 고유벡터(고유공간 기저)

주요 정리

정리 8-5 · 서로 다른 고윳값의 고유벡터는 선형독립
정방행렬 A의 서로 다른 r개의 고윳값 λ₁, λ₂, …, λᵣ에 대한 고유벡터 v₁, v₂, …, vᵣ은 선형독립이다.

PCA — 주성분 분석 ★★ 반드시

1데이터 평균 μ 계산
2중심화: 각 xᵢ − μ
3공분산행렬: C = (1/n) Σ(xᵢ−μ)(xᵢ−μ)ᵀ
4C의 고윳값 구하기: det(λI−C) = 0
5최대 고윳값 λ₁에 대응하는 고유벡터 → 정규화 → 주성분 벡터
PCA 핵심: 1차원 축소 시 λ₁(최대)에 대응하는 단위 고유벡터 하나만 쓴다. λ₂(=0)인 고유벡터는 버림.

직교기저 · QR분해 · 최소제곱해Orthogonality · QR Decomposition · Least Squares

직교(수직)는 내적이 0인 관계다. 기저가 직교이면 계산이 극도로 단순해진다. Gram-Schmidt 과정으로 임의 기저를 직교정규기저로 바꾸고, 이를 활용하면 QR 분해(A = QR)를 얻는다.

Ax = b의 해가 존재하지 않을 때 → 정규방정식 AᵀAx̂ = Aᵀb로 최소제곱해를 구한다. 이것이 선형회귀의 수학적 토대다.

직교 관련 개념

직교
u·v = 0 ↔ 벡터 u, v 직교. 직교집합: 모든 쌍이 직교.
정규직교
직교 + 각 벡터의 노름=1. UᵀU = I.
정사영
projᵥu = (u·v / v·v) v. v 방향으로 u를 투영한 벡터.
직교보공간
Col(A) ⊥ Nul(Aᵀ), Row(A) ⊥ Nul(A)

Gram-Schmidt & QR분해 ★★ 반드시

Gram-Schmidt — 직교화
u₁ = a₁ u₂ = a₂ − a₂·u₁u₁·u₁ u₁ u₃ = a₃ − a₃·u₁u₁·u₁ u₁ − a₃·u₂u₂·u₂ u₂
투영 = (내적/노름²) × 벡터. 암산 가능해도 과정 전부 기재 필수.
정규화 → Q
qᵢ = uᵢ / ‖uᵢ‖  →  Q = [q₁ | q₂ | q₃]
R = QᵀA
R은 상삼각행렬. 대각원소 = ‖uᵢ‖ A = QR

선형회귀 — 정규방정식 ★★ 반드시

행렬 세우기 (y = β₀ + β₁x)
데이터 (x₁,y₁), …, (xₙ,yₙ) → A = [1 x₁; 1 x₂; …], b = [y₁; y₂; …] 1열은 전부 1 (β₀ 계수), 2열은 x값 (β₁ 계수)
정규방정식 (외워야 함)
AᵀA β = Aᵀb β = (AᵀA)⁻¹ Aᵀb
두 점 지나는 직선으로 풀면 0점 — 반드시 정규방정식 과정 기재

대각화 · 대칭행렬Diagonalization · Symmetric Matrix · Quadratic Form

행렬 A를 A = SΛS⁻¹로 분해하는 것이 대각화다. Λ는 고윳값 대각행렬, S는 고유벡터 행렬.

대칭행렬(A = Aᵀ)은 특별하다. 반드시 직교대각화 가능하고 — S를 직교행렬 P로 잡으면 A = PΛPᵀ. 기말 증명에서 자주 나오는 두 성질: ①서로 다른 고윳값의 고유벡터는 직교, ②A와 Aᵀ의 고윳값은 동일.

대각화

대각화 가능 조건
n개의 선형독립인 고유벡터 존재 ↔ 각 고윳값의 대수적 중복도 = 기하적 중복도
A = SΛS⁻¹
S: 고유벡터를 열로 하는 행렬, Λ: 고윳값 대각행렬. Aᵏ = SΛᵏS⁻¹
닮음행렬
B = S⁻¹AS. 닮음행렬은 같은 고윳값, 같은 행렬식, 같은 trace를 가짐.

주요 정리 ★★ 기말 증명 출제

정리 10-10 · 대칭행렬 — 다른 고윳값 → 고유벡터 직교
대칭행렬 A에서 서로 다른 고윳값에 대응하는 고유벡터는 서로 직교한다.
증명: λ₁≠λ₂, Av₁=λ₁v₁, Av₂=λ₂v₂라 하자.
λ₁(v₁·v₂) = (Av₁)·v₂ = v₁ᵀAᵀv₂ = v₁ᵀAv₂ = v₁·(Av₂) = λ₂(v₁·v₂)
(λ₁−λ₂)(v₁·v₂) = 0. λ₁≠λ₂이므로 v₁·v₂ = 0. ∎
정리 10-12/13 · 대칭행렬 ↔ 직교대각화 가능
n×n 대칭행렬이다 ⟺ 직교대각화 가능 행렬이다 ⟺ n개의 직교하는 고유벡터를 갖는다.
따라서 A = PΛPᵀ (P: 직교행렬)
정리 · A와 Aᵀ의 고윳값은 동일 ★★ 반드시
행렬 A와 전치행렬 Aᵀ의 고윳값은 동일하다.
증명: det(λI−A) = det((λI−A)ᵀ) = det(λI−Aᵀ)
따라서 A와 Aᵀ의 특성방정식이 동일 → 고윳값 동일. ∎
정리 10-16 · 대칭행렬의 스펙트럼 분해
A = λ₁x₁x₁ᵀ + λ₂x₂x₂ᵀ + … + λₙxₙxₙᵀ (xᵢ: 단위 직교 고유벡터)
정리 10-17 · 대칭행렬의 계수
대칭행렬 A의 rank = A의 0이 아닌 고윳값 개수

이차형식 & 정부호

이차형식
Q(x) = xᵀAx (A: 대칭행렬). 고윳값으로 정부호 판별.
양의 정부호
모든 x≠0에 xᵀAx > 0 ↔ 모든 고윳값 > 0
양의 준정부호
xᵀAx ≥ 0 ↔ 모든 고윳값 ≥ 0. AᵀA는 항상 양의 준정부호.

특잇값 분해 (SVD)Singular Value Decomposition

대각화는 정방행렬만 가능하다. SVD는 임의의 m×n 행렬 A를 A = UΣVᵀ로 분해한다. U는 AAᵀ의 고유벡터(좌특이벡터), V는 AᵀA의 고유벡터(우특이벡터), Σ는 특잇값(σᵢ=√λᵢ) 대각행렬.

기말 7번 증명과 직결: AᵀA의 고유벡터 {vᵢ}에 A를 곱하면 {Avᵢ}는 직교집합이고 ‖Avᵢ‖=√λᵢ — 이것이 SVD의 핵심 근거다.

SVD 구조

A = UΣVᵀ
U: m×m 직교행렬(좌특이벡터), Σ: m×n 직사각대각(특잇값), V: n×n 직교행렬(우특이벡터)
특잇값 σᵢ
σᵢ = √λᵢ (AᵀA의 고윳값). σ₁ ≥ σ₂ ≥ … ≥ σᵣ > 0
V
AᵀA의 고유벡터 (단위, 직교). AᵀA vᵢ = λᵢvᵢ
U (r개)
uᵢ = Avᵢ/σᵢ. 나머지 u는 직교보공간에서 확장.
rank(A)
A의 0이 아닌 특잇값 개수 = rank(AᵀA)

SVD 계산 순서 ★★ 반드시

1AᵀA 계산
2AᵀA의 고윳값 λᵢ, 단위 고유벡터 vᵢ 구하기 → V 구성
3σᵢ = √λᵢ → Σ 구성
4uᵢ = Avᵢ/σᵢ (i=1,…,r) → 나머지 u는 직교 벡터로 확장 → U 구성
5A = UΣVᵀ 표현

핵심 정리 — 기말 7번 증명 ★★ 반드시

정리 · {Avᵢ}는 직교집합이고 ‖Avᵢ‖ = √λᵢ
AᵀA의 고윳값 λᵢ와 ‖vᵢ‖=1인 고유벡터 vᵢ에 대해, {Av₁, Av₂, …, Avₙ}은 직교집합이고 ‖Avᵢ‖ = √λᵢ이다.
① 직교: (Avᵢ)ᵀ(Avⱼ) = vᵢᵀAᵀAvⱼ = vᵢᵀ(λⱼvⱼ) = λⱼ(vᵢᵀvⱼ)
AᵀA 대칭 → 서로 다른 고윳값의 고유벡터 직교 → vᵢᵀvⱼ=0 → (Avᵢ)ᵀ(Avⱼ)=0 ∎

② 노름: ‖Avᵢ‖² = (Avᵢ)ᵀ(Avᵢ) = vᵢᵀAᵀAvᵢ = vᵢᵀ(λᵢvᵢ) = λᵢ(vᵢᵀvᵢ) = λᵢ
vᵢ는 단위벡터(‖vᵢ‖=1) → vᵢᵀvᵢ=1 → ‖Avᵢ‖ = √λᵢ ∎

낮은 계수 근사 (데이터 압축)

rank-k 근사
A ≈ Aₖ = σ₁u₁v₁ᵀ + σ₂u₂v₂ᵀ + … + σₖuₖvₖᵀ
k가 작을수록 압축률 ↑, 정보손실 ↑. σᵢ가 클수록 중요한 성분.

나사 불량 확률 (복원 / 비복원) ★★ 100% 출제

복원추출
꺼낸 후 되돌림 → 독립 → P(A∩B) = P(A)×P(B)
예: (3/10)×(3/10) = 9/100 = 0.09
비복원추출
꺼낸 후 제외 → 조건부확률 → P(A∩B) = P(A)×P(B|A)
예: (3/10)×(2/9) = 6/90 = 1/15 ≈ 0.067

균등분포 밀도함수 ★★ 100% 출제

(a) k 구하기
f(x) = k  (a≤x≤b),   0 elsewhere ∫ f(x)dx = 1  →  k(b−a) = 1  →  k = 1b−a
(b) 확률 — 겹치는 구간만
P(c≤X≤d) = k × (겹치는 구간 길이) f(x)=0인 구간은 제외, 정의역과 겹치는 부분만
예: f(x)=1/10 (−4~6), P(−7≤X≤2) → 겹침 [−4, 2] → (1/10)×6 = 0.6

정규분포 불량률 (tolerance limits) ★★ 100% 출제

표준화 공식
X ~ N(μ, σ²)  →  Z = X − μσ ~ N(0,1) P(a≤X≤b) = Φ( b−μσ ) − Φ( a−μσ ) Φ(−z) = 1 − Φ(z)
(a) 범위 → 불량률
허용 μ±c → 정상품률 = P(μ−c≤X≤μ+c) = 2Φ(c/σ) − 1 불량률 = 1 − (2Φ(c/σ) − 1) = 2(1 − Φ(c/σ))
예: μ=100, σ=1, c=0.44 → Φ(0.44)=0.6700 → 정상품 34% → 불량 66%
(b) 불량률 → 범위 역산
불량 α% → 정상 (1−α)% → 2Φ(c/σ)−1 = 1−α Φ(c/σ) = 2−α2 → 표에서 z값 → c = z × σ
예: 불량 66% → Φ(c)=0.67 → 표에서 c=0.44 → 범위 100±0.44
정규분포 표 읽는 법: 행 = z의 소수점 첫째 자리, 열 = 소수점 둘째 자리. Φ(z) = P(Z≤z). 항상 표가 제공됨.
