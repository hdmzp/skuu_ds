GOAL

교과목 목표The goal of the course

  • 계산적 방법으로 실제 문제 해결 — 컴퓨터 비전의 계산 기법으로 현실 세계의 문제를 푼다
  • 이론에서 프로젝트로 — 컴퓨터 비전의 이론과 기법을 배우고 실제 연구 프로젝트(과제)에 적용한다
  • SOTA 연구 이해의 기초 — 전통적인 비전 이론·방법론 학습을 통해 최신 연구를 이해할 기본기를 갖춘다
Computer Vision이란? 인간 시각 시스템의 복잡한 처리 과정을 컴퓨터에 적용하여, 사람의 뇌가 하는 것과 같은 방식으로 영상·비디오 속 객체를 인식하고 처리하게 하는 컴퓨터과학 분야.
대표 응용 — Image classification · Localization · Instance segmentation · Object identification · Object generation
