자카드 유사도\dfrac{|A\cap B|}{|A\cup B|}5
TF-IDF (시험 기준 · sklearn)TF_{\text{원시 빈도}} \times \left[\log\dfrac{1+N}{1+DF} + 1\right]5
TF-IDF (6주차 판 · 비교용)TF_{\text{상대 빈도}} \times \left[\log\dfrac{N}{1+DF} + 1\right]6
F1 점수\dfrac{2PR}{P+R}5 · 7
바이그램 확률\dfrac{C(w_{-1},w)}{C(w_{-1})}7
라플라스 스무딩\dfrac{C+1}{C(w_{-1})+V}7
ROUGE-N(참조와 겹치는 n-gram 수) / (참조의 n-gram 수)6
시험 출제는 5주차 · sklearn 식 — 6주차 식은 비교용이다. 일반 교재의 \log(N/DF)와도 다르다. 끝의 +1이 없으면 모든 문서에 나오는 단어(DF = N)의 IDF가 0이 되어 TF-IDF가 통째로 사라지므로, +1로 최솟값을 1로 유지한다.

예상 문제 (1) — 계산교안 23p · 시험 포인트 예제 포함 · 눌러서 답 보기

문제 1문서 3개 중 단어 t가 2개 문서에 등장한다. sklearn 기본식으로 IDF(t)를 구하시오.
\log\dfrac{1+3}{1+2} + 1 = \log\dfrac{4}{3} + 1 \approx 1.288 (자연로그)
문제 2|A| = 10, |B| = 8, |A∩B| = 4일 때 자카드 유사도는?
합집합은 |A|+|B|-|A\cap B| = 10+8-4 = 14이므로 4/14 \approx 0.286. 교집합을 두 번 빼거나 아예 안 빼는 실수가 잦다.
문제 3C(‘나는’) = 6, C(‘나는’,‘밥을’) = 3일 때 P(밥을 | 나는)은?
MLE: 3/6 = 0.5. 라플라스(V = 100)이면 (3+1)/(6+100) = 4/106 \approx 0.038.
문제 4TP = 30, FP = 10, FN = 20일 때 정밀도 · 재현율 · F1은?
P = 30/40 = 0.75,\; R = 30/50 = 0.60,\; F1 = \dfrac{2(0.75)(0.6)}{1.35} \approx 0.667
편집 거리kitten → sitting의 Levenshtein 거리는?
k→s 대체 1 · e→i 대체 1 · g 삽입 1 → 3. 인접 문자 전치(transposition)까지 허용하면 Damerau-Levenshtein이고, teh → the는 전치 1회라 거리 1이다.
ROUGE-L참조 ‘the cat is on the mat’, 후보 ‘the cat sat on mat’의 ROUGE-L P · R · F1은?
LCS = ‘the cat on mat’(길이 4, 연속일 필요는 없고 순서만 유지). R = 4/6 = 0.667,\; P = 4/5 = 0.800,\; F1 \approx 0.727

예상 문제 (2) — 서술교안 24p · 답의 뼈대는 교안 요약 슬라이드에서

문제 5불용어 제거를 품사 태깅보다 먼저 하면 어떤 문제가 생기나? (오류 전파 포함)
품사 태거는 주변 단어를 문맥으로 쓰는데, 불용어를 먼저 지우면 문맥이 깨져 태깅이 틀어진다. 그 오류는 품사 정보를 쓰는 표제어 추출 같은 뒤 단계로 그대로 전파된다. 그래서 표준 순서는 정제 → 정규화 → 토큰화 → 품사 태깅 → 불용어 제거 → 표제어 추출이다. 3주차
문제 6원-핫 인코딩과 분산 표현의 차이를 유사도 계산 관점에서 설명하시오.
원-핫은 모든 단어 벡터가 서로 직교해 어떤 두 단어의 코사인 유사도도 0이다. 분산 표현은 예측/공기 통계로 학습한 밀집 벡터라 비슷한 문맥의 단어끼리 유사도가 높게 나온다. 다만 정적 임베딩은 다의어를 한 벡터로 뭉갠다. 5주차
문제 7BIO 태깅이 필요한 이유 두 가지 이상과 예문 태깅
① 여러 토큰에 걸친 개체를 하나로 묶고 ② 연속된 두 개체의 경계를 구분하기 위해. 예: New/B-LOC York/I-LOC City/I-LOC is/O big/O. 태그 수는 2N+1. 7주차 7.1.4
문제 8N-gram에서 N을 키울 때의 장단점 (희소성 관점)
장점은 더 긴 문맥을 반영한다는 것. 단점은 경우의 수가 V^N으로 늘어 대부분의 n-gram이 관측되지 않는다(희소성)는 것이다. 미관측 n-gram이 하나라도 있으면 MLE의 PPL은 무한대가 되므로 스무딩 · 보간 · 백오프가 필요하다. 7주차 7.2.4
문제 9TextRank가 단순 빈도 요약보다 나은 점 (PageRank의 재귀성)
PageRank의 핵심은 링크 개수가 아니라 “중요한 노드가 가리키면 더 중요해진다”는 재귀성이다. 문장을 노드, 유사도를 에지로 두면 다른 중요한 문장들과 많이 닮은 문장이 높은 점수를 받는다. 고른 문장은 점수 순이 아니라 원문 순서로 배열한다. 6주차
문제 10정밀도와 재현율이 상충하는 사례와 우선할 지표
스팸 필터는 정상 메일을 스팸으로 버리는 오탐 비용이 커서 정밀도를, 질병 · 위험 탐지는 놓치는 누락 비용이 커서 재현율을 우선한다. 불균형 데이터에서는 둘의 조화평균인 F1을 기본으로 보고, 다중 분류에서는 매크로/마이크로 F1을 구분한다.

자주 틀리는 지점 ①~⑨교안 26~27p

⚠ 여기서 갈린다
  • ① IDF 공식 — 교재의 \log(N/DF)가 아니라 sklearn 기본식 \log\frac{1+N}{1+DF}+1이 기준
  • ② 자카드 합집합 — |A\cup B| = |A|+|B|-|A\cap B|
  • ③ 불용어 목록 맹신 — NLTK 영어 불용어는 179개이고 ‘one’은 없다. 감성 분석에서 not · no · never를 지우면 의미가 뒤집힌다. BERT 같은 사전학습 모델에서는 보통 지우지 않는다
  • ④ 전처리 순서 — 품사 태깅 전에 불용어를 지우면 태깅이 틀어지고 오류가 전파된다
  • ⑤ 의존 에지 방향 — 지배소(head) → 의존소(dependent)
  • ⑥ GloVe의 분류 — Word2Vec · FastText는 예측 기반, GloVe는 전역 공기 행렬을 분해하는 카운트 기반
  • ⑦ 어간 추출 결과 — Porter는 규칙만 적용해 ‘battling → battl’ 같은 비단어가 나온다. 정확한 기본형은 품사를 준 표제어 추출(‘was’ + v → ‘be’)
  • ⑧ 관용 표현 — ‘미역국을 먹다’는 복합어가 아니라 관용구
  • ⑨ 관형사 — 이 · 그 · 새 · 헌은 한국어 고유 품사인 관형사. 영어 ‘old’는 형용사의 한정적 용법
