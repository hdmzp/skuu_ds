01

Python 자료형List · Tuple · Dictionary

  • List [ … ] — 순서대로 저장하고 요소를 수정할 수 있다 (mutable). append(x) · remove(x) · pop() · pop(i)
  • Tuple ( … ) — 읽을 수는 있지만 요소 수정은 불가능(immutable). 변수에 새 튜플을 다시 할당하는 것은 가능하다
  • Dictionary {'key': value} — key로 접근하는 mutable 자료형 (list·tuple은 index로 접근)
  • 인덱싱 & 슬라이싱 — index는 0부터. list[i]는 i번째 값, list[start:end]는 start ~ (end−1)번째 값
02

NumPy와 이미지스칼라 · 벡터 · 행렬 · 텐서

  • 실제 이미지는 3차원 텐서 — (Height, Width, Channel[RGB]) 형태로 표현된다
  • 배열 만들기 — np.zeros, np.ones, np.arange, np.full, np.random.rand / randint / randn
  • 좌표 주의 — 이미지를 열면 0번째 차원이 Y축, 1번째 차원이 X축이다
  • 영역 지정(마스킹) — Region = Image[y1:y2, x1:x2]. 예) Image[0:50, 100:200] = 0 은 해당 영역을 검은색으로 만든다
  • 연산 — array 간 연산은 같은 위치의 원소끼리 수행되며 shape이 일치해야 한다 (아니면 에러)
  • 축 기준 함수 — np.sum, np.mean 등은 axis 로 방향을 지정한다
  • 형태 변환 — reshape(요소 개수 유지, -1은 자동 계산), transpose(axes)로 축 재배열
03

OpenCV 기초입출력 · 변환 · 필터링 · 에지 검출

이미지 입출력
  • cv2.imread() 로 읽고 cv2.imwrite('filename', image) 로 저장한다 (경로를 정확히 써야 동작)
  • 채널 순서 — matplotlib은 R-G-B, OpenCV는 B-G-R. cv2.cvtColor(img, cv2.COLOR_BGR2RGB) 로 변환
  • cv2.imshow 에는 채널 변환을 하지 않는다 (BGR을 그대로 쓰므로). plt.imshow 를 쓸 때만 변환한다
과제 감점 주의 — matplotlib으로 결과를 표시할 때 BGR → RGB 변환을 하지 않으면 감점이라고 자료에 명시되어 있습니다.
이미지 변환 (Transformations)
  • 이진화 — grayscale로 읽은 뒤(cv2.IMREAD_GRAYSCALE) threshold 기준으로 흑/백 분리
  • 크기 변경 — cv2.resize(img, dsize, fx, fy, interpolation). 축소는 INTER_AREA, 확대는 INTER_CUBIC 권장
  • 이동 · 회전 — Affine 변환 행렬 생성 후 cv2.warpAffine, 회전 행렬은 cv2.getRotationMatrix2D(center, angle, scale)
  • Affine / Perspective — 대응점 3개면 cv2.getAffineTransform, 4개면 Perspective 변환
필터링과 에지 검출
  • 블러 — cv2.blur · cv2.GaussianBlur · cv2.medianBlur(윈도우 안의 중간값)
  • 커스텀 커널 — cv2.filter2D(img, ddepth, kernel) 로 직접 만든 커널 적용 (ddepth −1이면 입력과 동일)
  • Sobel — cv2.Sobel() 로 방향별 그래디언트 기반 에지 검출
  • Canny — ① Gaussian으로 노이즈 제거 → ② gradient 계산(크기·방향) → ③ Non-maximum Suppression → ④ 이중 임계값 판정의 multi-stage 알고리즘
