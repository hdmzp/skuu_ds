인덱싱 & 슬라이싱실시간 수업 첫 주제 — 이미지 자르기가 전부 여기서 나온다

규칙 두 가지
  • Index는 0부터 시작한다 — list[i] 는 i번째 요소
  • 슬라이싱 list[start:end] 는 start부터 (end−1)까지 — 끝 번호는 포함하지 않는다
더 알아 두면 편한 것 
a = [0, 1, 2, 3, 4, 5]
a[2:5]    # [2, 3, 4]      end는 미포함
a[:3]     # [0, 1, 2]      start 생략 → 0부터
a[3:]     # [3, 4, 5]      end 생략 → 끝까지
a[-1]     # 5              음수는 뒤에서부터
a[-3:]    # [3, 4, 5]      뒤에서 3개
a[::2]    # [0, 2, 4]      step 2칸씩
a[::-1]   # [5, 4, 3, 2, 1, 0]  뒤집기
문자열도 똑같이 동작한다 — 'vision'[1:4] → 'isi'
03

NumPy 배열벡터·행렬 연산에 편리한 기능을 제공하는 라이브러리

NumPy는 ndarray라는 자료형을 제공한다. Pandas · OpenCV · PyTorch가 모두 이것을 기반으로 하므로, 이미지를 다룬다는 것은 결국 NumPy 배열을 다룬다는 뜻이다.
배열 만들기 
import numpy as np

np.zeros((2, 3))            # 0으로 채운 2×3
np.ones((2, 3))             # 1로 채운 2×3
np.full((2, 3), 7)          # 7로 채운 2×3
np.arange(10)               # [0 1 2 ... 9]
np.random.rand(2, 3)        # 0~1 균등분포 난수
np.random.randint(0, 256, (2, 3))   # 0~255 정수 난수 (화소값 흉내)
np.random.randn(2, 3)       # 표준정규분포 난수
배열의 정보 
a = np.arange(24).reshape(2, 3, 4)
a.ndim      # 3      차원 수 = 대괄호 겹친 개수
a.shape     # (2, 3, 4)   각 차원의 요소 수
a.size      # 24     전체 요소 개수
a.dtype     # int64  자료형 (이미지는 보통 uint8)
shape은 각 차원에 요소가 몇 개인지, axis(축)는 계산 방향을 가리킨다.
연산과 축(axis)
  • 배열끼리의 사칙연산은 같은 위치의 원소끼리 수행된다 — 그래서 shape이 맞지 않으면 에러가 난다
  • np.sum, np.mean 등은 axis로 방향을 지정한다 — axis=0은 세로(행 방향)로 합치고, axis=1은 가로(열 방향)로 합친다
m = np.array([[1, 2, 3],
              [4, 5, 6]])
m.sum()          # 21      전체 합
m.sum(axis=0)    # [5 7 9]  열끼리 합 (위아래로)
m.sum(axis=1)    # [6 15]   행끼리 합 (좌우로)

reshape vs transpose수업 중 나온 질문 — "그럼 둘의 차이가 뭐임?"

한 문장으로 — 핵심 차이는 메모리 상 데이터를 어떻게 재해석하느냐다. NumPy가 값을 저장하는 방식

np.reshape틀만 바꾼다

array의 차원을 변경한다. 단, reshape 이전과 이후의 요소 개수는 같아야 한다.
요소들의 나열 순서는 그대로 두고 담는 틀(shape)만 바꾼다. 종이를 접는 방식만 바꾸는 것.

np.transpose배치를 뒤집는다

shape의 축(axis) 자체를 서로 맞바꾼다 → 요소들의 실제 위치(짝)가 바뀐다. 내용물의 배치 자체를 뒤집는 것.

교안의 같은 배열로 비교하기

무엇이 달라졌나
  • reshape(4, 3, 2) — 값이 0, 1, 2, 3, 4 … 순서 그대로 다시 끊어 담겼다. 이웃한 값끼리 계속 붙어 있다
  • transpose(2, 1, 0) — 0과 12가 새로 짝이 되었다. 원래 가장 바깥 축(2개) 이 가장 안쪽으로 가면서 값의 짝이 완전히 새로 맺혔다
  • 둘 다 결과 shape은 요소 24개짜리지만, 안에 든 순서가 다르다 — reshape로는 transpose 결과를 절대 만들 수 없다
a = np.array([[1, 2, 3],
              [4, 5, 6]])          # shape (2, 3)

a.reshape(3, 2)      # [[1,2],[3,4],[5,6]]   순서 그대로 3×2로 접기
a.T                  # [[1,4],[2,5],[3,6]]   1과 4가 새로 짝지어짐
np.transpose(a)      # 위와 같음
이미지에서 왜 중요한가 — OpenCV·matplotlib은 이미지를 (H, W, C)로 다루지만 PyTorch는 (C, H, W)를 쓴다. 채널 축을 실제로 다른 위치로 옮겨야 하므로 반드시 transpose를 써야 한다. 
img = cv2.imread('cat.jpg')          # (H, W, 3)
tensor = img.transpose(2, 0, 1)      # (3, H, W)  PyTorch 입력 형태
# img.reshape(3, H, W) 로 하면 값이 뒤죽박죽 섞여 이미지가 깨진다
덧붙임 — reshape(4, -1) 처럼 −1을 쓰면 나머지 크기를 자동으로 계산해 준다 (전체 개수가 맞아떨어질 때만). 또 reshape·transpose는 대부분 view(뷰)라서 결과를 수정하면 원본도 함께 바뀔 수 있다. 안전하게 떼어 내려면 .copy()를 쓴다.

05

이미지 = 3차원 텐서Scalar · Vector · Matrix · Tensor

실제 이미지는 3차원 텐서로 표현된다 — (image_height, image_width, 3)
  • 0번째 차원 = 세로(Y축, 높이) · 1번째 차원 = 가로(X축, 너비) · 2번째 차원 = 채널(Channel, RGB)
  • 값의 자료형은 보통 uint8 — 0(어두움) ~ 255(밝음)
좌표 순서가 수학과 반대다 — 우리가 흔히 쓰는 (x, y)와 달리, 배열 인덱스는 img[y, x] 순서다. PIL·OpenCV로 이미지를 열었을 때 왼쪽 위가 (0, 0)이고 아래로 갈수록 y가 커진다. 이것을 헷갈리면 원하는 곳과 가로세로가 뒤바뀐 영역을 자르게 된다.

슬라이싱으로 영역 지정 = 마스킹

Region = Image[y1:y2, x1:x2] — 앞이 세로 범위, 뒤가 가로 범위다. 
image[0:50, 100:200] = 0
# 세로 0~50, 가로 100~200 픽셀을 검은색(0,0,0)으로 만든다
# 아래와 같은 뜻: image[0:50, 100:200, :] = [0, 0, 0]
활용 — 이 한 줄이 Masking, ROI 잘라내기, 이미지 위에 사각형 채우기, 이미지 합성의 기본이 된다. 필요한 부분만 잘라 처리하면 계산량도 줄어든다.

OpenCV의 BGR 채널 순서과제 감점 1순위 — 반드시 기억할 것

OpenCV(cv2)는 Open Source Computer Vision 라이브러리로 C·C++·Java·Python에서 쓸 수 있고, warping · filtering · binarize · edge detect · pattern recognition · ROI 처리를 제공한다. Python에서는 NumPy + OpenCV 조합이 강력하다.
핵심 차이 — matplotlib은 R-G-B, OpenCV는 B-G-R 순서로 채널을 다룬다. 그래서 cv2.imread로 불러온 이미지를 matplotlib으로 띄우면 이미지 색이 다르게 나온다 (파란 것이 빨갛게, 노란 눈이 파랗게).

cv2.cvtColor — 색공간 변환

dst = cv2.cvtColor(src, code)
src
입력 이미지 (NumPy 배열)
code
cv2.COLOR_BGR2RGB · cv2.COLOR_BGR2GRAY · cv2.COLOR_RGB2BGR 등
반환
변환된 새 이미지 (원본은 그대로)
img = cv2.imread('cat.jpg')                       # BGR로 읽힌다
img_rgb = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)    # matplotlib용으로 변환
plt.imshow(img_rgb)
과제 감점 주의 — 나중에 과제로 출제되며, 미적용 시 감점이라고 교안에 명시되어 있습니다. matplotlib으로 결과를 제출할 때는 반드시 BGR → RGB 변환을 거칠 것.

이미지 이진화Image Binarization — 쉽게 말하면 흑백 변환

1

기준값(threshold) 적용

grayscale 이미지에 기준값을 적용해, 그보다 밝으면 흰색(255) 어두우면 검정(0)으로 만든다 → 이진 이미지

cv2.threshold — 전역 이진화

ret, dst = cv2.threshold(src, thresh, maxval, type)

grayscale 이미지 (1채널)
thresh
기준값. 예제에서는 127
maxval
기준을 넘었을 때 부여할 값. 보통 255
type
THRESH_BINARY · THRESH_BINARY_INV(반전) · THRESH_TRUNC · THRESH_TOZERO
한계
이미지 전체에 하나의 기준을 쓰므로, 조명이 한쪽만 밝으면 그쪽이 통째로 뭉개진다

cv2.adaptiveThreshold — 적응형 이진화

dst = cv2.adaptiveThreshold(src, maxval, adaptiveMethod, thresholdType, blockSize, C)
adaptiveMethod
ADAPTIVE_THRESH_MEAN_C(주변 평균) · ADAPTIVE_THRESH_GAUSSIAN_C(가우시안 가중평균)
blockSize
기준값을 계산할 이웃 영역의 한 변 크기. 홀수여야 한다 (예제 15)
C
계산된 평균에서 빼 줄 상수. 값을 키우면 결과가 더 어두워진다 (예제 2)
결과 읽는 법 — 같은 고양이 사진인데도 Global(전역) 은 밝은 부분이 통째로 날아가 형체가 뭉개졌고, Mean · Gaussian(적응형) 은 털의 결까지 살아 있다. 조명이 고르지 않은 사진에서는 적응형이 유리하다는 것을 보여 주는 예다.

기하 변환Image Transformations — 2주차 교안의 변환 이론을 코드로

여기서 쓰는 행렬들이 바로 2주차 교안의 강체 · 유사 · 아핀 · 투영 변환이다. 이론에서 본 2×3 / 3×3 행렬을 cv2.warpAffine · cv2.warpPerspective에 그대로 넣는 것이 실습의 전부다.

① 크기 변경 — cv2.resize

dst = cv2.resize(src, dsize, fx, fy, interpolation)
dsize
결과 크기 (width, height). 배수로 지정할 때는 None 을 넣고 fx·fy를 쓴다
fx, fy
가로·세로 배율 (0.5면 절반, 2면 두 배)
interpolation
보간(interpolation) 방법 — 축소는 cv2.INTER_AREA, 확대는 cv2.INTER_CUBIC 권장
주의
dsize는 (width, height) 순서인데 img.shape는 (height, width) 순서다 — 서로 반대

② 이동(Translation) — cv2.warpAffine

교안의 평행이동 행렬을 그대로 np.float32 배열로 만들어 넣는다. 마지막 열이 이동량 (tx, ty)다.
10tx01ty
dst = cv2.warpAffine(src, M, dsize)
M
2×3 아핀 행렬 (np.float32). 3행짜리를 넣으면 에러가 난다
dsize
출력 캔버스 크기 (width, height). 작게 주면 밀려난 부분이 잘려 나간다
빈 영역
이동해서 생긴 빈 자리는 기본적으로 검은색(0)으로 채워진다
height, width = img.shape[:2]
M = np.float32([[1, 0, 100],
                [0, 1, 200]])          # x로 100, y로 200 이동
dst = cv2.warpAffine(img, M, (width, height))

③ 회전(Rotation) — cv2.getRotationMatrix2D

M = cv2.getRotationMatrix2D(center, angle, scale)
center
어디를 잡고 돌릴지 — 회전의 중심점 (x, y). 보통 이미지 중앙 (width/2, height/2)
angle
회전 각도(도 단위). 양수가 반시계 방향
scale
회전과 동시에 적용할 배율. 예제의 0.8은 조금 축소하면서 돌린다는 뜻 — 교안의 유사 변환(similarity) 그 자체다
반환
2×3 행렬 → 그대로 warpAffine에 넣는다
주의
회전하면 모서리가 캔버스 밖으로 나간다. 다 담으려면 dsize를 키우거나 회전 후 크기를 다시 계산해야 한다

④ 아핀 변환 — 3개의 대응점을 활용

M = cv2.getAffineTransform(pts1, pts2)
pts1 / pts2
변환 전 / 후의 대응점 3쌍 (np.float32, shape (3, 2))
왜 3개인가
아핀 변환의 자유도가 6이고 대응점 한 쌍이 식 2개를 주므로 3쌍이면 정확히 결정된다
성질
변환 후에도 평행선은 평행하게 유지된다

⑤ 원근 변환 — 4개의 대응점

M = cv2.getPerspectiveTransform(pts1, pts2) dst = cv2.warpPerspective(src, M, dsize)
pts1 / pts2
대응점 4쌍. 교안은 좌상 → 좌하 → 우상 → 우하 순서로 찍는다 (순서가 뒤섞이면 이미지가 꼬인다)
M
3×3 원근(투영) 행렬 — 자유도 8이라 4쌍이 필요하다
활용
비스듬히 찍은 문서·표지판을 정면으로 펴는 보정(문서 스캔), 도로를 위에서 본 것처럼 바꾸는 bird's-eye view
교안 코드의 cv2.circle — 어떤 점을 잡았는지 눈으로 확인하려고 대응점 위치에 원을 그려 표시한 것이다. cv2.circle(img, center, radius, color, thickness) 에서 thickness에 −1을 주면 속이 채워진 원이 된다.
10

이미지 필터링Image Filtering — 블러와 커스텀 커널

컨볼루션(convolution) — 필터링은 커널(kernel)을 이미지 위에 올려 두고, 겹친 화소들과 커널 값을 곱해 더한 값을 그 자리의 새 화소로 삼는 연산이다. 커널 값을 무엇으로 두느냐에 따라 흐려지기도 하고, 에지가 뽑히기도 한다.

기본 블러 3종

cv2.blur(src, ksize) cv2.GaussianBlur(src, ksize, sigmaX) cv2.medianBlur(src, ksize)
blur
단순 평균 — ksize는 (7, 7)처럼 튜플
GaussianBlur
가우시안 가중평균. sigmaX=0이면 ksize로부터 자동 계산
medianBlur
중간값 필터 — ksize는 정수 홀수 (예: 9). 점 노이즈 제거에 강하다
공통
커널이 클수록 더 많이 흐려진다. 크기는 홀수로 주는 것이 원칙

cv2.filter2D — 직접 만든 커널 적용

dst = cv2.filter2D(src, ddepth, kernel)
ddepth
출력 자료형(depth) — −1이면 입력과 동일하게 맞춘다
kernel
NumPy 배열. 값의 합이 1이면 밝기가 유지되고, 합이 0이면 에지만 남는다
3×3 전부 1인 커널을 9로 나누면 주변 9칸의 평균이 되어 cv2.blur와 같은 효과가 난다. 
kernel = np.ones((3, 3)) / 9.
dst = cv2.filter2D(img, -1, kernel)    # -1은 입력·출력 크기(자료형) 맞추기
11

에지 검출Edge Detection — 밝기가 급격히 변하는 곳 찾기

에지란 — 이웃 화소와의 밝기 차이(그래디언트)가 큰 지점이다. 물체의 경계, 도로의 차선처럼 의미 있는 구조가 대부분 여기에 있어서 컴퓨터비전의 출발점이 된다.

① 커스텀 커널로 방향별 에지 뽑기

커널을 읽는 법 — [[-1,0,1], [-1,0,1], [-1,0,1]] 은 오른쪽 값에서 왼쪽 값을 빼는 모양이다. 좌우 밝기가 같으면 0(검정), 급격히 달라지면 큰 값(밝음) → 세로선(수직 에지)이 뽑힌다. 행/열을 뒤집은 [[-1,-1,-1], [0,0,0], [1,1,1]] 은 위아래를 비교하므로 가로선이 뽑힌다. 두 결과를 더하면 모든 방향의 윤곽이 남는다. 커널 값의 합이 0이라 평평한 영역은 자연히 검게 된다.

② cv2.Sobel — 미분 + 평활화

dst = cv2.Sobel(src, ddepth, dx, dy, ksize)
dx, dy
미분할 방향과 차수. (1, 0)이면 x방향(세로선 검출), (0, 1)이면 y방향(가로선 검출)
ksize
커널 크기(홀수). 클수록 두껍고 부드러운 에지
특징
Sobel 커널 — 미분과 평활화를 함께 하므로 단순 차분보다 노이즈에 강하다
주의
ddepth=-1(uint8)로 두면 음수 그래디언트가 0으로 잘린다. 정확히 보려면 cv2.CV_64F로 받고 np.absolute 후 uint8로 되돌린다

③ cv2.Canny — 가장 널리 쓰는 에지 검출

edges = cv2.Canny(src, threshold1, threshold2)
동작
multi-stage 알고리즘 — ① Gaussian 필터로 노이즈 제거 → ② 그래디언트 크기·방향 계산 → ③ Non-maximum Suppression로 선을 얇게 → ④ 이중 임계값 히스테리시스 판정
threshold1/2
낮은 값 / 높은 값. 예제는 100, 200. 대략 1:2 ~ 1:3 비율을 권장
입력
보통 grayscale을 넣는다. 결과는 에지가 흰색(255)인 1채널 이미지
12

활용 — 자율주행 차선 인식수업에서 강조된 대표 응용

edge 추출은 자율주행 분야에서 많이 쓰인다. 아스팔트에서 흰색 선을 추출해서 차선을 인식하는 경우가 많다. 아스팔트(어두움)와 차선(밝음)의 밝기 차가 크기 때문에 에지 검출이 특히 잘 통하는 문제다.
1

grayscale + 블러

색은 필요 없으니 1채널로 바꾸고, GaussianBlur로 노면의 잔 노이즈를 지운다

2

Canny 에지

차선의 경계만 흰 선으로 남긴다

3

ROI(관심 영역) 지정

하늘·건물은 필요 없으므로 도로가 있는 아래쪽 사다리꼴만 마스킹으로 남긴다 — 앞에서 배운 슬라이싱·마스킹이 여기 쓰인다

4

허프 변환(Hough Transform)로 직선 찾기

cv2.HoughLinesP로 남은 에지 점들에서 긴 직선을 뽑아 좌·우 차선으로 정리한다

gray  = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
blur  = cv2.GaussianBlur(gray, (5, 5), 0)
edges = cv2.Canny(blur, 50, 150)

mask = np.zeros_like(edges)                      # ROI 마스크
h, w = edges.shape
roi = np.array([[(0, h), (w // 2, h // 2), (w, h)]], np.int32)
cv2.fillPoly(mask, roi, 255)
cropped = cv2.bitwise_and(edges, mask)           # 관심 영역만 남기기

lines = cv2.HoughLinesP(cropped, 1, np.pi / 180, 50,
                        minLineLength=40, maxLineGap=20)
