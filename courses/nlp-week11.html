11.1

딥러닝과 NLP교안 4~6p · 특징 공학에서 표현 학습으로

자연어처리 방법론의 세 시대 (교안 4p)

시대방식한계 · 변화
규칙 기반
1950~1980년대		언어학자가 문법 규칙과 사전을 직접 작성규칙 수가 폭발적으로 늘어나고 예외 처리가 불가능
통계 기반
1990~2000년대		말뭉치에서 확률을 추정 — n-gram, HMM, CRF사람이 설계한 특징(feature)에 성능이 좌우됨
신경망 기반
2010년대~		표현과 분류를 데이터로부터 함께 학습특징 공학의 부담이 사라지고, 대규모 말뭉치를 그대로 활용

지금까지 배운 것을 이 표에 놓아 보면 — 7주차의 n-gram 언어 모델 · CRF 개체명 인식, 10주차의 TF-IDF + 로지스틱 회귀가 모두 통계 기반이다. TF-IDF 피처를 고르고 n-gram 범위를 정하는 일이 바로 ‘사람이 설계한 특징’이다.

특징 공학에서 표현 학습으로 (교안 5p)

딥러닝은 원시 데이터로부터 과제에 유용한 표현을 스스로 찾아낸다. 사람은 ‘어떤 특징을 뽑을까’ 대신 ‘어떤 구조로 학습시킬까’를 고민하게 된다.

딥러닝이 가져온 네 가지 변화 (교안 6p)

① 이산 기호(단어)를 연속 벡터로단어 사이의 의미적 거리를 계산할 수 있다 → 11.4 · 11.9
② 사람의 주석 없이도 학습대량의 말뭉치를 비지도 학습으로 활용 → word2vec
③ 하나의 표현을 여러 과제에 재사용사전학습(pre-training)과 전이 학습
④ 하나의 범용 구조로 수렴문제별 모델이 아니라 하나의 구조 → 오늘날의 대규모 언어모델

이번 주는 ①과 ②를 담당하는 word2vec, 그리고 특징 추출기로서의 합성곱 신경망을 배운다.

④를 뒤집은 보기에 주의 — “과제마다 특화된 별도 모델이 점점 늘어남”은 네 가지 변화가 아니다. 실제 흐름은 정반대로, 번역 · 분류 · 질의응답을 각각의 모델로 풀던 것이 하나의 범용 구조(Transformer → LLM)로 모였다.
11.2

신경망 기초교안 7~13p · 퍼셉트론 → 순전파 → 손실 → 역전파

퍼셉트론과 다층 퍼셉트론 (교안 7p)

y=f(w_1x_1+w_2x_2+\cdots+w_nx_n+b)

퍼셉트론 = 입력의 가중합에 활성화 함수 f를 적용해 출력하는 계산 단위. 신경망의 기본 벽돌이다.

  • 단층 퍼셉트론은 선형 결정 경계만 만들 수 있어 XOR 문제를 풀 수 없다 — (0,0)→0, (1,1)→0, (0,1)→1, (1,0)→1은 직선 하나로 나눌 수 없다
  • 은닉층을 추가하면(다층 퍼셉트론, MLP) 비선형 결정 경계를 표현할 수 있다
  • 은닉층이 2개 이상으로 깊어진 신경망을 심층 신경망(deep neural network)이라 한다

심층 신경망의 구조 (교안 8p)

입력층 → 은닉층(여러 개) → 출력층으로 구성되고, 인접한 층은 가중치로 연결된다. 교안 그림은 각 층의 연산을 한 줄로 적는다.

h=f(xW+b)\qquad(f:\ \text{활성화 함수})

층마다 가중치 W_1,b_1 · W_2,b_2 · W_3,b_3가 따로 있다. 입력 4개 · 은닉 5개 · 은닉 5개 · 출력 2개인 교안 그림이라면 W_1은 4×5, W_2는 5×5, W_3은 5×2 행렬이다.

왜 깊게 쌓는가 · 그 대가 (교안 9p)

얻는 것
  • 층이 깊어질수록 점점 더 추상적인 표현을 계층적으로 학습 — 문자 → 형태소/단어 → 구(phrase) → 문장의 의미
  • 같은 표현력을 얻는 데 필요한 뉴런 수가 얕은 신경망보다 훨씬 적다 = 파라미터 효율이 높다
  • 다만 표현력이 커지는 만큼 과적합 위험도 커져 규제가 필요하다(11.3)
치르는 대가
  • 경사가 소실 · 폭주하기 쉽다
  • 학습에 더 많은 데이터와 연산이 필요하다
  • 완화 기법이 함께 발전 — ReLU, 정규화, 규제, Adam

순전파 계산 예시 (교안 10p)

순전파(forward propagation)는 입력에서 출력 방향으로 행렬곱과 활성화 함수를 번갈아 적용하는 과정이다. 교안의 숫자를 그대로 따라가 보자.

x  = [1.0, 2.0]
W1 = [[0.5, -0.3],      b1 = [0.1, 0.0]
      [0.2,  0.8]]
# 은닉층 : z1 = x·W1 + b1
z1 = [0.5×1 + 0.2×2 + 0.1,  -0.3×1 + 0.8×2 + 0.0] = [1.0, 1.3]
h  = ReLU(z1) = [1.0, 1.3]          # 둘 다 양수라 그대로
# 출력층 : z2 = h·W2 + b2  ->  y_hat = softmax(z2)
🔎 출력층까지 마저 계산해 보기 — 교안은 W_2를 주지 않았다. 계산을 끝까지 보려고 W_2 = 단위행렬, b_2=0이라고 가정하면 z_2=[1.0,\,1.3]이고
\hat y=\mathrm{softmax}(z_2)=\left[\tfrac{e^{1.0}}{e^{1.0}+e^{1.3}},\ \tfrac{e^{1.3}}{e^{1.0}+e^{1.3}}\right]=[0.426,\ 0.574]
정답이 두 번째 클래스라면 교차 엔트로피 손실은 -\ln 0.574=0.554다. 열 계산 순서를 헷갈리면 안 된다 — x\cdot W_1의 첫 칸은 W1의 첫 번째 열(0.5, 0.2)과 x의 내적이다. 행(0.5, −0.3)과 곱하면 0.5 − 0.6 + 0.1 = 0.0이 되어 틀린 보기가 된다.

활성화 함수 (교안 11p)

활성화 함수가 없다면 층을 쌓아도 하나의 선형 변환과 같아진다 — (xW_1)W_2=x(W_1W_2)이므로 두 층이 행렬 하나 W_1W_2로 합쳐진다.

함수식출력 범위특징
Sigmoid\sigma(z)=\frac{1}{1+e^{-z}}0 ~ 1양 끝에서 기울기가 0에 가까워 경사 소실. 이진 분류 출력층에 쓴다
Tanh\tanh z−1 ~ 10을 중심으로 대칭이지만 역시 양 끝에서 포화
ReLU\max(0,z)0 ~ ∞양수 구간 기울기가 항상 1 → 경사 소실이 적고 계산이 빠르다 → 은닉층 기본

손실 함수와 소프트맥스 (교안 12p)

과제손실 함수식
회귀평균제곱오차 (MSE)L=\frac1N\sum(y-\hat y)^2
이진 분류이진 교차 엔트로피L=-[\,y\log\hat y+(1-y)\log(1-\hat y)\,]
다중 분류소프트맥스 + 교차 엔트로피L=-\sum_k y_k\log\hat y_k
\hat y_k=\frac{\exp(z_k)}{\sum_j\exp(z_j)}

소프트맥스는 출력 점수를 합이 1인 확률로 바꾼다. 단어를 예측하는 word2vec의 출력층도 어휘 크기 V의 소프트맥스를 쓴다 — 이것이 11.8에서 병목이 된다. 원핫 정답에서는 y_k가 정답 위치만 1이므로 교차 엔트로피는 -\log\hat y_{\text{정답}} 한 항만 남는다.

역전파와 경사하강법 (교안 13p)

W\leftarrow W-\eta\cdot\frac{\partial L}{\partial W}\qquad(\eta:\ \text{학습률})

역전파(backpropagation)는 연쇄법칙으로 각 가중치의 기울기를 출력층에서 입력층 방향으로 계산한다. 기울기가 손실이 커지는 방향이므로 그 반대로 \eta만큼 움직인다.

🔎 학습 한 바퀴 = 네 단계 — 교안 59p 요약 그대로, 순전파 → 손실 계산 → 역전파 → 경사하강법 갱신의 반복이 학습의 본질이다. 실습 1의 train_cbow 루프가 정확히 이 네 줄이다: loss = model.forward(...) → model.backward() → remove_duplicate → optimizer.update(...). 소프트맥스 + 교차 엔트로피의 역전파는 놀랍게도 \hat y-y(예측 − 정답) 한 줄이다 — 실습의 SoftmaxWithLoss.backward가 dx[np.arange(N), t] -= 1로 이것을 구현한다.

학습률 (교안 14p)

왜 벡터가 필요한가 · 단어집 (교안 18p)

신경망은 실수 벡터만 입력으로 받는다 — 문자열을 숫자로 바꿔야 한다. 첫 단계는 학습 말뭉치의 단어를 모아 단어집(vocabulary)을 만들고 고유 번호를 붙이는 것이다. 보통 등장 빈도순으로 정렬하고, 희귀 단어는 <UNK> 하나로 묶는다. 실습 2의 imdb.load_data(num_words=10000)가 바로 ‘빈도 상위 10,000단어만 남기고 나머지는 <UNK>(번호 2)’다.

원핫 인코딩과 두 가지 한계 (교안 18 · 19p)

원핫 인코딩 — 단어집 크기 V와 같은 길이의 벡터에서 자기 번호 위치만 1, 나머지는 0. ["사과", "딸기", "바나나", "배"]이면 사과 = [1,0,0,0], 딸기 = [0,1,0,0].

① 차원의 저주

어휘가 수십만 개면 벡터 차원도 수십만 → 계산 · 메모리 낭비. 대부분이 0인 희소 벡터다.

② 의미를 담지 못함

서로 다른 원핫 벡터의 내적은 항상 0 → 모든 단어가 서로 등거리. ‘사과 · 딸기’와 ‘사과 · 자동차’의 유사도가 똑같다.

분산 표현(distributed representation) — 단어의 의미를 100~300차원의 밀집 벡터로 표현한다. 0이 거의 없는 실수 벡터라 차원이 작고, 비슷한 단어끼리 가까이 놓여 코사인 유사도로 의미 거리를 잴 수 있다. ‘분산’이라는 이름은 의미가 한 칸(원핫)이 아니라 여러 차원에 나뉘어(분산되어) 담긴다는 뜻이다.

분포 가설과 추론 기반 방법교안 21~23p

분포 가설 (교안 21p)

“단어의 의미는 그 주변 단어(맥락)에 의해 형성된다.”
  • “나무에 열린 A가 맛있게 익었다” / “나무에서 딴 B를 맛있게 먹었다” → A와 B는 비슷한 의미(나무에 열리는 먹을 수 있는 것)일 것이다
  • “C가 빠른 속도로 사라졌다” → C는 A · B와 매우 다른 성질을 가질 것이다
단어 자체를 들여다보지 않고, 그 단어가 어떤 자리에 쓰이는지만으로 의미를 짐작한다. 이 가정 하나가 통계 기반과 추론 기반 방법 모두의 토대다.

맥락과 윈도우 크기 — 주목하는 단어의 좌우로 몇 개까지 볼지를 윈도우 크기(window size)로 정한다. 윈도우 1이면 좌우 한 단어씩, 맥락은 2개다.

통계 기반 방법 — 동시발생 행렬 · PPMI · SVD (교안 22p)

  • 동시발생 행렬 — 각 단어의 맥락에 어떤 단어가 몇 번 나왔는지 센 V×V 행렬
  • 점별 상호정보량(PPMI)으로 고빈도 단어의 영향을 보정한다
  • 특이값 분해(SVD)로 밀집 벡터로 차원 축소(10주차 LSA의 SVD와 같다)
\mathrm{PMI}(x,y)=\log_2\frac{P(x,y)}{P(x)\,P(y)},\qquad\mathrm{PPMI}=\max(0,\ \mathrm{PMI})

단순 횟수로는 ‘은 · 는 · 이 · 가’가 모든 단어와 자주 붙어 다녀 가장 ‘관련 깊은’ 단어가 된다. PMI는 각자 따로 나올 확률로 나눠 이 효과를 지운다. 음수(우연보다 덜 같이 나옴)는 믿기 어려우므로 0으로 자른 것이 PPMI다.

🔎 숫자로 보는 PMI — 말뭉치 10,000단어에서 ‘은’이 1,000번, ‘사과’가 20번, 둘이 함께 10번 나왔다고 하자. P(x,y)=10/10000, P(x)P(y)=(1000/10000)(20/10000)이므로 \mathrm{PMI}=\log_2\frac{10\times10000}{1000\times20}=\log_2 5=2.32. 함께 나온 횟수 10은 크지만, ‘은’이 워낙 흔해 PMI는 그리 크지 않다. 반대로 20번 나온 ‘먹었다’와 ‘사과’가 10번 함께 나왔다면 \log_2\frac{10\times10000}{20\times20}=\log_2 250\approx7.97로 훨씬 크다.

통계 기반의 한계 (교안 22p)

  • 어휘 V에 대해 SVD 계산량이 대략 O(V³) → 어휘 100만 개 규모에서는 비현실적(절단 SVD를 쓰면 실용적으로 빠름)
  • 말뭉치가 추가되면 행렬을 다시 만들고 처음부터 다시 계산해야 한다

  • word2vec(Mikolov et al., 2013)은 계층이 두 개뿐인 얕은 신경망이다 — 계산량이 적어 대규모 말뭉치를 학습할 수 있다

학습 데이터 만들기 — 맥락과 타깃 (교안 25p)

말뭉치를 윈도우만큼 미끄러뜨리며 (맥락, 타깃) 쌍을 자동으로 생성한다. 사람이 레이블을 달 필요가 없다 — 이것이 11.1의 변화 ②(주석 없는 학습)다.

나는 매일 아침 커피 를 마신다 · 윈도우 1맥락 (입력)타깃 (정답)
나는 매일 아침 …(나는, 아침)매일
… 매일 아침 커피 …(매일, 커피)아침
… 아침 커피 를 …(아침, 를)커피

양 끝 단어(‘나는’, ‘마신다’)는 한쪽 맥락이 없어 타깃이 되지 못한다 — 길이 6인 말뭉치에서 윈도우 1이면 타깃은 6 − 2 = 4개다(아래 코드의 corpus[window_size:-window_size]).

CBOW의 신경망 구조 (교안 26p)

입력은 맥락 단어들의 원핫 벡터(2 × 윈도우 개). 입력측 가중치 W_in(V×D)은 모든 맥락에서 공유되며, 은닉층은 그 평균이다.

순전파 수식과 파라미터 수 (교안 27p)

h_1=x_1W_{in},\quad h_2=x_2W_{in},\quad h=\frac{h_1+h_2}{2}\ (D\text{차원})
s=h\cdot W_{out}\ (V\text{차원}),\quad\hat y=\mathrm{softmax}(s),\quad L=-\log\hat y[\text{타깃}]

D는 보통 100~300. 순서는 맥락 원핫 → W_in 곱 → 평균 h → W_out 곱으로 점수 s → 소프트맥스 → 교차 엔트로피다.

W_{in}:V\times D,\quad W_{out}:D\times V\quad\Rightarrow\quad 100{,}000\times100=10{,}000{,}000\ \text{(각각 1,000만 개)}

어휘 10만, D = 100이면 W_in · W_out이 각각 1,000만 개, 합쳐 2,000만 개다. 은닉층 크기 D는 어휘 V보다 훨씬 작다 — 이 ‘좁은 병목’을 지나야 하므로 비슷한 맥락의 단어들이 비슷한 D차원 벡터로 압축된다.

학습 후 단어 벡터는 어디에 있는가 · 이름의 뜻 (교안 28p)

  • W_in의 i번째 행 = i번째 단어의 분산 표현 → 일반적으로 이것을 단어 벡터로 쓴다
  • W_out의 i번째 열도 단어를 표현하지만, 관례적으로 W_in을 쓴다. 두 가중치를 더하거나 이어 붙이는 방법도 있다
  • CBOW라는 이름 — 맥락 단어들을 평균하므로 순서 정보가 사라진다 → “bag of words”(10주차 BoW와 같은 뜻). 대신 여러 맥락이 평균되어 잡음에 강하고 학습이 빠르다
🔎 왜 W_in의 ‘행’인가 — 원핫 벡터 x(1×V)에 W_{in}(V×D)을 곱하면, 1이 있는 i번째 위치만 살아남아 W_{in}의 i번째 행이 그대로 나온다. 즉 입력 단어 i가 은닉층에 보내는 벡터가 바로 그 행이다. 학습은 이 행들을 ‘같은 맥락에 나오는 단어끼리 비슷해지도록’ 움직인다. 이 성질이 그대로 11.8의 Embedding 계층이 된다.

CBOW를 코드로 — 맥락과 타깃 만들기 (교안 29p)

def create_contexts_target(corpus, window_size=1):
    target = corpus[window_size:-window_size]        # 양 끝 window_size개는 타깃 제외
    contexts = []
    for idx in range(window_size, len(corpus) - window_size):
        cs = []
        for t in range(-window_size, window_size + 1):
            if t == 0: continue                      # 자기 자신은 제외
            cs.append(corpus[idx + t])
        contexts.append(cs)
    return np.array(contexts), np.array(target)

실습 1에서 이 함수 그대로 맥락 · 타깃을 만들고, convert_one_hot으로 (N, 2, V) · (N, V) 원핫 배열로 바꾼다.

Skip-gram — 타깃 하나로 맥락 여럿을 (교안 30p)

  • 중앙의 타깃 단어 하나를 입력해 주변 맥락 단어들을 각각 예측한다
  • 맥락이 2 × 윈도우 개라면 손실도 그 개수만큼 계산해 모두 더한다
  • 더 어려운 문제 — 하나의 입력으로 여러 정답을 맞혀야 한다. 더 어려운 문제를 풀게 하면 단어 벡터 품질이 더 좋아지는 경향이 있고, 특히 희귀 단어의 표현이 CBOW보다 우수하다

Skip-gram의 신경망 구조 (교안 31p)

CBOW에서 W_in이 공유되었듯, Skip-gram에서는 여러 맥락 위치의 출력에 같은 W_out이 공유된다. 위치마다 다른 출력층을 두는 것이 아니다.

Embedding 계층 (교안 34p)

원핫 벡터와의 행렬곱은 결국 특정 행 하나를 꺼내는 것과 같다. 그러니 곱하지 말고 행을 조회(lookup)하면 된다.

원핫 (V=6) = [0, 0, 1, 0, 0, 0]
W_in (6×3) = [[ 0.1,  0.4, -0.2],
              [ 0.3, -0.1,  0.5],
              [ 0.8,  0.2, -0.6],    # ← 3번째 행
              [-0.4,  0.7,  0.1],
              [ 0.2,  0.2,  0.2],
              [-0.1, -0.5,  0.3]]
Embedding 계층 출력 = W_in[2] = [0.8, 0.2, -0.6]     # 0부터 세면 인덱스 2

케라스의 layers.Embedding(input_dim=V, output_dim=D)가 정확히 이것이다 — 정수 ID를 받아 (V×D) 표에서 그 행을 꺼낸다. 실습 2의 입력이 원핫이 아니라 정수 시퀀스인 이유다.

네거티브 샘플링 (교안 35p)

“어휘 V개 중 정답 고르기”(다중 분류, Softmax)를 “이 맥락에서 이 단어가 타깃인가? 예/아니오”(이진 분류, Sigmoid)로 바꾼다. 정답 1개(positive) + 무작위로 뽑은 오답 k개(negative, 보통 5~20)에 대해서만 이진 분류 손실을 계산한다.

네거티브 샘플링의 손실 함수 (교안 36p)

L^{+}=-\log\sigma(h\cdot v_{\text{target}}),\qquad L^{-}=-\sum_{k}\log\sigma(-h\cdot v_{\text{neg}_k})
L=L^{+}+L^{-}\qquad\Rightarrow\qquad\text{계산량 }V\ \to\ (k+1)

v는 W_out에서 꺼낸 그 단어의 열 벡터다. 정답 단어와는 내적을 크게(σ → 1), 오답과는 내적을 작게(σ(−·) → 1) 만든다. 어휘 10만, k = 5라면 출력층에서 점수를 계산하는 단어가 100,000개 → 6개로 줄어든다.

샘플링 확률의 0.75 제곱 — 단어 빈도를 그대로 쓰면 “은/는/이/가” 같은 조사만 뽑힌다. 0.75 제곱을 하면 저빈도 단어가 뽑힐 확률이 상대적으로 높아진다.

P(w_i)=\frac{f(w_i)^{0.75}}{\sum_j f(w_j)^{0.75}}

빈도 100인 단어와 1인 단어 둘만 있다면 — 그대로면 0.990 : 0.0099, 0.75 제곱하면 0.969 : 0.031. 드문 단어의 확률이 약 3배로 오른다. 실습 1의 (7) 셀이 같은 비교를 막대그래프로 보여 준다.

코사인 유사도 (교안 38p)

\cos(x,y)=\frac{x\cdot y}{\lVert x\rVert\,\lVert y\rVert}\qquad(-1\le\cos\le1)

두 벡터가 이루는 각도로 유사도를 잰다. 1에 가까울수록 의미가 비슷하다. 벡터의 길이(빈도의 영향)를 제거하고 방향만 비교하므로 단어 유사도에 알맞다.

def cos_similarity(x, y, eps=1e-8):
    nx = x / (np.sqrt(np.sum(x**2)) + eps)     # eps : 영벡터일 때 0으로 나누기 방지
    ny = y / (np.sqrt(np.sum(y**2)) + eps)
    return np.dot(nx, ny)

유추 문제 (교안 39p)

“a : b = c : ?”를 벡터의 덧셈 · 뺄셈으로 풀 수 있는지로 임베딩 품질을 평가한다.

\mathrm{vec}(\text{king})-\mathrm{vec}(\text{man})+\mathrm{vec}(\text{woman})\approx\mathrm{vec}(\text{queen})

유추를 푼다는 것은 “성별”, “복수형”, “국가–수도” 같은 관계가 벡터의 방향으로 인코딩되었다는 뜻이다. king → man과 queen → woman이 같은 ‘성별 방향’ 화살표다. 실제로는 결과 벡터와 코사인 유사도가 가장 큰 단어를 찾되, 질문 단어 세 개(king · man · woman)는 후보에서 뺀다.

CNN이 등장한 배경과 세 가지 특성 (교안 43p)

  • 2차원 이미지를 1차원 벡터로 펼치면 이웃 픽셀의 공간 정보가 사라진다
  • 전결합층으로 처리하면 파라미터가 폭발한다 — 28×28 = 784 입력에 은닉 1,000개면 784 × 1,000 = 78만 4천 개(편향 포함 78만 5천)
특성뜻
지역 수용 영역 (local receptive field)인접한 입력만 함께 본다
파라미터 공유 (parameter sharing)같은 커널을 모든 위치에 재사용한다 — 3×3 커널 하나는 가중치 9개뿐
이동 등가성 (equivariance)입력의 패턴이 옮겨 가면 반응(특징 맵)도 같이 옮겨 간다
등가성과 불변성 구분 — 교안은 등가성을 “같은 패턴이면 위치가 달라도 같은 반응이 나옴”이라고 적었다. 정확히는 ‘같은 크기의 반응이 옮겨진 위치에 나온다’는 뜻이다(입력을 옮기면 출력도 그만큼 옮겨짐). 여기에 풀링을 결합하면 위치 변화에 둔감해져 출력 자체가 거의 같아지는데, 이것이 이동 불변성(invariance)이다. 순차 처리는 CNN의 특성이 아니라 RNN의 특성이다.

커널(kernel)을 입력 위로 이동시키며 원소별 곱의 합을 계산한다. 교안 그림의 숫자를 직접 확인했다.

커널(= 필터)의 의미 · 크기와 개수 (교안 45p)

  • 커널의 값이 바로 학습되는 가중치 — 무작위로 초기화되고 역전파로 갱신된다
  • 커널이 위치한 입력의 범위를 수용 영역(receptive field)이라 한다
  • 커널 크기 — 작으면(3×3) 세밀한 패턴, 크면(7×7) 넓은 범위의 패턴
  • 필터 수 — 커널을 몇 개 쓸지 = 출력 특징 맵의 개수(= 다음 층의 깊이)
  • 층이 깊어질수록 — 첫 층은 모서리 · 직선, 다음 층은 원 · 사각형, 더 깊은 층은 복잡한 형태

스트라이드와 패딩 (교안 46p)

  • 스트라이드(stride) — 커널이 한 번에 이동하는 칸 수. 값이 커지면 출력 크기가 줄어든다
  • 제로 패딩(zero padding) — 테두리에 0을 덧붙여 출력 크기를 유지하고 경계 정보를 보존한다. 패딩이 없으면 가장자리 픽셀은 커널이 몇 번밖에 지나가지 않는다

출력 크기 계산 공식 (교안 47p)

\text{출력}=\left\lfloor\frac{\text{입력}-\text{커널}+2\times\text{패딩}}{\text{스트라이드}}\right\rfloor+1

입력 28 · 커널 3 · 패딩 0 · 스트라이드 1 → 26. 패딩 1이면 (28 − 3 + 2)/1 + 1 = 28(크기 유지). 스트라이드 2 · 패딩 1이면 ⌊27/2⌋ + 1 = 14.

#   padding='same'  -> 스트라이드 1일 때 출력 = 입력 (일반적으로 ceil(입력/스트라이드))
#   padding='valid' -> 패딩 없음 (크기가 줄어듦)
🔎 ‘same’이 스트라이드 2에서도 같은 크기는 아니다 — padding='same'은 이름과 달리 ‘출력 = ⌈입력 / 스트라이드⌉’가 되도록 패딩을 자동으로 넣는 옵션이다. 스트라이드 1이면 입력과 같고, 스트라이드 2면 28 → 14로 절반이 된다. 실습 2의 Conv1D는 padding='valid'라 길이가 200 → 198로 줄어든다.

문장에 CNN을 쓸 수 있을까 (교안 51p)

  • 문장을 임베딩하면 (문장 길이 × 임베딩 차원)의 2차원 행렬이 된다 — 이미지처럼 보인다
  • 하지만 임베딩 차원 축은 “공간”이 아니다. 37번째 차원과 38번째 차원은 이웃이라는 뜻이 없으므로 그 방향으로 커널을 움직이면 의미가 없다
  • → 단어(시간) 축으로만 이동하는 1차원 합성곱을 쓴다
왜 효과적인가 ① n-gram 탐지기

폭이 n인 커널은 n-gram 패턴 탐지기다. “별로 재미 없다”, “정말 최고” 같은 표현을 위치와 무관하게 잡아낸다(파라미터 공유).

왜 효과적인가 ② 병렬 계산

순환 신경망과 달리 모든 위치를 동시에 계산할 수 있어 학습이 매우 빠르다.

1차원 합성곱 연산 (교안 52p)

커널의 폭 = 함께 볼 단어 수, 커널의 높이 = 임베딩 차원 D (고정). 커널은 임베딩 벡터 전체를 한꺼번에 덮고 단어 축으로만 미끄러진다.

🔎 Conv1D 커널 하나의 실제 크기 — ‘1차원’은 움직이는 방향이 하나라는 뜻이지 커널이 한 줄이라는 뜻이 아니다. 실습 2의 Conv1D(128, 3)에서 커널 하나는 3(단어) × 100(임베딩 차원) = 300개의 가중치를 갖고, 이런 커널이 128개다. 그래서 파라미터는 3 × 100 × 128 + 128(편향) = 38,528개다. 확인문제 ⑤(입력 길이 100, 커널 5, 패딩 0, 스트라이드 1)의 답은 (100 − 5)/1 + 1 = 96이다.

Text-CNN (Kim, 2014) 구조 (교안 53p)

여러 크기의 커널(원 논문은 3 · 4 · 5-gram, 각 100개)을 병렬로 적용해 결과를 이어 붙인다. 교안 그림은 ‘이 영화 정말 재미 있다’에 커널 폭 2(주황)와 3(파랑)을 겹쳐 보여 준다 — 폭 2는 4칸, 폭 3은 3칸의 특징 맵을 만들고, 각각 Max Pooling(문장 전체) → Dense + Sigmoid → 긍정/부정.

전역 최대 풀링 · 임베딩 층의 세 가지 선택 (교안 54p)

전역 최대 풀링(Global Max Pooling) — 각 특징 맵에서 가장 큰 값 하나만 남긴다.
  • 문장 길이와 무관한 고정 길이 벡터가 된다 — 길이 198이든 50이든 필터 128개면 128차원
  • “해당 n-gram 패턴이 문장 어딘가에 강하게 존재했는가”를 하나의 값으로 요약한다
임베딩 층 선택언제케라스
무작위 초기화 후 함께 학습데이터가 충분할 때Embedding(V, D) (실습 2가 이것)
사전학습 word2vec을 넣고 고정데이터가 적을 때trainable=False

케라스 구현 — 감성 분석 (교안 55p)

inp = Input(shape=(max_len,), dtype="int32")
e   = Embedding(vocab_size, 100)(inp)                     # 단어 임베딩 (V x 100)
br  = [GlobalMaxPooling1D()(Conv1D(100, k, activation="relu")(e))
       for k in (3, 4, 5)]                                # 폭 3·4·5 커널 각 100개
x   = Concatenate()(br)                                   # 세 분기를 이어 붙임 → 300차원
x   = Dropout(0.5)(x)
x   = Dense(64, activation="relu")(x)
out = Dense(1, activation="sigmoid")(x)                   # 긍정/부정 이진 분류
model = Model(inp, out)
model.compile(optimizer='adam', loss='binary_crossentropy', metrics=['accuracy'])

분기가 셋으로 갈라졌다 합쳐지므로 Sequential로는 못 쓰고 Functional API가 필요하다. 출력이 1개 + sigmoid라 손실은 binary_crossentropy(11.2의 이진 교차 엔트로피)다.

튜닝 우선순위 · 다른 모델과의 비교 (교안 56p)

하이퍼파라미터 튜닝 우선순위(경험적) — ① 커널 크기 조합(2~5 중 선택) → ② 필터 수(100~600) → ③ 드롭아웃 비율(0.3~0.5). 활성화 함수는 ReLU, 풀링은 전역 최대 풀링이 대체로 안정적이다.

🔎 손실이 0.78 아래로 내려가지 않는 이유 — 윈도우 1이면 맥락 (나는, 를)은 사과 · 딸기 · 바나나 · 포도 · 강아지 · 고양이 · 토끼 · 병아리 여덟 단어 모두의 맥락이다. 같은 입력에 정답이 여러 개이므로 아무리 잘 학습해도 확률을 나눠 줄 수밖에 없다. 이 말뭉치에서 윈도우 1의 이론적 최소 교차 엔트로피(맥락이 주어졌을 때 타깃의 조건부 엔트로피)를 직접 계산하면 0.7771이다 — 학습 손실 0.775~0.78은 사실상 바닥에 닿은 값이다. 오르내림은 Adam(lr=0.01)이 바닥 근처에서 흔들리는 것이다.
🔎 그런데도 과일끼리 모이는 이유 · 동물과 장소가 가까운 이유 — W_in의 ‘사과’ 행은 사과가 맥락으로 쓰일 때 학습된다. 사과는 (사과, 먹었다) → 를, (사과, 정말) → 는처럼 오른쪽 이웃이 먹었다 · 사왔다 · 맛있다 쪽인 맥락에 들어가므로, 같은 자리의 딸기 · 포도와 같은 방향으로 밀린다. 반면 동물과 장소는 ‘동생이 강아지 를 키운다’ · ‘동생이 학교 에 있다’처럼 ‘동생이’를 함께 쓰므로, 고양이의 4위가 공원(0.927), 도서관의 4위가 고양이(0.926)로 서로 가깝다. 반면 과일만 쓰는 ‘엄마가’ 덕분에 사과의 4위는 0.54로 뚝 떨어진다 — 분포 가설이 말뭉치의 문장틀을 그대로 반영한 것이다.
공유 가중치의 기울기 — remove_duplicate — CBOW의 두 입력 계층은 같은 W_in 배열을 가리킨다. 그래서 model.params에 W_in이 두 번 들어 있고, 그대로 Adam에 넘기면 한 번의 반복에서 W_in이 두 번 갱신된다(실효 학습률 2배, Adam의 m · v도 꼬인다). 노트북은 params[i] is params[j]로 같은 객체를 찾아 기울기를 더한 뒤 하나만 남긴다. 역전파의 da *= 0.5는 은닉층이 평균(0.5배)이었기 때문이다.
