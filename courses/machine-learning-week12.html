12. 이미지 분할 — 픽셀마다 클래스를 붙인다

11주차 분류는 사진 한 장에 레이블 하나였다. 분할(segmentation)은 픽셀 하나하나에 레이블을 붙여, 입력과 같은 크기의 레이블 맵을 내놓는다. 그러려면 CNN이 줄여 놓은 특징 맵을 다시 원래 크기로 키워야 한다 — 그래서 인코더-디코더 구조와, 키우는 기술(전치 합성곱 · 언풀링 · 팽창 합성곱)이 이번 주의 중심이다. 그 위에 FCN · U-Net, 학습에 쓰는 교차 엔트로피 · IoU · Dice, 사람을 한 명씩 구분하는 인스턴스 분할(Mask R-CNN), 그리고 SegNet · DeepLab · PSPNet 같은 모델들을 훑는다.

  • 인코더는 입력을 작은 잠재 공간으로 압축하고, 디코더는 그것을 타깃 도메인으로 펼친다. 입력 = 타깃이면 오토인코더 — 병목 때문에 ‘중요한 것만 남기는 압축’을 배운다. 입력에 노이즈를 넣고 깨끗한 원본을 맞히게 하면 노이즈 제거 오토인코더

  • FCN = VGG-16의 FC 층을 1×1 합성곱으로 바꾸고 업샘플링 + 스킵 연결(덧셈). U-Net = 대칭 U자 인코더-디코더 + 스킵 연결(이어 붙이기)

교안세그멘테이션 — 영상을 여러 영역으로 나눈다 (2 · 3p)

학습 목표는 세그멘테이션에 대해서 이해한다. 세그멘테이션(segmentation)은 영상을 여러 개의 영역으로 분할하는 것이고, 종류는 인스턴스 세그멘테이션과 의미론적인(semantic) 세그멘테이션 두 가지다. 3p 그림은 같은 사진(사람 여럿)을 세 방식으로 처리한 결과를 나란히 보여 준다.

12.2

인코더-디코더와 오토인코더교안 4~10p

교안 슬라이드 모아보기 4p · 5p · 6p · 7p · 8p · 9p · 10p

교안인코딩과 디코딩 (4 · 5p)

교안의 정의
인코더입력 샘플을 잠재 공간(latent space), 즉 인코더가 정의한 숨겨진 구조화된 값 집합에 매핑하는 함수. 샘플에 담긴 의미론적 정보를 추출 · 압축하도록 설계 · 훈련된다
디코더잠재 공간의 요소를 사전 정의된 타깃 도메인으로 매핑하는 여함수. 타깃 도메인에 대한 지식을 적용해 정보를 적절하게 압축 해제 · 완성한다
공통 속성입력 공간과 목표 공간보다 작은 잠재 공간을 갖는다

머신러닝에서 인코더-디코더는 오래 쓰여 왔다. 대표가 기계 번역 — 인코더는 source language 문장을 받아 문장의 의미를 특징 벡터로 인코딩한 잠재 공간으로 투사하는 법을 배우고, 디코더는 그 벡터를 target 언어 문장으로 바꾸도록 인코더와 함께 훈련된다. 4p 그림은 손글씨 8 · 4가 인코더 → 작은 코드 → 디코더를 거쳐 다시 8 · 4로 나오는 모습과, 코드들을 2차원에 흩뿌린 점 구름이다.

자연어처리 12주차의 seq2seq(RNN 인코더-디코더)와 같은 틀이다 — 문장 대신 영상, 단어 대신 픽셀일 뿐이다(NLP 12주차).

교안오토인코더 — 입력과 타깃이 같은 인코더-디코더 (5 · 6p)

오토인코더(Auto-encoder)는 입력과 타깃 도메인이 동일하다. 중간의 병목 계층에도 불구하고 적절하게 인코딩한 다음, 품질을 해치지 않고 원래 이미지로 디코딩하는 것이 목표다. 입력은 압축된 표현으로 줄고, 원본이 필요하면 디코더가 그 압축된 표현에서 다시 만들어 낸다.

  • 손실 함수 = 입력과 출력 데이터 사이의 차이. 손실을 계산할 목표 이미지가 입력 이미지 자체다
  • 잠재 공간이 더 작으므로 인코더는 데이터를 적절히 압축하는 법을, 디코더는 다시 압축을 푸는 매핑을 배워야 한다
오토인코더 학습의 두 이름왜 그렇게 부르나 (6p)
비지도 학습훈련에 추가 레이블이 필요하지 않기 때문
자기 지도 학습명확하게 정의된 타깃(입력 자신)이 있고, 레이블 없는 데이터에서 패턴을 발견하려고 학습하기 때문

교안오토인코더(인코더-디코더)의 쓰임 (7p)

  • 이미지를 변환하거나 한 도메인에서 다른 도메인으로 매핑할 수 있다. 예: 깊이 회귀(depth regression) — 각 픽셀마다 카메라와 이미지 콘텐츠 사이의 거리를 추정
  • 의미론적 분할에 인코더-디코더를 흔히 쓴다 — 이때 네트워크는 깊이가 아니라 각 픽셀에 대해 추정한 클래스를 반환하도록 훈련된다
  • 예술적 응용으로도 유명하다 — 낙서를 현실적인 허구 이미지로, 밤 사진을 낮 사진으로 추정

7p 아래 그림 세 개: a) 노이즈 제거 · b) 해상도 개선 · c) 의미론적 분할. 구조는 셋 다 같은 인코더-디코더이고, 무엇을 타깃으로 주느냐만 다르다 — 깨끗한 원본 / 고해상도 원본 / 픽셀별 클래스.

교안오토인코더의 원리 — 병목 (8 · 9p)

“입력을 그대로 돌려주도록 훈련하는 게 무슨 의미가 있나?” — 답은 병목(bottleneck) 속성에 있다.

  • 인코더와 디코더는 한 덩어리로 훈련되지만, 용도에 따라 따로따로 쓸 수 있다
  • 병목 때문에 인코더는 가능한 많은 정보를 보존하면서 데이터를 압축해야 한다. 훈련 데이터에 반복 패턴이 있으면 네트워크는 인코딩을 개선하려고 그 상관관계를 알아내려 한다
  • 인코더만 떼어 쓰면 그 도메인 이미지의 저차원 표현을 얻는다 — 이미지 사이의 콘텐츠 유사도를 보존하므로, 클러스터 · 패턴을 드러내는 데이터 시각화에 쓴다
  • 디코더를 위해 훈련해 생성 작업에 쓰기도 한다(13주차 생성 모델로 이어진다)

노이즈 제거 오토인코더(denoising autoencoder)가 가장 보편적이다. 특수성은 입력 이미지가 네트워크에 들어가기 전에 손실이 있는 변환(노이즈 · 흐림 등)을 겪는다는 것. 그래도 모델은 원본 이미지를 돌려주도록 훈련되므로, 손실이 있는 연산을 되돌리고 누락된 정보를 복원하는 법을 배운다. 같은 원리가 스마트 이미지 업스케일링(smart image upscaling), 곧 이미지 해상도 개선(image super-resolution)에 쓰인다 — 작게 줄인 사진을 입력으로, 원본을 타깃으로.

“입력을 그대로 출력하게 학습시키는 게 왜 의미가 있나?” — 병목이 하는 일 세 가지

병목이 없다면? 은닉층이 입력만큼(또는 더) 크면 모델은 입력을 그냥 베껴 내는 항등 함수(identity function)만 배워도 손실이 0이 된다 — 복원은 완벽하지만 배운 특징은 하나도 없다. 오토인코더의 목적은 출력이 아니라 가운데 압축된 표현이다.

이상 탐지와 연결 — 정상 데이터로만 학습하면 병목에는 ‘정상의 패턴’만 담긴다. 처음 보는 이상한 입력은 그 패턴으로 설명되지 않아 복원 오차(입력과 출력의 차이)가 크게 나온다 → 복원 오차가 기준보다 크면 이상으로 판정한다.

교안이미지 노이즈 제거 예제 (10p)

낮은 차원의 병목 계층이 있는 대칭 인코더-디코더다. 오토인코더를 학습할 때는 이미지를 입력과 타깃으로 모두 쓰고, 노이즈 제거에 적용할 때는 입력만 노이즈를 섞은 이미지로 바꾼다.

교안전치 합성곱 (transposed convolution, 디컨볼루션) (11 · 12p)

기호 — 커널 크기 k, 입력 깊이 D, 커널 개수 N, 패딩 p, 보폭 s. 전치 합성곱은 합성곱 계층을 반전시켜, 특징 맵과 훈련 가능한 필터 사이의 합성곱으로 특징 맵의 공간 차원을 증가시킨다.

합성곱 (피드 포워드 방향) — 크기가 줄어든다

H_o=\frac{H-k+2p}{s}+1,\qquad W_o=\frac{W-k+2p}{s}+1

전치 합성곱 — 위 식을 H에 대해 거꾸로 푼 것, 크기가 커진다

H=(H_o-1)\,s+k-2p,\qquad W=(W_o-1)\,s+k-2p

아래 식은 위 식을 정리한 것뿐이다: H_o-1=\frac{H-k+2p}{s} → 양변에 s를 곱하고 k-2p를 넘기면 H=(H_o-1)s+k-2p. 출력 깊이는 두 경우 모두 커널 개수 N이다.

12p 그림 — 위는 일반 합성곱(입력에 패딩을 두르고 보폭 s로 훑어 출력이 작아짐), 아래는 전치 합성곱(입력 칸 사이를 벌리고 주위에 패딩을 둔 뒤 합성곱 → 출력이 커짐). 그림 오른쪽 아래 상자는 출력 한 칸이 필터와 겹친 입력 칸들의 곱의 합이라는 표시다.

이름 주의 — ‘디컨볼루션’이라고 부르지만 수학의 역합성곱(deconvolution)처럼 원래 값을 되돌리는 것이 아니다. 크기만 키우고, 값은 학습된 필터가 새로 만든다.

① 합성곱이란 — 뒤집고, 밀고, 곱해서 더한다

수학의 합성곱 f*g는 한 함수를 반전(뒤집기)하고 이동(shift)시켜 가며 두 함수를 곱한 뒤 그 적분(또는 합)을 구하는 연산이다.

연속 · 이산 정의

(f*g)(t)=\int_{-\infty}^{\infty} f(\tau)\,g(t-\tau)\,d\tau,\qquad (f*g)[n]=\sum_{m} f[m]\,g[n-m]

g(t-\tau)의 마이너스가 ‘뒤집기’, t가 ‘밀기’다. t를 바꿀 때마다 겹친 부분을 곱해 더한 값 하나가 나온다.

  • 신호 처리 — 입력 신호에 필터(가중치)를 적용해 노이즈를 지우거나 특정 주파수를 걸러 낸다
  • 이미지 · CNN — 이미지 위에 작은 커널을 도장 찍듯 미끄러뜨리며(sliding window) 겹친 픽셀끼리 곱해 더한다(곱셈-누산, FMA). 경계선 · 질감 · 형태 같은 지역적 특징이 뽑힌다(10주차 10.5 합성곱층)
  • 딥러닝 — 커널 값을 사람이 정하지 않고 학습 가능한 파라미터로 두어 데이터에 맞게 최적화한다

작은 차이 하나 — 딥러닝 라이브러리의 ‘합성곱’은 사실 커널을 뒤집지 않는 교차 상관 y[i]=\sum_m x[i+m]\,w[m]이다. 커널을 어차피 학습하므로 뒤집었든 아니든 결과가 같아 그냥 합성곱이라 부른다.

  • 역연산이 아니다 — C는 2×5라 역행렬이 없다. C^{T}는 모양(크기)만 되돌릴 뿐이고, 합성곱에서 이미 잃은 세부 픽셀 정보를 되살리지는 못한다. 값은 학습된 필터가 새로 만든다
  • 학습 가능한 업샘플링 — 고정된 보간법과 달리 필터가 학습되므로 오토인코더의 디코더 · 의미론적 분할(FCN · U-Net) · 생성 모델(13주차 GAN의 생성자)에서 해상도를 높일 때 쓴다

교안팽창 합성곱 (dilated / atrous convolution) (14p)

데이터의 공간 차원을 더 희생시키지 않고 합성곱의 수용 영역을 인위적으로 키우는 방법이다. 팽창 연산이 적용되고, 커널에 적용될 팽창률(dilation rate)이라는 초매개변수가 하나 더 있다는 점을 빼면 일반 합성곱과 같다.

보충설명팽창률 d면 커널이 실제로 덮는 크기는 k + (k−1)(d−1)

3×3 커널칸 사이 간격덮는 범위학습 파라미터

교안완전 컨볼루션 네트워크 FCN (15p)

FCN(Fully Convolutional Networks)은 VGG-16에 기반해, 마지막 FC layer를 1×1 합성곱 계층으로 대체해 구성한다. 전결합층이 사라지니 이름 그대로 ‘전부 합성곱’이다. FCN이 보여 준 두 가지:

  • 특징 추출용 CNN을 효율적으로 인코더로 쓰는 방법
  • CNN의 특징 맵을 효율적으로 업샘플링하고 디코딩하는 방법

15p 그림 — 왼쪽 ‘VGG-16 특징 추출기’, 오른쪽 ‘분류 헤드(제거)’, 그리고 마지막 블록의 출력을 얼마나 키우느냐에 따라 FCN-32s · FCN-16s · FCN-8s 세 모델. 숫자는 마지막에 한 번에 키우는 배수다.

보충설명FC를 1×1 합성곱으로 바꾸면 무엇이 좋아지나

  • 위치가 남는다 — Flatten + Dense는 공간 구조를 펴 버리지만, 1×1 합성곱은 칸마다 같은 연산을 해 H×W 격자를 유지한다. 칸마다 클래스 점수가 나오니 곧 ‘거친 분할 지도’다
  • 입력 크기가 자유롭다 — Dense는 입력 길이가 고정이라 학습 때와 같은 크기 사진만 받지만, 합성곱만 있으면 어떤 크기든 받는다
  • 11주차 Inception · MobileNet의 1×1 합성곱(채널 수 조절, pointwise)과 같은 연산이다(11.6)

교안FCN-8s 구현 (17p)

inputs = Input(shape=(224, 224, 3))
# 인코더로 사전 훈련된 VGG-16 특징 추출기를 구성:
vgg16 = VGG16(include_top=False, weights='imagenet', input_tensor=inputs)
# 3개의 최종 블록 각각이 반환한 특징 맵을 복원:
f3 = vgg16.get_layer('block3_pool').output   # shape: (28, 28, 256)
f4 = vgg16.get_layer('block4_pool').output   # shape: (14, 14, 512)
f5 = vgg16.get_layer('block5_pool').output   # shape: ( 7,  7, 512)
# VGG 밀집 계층을 합성곱 계층으로 대체하고 대신 합성곱/풀링 블록 다음에 "디코딩" 계층을 추가:
f3 = Conv2D(filters=out_ch, kernel_size=1, padding='same')(f3)
f4 = Conv2D(filters=out_ch, kernel_size=1, padding='same')(f4)
f5 = Conv2D(filters=out_ch, kernel_size=1, padding='same')(f5)
# 'f4'와 결합시킬 수 있도록 'f5'를 14x14 맵으로 업스케일링:
f5x2 = Conv2DTranspose(filters=out_ch, kernel_size=4, strides=2,
                       padding='same', activation='relu')(f5)
# 2개의 특징 맵을 요소-단위 덧셈으로 통합:
m1 = add([f4, f5x2])
# 'm1'과 'f3'을 28x28 map으로 통합하기 위해 이 연산을 반복:
m1x2 = Conv2DTranspose(filters=out_ch, kernel_size=4, strides=2,
                       padding='same', activation='relu')(m1)
m2 = add([f3, m1x2])
# 마지막으로 transp-conv를 사용해 원본 형상을 복원:
outputs = Conv2DTranspose(filters=out_ch, kernel_size=16, strides=8,
                          padding='same', activation='sigmoid')(m2)
fcn_8s = Model(inputs, outputs)

보충설명모양을 따라가면 이름이 왜 ‘8s’인지 보인다

입력 224×224×3VGG16(include_top=False: 분류 헤드 제거, weights='imagenet': 사전 학습 가중치)
f3 28×28 (1/8) · f4 14×14 (1/16) · f5 7×7 (1/32)풀링 다섯 번 중 3 · 4 · 5번째 출력. 1×1 합성곱으로 채널을 클래스 수 out_ch로 맞춘다
f5 7×7 → ×2 → 14×14, f4와 더함 = m1전치 합성곱(k=4, s=2)으로 2배 — (7-1)\cdot2+4-2=14
m1 14×14 → ×2 → 28×28, f3와 더함 = m2같은 연산 반복. 깊은 층의 ‘무엇’과 얕은 층의 ‘어디’를 합친다
m2 28×28 → ×8 → 224×224×out_chkernel_size=16, strides=8 — 1/8 해상도를 8배로 한 번에 복원 → FCN-8s

FCN-32s는 f5(1/32)만 32배로 한 번에 키워 경계가 뭉툭하고, FCN-16s는 f4까지, FCN-8s는 f3까지 섞어 경계가 가장 정교하다. 결합은 add — 원소별 덧셈이라 두 특징 맵의 크기와 채널 수가 같아야 한다(그래서 1×1 합성곱으로 채널을 먼저 맞췄다).

교안U-Net (16p)

  • 의미론적 분할을 위해 개발되었고 FCN과 여러 속성을 공유한다
  • 특징 깊이를 늘리면서 공간 차원은 줄이는 다중 블록 축소 인코더 + 이미지 해상도를 복원하는 확장 디코더
  • FCN처럼 스킵 연결이 인코딩 블록을 그에 대응하는 디코딩 블록과 잇는다
  • 디코딩 블록은 이전 블록에서 컨텍스트 정보를, 인코딩 경로에서 위치 정보를 받는다
  • 전통적인 U자 형태의 인코더-디코더로 돌아간 대칭형
  • 스킵 연결에서 온 특징 맵은 덧셈 대신 연결(concatenation)로 결합한다

FCN (-8s)U-Net

덧셈은 ‘두 지도를 겹쳐 하나로’, 연결은 ‘두 지도를 나란히 쌓아 다음 층이 알아서 섞게’다. 11주차로 치면 ResNet은 더하고, DenseNet은 이어 붙인다와 같은 대비다(11.6).

교안학습의 문제와 평가지표 — 클래스 불균형 · IoU · Dice (20p)

이미지 단위 분류나 픽셀 단위 분류에서는 보통 클래스 불균형 문제가 생겨, 학습에서 반드시 해결해야 한다(20p 그림: 입력 이미지 · 실제 레이블 맵 · 클래스당 가중치 맵 · 윤곽 가중치 맵). 평가지표는 IoU(Intersection-over-Union)와 Dice다.

\text{Dice}(A,B)=\frac{2\,|A\cap B|}{|A|+|B|}
\text{IoU}(A,B)=\frac{\text{Dice}(A,B)}{2-\text{Dice}(A,B)}\qquad;\qquad \text{Dice}(A,B)=\frac{2\times\text{IoU}(A,B)}{1+\text{IoU}(A,B)}

A = 예측 마스크, B = 정답 마스크, |A\cap B| = 둘이 겹치는 픽셀 수. IoU의 원래 정의는 \frac{|A\cap B|}{|A\cup B|}(겹친 넓이 ÷ 합친 넓이).

보충설명숫자로 — 그리고 두 관계식은 어디서 나오나

예: 예측 A 100픽셀, 정답 B 100픽셀, 겹침 80픽셀이면

\text{Dice}=\frac{2\times80}{100+100}=0.8,\qquad |A\cup B|=100+100-80=120,\qquad \text{IoU}=\frac{80}{120}\approx0.667

관계식으로 확인: 0.8/(2-0.8)=0.8/1.2\approx0.667 ✓. 항상 IoU ≤ Dice이고, 둘 다 완벽하면 1, 전혀 안 겹치면 0이다.

유도 — 겹침을 I, 합친 넓이를 U라 하면 |A|+|B|=U+I(겹친 부분이 두 번 세어지니까). 그러면 \text{Dice}=\frac{2I}{U+I}, \text{IoU}=\frac{I}{U}. 분자 · 분모를 U로 나누면 \text{Dice}=\frac{2\,\text{IoU}}{1+\text{IoU}}, 이것을 IoU에 대해 풀면 \text{IoU}=\frac{\text{Dice}}{2-\text{Dice}}.

왜 정확도(맞힌 픽셀 비율) 대신 이걸 쓰나? — 사진의 95%가 배경이고 종양이 5%라면, 전부 배경이라고 찍어도 픽셀 정확도 95%다. 하지만 종양 마스크의 Dice는 0이다. IoU · Dice는 찾아야 할 영역끼리만 비교하므로 작은 클래스를 놓치면 바로 드러난다 — 이것이 ‘클래스 불균형’과 짝지어 나오는 이유다.

교안Dice를 손실로 쓰는 경우 (21p)

def dice_loss(labels, logits, num_classes, eps=1e-6, spatial_axes=[1, 2]):
    # 로짓을 확률로, 실제 값을 원-핫 인코딩된 텐서로 변환:
    pred_proba = tf.nn.softmax(logits, axis=-1)
    gt_onehot  = tf.one_hot(labels, num_classes, dtype=tf.float32)
    # 다이스 계수의 분자와 분모 계산:
    num_perclass = 2 * tf.reduce_sum(pred_proba * gt_onehot, axis=spatial_axes)
    den_perclass = tf.reduce_sum(pred_proba + gt_onehot, axis=spatial_axes)
    # 배치와 클래스에 대한 평균과 다이스 계수 계산:
    dice = tf.reduce_mean((num_perclass + eps) / (den_perclass + eps))
    return 1 - dice

보충설명dice_loss를 한 줄씩 — 식 2|A∩B| / (|A|+|B|)가 그대로 들어 있다

줄모양 (배치 B, 224×224, 클래스 N)식에서의 역할
softmax(logits, axis=-1)(B, 224, 224, N)로짓을 클래스 축에서 확률로 — ‘부드러운’ 예측 마스크 A
one_hot(labels, N)(B, 224, 224) → (B, 224, 224, N)정수 레이블을 원-핫으로 — 정답 마스크 B. 예측과 원소별로 곱할 수 있게 모양을 맞춘다
2 * reduce_sum(A * B, axis=[1,2])(B, N)분자 2|A∩B| — 높이 · 너비 두 공간 축을 따라 합해 클래스별로
reduce_sum(A + B, axis=[1,2])(B, N)분모 |A|+|B|
+ eps사진에 없는 클래스는 분모가 0 — 0으로 나누기 방지
reduce_mean(…)스칼라배치와 클래스에 걸쳐 평균 — 클래스마다 같은 무게로 평균하므로 작은 클래스도 큰 클래스만큼 손실에 반영된다
return 1 - diceDice는 클수록 좋은 지표, 손실은 작을수록 좋아야 하므로 1에서 뺀다

방법어떻게
사후 처리로 인스턴스 마스크로 변환의미론적 분할 결과에 마스크 침식(erosion)과 팽창(dilation) 같은 모폴로지 함수를 적용해, 붙어 있는 덩어리를 개체별로 떼어 낸다
의미론적 분할을 경계 상자에 적용① 객체 탐지 모델로 타깃 클래스의 각 인스턴스의 경계 상자를 얻고 ② 상자마다 잘라 낸 패치를 의미론적 분할 모델에 넣어 ③ 인스턴스 마스크를 얻는다

침식은 덩어리 가장자리를 깎아 가늘게 붙은 두 사람을 떼어 놓고, 팽창은 다시 부풀려 원래 크기로 돌린다(컴퓨터비전 수업의 모폴로지 연산).

교안Mask R-CNN — Faster R-CNN에 마스크 분기를 더한다 (23p)

  • 탐지와 분할 두 네트워크를 하나로 이어 앤드-투-앤드로 훈련하면 전체 파이프라인 성능이 향상된다 — 이것이 Mask R-CNN
  • 구조: 영역 제안 네트워크 하나 → 제안된 영역마다 클래스와 상자 오프셋을 예측하는 두 분기(= Faster R-CNN) + 세 번째 병렬 분기가 각 영역의 이진 마스크를 출력
  • 분할 분기는 N개의 이진 마스크(클래스당 한 개)를 출력하고, 다른 분기가 예측한 클래스에 대응하는 마스크만 최종 예측과 훈련 손실에 쓴다 — 그 인스턴스 클래스의 마스크만 분할 분기의 교차 엔트로피 손실에 영향을 준다

보충설명왜 ‘클래스당 마스크 하나’이고, 왜 하나만 쓰나

영역 하나에 대해 마스크 분기가 사람 마스크 · 차 마스크 · 개 마스크 …를 각각 따로(시그모이드, 이진) 내놓는다. 클래스 분기가 ‘사람’이라고 하면 사람 마스크만 꺼내 쓴다. 이렇게 하면 마스크 분기는 ‘이게 무슨 물체인가’를 고민하지 않고 ‘이 물체의 모양이 어디까지인가’만 배우면 된다 — 분류는 클래스 분기가, 모양은 마스크 분기가 나눠 맡는다. 픽셀마다 N개 중 하나를 고르는 소프트맥스(의미론적 분할)와 다른 점이다.

교안SegNet (24p)

인코더 및 디코더 방식이다. 인코더에는 여러 컨볼루션 레이어, 디코더에는 여러 디컨볼루션 레이어가 있고, FCN이 만든 출력 결과를 향상시켰다. 24p 그림: 입력 3×H×W → 줄어드는 상자(인코더) → 커지는 상자(디코더) → 예측 결과 H×W.

(보충) SegNet 논문의 핵심은 디코더가 인코더의 풀링 위치(마스크)를 받아 언풀링으로 키운다는 점이다(12.3 언풀링). 큰 특징 맵을 통째로 넘기는 U-Net보다 메모리가 적게 든다.

교안DeepLab (25p)

  • 여러 스케일로 컨볼루션을 수행하고, 다양한 스케일의 특징으로 score map을 얻는다
  • score map은 최종 분할을 위해 CRF(조건부 랜덤 필드)로 보간되어 전달된다
  • 스케일 처리는 CNN으로 다양한 크기의 이미지를 처리하거나, 확장(팽창) 컨볼루션의 여러 레벨로 병렬 컨볼루션을 해서 이루어진다

25p 그림: 입력 → DCNN(atrous 합성곱) → 거친 score map → 쌍선형 보간 → 완전 연결 CRF → 최종 출력. CRF는 ‘색이 비슷하고 가까운 픽셀은 같은 클래스일 가능성이 높다’는 규칙으로 경계를 다듬는다.

교안RefineNet (26p)

확장 컨볼루션은 더 큰 입력을 필요로 해 메모리를 많이 쓰고, 고해상도 그림에서 계산할 때 문제가 생길 수 있다. 이를 해결하려고 제안한 방법이다 — 26p 그림처럼 1/4 · 1/8 · 1/16 · 1/32 해상도의 특징을 RefineNet 블록으로 아래에서부터 차례로 합치며 다듬는다. (교안 표기는 ‘RefiNet’)

교안PSPNet · 대형 커널 문제 (27p)

  • PSPNet — 풀링 레이어의 커널 크기를 확장하고, 풀링에서 피라미드 방식을 쓴다. 피라미드는 이미지의 다양한 부분과 크기를 동시에 커버한다
  • 대형 커널 문제 — 대형 커널은 작은 커널보다 훨씬 큰 수용 필드를 갖지만 계산이 복잡하다. 이 복잡성은 작은 커널을 써서 해결할 수 있다

(보충) 피라미드 풀링: 같은 특징 맵을 1×1 · 2×2 · 3×3 · 6×6 칸으로 평균 풀링해 ‘사진 전체 분위기’부터 ‘부분’까지 요약한 뒤 다시 키워 이어 붙인다. 작은 커널로 큰 커널 흉내 내기의 예: 7×7 하나 대신 1×7과 7×1을 이어 쓰면 49 → 14로 준다.

교안DeepLabV3 (28 · 29p)

  • 배치 정규화(Batch normalization)를 성능 향상을 위해 사용
  • 특징의 다중 스케일을 캐스케이드(cascade) 방식으로 인코딩해 성능을 높였다

28p 그림 위는 다중 스케일을 얻는 네 방식(a 이미지 피라미드 · b 인코더-디코더 · c 더 깊은 atrous 합성곱 · d 공간 피라미드 풀링), 아래는 블록 1~4 뒤에 팽창률을 키운 블록을 이어 쌓는(캐스케이드) 구조다.

핵심 정리시험 전에 이것만

분할의 종류

탐지 = 사각형. 의미론적 분할 = 픽셀마다 클래스(같은 클래스는 한 색). 인스턴스 분할 = 개체마다 다른 라벨.

인코더-디코더

인코더: 입력 → 작은 잠재 공간(의미 압축). 디코더: 잠재 → 타깃 도메인(압축 해제). 잠재 공간이 입력 · 목표보다 작다.

오토인코더

입력 = 타깃. 손실 = 입력과 출력의 차이. 비지도(레이블 불필요) · 자기 지도(타깃 = 입력). 병목 때문에 압축을 배운다.

노이즈 제거 · 해상도 개선

망가진 입력 → 원본 타깃. fit(x_noisy, x_train). 출력 층 크기 = 입력 크기.

전치 합성곱

H_o=\frac{H-k+2p}{s}+1 ↔ H=(H_o-1)s+k-2p. 학습되는 필터로 키운다. k=4, s=2, p=1 → 2배.

언풀링 · 팽창

언풀링: 풀링 마스크 자리에만 값, 나머지 0, 파라미터 없음. 팽창: 크기 유지 · 수용 영역 확대, 3×3 d=2 → 5×5.

FCN · U-Net

FCN: VGG-16 FC → 1×1, FCN-8s(f3 · f4 · f5, ×2 ×2 ×8), 스킵 덧셈. U-Net: 대칭 U자, 스킵 연결(concat), 컨텍스트 + 위치.

출력 · 손실

H×W×N → argmax(axis=-1) → H×W 레이블 맵. sparse_categorical_crossentropy(정수 레이블) · adam. Cityscapes 19클래스.

IoU · Dice

Dice = 2|A∩B|/(|A|+|B|), IoU = Dice/(2−Dice), Dice = 2IoU/(1+IoU). 100 · 100 · 80 → 0.8 · 0.667. Dice 손실 = 1 − dice.

인스턴스 분할

모폴로지(침식 · 팽창) 사후 처리 / 상자 → 패치 분할 / Mask R-CNN: 세 번째 분기, 클래스당 이진 마스크, 예측 클래스 마스크만 손실.

여러 모델
