Ch·3

확률Probability · p.38–73

어떤 실험에서 나올 수 있는 모든 결과를 모은 것이 표본공간 S, 우리가 관심 있는 결과들의 묶음이 사상(Event)이다.

확률을 계산할 때 가장 먼저 확인할 것은 "두 사상이 동시에 일어날 수 있는가?"다. 동시에 일어날 수 없는 상호배반이라면 단순히 더하면 되고, 그렇지 않다면 합법칙 P(A∪B) = P(A)+P(B)−P(A∩B)으로 겹치는 부분을 뺀다.

다음은 "이미 어떤 정보가 주어진 상황"이다. B가 일어났음을 알고 있을 때 A의 확률은? 이것이 조건부 확률 P(A|B) = P(A∩B)/P(B)다.

조건부 확률에서 두 갈래가 생긴다.① 조건을 줘도 확률이 그대로면 → A와 B는 독립. P(A∩B) = P(A)·P(B)로 곱만 하면 된다.② 원인은 여럿인데 결과만 알고 역으로 원인의 확률을 구하고 싶다면 → 베이즈 정리. 먼저 전확률 정리로 P(A) 전체를 구하고, 그것을 분모에 놓아 역방향 확률을 계산한다.

핵심 개념

표본공간 S
실험에서 나올 수 있는 모든 결과의 집합. 사상(Event)은 S의 부분집합.
확률의 공리
① P(A) ≥ 0  ② P(S) = 1  ③ 상호배반 Ai: P(A1∪A2∪…) = P(A1)+P(A2)+…
조건부 확률
B가 주어졌을 때 A의 확률. P(B) > 0 이어야 정의됨.
사상의 독립
P(A∩B) = P(A)·P(B) ↔ P(A|B) = P(A). 독립이면 공분산=0 (역은 성립 안 함).
전확률 정리
B1,…,Bn이 S의 분할이면 P(A)를 조건부 확률의 합으로 표현.
베이즈 정리
사전확률 → 사후확률 변환. 역방향 조건부 확률 계산에 사용.

주요 수식

조건부 확률 ★ 자주
P(A|B)  =  P(A∩B)P(B)  ,  P(B) > 0
확률의 합법칙
P(A∪B) = P(A) + P(B) − P(A∩B) A, B가 배반이면: P(A∪B) = P(A) + P(B)
전확률의 정리
P(A) = P(B1)·P(A|B1) + P(B2)·P(A|B2) + … + P(Bn)·P(A|Bn)
단, B1,…,Bn 은 S의 분할 — Bi∩Bj = ∅ (i≠j), B1∪…∪Bn = S
베이즈 정리
P(Bk|A)  =  P(Bk) · P(A|Bk) P(B1)·P(A|B1) + … + P(Bn)·P(A|Bn)
P(Bk): 사전확률(prior)  |  P(Bk|A): 사후확률(posterior)
Ch·4

확률변수Random Variable · p.74–119

3장에서 사상에 확률을 붙였다면, 4장은 그 결과를 숫자로 매핑하는 것에서 시작한다. 실험 결과를 실수로 변환하는 함수가 확률변수 X다.

확률변수는 두 종류로 나뉜다.값을 셀 수 있으면 이산형 → 각 값에 확률을 직접 부여하는 PMF p(x)를 사용한다.값이 연속적이면 연속형 → 구간의 면적으로 확률을 표현하는 PDF f(x)를 사용하고, P(a<X<b)는 f(x)의 적분으로 구한다.

분포를 요약하는 두 숫자가 기대값(평균) μ과 분산 σ²이다. 기대값은 분포의 중심, 분산은 얼마나 퍼져 있는지를 나타낸다. aX+b처럼 변수를 선형변환하면 기대값은 그대로 따라 변하고, 분산은 a²배가 된다.

분포를 몰라도 평균과 분산만 알면 확률의 범위를 보장할 수 있다. 체비쇼프 부등식이 그것으로, 평균에서 kσ 이상 벗어날 확률은 반드시 1/k² 이하임을 보장한다. 분포 형태와 무관하게 항상 성립한다는 점이 핵심이다.

핵심 개념

확률변수
X: S → ℝ. 이산형(PMF) vs 연속형(PDF)으로 구분.
PMF (이산)
p(x) = P(X=x) ≥ 0, 모든 x에 대해 Σp(x) = 1
PDF (연속)
f(x) ≥ 0, ∫f(x)dx = 1, P(a < X < b) = ∫ab f(x)dx
CDF
F(x) = P(X ≤ x). 단조증가, F(−∞)=0, F(∞)=1. 연속형: f(x) = F′(x).
기대값
분포의 중심. 선형성 E(aX+b) = aE(X)+b 성립.
분산
Var(aX+b) = a²Var(X). 표준편차 σ = √Var(X).
체비쇼프
분포 무관. 평균 주변 kσ 범위에 1−1/k² 이상의 확률.
MGF
m(t) = E(etX). m′(0)=E(X), m″(0)=E(X²). 분포를 유일 결정.

주요 수식

기대값
이산형: E(X) = Σ x · p(x) 연속형: E(X) = ∫ x · f(x) dx
분산
Var(X) = E(X²) − [E(X)]² = E[(X−μ)²]
선형결합
E(aX+b) = a·E(X) + b Var(aX+b) = a²·Var(X)
체비쇼프 부등식
P(|X−μ| ≥ kσ) ≤ 1k²  ,   k > 1
동치: P(|X−μ| < kσ) ≥ 1 − 1/k²

확률분포Probability Distributions · p.120–178

4장에서 만든 확률변수에 구체적인 분포 모형을 씌운다. 현실의 패턴이 어떤 분포를 따르는지 파악하는 것이 5장의 핵심이다.

이산형부터: 동전을 n번 던져 앞면이 몇 번 나오는가처럼, 독립 시행을 반복해서 성공 횟수를 셀 때는 이항분포 B(n,p)를 쓴다. 반면 단위 시간 동안 전화가 몇 번 오는가처럼 드문 사건을 시간/공간 단위로 셀 때는 포아송분포 pois(λ)가 맞는다. n이 매우 크고 p가 매우 작다면(n>50, np<5) 이항분포가 포아송으로 근사된다.

연속형으로 넘어오면: 가장 중요한 것이 정규분포 N(μ,σ²)다. 실제 데이터 대부분이 정규분포를 따르거나 근사한다. 정규분포를 다룰 때는 반드시 표준화 Z = (X−μ)/σ를 거쳐 표준정규분포표를 이용한다.

이산형 분포를 정규로 근사할 때는 연속성 수정이 필요하다.이항분포 → 정규근사: min(np, nq) > 5인 경우 사용, P(X≤k)를 구할 때 k를 k+0.5로 수정.포아송 → 정규근사: λ ≥ 10인 경우 사용.

암기 세트: 각 분포마다 ① PMF/PDF  ② 평균·분산  ③ 적용 조건을 묶어서 외우세요.

이항분포 B(n, p) ★ 자주

PMF
p(x) = C(n,x) · px · (1−p)n−x  ,   x = 0, 1, …, n
n번 독립 베르누이 시행, 성공확률 p, 성공 횟수 X
평균 · 분산 · MGF
E(X) = np Var(X) = npq   (q = 1−p) m(t) = (pet + q)n

포아송분포 pois(λ)

PMF
p(x ; λ) = e−λ · λxx!  ,   x = 0, 1, 2, …
단위 시간/공간의 사건 횟수 | n > 50, np < 5이면 이항분포 근사로 사용
평균 · 분산
E(X) = Var(X) = λ

초기하분포

PMF
p(x) = C(K,x) · C(N−K, n−x) C(N,n)
비복원 추출 | N: 전체, K: 관심 범주, n: 표본크기
평균 · 분산
E(X) = nKN Var(X) = nK(N−K)(N−n)N²(N−1)

기하분포

PMF · 평균 · 분산
p(x) = (1−p)x−1 · p  ,   x = 1, 2, … E(X) = 1p  ,   Var(X) = 1−pp²
첫 번째 성공까지의 시행 횟수. 무기억성(memoryless) 성질 보유.

정규분포 N(μ, σ²) ★★ 반드시

PDF
f(x) = 1√(2π) · σ · exp (− (x−μ)²2σ² )  ,   −∞ < x < ∞
E(X) = μ  ,   Var(X) = σ²
표준화 · 표준정규
Z = X − μσ ~ N(0, 1) P(a < X < b) = P( a−μσ < Z < b−μσ )
이항분포의 정규근사 (연속성 수정)
적용 조건: min(np, nq) > 5 Z = X − np√(npq) ≈ N(0, 1) 연속성 수정: P(X ≤ k) ≈ P(Z ≤ k + 0.5 − np√(npq) )
포아송의 정규근사
적용 조건: λ ≥ 10 Z = X − λ√λ ≈ N(0, 1)

지수분포 Exp(λ)

PDF · CDF · 평균 · 분산
f(x) = λe−λx   (x ≥ 0) F(x) = 1 − e−λx E(X) = 1λ  ,   Var(X) = 1λ²
무기억성: P(X > s+t | X > s) = P(X > t)

이변량 확률변수Bivariate RV · p.180–227

5장까지는 변수 하나(X)만 봤다면, 6장은 두 변수 X와 Y를 동시에 다룬다. 두 변수의 관계가 있는지, 있다면 얼마나 강한지를 파악하는 것이 목표다.

두 변수의 동시 분포가 결합분포 f(x,y)다. 여기서 한 변수만 꺼내고 싶으면 나머지 변수에 대해 적분(합산)해서 주변분포 fX(x)를 구한다.

핵심 질문은 "두 변수가 서로 영향을 주는가?"이다.f(x,y) = fX(x)·fY(y) 가 성립하면 → 독립. 하나가 뭔지 알아도 다른 하나의 분포가 전혀 달라지지 않는다.독립이 아니라면 → 두 변수 사이에 관계가 있고, 그 크기와 방향을 공분산 Cov(X,Y)로 측정한다. 단위의 영향을 없애고 −1에서 1 사이로 정규화한 것이 상관계수 ρ다.

두 변수의 선형결합 aX+bY의 분산을 구할 때 독립이면 단순히 a²Var(X)+b²Var(Y)이지만, 독립이 아니면 공분산 항 2ab·Cov(X,Y)가 추가로 붙는다.

핵심 개념

결합분포
두 RV (X,Y)의 동시 분포. 이산: p(x,y), 연속: f(x,y). 전체 합/적분 = 1.
주변분포
다른 변수에 대해 합산(적분)하여 한 변수의 분포만 추출.
독립 조건
f(x,y) = fX(x)·fY(y) 이면 독립. 공분산=0은 필요조건 (충분 아님).
공분산
두 변수의 선형관계 크기·방향. Cov > 0: 양의 관계.
상관계수 ρ
−1 ≤ ρ ≤ 1. 단위 없는 선형관계 강도. |ρ|=1: 완전 선형.
조건부분포
fX|Y(x|y) = f(x,y)/fY(y). 독립이면 조건부=주변분포.

주요 수식

주변확률밀도함수
fX(x) = ∫ f(x,y) dy fY(y) = ∫ f(x,y) dx
공분산
Cov(X,Y) = E(XY) − E(X)·E(Y) = E[(X−μX)(Y−μY)]
상관계수
ρXY = Cov(X,Y)σX · σY  ,   −1 ≤ ρ ≤ 1
선형결합의 분산
Var(aX + bY) = a²Var(X) + b²Var(Y) + 2ab·Cov(X,Y)
독립이면 Cov=0 이므로: Var(aX+bY) = a²Var(X) + b²Var(Y)

표본분포Sampling Distributions · p.224–270

지금까지는 모집단의 분포가 알려진 상태에서 확률을 계산했다. 7장부터는 반대 방향, 즉 표본을 뽑아서 모집단을 추론하는 방향으로 전환된다. 8~10장의 추정·검정은 전부 7장의 표본분포 위에서 작동한다.

표본을 뽑으면 표본평균 X̄가 나오는데, 이 X̄ 자체도 확률변수라 매번 다른 값이 나온다. X̄의 분포가 표본분포다. 핵심은 두 가지다.E(X̄) = μ → 평균적으로 모평균을 정확히 맞힌다.Var(X̄) = σ²/n → 표본이 클수록 X̄는 μ 근처에 밀집된다.

모집단 분포가 정규면 X̄도 정확히 정규다. 정규가 아니어도 n ≥ 30이면 중심극한정리(CLT)에 의해 X̄는 근사적으로 정규분포를 따른다. 이것이 정규분포가 통계학 전반에 등장하는 이유다.

이후 검정에서 사용할 세 가지 분포가 정규분포로부터 파생된다.χ² 분포: 표준정규 Z를 제곱해서 합산. 모분산 추정/검정에 사용.t 분포: σ를 모를 때 S로 대체하면 Z가 아닌 t 통계량이 나온다. 꼬리가 두꺼워서 σ를 모를 때의 불확실성을 반영.F 분포: 두 χ²의 비. 두 집단의 분산을 비교할 때 등장.

핵심 개념

확률표본
X1,…,Xn i.i.d. 통계량은 표본의 함수이자 확률변수.
중심극한정리
모집단 무관, n ≥ 30이면 X̄는 근사 정규분포. 통계추론의 핵심 근거.
대수의 법칙
n→∞이면 X̄ → μ (확률수렴). 표본 증가 → 추정 정확도 향상.
χ² 분포
Z1²+…+Zk² ~ χ²(k). 비음수·오른쪽 치우침. 모분산 추정/검정에 사용.
t 분포
T = Z/√(U/k) ~ t(k). 정규보다 두꺼운 꼬리. k→∞이면 N(0,1)로 수렴.
F 분포
두 독립 χ²의 비. 두 분산의 비 검정에 사용.

주요 수식

표본평균의 분포
E(X̄) = μ Var(X̄) = σ²n X̄ ~ N(μ, σ²/n) — 정규모집단이면 정확, 일반 모집단이면 CLT에 의해 근사
중심극한정리 (CLT)
Z = X̄ − μσ/√n → N(0,1)   (n → ∞)
표본분산과 χ² 분포
(n−1)S²σ² ~ χ²(n−1) S² = 1n−1 · Σ(Xi − X̄)²
t 통계량 (σ 미지)
T = X̄ − μS/√n ~ t(n−1)
표본비율의 분포
E(p̂) = p  ,   Var(p̂) = p(1−p)n n이 충분히 크면: p̂ ≈ N(p, p(1−p)/n)
Ch·8

점추정Point Estimation · p.272–299

모수(μ, σ², p 등)는 알 수 없다. 대신 표본을 뽑아 모수를 하나의 숫자로 추측하는 것이 점추정이다. 표본평균 X̄로 μ를 추정하고, 표본비율 p̂으로 p를 추정하는 식이다.

추정량이 좋은지 판단하는 기준이 세 가지다.① 불편성: 반복 추정하면 평균적으로 모수를 정확히 맞히는가? E(θ̂) = θ이면 불편추정량이다.② 효율성: 불편추정량이 여럿이면 분산이 가장 작은 것을 고른다. MSE = Var + bias²로 종합 평가한다. bias가 있어도 분산이 훨씬 작으면 더 실용적일 수 있다.③ 일치성: 표본이 커질수록 추정값이 모수에 가까워지는가? MSE → 0이면 일치추정량이다.

좋은 추정량을 찾는 방법이 두 가지다.적률방법(MOM): 모적률 = 표본적률로 방정식을 세워 푼다. 계산이 간단하지만 최적이 아닐 수 있다.최대우도법(MLE): 관측된 데이터가 나올 확률(우도)을 가장 크게 만드는 θ를 찾는다. 로그우도를 미분해서 0으로 놓으면 된다. 불변성·일치성·근사 정규성을 자동으로 만족하는 강력한 방법이다.

핵심 개념

불편성
E(θ̂) = θ. X̄→μ, S²→σ² 의 불편추정량.
최소분산(MVUE)
불편추정량 중 분산이 가장 작은 것. 이론적 하한: 크래머-라오 하한.
MSE
MSE = Var(θ̂) + bias². 불편이면 MSE = Var(θ̂).
일치성
n→∞이면 θ̂ → θ (확률수렴). MSE→0이면 일치추정량.
적률방법 MOM
모적률=표본적률 방정식 풀기. 계산 간단, MLE보다 효율 낮을 수 있음.
최대우도법 MLE
우도함수 L(θ) 최대화. 불변성·일치성·근사 정규성 등 우수한 성질.

주요 수식

평균제곱오차 (MSE)
MSE(θ̂) = Var(θ̂) + [E(θ̂) − θ]²
상대효율
RE(θ̂1, θ̂2) = MSE(θ̂2)MSE(θ̂1) > 1 이면 θ̂1이 더 효율적
r차 표본적률 (MOM)
M′r = 1n · Σ Xir μ′r = M′r 로 방정식 구성하여 θ 추정
우도함수 · MLE
L(θ) = Π f(xi ; θ) ln L(θ) = Σ ln f(xi ; θ) ∂lnL / ∂θ = 0 을 풀어 θ̂MLE 도출
Ch·9

구간추정Interval Estimation · p.301–344

점추정은 단 하나의 숫자로 모수를 추측하는데, 그 숫자가 얼마나 믿을 만한지는 알 수 없다. 구간추정은 "이 범위 안에 모수가 있을 확률이 95%"처럼 신뢰도와 함께 구간을 제시한다.

구간 공식은 항상 같은 구조다: 추정량 ± (임계값) × (표준오차). 달라지는 것은 임계값의 종류다.모분산 σ²을 아는 경우 → Z 통계량 사용. X̄를 표준화하면 N(0,1)을 따르므로 임계값은 zα/2.모분산을 모르는 경우 → σ 대신 S를 쓰면 t 통계량이 된다. 임계값은 자유도 n−1인 tα/2(n−1). n이 작을수록 t값이 z값보다 커서 구간이 넓어진다 — σ를 모르는 불확실성을 반영한 것이다.

두 집단을 비교할 때는 상황에 따라 다시 갈린다.두 표본이 독립이고 등분산이라면 → 두 표본의 정보를 합친 합동분산 Sp²을 써서 구간을 좁힌다.같은 대상을 두 번 측정한 대응표본이라면 → 차이 Di = Xi−Yi를 만들어 단일표본 문제로 환원한다.

신뢰구간의 폭을 원하는 허용오차 E 이하로 하고 싶다면 역으로 필요 표본크기 n을 구할 수 있다. 오차가 작을수록, 신뢰수준이 높을수록 더 많은 표본이 필요하다.

선택 기준: ① σ² 알면 → Z  ② σ² 모르면 → t (자유도 n−1)  ③ 두 그룹 등분산이면 합동분산 Sp², 아니면 Welch 자유도 사용.

모평균 구간추정

① σ² 아는 경우 — Z 신뢰구간
X̄ ± zα/2 · σ√n
95%: z0.025 = 1.96  |  90%: z0.05 = 1.645  |  99%: z0.005 = 2.576
② σ² 모르는 경우 — t 신뢰구간
X̄ ± tα/2(n−1) · S√n

두 모평균 차의 구간추정

독립표본 — 등분산 (합동분산 Sp²)
(X̄−Ȳ) ± tα/2(n1+n2−2) · Sp · √1/n1 + 1/n2 Sp² = (n1−1)S1² + (n2−1)S2² n1 + n2 − 2
대응표본 (Paired)
Di = Xi − Yi 로 정의 D̄ ± tα/2(n−1) · SD√n

기타 구간추정

모비율
p̂ ± zα/2 · √p̂(1−p̂) / n
모분산 (χ² 분포)
하한: (n−1)S²χ²α/2(n−1)  ,   상한: (n−1)S²χ²1−α/2(n−1)
표본크기 결정 (허용오차 E)
모평균: n ≥ (zα/2 · σ / E)² 모비율: n ≥ zα/2² · p(1−p) / E²

가설검정Hypothesis Testing · p.346–395

구간추정이 "모수가 어디쯤 있을 것이다"라면, 가설검정은 "모수가 특정 값이다/아니다"를 증거로 판정하는 것이다. 재판에서 무죄 추정 원칙처럼, 통계에서도 귀무가설 H0을 사실이라 가정하고 데이터가 그것을 뒤집을 만큼 충분히 강한 증거인지를 따진다.

검정 흐름은 항상 이 순서로 흘러간다.① H0와 H1을 설정한다 → ② 유의수준 α를 정한다(오경보를 얼마나 허용할지) → ③ 기각역을 설정한다 → ④ 검정통계량을 계산한다 → ⑤ 기각역에 해당하면 H0를 기각한다.

검정통계량 선택이 핵심이다.모분산 σ²을 아는 경우 → Z0 = (X̄−μ0)/(σ/√n). |Z0| > zα/2이면 H0 기각.모분산을 모르는 경우 → S로 대체해 T0 = (X̄−μ0)/(S/√n) ~ t(n−1). 자유도를 반드시 확인.두 집단 비교, 등분산 가정 → 합동분산 Sp²로 t 검정. 자유도 n1+n2−2.대응표본 → Di를 만들어 단일표본 t 검정으로 환원.

P값은 "귀무가설이 참일 때 이 정도 극단적인 결과가 나올 확률"이다. P < α이면 그런 결과는 우연이라 보기 어려우므로 H0를 기각한다. 9장의 신뢰구간과 정확히 대응된다 — μ0이 신뢰구간 밖에 있으면 기각, 안에 있으면 채택.

핵심 개념

H0 vs H1
H0: 기각하려는 가설(등호 포함). H1: 입증하려는 가설. 양측(≠) / 단측(< 또는 >).
제1종 오류 α
H0 참인데 기각. = 유의수준. 연구자가 사전 설정.
제2종 오류 β
H0 거짓인데 채택. 검정력 = 1−β. α↓이면 β↑ (tradeoff).
P값
관측 통계량보다 더 극단적인 값이 나올 확률. P < α이면 H0 기각.
구간추정과의 관계
θ0이 1−α 신뢰구간 밖 ↔ 유의수준 α로 H0 기각.

검정 절차 6단계

1가설 설정: H0와 H1 명확히
2유의수준 α 설정 (0.05 또는 0.01)
3기각역: 임계값으로 기각역 설정
4검정통계량: 관측 자료로 산출
5결론: 기각역 해당 여부 판정
6P값: P < α이면 H0 기각

주요 수식

단일모평균 — σ 아는 경우 (Z 검정)
Z0 = X̄ − μ0σ/√n ~ N(0,1) under H0
양측: |Z0| > zα/2 이면 기각  |  우측단측(H1: μ > μ0): Z0 > zα 이면 기각
단일모평균 — σ 모르는 경우 (t 검정)
T0 = X̄ − μ0S/√n ~ t(n−1)
두 모평균 차 (등분산, 독립표본)
T0 = (X̄−Ȳ) − δ0 Sp · √(1/n1 + 1/n2) ~ t(n1+n2−2)
δ0 = μ1−μ2 (귀무가설 값, 보통 0)
대응표본 검정
T0 = D̄ − δ0SD/√n ~ t(n−1)  ,   Di = Xi − Yi
모비율 검정
Z0 = p̂ − p0 √(p0(1−p0)/n) ~ N(0,1)

검정 유형 요약표

검정 대상조건통계량분포
단일 모평균σ² 알 때(X̄−μ0)/(σ/√n)N(0,1)
단일 모평균σ² 모를 때(X̄−μ0)/(S/√n)t(n−1)
두 평균 차독립, 등분산합동분산 Sp 사용t(n1+n2−2)
두 평균 차대응표본D̄/(SD/√n)t(n−1)
모비율대표본(p̂−p0)/√(p0q0/n)N(0,1)

범주형 자료분석Categorical Data · p.397–430

지금까지는 키, 점수처럼 수치 데이터를 다뤘다. 11장은 성별·등급·찬반처럼 범주로 나뉜 데이터를 다룬다. 평균이나 분산 대신 도수(빈도)와 비율을 분석의 도구로 쓴다.

분석 유형이 목적에 따라 세 가지로 갈린다.적합도 검정: 데이터가 특정 이론 분포를 따르는가? 예) 주사위가 공정한가, 완두콩 비율이 멘델 법칙을 따르는가. 각 범주의 기대도수 Ei = n·pi를 계산하고, 관측도수 Oi와 얼마나 다른지를 χ² 통계량으로 측정한다. 자유도 = 범주수 − 1 − 추정 모수수.독립성 검정: 두 범주형 변수가 서로 관련 있는가? 예) 성별과 선호 정당은 관계가 있는가. r×c 분할표를 만들고 각 칸의 기대도수를 (행 합계 × 열 합계)/전체로 계산한다. 자유도 = (r−1)(c−1).동질성 검정: 여러 모집단에서 어떤 특성의 분포가 같은가? 형태는 독립성 검정과 동일하지만 질문의 방향이 다르다.

셋 모두 같은 검정통계량 χ² = Σ(O−E)²/E를 사용하고, 이 값이 χ²α(자유도)보다 크면 H0를 기각한다. 단, 모든 기대도수가 5 이상이어야 이 근사가 타당하다는 점을 반드시 확인해야 한다.

핵심 개념

적합도 검정
관측 도수가 이론 분포에 적합한지 검정. 자유도 = 범주수 − 1 − 추정 모수수.
독립성 검정
두 범주형 변수의 연관성 유무. r×c 분할표. 귀무: 두 변수는 독립.
동질성 검정
여러 모집단에서 분포가 동일한지 검정. 통계량 형태는 독립성과 같음.
기대도수 조건
모든 Eij ≥ 5이어야 χ² 근사 타당. 미충족 시 범주 합병 또는 Fisher 검정.

Data Analysis · 확률론 Probability Theory · 교재 Ch.24 + 인공지능수학 기말 연계

이 챕터는 통계학원론 7–11장의 확률 기초와 인공지능수학 기말 통계 파트가 겹치는 핵심 구간이다. 기말에서 매번 고정 출제되는 3문제가 모두 여기서 나온다.

첫 번째는 나사 불량 확률: 복원/비복원 추출을 구분하고 조건부 확률 곱셈공식을 적용한다. 두 번째는 균등분포 밀도함수: ∫f(x)dx=1 조건으로 k를 구하고, 구간 겹침을 이용해 확률을 계산한다. 세 번째는 정규분포 불량률: 표준화 Z=(X−μ)/σ 후 표에서 Φ값을 읽는다. (a)는 범위→불량률%, (b)는 불량률%→범위 역산.

🎯 기말 100% 고정 출제 3문제 — 나사 불량(복원/비복원) · 균등분포 k구하기+확률 · 정규분포 불량률±역산. 숫자만 바뀌고 구조 동일.

복원 / 비복원 추출 확률 ★★ 반드시

복원추출
with replacement
매번 되돌려 놓음 → 시행 독립 → 곱셈
P(둘 다 불량) = P(불량) × P(불량) = (M/N)²
비복원추출
without replacement
꺼낸 것 제외 → 조건부 확률 곱
P(A∩B) = P(A) × P(B|A) = (M/N) × (M−1)/(N−1)
복원 — 이항분포
P(둘 다 불량) = MN × MN = M²N² 예: N=10, M=3 → (3/10)² = 9/100 = 0.09
비복원 — 초기하분포 / 조건부확률
P(A∩B) = P(A) × P(B|A) = MN × M−1N−1 예: N=10, M=3 → (3/10) × (2/9) = 6/90 = 1/15 ≈ 0.067

균등분포 밀도함수 ★★ 반드시

밀도함수 & k 구하기
f(x) = k   (a ≤ x ≤ b),   0 elsewhere ∫ab k dx = 1  →  k(b−a) = 1  →  k = 1b−a
예: f(x)=k (−4≤x≤6) → k×10=1 → k=1/10
확률 계산 — 구간 겹침
P(c ≤ X ≤ d) = k × (겹치는 구간 길이) 단, f(x)=0인 구간은 제외하고 겹치는 구간만 적분
예: f(x)=1/10 (−4~6), P(−7≤X≤2) → 겹치는 구간 [−4, 2] → (1/10)×6 = 0.6

정규분포 불량률 (tolerance limits) ★★ 반드시

(a) tolerance → 불량률%: 범위 주어지면 표준화 후 Φ 계산 → 1 − 정상품률

(b) 불량률% → tolerance 역산: 불량률 α% → 정상품 (1−α)% → Φ(c/σ) 구하고 표에서 역산

(a) 범위 → 불량률
X ~ N(μ, σ²), 허용범위 μ±c 정상품률 = P(μ−c ≤ X ≤ μ+c) = 2Φ(c/σ) − 1 불량률 = 1 − (2Φ(c/σ) − 1) = 2(1 − Φ(c/σ))
예: μ=100, σ=1, c=0.44 → Φ(0.44)=0.6700 → 정상품 2(0.67)−1=0.34 → 불량 66%
(b) 불량률 → 범위 역산
불량률 α → 정상품률 1−α 2Φ(c/σ) − 1 = 1−α  →  Φ(c/σ) = 2−α2 표에서 z값 찾기 → c = z × σ
예: 불량률 66% → 정상품 34% → 2Φ(c)−1=0.34 → Φ(c)=0.67 → c/1=0.44 → c=0.44
정규분포 표 읽는 법: Φ(z) = P(Z ≤ z). 표 행=소수점 첫째, 열=소수점 둘째. 음수: Φ(−z) = 1−Φ(z)
