00

이미지 다운샘플링Image scaling · sub-sampling

문제 — 이미지가 화면보다 너무 크다. 절반 크기로 만들려면?
가장 단순한 방법 — 한 줄 건너 한 줄씩 행과 열을 버린다(sub-sampling). 1/2, 1/4, 1/8로 줄여 나간다.
01

에일리어싱 (Aliasing)샘플링이 촘촘하지 않으면 가짜 신호가 보인다

샘플링 — 연속적인 신호(빛, 사인파)를 일정 간격으로 찍어 숫자로 만드는 것. 디지털 이미지 자체가 연속적인 장면을 화소 간격으로 샘플링한 결과다(3주차 00).
에일리어싱 — 샘플링 간격이 이미지의 세밀함을 담기에 충분하지 않을 때 생기며, 원래와 다른 신호(alias, ‘가명’)를 보여 준다.
02

에일리어싱을 피하는 두 가지 방법① 더 촘촘히 샘플링 ② 먼저 블러, 그다음 서브샘플

Solution 1) Oversample the signal샘플링을 충분히 촘촘하게

샘플링 주파수가 이미지의 최대 주파수의 2배 이상이어야 한다 = 한 주기에 샘플 2개 이상. 이 최소 샘플링률이 나이퀴스트율(Nyquist rate).

Solution 2) Filter, then subsample이미 찍힌 이미지를 줄일 때

에일리어싱을 일으키는 세밀한 디테일(고주파)을 먼저 없앤 뒤 줄인다. 정보는 잃지만 가짜 무늬보다는 낫다.

나이퀴스트 조건

f_s\;\ge\;2f_0\qquad(f_s:\text{ 샘플링 주파수},\;f_0:\text{ 신호의 최대 주파수})

교안 15p 오른쪽 그림: 샘플링하면 원래 스펙트럼이 f_s 간격으로 복제되는데, f_s<2f_0 이면 복제본끼리 겹쳐서(aliasing) 원래 신호를 분리할 수 없게 된다. 겹치기 전에 저역 통과 필터(LPF)로 고주파를 잘라 두면 겹치지 않는다 — 이것이 Solution 2의 원리다.

3주차와의 연결 — 가우시안 필터는 저역 통과 필터다(가는 무늬 = 고주파를 걸러 냄). 3주차에는 ‘노이즈를 줄이는 도구’였던 가우시안이 이번 주에는 ‘줄여도 안 깨지게 하는 도구’로 쓰인다.
03

가우시안 피라미드 (Gaussian Image Pyramid)blur → subsample 을 반복해 쌓은 해상도 계층

만드는 법

F_0\;\xrightarrow{\;*H\ (\text{blur})\;}\;F_0*H\;\xrightarrow{\;\downarrow2\ (\text{subsample})\;}\;F_1\;\xrightarrow{\;*H\;}\;F_1*H\;\xrightarrow{\;\downarrow2\;}\;F_2\;\cdots

H 는 가우시안 커널, \downarrow2 는 가로·세로 절반. 한 층 올라갈 때마다 해상도 1/2, 화소 수 1/4. Level 0이 원본, 위로 갈수록 작고 흐릿하다.

교안 질문 가우시안 피라미드 전체는 원본 대비 얼마의 저장 공간을 차지하나?

①
층마다 화소 수가 1/4: 1+\tfrac14+\tfrac1{16}+\tfrac1{64}+\cdots
②
등비급수 합 \dfrac{1}{1-1/4}=\dfrac43
답 — 원본의 4/3배, 즉 원본보다 약 33%만 더 쓰면 모든 해상도를 다 가질 수 있다
교안의 질문 (23p)답
위층으로 갈수록 디테일은?점점 뭉개진다(smoothed out)
위층에 남는 것은?원본의 크고 균일한 영역 위주
위층 이미지로 원본을 복원할 수 있나?불가능 — 블러로 잃은 정보는 돌아오지 않는다 (lossy)
04

라플라시안 피라미드 (Laplacian Image Pyramid)블러 이미지 대신 ‘예측 오차(잔차)’를 저장한다

복원하려면 무엇을 저장해야 하나? — 각 층에서 블러 이미지 자체 대신 잔차(residual)를 보관한다. 오른쪽 그림 아래줄의 잔차 이미지들은 대부분 회색(0 근처)이고 히스토그램이 가운데 한 점에 몰려 있다 — 값이 0 주변에 모여 있으면 압축이 아주 잘 된다.

교안 30~31p 기호 읽기

x_{k+1}=G_k\,x_k,\qquad L_k=(I-F_kG_k)\,x_k=x_k-F_k\,x_{k+1},\qquad x_k=L_k+F_k\,x_{k+1}

· G_k — 가우시안 블러 + 다운샘플(한 층 올리기) · F_k — 업샘플 + 보간(한 층 내리기) · I — 항등(원본 그대로)
· 분해: L_1,L_2,L_3 와 맨 위의 작은 이미지 g_3 만 저장
· 복원(31p): x_3=g_3+L_3\to x_2=F(x_3)+L_2\to x_1=F(x_2)+L_1 — 위에서부터 ‘키우고 더하기’를 반복하면 원본이 정확히 돌아온다

‘라플라시안’이라는 이름 — 원본 − 블러 = 가우시안의 차이(DoG)이고, DoG는 3주차 11절에서 본 대로 LoG(라플라시안 오브 가우시안)의 근사다. 그래서 잔차 이미지가 에지 검출 결과처럼 윤곽선만 남은 모양으로 보인다.
# OpenCV 한 층 분해 · 복원 (3주차 실습 PY2와 과제 3-3)
down = cv2.pyrDown(img)                    # G: 블러 + 1/2
up   = cv2.pyrUp(down, dstsize=(img.shape[1], img.shape[0]))   # F: 2배 + 보간 (크기 맞춤)
L    = cv2.subtract(img, up)               # 잔차 L = x − F(G x)
restored = cv2.add(up, L)                  # 복원 x = F(G x) + L
uint8 함정 — 잔차는 원래 음수도 나오는 값이다. uint8로 cv2.subtract하면 음수가 0으로 잘려 복원이 완벽하지 않을 수 있다. 정확히 하려면 img.astype(np.float32)로 바꿔 빼고 더한 뒤 마지막에 np.clip(..., 0, 255).astype(np.uint8). pyrUp의 dstsize는 원본 크기가 홀수일 때 두 이미지 크기를 맞추기 위한 인자다.
05

이미지 피라미드 정리와 응용Gaussian vs Laplacian · Applications

  • Gaussian pyramid — 점점 흐리게 · 작게 만든 버전들. 고정 크기 알고리즘에 스케일 불변성을 더해 준다 (예: 24×24 얼굴 검출기를 층마다 돌리면 크고 작은 얼굴을 모두 찾는다)
  • Laplacian pyramid — 가우시안 피라미드에서 각 공간 스케일에 더해지는 정보. 노이즈 제거와 부호화(압축)에 유용

웨이블릿 변환 (Wavelet Transform)근사(a) + 가로(h) · 세로(v) · 대각(d) 디테일로 쪼개기

무엇인가 — 웨이블릿 부호화는 DCT 부호화의 변형으로, DCT의 블록 단위 방식 대신 웨이블릿을 쓴다(JPEG 2000이 대표 예). 라플라시안 피라미드와 발상이 같지만, 디테일을 방향별로 나누고 전체 계수 개수가 원본과 똑같다는 점이 다르다.

개수 세기 웨이블릿 계수의 총 개수는?

①
\tfrac N2+\tfrac N4+\tfrac N8+\tfrac N8=N
원본과 똑같이 N개 — 라플라시안 피라미드가 4/3배로 늘어나는 것과 대비된다(교안 36p 빨간 글씨). 정보를 잃지도 늘리지도 않는 ‘딱 맞는’ 표현

보간 (Interpolation)키울 때 빈칸을 무엇으로 채우나 — 재구성 필터로 보기

업샘플링의 가장 단순한 방법 — 이미지를 10배로 키우려면 각 행·열을 10번씩 반복한다 → 최근접 이웃 보간(Nearest neighbor). 결과는 오른쪽처럼 계단(블록) 모양.

보간을 ‘필터링’으로 보기 (교안 43~44p)

F[x,y]=\text{quantize}\{f(xd,\,yd)\},\qquad f_F(x)=\begin{cases}F(x/d)&x/d\text{ 가 정수}\\0&\text{그 외}\end{cases},\qquad \tilde f=h*f_F

① 디지털 이미지 F 는 연속 함수 f 를 간격 d 로 점 샘플링하고 양자화한 것 ② 원래 f 를 복원할 수 있으면 어떤 해상도로든 다시 만들 수 있다 ③ 모르니까 근사 \tilde f 를 추정 — 샘플 사이를 0으로 채운 f_F 에 재구성 필터 h 를 컨볼루션한다(3주차 10절의 컨볼루션). 어떤 h 를 쓰느냐가 곧 어떤 보간이냐다.

바이리니어 · 바이큐빅 보간격자 예제 직접 계산 · 세 방식 비교

1D 선형 보간 (교안 47p)

f(x)=\frac{d_2}{d_1+d_2}\,f(x_1)+\frac{d_1}{d_1+d_2}\,f(x_2)

d_1 = x 에서 x_1 까지 거리, d_2 = x_2 까지 거리. 가까운 쪽 값에 더 큰 가중치(가중치가 반대편 거리에 비례하는 것에 주의).

바이리니어 = x방향 선형 보간 2번 → y방향 1번 (교안 48p)

\begin{aligned}f(x,y_1)&\approx\tfrac{x_2-x}{x_2-x_1}f(Q_{11})+\tfrac{x-x_1}{x_2-x_1}f(Q_{21}),\qquad f(x,y_2)\approx\tfrac{x_2-x}{x_2-x_1}f(Q_{12})+\tfrac{x-x_1}{x_2-x_1}f(Q_{22})\\ f(x,y)&\approx\tfrac{y_2-y}{y_2-y_1}f(x,y_1)+\tfrac{y-y_1}{y_2-y_1}f(x,y_2)\end{aligned}

주변 네 점 Q_{11},Q_{21},Q_{12},Q_{22} 만 쓴다. 최근접보다 매끄럽고, 격자 위 임의 위치의 값을 구할 때(이미지 회전·워핑, 텍스처 맵) 쓰인다.

교안 49p 직접 풀기 원래 값 10·15·24 / 24·18·27 / 16·21·30 이 7×7 격자의 0·3·6번째 행·열에 놓였다. 4행 5열(0부터 셈)의 빨간 칸은?

①
둘러싼 네 점: 3행의 18(3열)·27(6열), 6행의 21(3열)·30(6열). 가로 위치는 3→6 중 5 → 비율 \tfrac23, 세로는 3→6 중 4 → 비율 \tfrac13
②
3행 가로 보간: 18+(27-18)\cdot\tfrac23=24 · 6행 가로 보간: 21+(30-21)\cdot\tfrac23=27
③
세로 보간: 24+(27-24)\cdot\tfrac13=25
답 25 — 순서를 바꿔 세로 먼저 해도 18\to19,\;27\to28 에서 19+(28-19)\cdot\tfrac23=25 로 같다. 참고로 최근접 이웃이면 가장 가까운 원래 점(3행 6열)의 27이 된다

바이큐빅 (교안 50p)

g(x,y)=\frac1{16}\sum_{l=-1}^{2}\sum_{m=-1}^{2}f(x+l,\,y+m)\,u(d_x)\,u(d_y)

주변 4×4 = 16점을 쓴다. f(x+l,y+m) 은 화소값, u(d_x),u(d_y) 는 x·y 방향 거리에 따른 3차 다항식 가중치. 이웃을 넓게 보고 곡선으로 이어서 가장 매끄럽지만 계산량이 가장 많다.
