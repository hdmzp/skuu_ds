01

이번 주 공부 방법교수님이 가장 강조하신 것

교수님 멘트
“오늘 내용은 알고리즘이 많은데 — 함수 위주로 보세요. 예를 들어서 ‘피라미드’는 이렇게 쓰는 거구나~”
“여튼 함수 위주로 체크하라” · “OpenCV는 이런 거구나~”
어떻게 읽으라는 뜻인가
  • 알고리즘 내부를 외우는 것이 목표가 아니다 — 가우시안 커널을 손으로 계산하는 능력보다, 어떤 상황에서 어떤 함수를 부르는지를 아는 것이 이번 주의 목표다
  • 함수 하나를 볼 때 세 가지만 챙기면 된다 — ① 무엇을 입력받고 ② 무엇을 돌려주고 ③ 언제 쓰는가
  • 예) cv2.pyrDown(img) — ① 이미지를 받아 ② 가로 · 세로가 절반인 이미지를 돌려주고 ③ 해상도를 낮출 때 쓴다
시험 관점 — 함수 이름과 역할이 짝지어져 나오는 형태를 염두에 두면 좋다. “축소는 pyrDown, 확대는 pyrUp”처럼 이름에서 동작이 읽히는 함수가 많다.
02

지난 실습에서 다룬 함수 복습교수님이 예로 드신 피라미드 — 자세한 코드와 결과는 3주차 실습 자료에 있습니다

교수님 멘트 — “예를 들어서 ‘피라미드’는 이렇게 쓰는 거구나~” “피라미드다운, 피라미드업” 
cv2.pyrDown(img)
cv2.pyrUp(img)
딱 이만큼만 기억하면 된다
  • cv2.pyrDown(img) — 가로 · 세로가 절반(화소 수 1/4). 가우시안 스무딩을 먼저 하고 표본을 뽑기 때문에 에일리어싱을 피한다
  • cv2.pyrUp(img) — 가로 · 세로가 두 배. 빈 화소를 가우시안으로 메운다
  • 왕복해도 원본으로 돌아오지 않는다 — 내려갈 때 버린 세부는 되살아나지 않는다. 그 ‘잃어버린 차이’를 모아 둔 것이 라플라시안 피라미드다

왜 여기서는 짧게만 다루나 — 이 함수들은 3주차 실시간 강의(기초 코드 실습 2) 자료에 실습 교안 캡처와 함께 이미 정리되어 있다. 같은 내용을 두 번 적지 않고 링크로 연결했다.
03

cv2라는 이름의 뜻수업 중 나온 궁금증에 대한 답

수업 중 나온 질문
“cv 2.0, 3.0 계속 나오고 있는데, 공통적으로 차세대 개념으로 cv2.로 통칭하는 건가?”
정리하면 — “차세대 API를 가리킨다”는 감은 맞고, “버전 2를 뜻한다”는 아니다
  • cv2의 2는 OpenCV 버전 번호가 아니라 “2세대 API”를 뜻한다
  • 초기 OpenCV는 C 언어 API를 썼고 파이썬에서 import cv로 불렀다. OpenCV 2.0에서 C++ API가 새로 도입되면서, 그 새 API를 감싼 파이썬 모듈 이름이 cv2가 되었다
  • 그래서 OpenCV 3.x든 4.x든 지금도 전부 import cv2다 — 모듈 이름은 버전과 함께 바뀌지 않는다
확인해 보는 법 
import cv2
print(cv2.__version__)   # 실제 설치된 버전은 여기에 찍힌다
4.10.0          # ← 4.x인데도 모듈 이름은 여전히 cv2
설치할 때 쓰는 패키지 이름은 opencv-python이고, 불러올 때 쓰는 모듈 이름이 cv2다 — 둘이 다르다는 점도 함께 기억해 두자.
04

라이브러리 지도무엇에 특화된 도구인가 — 교수님이 비교해 주신 내용

교수님 멘트
  • NumPy는 데이터분석 직군이면 많이 쓸 거야. 행렬 · 배열 위주로 최적화
  • OpenCV는 컴퓨터비전에 특화
  • 사이킷런은 파이썬의 머신러닝 라이브러리, 사이킷이미지는 이미지처리 알고리즘 패키지. 사이킷 바이오도 있어요
  • import 시킬 땐 sklearn.~~, skimage.~~ 이렇게 불러서 쓴다
라이브러리무엇에 특화설치 이름 → import 이름
NumPy행렬 · 배열 연산 최적화. 아래 모든 라이브러리가 이 위에 올라간다numpy → import numpy as np
OpenCV컴퓨터비전 특화 — 입출력 · 변환 · 필터링 · 검출opencv-python → import cv2
SciPy과학 · 공학 계산 전반 — 적분 · 최적화 · 신호처리 · 통계scipy → import scipy
scikit-learn머신러닝 — 분류 · 회귀 · 군집 · 전처리 · 모델 평가scikit-learn → import sklearn
scikit-image이미지 처리 알고리즘 — 필터 · 분할 · 특징 · 측정scikit-image → import skimage
scikit-bio생물정보학 — 서열 · 계통 · 다양성 분석scikit-bio → import skbio
설치 이름과 import 이름이 다르다 — 교수님이 짚어 주신 바로 그 지점이다. pip install scikit-learn으로 깔고 import sklearn으로 부른다. pip install sklearn은 올바른 방법이 아니다.

scikit이라는 이름은 어디서 왔나

  • SciPy = Scientific Python — 과학 계산용 파이썬
  • scikit = SciPy Toolkit — SciPy 생태계에 얹어 쓰는 전문 분야별 도구 모음이라는 뜻
  • 그래서 scikit-learn(머신러닝) · scikit-image(이미지) · scikit-bio(생물정보)처럼 “scikit- + 분야” 형태의 형제 패키지가 여럿 있다
발음 메모 — 수업에서 “싸이-킷 런”으로 들린 대로, scikit은 “사이킷”으로 읽고 SciPy는 “사이파이”로 읽는다. 필기에 scikit과 SciPy가 섞여 적혀 있었는데, scikit이 SciPy에서 파생된 이름이라 생각하면 헷갈리지 않는다.

그래서 이 수업에서는

주력이 과목에서 계속 쓴다

NumPy로 이미지를 배열로 다루고, OpenCV로 변환 · 필터링 · 검출을 한다. 2주차-1 실습이 그 기초였다.

참고알아만 두면 되는 것

scikit-image는 OpenCV와 기능이 겹치는 부분이 많다. 같은 작업을 다른 문법으로 제공하는 대안 정도로 알아 두면 충분하다.
