13. 이미지 생성 — 위조지폐범과 경찰이 서로를 키운다 (GAN)

지금까지의 신경망은 사진을 보고 ‘무엇인가’를 맞히는 결정론적인 과업(분류 · 탐지 · 분할)을 했다. 이번 주는 세상에 없던 이미지를 만들어 내는 생성 모델, 그중 생성적 적대 신경망(GAN)이다. 노이즈로 가짜를 만드는 생성자와 진짜 · 가짜를 가려내는 판별자가 경쟁하며 함께 좋아진다. 두 네트워크의 구조(판별자 = 줄어드는 CNN, 생성자 = 거꾸로 커지는 CNN), 판별자를 고정한 통합 신경망으로 생성자를 학습하는 방법, 이 경쟁을 수식으로 쓴 미니맥스 가치 함수, 평가 지표(인셉션 점수 · FID)와 응용, 그리고 패션 MNIST로 GAN을 직접 만드는 7단계 프로젝트를 다룬다.

이번 주 한 줄 요약

  • 생성 모델 = 기존에 없던 새로운 콘텐츠(이미지 · 영상 · 음악 · 텍스트)를 만드는 신경망. GAN은 적대적 훈련에 기반해 서로 경쟁하는 두 신경망으로 이뤄진다
  • 생성자(위조지폐범) = 무작위 노이즈 → 진짜 같은 이미지. 판별자(경찰) = 이미지 → 진짜일 확률(0 가짜 · 1 진짜). 판별자는 줄어드는 CNN, 생성자는 1차원 벡터에서 커지는 CNN(업샘플링 = 픽셀 반복)
  • 학습은 번갈아: ① 판별자 = 진짜(1) · 가짜(0)를 레이블과 함께 넣는 지도 학습 ② 생성자 = 판별자를 붙인 통합 신경망에 노이즈를 넣고 정답을 ‘진짜(1)’로 — 이때 판별자 가중치는 고정(trainable=False)
  • 미니맥스 게임(제로섬): \min_G\max_D V(D,G), V=\mathbb E[\log D(x)] +\,\mathbb E[\log(1-D(G(z)))] — D는 키우고 G는 줄인다. 로그는 틀릴수록 벌점을 크게
  • 평가: 인셉션 점수(예측 확신도 높음 + 다양성 높음) · FID(실제와 생성 이미지의 인셉션 출력 분포 사이 프레셰 거리, 작을수록 좋음). 응용: StackGAN(문장 → 이미지, 2단계) · 이미지-이미지 번역 · 초해상도

13.1

생성 모델 개요와 GAN의 기본 개념교안 2~5p

교안 슬라이드 모아보기 2p · 3p · 4p · 5p

교안생성 모델 — 없던 것을 만든다 (2 · 3p)

학습 목표는 생성적 적대 신경망에 대해 알아본다. 지금까지 딥러닝 · 신경망은 이미지의 시각적 특징을 이해해 사물 탐지 같은 결정론적인 과업을 하도록 배웠다. 이번 주는 컴퓨터 비전에서 딥러닝을 응용하는 새로운 영역인 생성 모델(generative model)이다.

  • 생성 모델 = 기존에 존재하지 않았던 새로운 콘텐츠를 생성하는 능력을 가진 신경망 모델
  • 실제와 매우 흡사한 이미지 · 영상 · 음악 · 텍스트를 생성할 수 있다

기계학습특론 1주차의 ‘판별 모델 vs 생성 모델’(1주차)이 여기서 실제 구조로 이어진다 — 판별 모델은 ‘이 사진은 무엇인가’, 생성 모델은 ‘이런 사진을 하나 그려라’.

교안GAN — 서로 경쟁하는 두 신경망 (4p)

생성적 적대 신경망(GAN, Generative Adversarial Network)은 적대적 훈련(adversarial training)이라는 개념에 기반하며, 서로 경쟁하는 2개의 신경망으로 구성된다.

입력하는 일
생성자 (generator)무작위 노이즈노이즈를 원래 데이터셋에서 본 표본과 비슷하도록 변환한다
판별자 (discriminator)이미지(관찰)입력이 생성자가 만든 가짜인지, 원래 데이터셋의 진짜인지 예측한다

교안위조지폐범과 경찰 (5p)

  • 생성자 = 위조지폐범, 판별자 = 경찰
  • 위조지폐범은 더 진짜 같은 위조지폐를 만드는 법을 익히고, 경찰은 그것을 찾아내는 법을 익힌다
  • 상대의 기술이 향상되면서 서로의 학습 목표도 변한다 — 위조지폐범이 완벽한 위조지폐를 만들면 경찰은 새로운 감별법을 익힌다
  • 상대방의 기술을 깨는 방법을 끝없이 학습하는 과정 — 이것이 ‘적대(adversarial)’의 뜻이다

두 신경망은 같은 목표를 공유하지 않는다. 판별자가 이기면 생성자가 지고, 생성자가 이기면 판별자가 진다 — 13.4의 제로섬 게임.

13.2

GAN의 구조와 동작 원리교안 6~9p

교안 슬라이드 모아보기 6p · 7p · 8p · 9p

교안두 네트워크의 모양과 동작 순서 (6p)

판별자 신경망생성자 신경망
구조출력이 1차원이 될 때까지 합성곱층의 크기가 작아지는 일반적인 CNNCNN 층 배치를 반대로 바꾼 구조 — 1차원 벡터를 받아 합성곱의 크기가 입력 이미지 크기까지 점점 커진다
입력 → 출력이미지 → 진짜일 확률 1개노이즈 벡터 → 이미지
① 생성자가 무작위 숫자를 입력받아 이미지를 반환노이즈 z → G(z)
② 생성된 이미지가 데이터셋의 실제 이미지와 함께 판별자에 입력가짜와 진짜가 섞여 들어간다
③ 판별자가 각 이미지가 실제 이미지일 확률을 반환0이면 가짜, 1이면 진짜

교안판별자 모델 (7p)

목표: 입력받은 이미지가 생성자가 만든 가짜인지 진짜인지 예측하는 것. 7p 코드는 Sequential에 합성곱층을 쌓되, 합성곱층마다 LeakyReLU(alpha=0.2)와 Dropout(0.25)을 붙이고, 중간에 ZeroPadding2D · BatchNormalization(momentum=0.8)을 두며, 마지막에 Flatten → Dense(1, activation='sigmoid')로 진짜일 확률 하나를 낸다.

교안생성자 모델 (8p)

생성자는 무작위 데이터를 받아 훈련 데이터를 흉내 낸 가짜 이미지를 만든다. 목표: 판별자가 진짜라고 판정할 만큼 훈련 데이터와 완벽하게 비슷한 이미지를 만드는 것. 8p 코드는 노이즈를 Dense(128*7*7)로 키운 뒤 Reshape((7, 7, 128))로 특징 맵 모양을 만들고, 그다음 업샘플링과 합성곱을 반복해 7×7 → 14×14 → 28×28 이미지로 키운다.

교안다운 샘플링과 업샘플링 (9p)

  • 다운 샘플링 — 풀링 층을 이용해 입력 이미지를 줄이는 것
  • 업샘플링 — 입력 픽셀을 반복하는 형태로 늘리는 층. 코드: keras.layers.UpSampling2D(size=(2, 2))

각 값이 가로 · 세로로 size배씩 복제된다. 학습할 파라미터가 없다 — 그래서 바로 뒤에 합성곱층을 붙여 복제된 덩어리를 매끄럽게 다듬는다. 12주차의 언풀링(마스크 자리에만 값, 나머지 0)이나 전치 합성곱(학습되는 필터)과 다르다(12.3).

보충설명모양으로 비교 — 판별자는 줄이고, 생성자는 키운다

판별자는 11주차 분류 CNN과 같은 모양(크기 ↓ 채널 ↑ → 값 하나), 생성자는 그것을 거꾸로 세운 모양(크기 ↑ 채널 ↓ → 이미지)이다. 7×7을 8×8로 만드는 ZeroPadding2D(((0,1),(0,1)))는 아래 · 오른쪽에 0을 한 줄씩 덧대 다음 보폭 2 합성곱이 4×4로 딱 떨어지게 하려는 것이다. 판별자에 LeakyReLU를 쓰는 이유: 음수 쪽에도 작은 기울기(0.2)를 남겨, 판별자를 거쳐 생성자까지 가는 기울기가 끊기지 않게 한다.

13.3

GAN의 학습 과정과 통합 신경망교안 10~14p

교안 슬라이드 모아보기 10p · 11p · 12p · 13p · 14p

교안판별자 학습 — 평범한 지도 학습 (10 · 12p)

  • 일반적인 지도 학습 모델의 학습 과정이다 — 생성자가 만든 가짜 이미지와 훈련 데이터에서 뽑은 진짜 이미지를 레이블과 함께 입력한다(진짜 = 1, 가짜 = 0)
  • 진짜인지 여부를 시그모이드 함수로 확률 값으로 예측한다
  • 12p 코드: discriminator = Discriminator_Model()로 만들고, binary_crossentropy 손실 · Adam 최적화 · metrics=['accuracy']로 컴파일
noise = np.random.normal(0, 1, (batch_size, 100))     # 노이즈 데이터 생성
gen_imgs = generator.predict(noise)                   # 생성자로 가짜 이미지 한 배치 생성
# 판별자 모델 학습(진짜 이미지는 1, 가짜 이미지는 0)
d_loss_real = discriminator.train_on_batch(imgs, valid)
d_loss_fake = discriminator.train_on_batch(gen_imgs, fake)

교안생성자 학습 — 판별자를 붙인 통합 신경망 (10 · 11 · 14p)

생성자를 학습하려면 만든 가짜 이미지가 얼마나 진짜 같았는지 알려 줄 판별자가 필요하다. 그래서 판별자와 생성자를 합친 통합 신경망을 만들어 생성자를 학습한다.

병렬 학습 (11p)오차가 고치는 가중치
판별자 모델의 오차역전파 → 판별자 가중치 수정
통합 신경망의 오차역전파 → 생성자 가중치 수정
 
discriminator.trainable = False             # 판별자 가중치 고정
z = Input(shape=(100,))                     # 생성자 입력: 노이즈
img = generator(z)                          # 노이즈 → 가짜 이미지
valid = discriminator(img)                  # 가짜 이미지 → 판별자의 판정
combined = Model(inputs=z, outputs=valid)   # 통합 신경망
combined.compile(loss='binary_crossentropy', optimizer=optimizer)
g_loss = combined.train_on_batch(noise, valid)   # 노이즈 → '진짜(1)'라고 답하게

14p 코드를 13.6 5단계(26p)의 표기로 옮겼다 — 두 슬라이드는 같은 흐름이다.

14p 아래 그림은 학습 에포크별 생성 이미지 — 처음엔 잡음이던 것이 에포크가 늘수록 숫자 모양이 된다.

교안왜 판별자 가중치를 고정하나 (13p)

  • 생성자를 학습할 때는 판별자 모델의 가중치를 고정해야 한다
  • 이유: 생성자와 판별자의 손실 함수가 서로 달라 가중치 수정 방향도 서로 다르기 때문
  • 고정하지 않으면 생성자의 손실 함수가 이끄는 방향으로 판별자 가중치가 수정되어, 판별자가 가짜 이미지를 진짜로 판정하는 경향을 보이게 된다

보충설명한 번의 반복(iteration)을 순서대로 — 같은 가짜 이미지에 정답이 두 번 다르다

① 진짜 배치 뽑기훈련 데이터에서 무작위 32장 → imgs, 정답 valid = 1
② 가짜 배치 만들기노이즈 32개 → generator.predict → gen_imgs, 정답 fake = 0
③ 판별자 학습진짜엔 1, 가짜엔 0이라고 답하도록 — 판별자만 바뀐다. d_loss = 0.5 × (real + fake)
④ 생성자 학습 (통합 신경망)새 노이즈를 넣고 정답을 1(진짜)로 — 판별자는 얼어 있으니 생성자만 바뀐다

③에서는 가짜에 0을, ④에서는 가짜에 1을 정답으로 준다 — 같은 가짜를 두고 경찰은 ‘가짜다’를, 위조범은 ‘진짜로 보이게’를 배운다. 이것이 적대적 훈련이다. ④에서 판별자를 고정하지 않으면 ‘가짜에 1’이라는 정답이 판별자까지 고쳐 버려, 경찰이 위조범 편을 들게 된다(13p의 경고).

Keras 주의: trainable = False는 compile 시점에 적용된다. 판별자 자체는 그 전에 따로 compile해 두었으므로 ③에서는 여전히 학습되고, 통합 신경망 안에서만 얼어 있다 — 그래서 코드 순서가 ‘판별자 compile → trainable=False → combined compile’이다.

판별자 학습 vs 생성자 학습 — 무엇을 넣고 무엇이 바뀌나
판별자 학습생성자 학습 (통합 신경망)
입력진짜 이미지 + 가짜 이미지노이즈 z
정답진짜 1 · 가짜 0전부 1 (진짜)
손실binary_crossentropybinary_crossentropy
바뀌는 가중치판별자생성자만 (판별자 고정)

결론(30p): GAN 학습은 판별자 모델과 통합 신경망을 교대로 학습하는 방식이다. ‘통합 신경망에서 생성자를 고정한다’는 보기는 거꾸로다.

미니맥스 게임과 가치 함수교안 15 · 16 · 17p

교안 슬라이드 모아보기 15p · 16p · 17p

교안제로섬 게임과 미니맥스 (15p)

  • GAN의 학습은 최적화 문제보다 제로섬 게임에 가깝다 — 참가자들이 총합이 정해진 점수를 나눠 가지므로 한 참가자의 득점이 다른 참가자의 실점이 된다
  • 이를 인공지능에서는 미니맥스 게임 이론(mini-max game theory)이라 한다. 미니맥스는 의사 결정 알고리즘의 한 종류로, 두 참가자가 순서대로 행동하는 게임의 의사 결정에 주로 쓰인다
  • 목표는 최적의 다음 수를 예측하는 것 — 최대화 참가자(maximizer)는 자기 점수가 최대가 되게, 최소화 참가자(minimizer)는 최대화 참가자의 수에 대응하면서 그 점수가 최소가 되게 한다

교안가치 함수 V(D, G) (16 · 17p)

\min_G\max_D V(D,G)=\mathbb{E}_{x\sim p_{\text{data}}(x)}\big[\log D(x)\big]+\mathbb{E}_{z\sim p_z(z)}\big[\log\big(1-D(G(z))\big)\big]

앞 항 = 실제 데이터 x에 대한 판별자의 출력, 뒤 항 = 생성자가 만든 가짜 이미지에 대한 판별자의 출력.

기호의미
G / D생성자 모델 / 판별자 모델
z생성자에 입력되는 무작위 노이즈
G(z)생성자가 노이즈 z를 받아 만든 (실제와 비슷한) 가짜 이미지
D(G(z))생성 이미지에 대한 판별자의 예측 결과
\log D(x)실제 이미지 x에 대한 판별자의 예측 결과
  • D의 목표 — 이미지 레이블을 정확히 예측할 확률을 최대로. 실제와 가짜를 모두 정확히 분류하도록 학습한다. 단독 학습에서는 \log D(x)의 D(x)가 1에 가까워지도록 해 미니맥스 함숫값을 최대로
  • G의 목표 — 생성 이미지의 레이블이 정확히 예측될 확률을 최소로. \log(1-D(G(z)))가 최소가 되도록(=D(G(z))를 1 쪽으로) 학습한다
  • 두 부분은 서로 다른 오차 함수를 쓴다. 결론: 진짜에 대한 D(x)는 최대로, 가짜에 대한 D는 최소로(판별자 입장). 로그를 씌운 이유 — 원하는 값과 차이가 날수록 벌점이 커지도록

보충설명숫자로 보는 ‘로그는 틀릴수록 벌점을 키운다’

상황판별자 출력해당 항값
진짜를 진짜라고 잘 봄D(x) = 0.9\log D(x)−0.11 (거의 0, 벌점 작음)
진짜를 가짜라고 봄D(x) = 0.1\log D(x)−2.30 (벌점 큼)
가짜를 가짜라고 잘 봄D(G(z)) = 0.1\log(1-D(G(z)))−0.11
가짜에 속음D(G(z)) = 0.9\log(1-D(G(z)))−2.30
완전히 틀림D(x) → 0\log D(x)→ −∞

판별자는 두 항을 모두 0 쪽(최댓값)으로 올리려 하고, 생성자는 뒤 항을 −∞ 쪽(최솟값)으로 끌어내리려 한다 — 같은 V를 하나는 키우고 하나는 줄이니 ‘min max’다. 확률을 그대로 쓰면 0.1과 0.01의 차이가 0.09지만, 로그로는 −2.3과 −4.6으로 크게 벌어져 ‘많이 틀린 것’을 강하게 꾸짖는다. 이 식은 판별자의 이진 교차 엔트로피와 같은 꼴이다(정답 1에는 \log D, 정답 0에는 \log(1-D)).

(교안 밖) 이론상 둘이 끝까지 균형을 이루면 생성 분포가 실제 분포와 같아지고 판별자는 무엇을 넣든 D = 0.5(반반 찍기)가 된다. 또 13.3 코드처럼 생성자를 ‘정답 1’로 학습하면 실제로는 -\log D(G(z))를 줄이는 셈인데, 학습 초반 기울기가 더 커서 실무에서 흔히 쓰는 변형이다.

평가 방법은 인셉션 점수(Inception Score)와 프레셰 인셉션 거리(Frechet Inception Distance, FID) 두 가지다.

인셉션 점수FID

결론(30p): 실제로는 생성 이미지의 품질을 사람이 직접 평가하는 방식이 주로 쓰이고, 인셉션 점수 · 인셉션 거리가 함께 쓰인다.

보충설명두 기준을 예로 — 그리고 FID가 더 많이 쓰이는 이유

  • 신발만 아주 선명하게 만드는 생성자 — 인셉션이 ‘신발!’이라고 확신하니 ①은 높지만, 한 클래스에 몰려 ②가 낮다. 생성자가 진짜 같아 보이는 몇 종류만 반복해 만드는 이 현상을 모드 붕괴(mode collapse)라고 한다
  • 흐릿한 이미지 — 인셉션이 무엇인지 확신하지 못해 ①이 낮다
  • FID는 실제 이미지 분포와 직접 비교하므로, 인셉션 점수가 놓치는 ‘실제 데이터와 얼마나 닮았나’를 본다. 두 분포의 평균 차이와 퍼짐(공분산) 차이를 함께 재므로 품질과 다양성을 한 숫자로 본다 — 0이면 두 분포가 같다

23p 아래 visualize_input 함수는 이미지 한 장을 흑백으로 그리고 칸마다 픽셀 값을 적어 보여 준다. 레이블(_)은 버린다 — GAN은 정답 레이블 없이 이미지 자체의 분포를 배운다.

11주차 분류는 /255로 [0, 1]이었다. GAN 예제가 [−1, 1]로 바꾸는 것은 진짜 이미지와 가짜 이미지의 값 범위를 맞추기 위해서다 — 범위가 다르면 판별자가 ‘모양’이 아니라 ‘값의 범위’만 보고도 진위를 가려 버린다. expand_dims(axis=3)은 흑백 이미지에 채널 축 1을 붙여 Conv2D가 받는 (28, 28, 1) 모양으로 맞춘다(11주차 채널).

교안 코드의 함정 — 진짜는 [−1, 1]인데 생성자 마지막 층은 relu — 24p 생성자의 마지막 층은 Conv2D(1, kernel_size=3, padding="same", activation="relu")라 출력이 0 이상뿐이다. 진짜 이미지에는 −1 ~ 0 값(어두운 픽셀)이 많은데 생성자는 그 값을 만들 수 없어, 판별자가 ‘음수가 있으면 진짜’로 쉽게 가려낼 수 있다. 범위를 맞추려면 마지막 활성화를 출력 범위 −1 ~ 1인 tanh로 두는 것이 원래 DCGAN의 방식이다. 시험에서는 교안 그대로(relu) 묻겠지만, 직접 돌려 본다면 이 한 줄을 바꿔야 결과가 제대로 나온다.

교안3단계 — 생성자 (24p)

def build_generator():
    generator = Sequential()
    generator.add(Dense(128 * 7 * 7, activation="relu", input_dim=100))   # 유닛 6,272개
    generator.add(Reshape((7, 7, 128)))                                   # 이미지 모양 7×7×128로
    generator.add(UpSampling2D())                                         # 14×14로 두 배
    generator.add(Conv2D(128, kernel_size=3, padding="same", activation="relu"))
    generator.add(BatchNormalization(momentum=0.8))
    generator.add(UpSampling2D())                                         # 28×28로 두 배
    generator.add(Conv2D(64, kernel_size=3, padding="same", activation="relu"))
    generator.add(BatchNormalization(momentum=0.8))
    generator.add(Conv2D(1, kernel_size=3, padding="same", activation="relu"))  # 필터 1개 → 28×28×1
    generator.summary()
    noise = Input(shape=(100,))                                           # 길이 100인 노이즈 벡터
    fake_image = generator(noise)
    return Model(inputs=noise, outputs=fake_image)

24p 그림: 100 z → 7×7×128 → 14×14×128 → 28×28×64 → 28×28×1. 데이터셋 이미지 크기(28×28)에 도달했으므로 업샘플링은 두 번으로 끝난다. UpSampling2D()의 기본 size가 (2, 2)다.

교안4단계 — 판별자 (25p)

입력 28×28×1 → Conv2D(32, 보폭 2) → 14×14×32 → Conv2D(64, 보폭 2) + ZeroPadding → 8×8×64 → Conv2D(128, 보폭 2) → 4×4×128 → Conv2D(256) → 4×4×256 → Flatten → Dense(1, sigmoid) → 값 1개(진짜일 확률). 층마다 LeakyReLU · Dropout · BatchNormalization.

optimizer = Adam(learning_rate=0.0002, beta_1=0.5)
discriminator = build_discriminator()

Adam의 기본값은 학습률 0.001 · beta_1 0.9인데, GAN에서는 0.0002 · 0.5로 낮춘다(DCGAN 논문의 권장값). 두 네트워크가 서로를 쫓는 불안정한 학습이라 한 번에 크게 움직이지 않게 하려는 것이다.

교안6 · 7단계 — 학습 함수와 결과 (27 · 28p)

def train(epochs, batch_size=128, save_interval=50):
    valid = np.ones((batch_size, 1))       # 진짜 정답 = 1
    fake  = np.zeros((batch_size, 1))      # 가짜 정답 = 0
    for epoch in range(epochs):
        # --- 판별자 학습 ---
        idx  = np.random.randint(0, X_train.shape[0], batch_size)   # 무작위 배치
        imgs = X_train[idx]
        noise = np.random.normal(0, 1, (batch_size, 100))
        gen_imgs = generator.predict(noise)
        d_loss_real = discriminator.train_on_batch(imgs, valid)
        d_loss_fake = discriminator.train_on_batch(gen_imgs, fake)
        d_loss = 0.5 * np.add(d_loss_real, d_loss_fake)              # 두 손실의 평균
        # --- 생성자 학습 ---
        g_loss = combined.train_on_batch(noise, valid)               # 가짜를 '진짜'로 판정하도록
        print("%d [D loss: %f, acc.: %.2f%%] [G loss: %f]" % (epoch, d_loss[0], 100*d_loss[1], g_loss))
        if epoch % save_interval == 0:
            plot_generated_images(epoch, generator)                  # 생성 이미지를 그려 파일로 저장

train(epochs=1000, batch_size=32, save_interval=50)

28p 결과 그림: 0 에포크의 잡음에서 시작해 50 · 1,000 · 10,000 에포크로 갈수록 생성 이미지가 패션 MNIST(옷 · 신발 · 가방)의 형태에 점점 가까워진다.

보충설명train() 인자와 숫자 읽기

  • train(epochs=1000, batch_size=32, save_interval=50) — 반복 1,000회, 한 번에 진짜 32장 + 가짜 32장, 50회마다 생성 이미지 저장. 여기서 ‘epoch’는 사실 배치 한 번(iteration)이다 — 6만 장 전체를 도는 것이 아니라 32장만 뽑으므로, 1,000회면 전체 데이터의 약 절반(32,000장)만 본 셈이다
  • np.random.randint(0, 60000, 32) — 0 ~ 59,999 중 무작위 번호 32개 → 그 이미지들로 배치
  • d_loss = 0.5 * (real + fake) — 진짜 손실과 가짜 손실의 평균. 판별자가 반반 찍으면 각 손실이 약 -\log 0.5\approx0.69이다. 학습이 균형을 이루면 d_loss · g_loss가 이 근처에서 오르내리고, 한쪽이 0으로 떨어지면 그쪽이 너무 강해 상대가 배울 것이 없어졌다는 신호다

생성 모델 · GAN

없던 콘텐츠를 만드는 신경망. GAN = 적대적 훈련, 경쟁하는 두 신경망. 학습한 데이터와 비슷한 분포의 새 이미지를 만든다.

생성자 · 판별자

생성자(위조지폐범): 노이즈 → 이미지. 판별자(경찰): 이미지 → 진짜일 확률(0 가짜, 1 진짜) = 이미지 분류 신경망.

구조

판별자 = 출력 1차원까지 줄어드는 CNN(LeakyReLU · Dropout · sigmoid 1개). 생성자 = 1차원 입력을 이미지 크기까지 업샘플링(Dense → Reshape 7×7×128 → 14 → 28).

업샘플링

픽셀을 가로세로로 반복. (2, 2): 2×2 → 4×4, (3, 3): 2×2 → 6×6. 다운 샘플링 = 풀링으로 줄이기.

학습

판별자 = 진짜 1 · 가짜 0 지도 학습(sigmoid, binary_crossentropy, Adam). 생성자 = 통합 신경망(노이즈 → 정답 1), 판별자 고정. 둘을 교대로.

판별자 고정 이유

두 손실 함수가 달라 수정 방향이 다르다. 고정 안 하면 판별자가 가짜를 진짜로 판정하게 된다.

미니맥스

제로섬 게임. \min_G\max_D\,\mathbb E[\log D(x)]+\mathbb E[\log(1-D(G(z)))]. D는 최대, G는 최소. 로그 = 틀릴수록 큰 벌점.

평가

인셉션 점수: 예측 확신도 ↑ · 다양성 ↑(클수록 좋다). FID: 실제 · 생성 출력의 다변량 가우시안 사이 프레셰 거리(작을수록 좋다). 주로 사람이 직접 평가.

응용

StackGAN(문장 → 저해상도 형태 · 색 → 고해상도 세부), 이미지-이미지 번역, 초해상도.

프로젝트

패션 MNIST · /127.5 − 1 → [−1, 1] · expand_dims → (28, 28, 1) · 노이즈 100 · Adam(0.0002, 0.5) · train(1000, 32, 50) · d_loss = 평균.
