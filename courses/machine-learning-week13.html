13. 이미지 생성 — 위조지폐범과 경찰이 서로를 키운다 (GAN)

지금까지의 신경망은 사진을 보고 ‘무엇인가’를 맞히는 결정론적인 과업(분류 · 탐지 · 분할)을 했다. 이번 주는 세상에 없던 이미지를 만들어 내는 생성 모델, 그중 생성적 적대 신경망(GAN)이다. 노이즈로 가짜를 만드는 생성자와 진짜 · 가짜를 가려내는 판별자가 경쟁하며 함께 좋아진다. 두 네트워크의 구조(판별자 = 줄어드는 CNN, 생성자 = 거꾸로 커지는 CNN), 판별자를 고정한 통합 신경망으로 생성자를 학습하는 방법, 이 경쟁을 수식으로 쓴 미니맥스 가치 함수, 평가 지표(인셉션 점수 · FID)와 응용, 그리고 패션 MNIST로 GAN을 직접 만드는 7단계 프로젝트를 다룬다. 대면수업 교안(50p)과 개정판(63p)은 여기서 한 걸음 더 나가 VAE(구름처럼 퍼진 잠재 공간) · 확산 모델(노이즈를 조금씩 걷어내기) · 흐름 매칭(노이즈에서 데이터로 가는 직선 길) · 최신 생성 AI(Stable Diffusion · FLUX · Veo)까지 이어 간다 — 13.7~13.10에 정리했다.

이번 주 한 줄 요약

  • 생성 모델 = 기존에 없던 새로운 콘텐츠(이미지 · 영상 · 음악 · 텍스트)를 만드는 신경망. GAN은 적대적 훈련에 기반해 서로 경쟁하는 두 신경망으로 이뤄진다
  • 생성자(위조지폐범) = 무작위 노이즈 → 진짜 같은 이미지. 판별자(경찰) = 이미지 → 진짜일 확률(0 가짜 · 1 진짜). 판별자는 줄어드는 CNN, 생성자는 1차원 벡터에서 커지는 CNN(업샘플링 = 픽셀 반복)
  • 학습은 번갈아: ① 판별자 = 진짜(1) · 가짜(0)를 레이블과 함께 넣는 지도 학습 ② 생성자 = 판별자를 붙인 통합 신경망에 노이즈를 넣고 정답을 ‘진짜(1)’로 — 이때 판별자 가중치는 고정(trainable=False)
  • 미니맥스 게임(제로섬): \min_G\max_D V(D,G), V=\mathbb E[\log D(x)] +\,\mathbb E[\log(1-D(G(z)))] — D는 키우고 G는 줄인다. 로그는 틀릴수록 벌점을 크게
  • 평가: 인셉션 점수(예측 확신도 높음 + 다양성 높음) · FID(실제와 생성 이미지의 인셉션 출력 분포 사이 프레셰 거리, 작을수록 좋음). 응용: StackGAN(문장 → 이미지, 2단계) · 이미지-이미지 번역 · 초해상도
  • VAE = 오토인코더 + 확률: 인코더가 점이 아니라 분포(μ, σ)를 내고 KL 항이 잠재 공간을 N(0, I)로 모은다 → 아무 z나 뽑아도 그럴듯하다. 결과는 흐릿한 편이지만 오늘날 잠재 확산의 압축기다
  • 확산 모델 = 망가뜨리기(노이즈 추가)는 정해져 있고 되돌리기(노이즈 제거)만 배운다. 학습은 ‘섞인 노이즈 ε 맞히기’라는 단순 회귀 → 안정적 · 다양, 대신 수십~1,000 스텝이라 느리다. 잠재 확산(Stable Diffusion)은 VAE로 줄인 공간에서 확산한다
  • 흐름 매칭 = 노이즈와 데이터를 직선으로 잇고 그 위의 속도 v=x_1-x_0를 회귀 → 곧은 길이라 적은 스텝으로 도착(SD3 · FLUX). 증류로 1~4 스텝까지 줄인다
  • 세 계열의 삼중고: GAN(고품질 · 빠름, 다양성 ↓) · VAE(빠름 · 다양, 품질 ↓) · 확산(고품질 · 다양, 느림). 최신 흐름은 확산 트랜스포머 + 흐름 매칭 + VAE 잠재 공간, 그리고 멀티모달 LLM과의 결합

교안생성 모델 — 없던 것을 만든다 (2 · 3p)

학습 목표는 생성적 적대 신경망에 대해 알아본다. 지금까지 딥러닝 · 신경망은 이미지의 시각적 특징을 이해해 사물 탐지 같은 결정론적인 과업을 하도록 배웠다. 이번 주는 컴퓨터 비전에서 딥러닝을 응용하는 새로운 영역인 생성 모델(generative model)이다.

  • 생성 모델 = 기존에 존재하지 않았던 새로운 콘텐츠를 생성하는 능력을 가진 신경망 모델
  • 실제와 매우 흡사한 이미지 · 영상 · 음악 · 텍스트를 생성할 수 있다

기계학습특론 1주차의 ‘판별 모델 vs 생성 모델’(1주차)이 여기서 실제 구조로 이어진다 — 판별 모델은 ‘이 사진은 무엇인가’, 생성 모델은 ‘이런 사진을 하나 그려라’.

교안GAN — 서로 경쟁하는 두 신경망 (4p)

생성적 적대 신경망(GAN, Generative Adversarial Network)은 적대적 훈련(adversarial training)이라는 개념에 기반하며, 서로 경쟁하는 2개의 신경망으로 구성된다.

입력하는 일
생성자 (generator)무작위 노이즈노이즈를 원래 데이터셋에서 본 표본과 비슷하도록 변환한다
판별자 (discriminator)이미지(관찰)입력이 생성자가 만든 가짜인지, 원래 데이터셋의 진짜인지 예측한다

교안위조지폐범과 경찰 (5p)

  • 생성자 = 위조지폐범, 판별자 = 경찰
  • 위조지폐범은 더 진짜 같은 위조지폐를 만드는 법을 익히고, 경찰은 그것을 찾아내는 법을 익힌다
  • 상대의 기술이 향상되면서 서로의 학습 목표도 변한다 — 위조지폐범이 완벽한 위조지폐를 만들면 경찰은 새로운 감별법을 익힌다
  • 상대방의 기술을 깨는 방법을 끝없이 학습하는 과정 — 이것이 ‘적대(adversarial)’의 뜻이다

두 신경망은 같은 목표를 공유하지 않는다. 판별자가 이기면 생성자가 지고, 생성자가 이기면 판별자가 진다 — 13.4의 제로섬 게임.

교안판별자 모델 (7p)

목표: 입력받은 이미지가 생성자가 만든 가짜인지 진짜인지 예측하는 것. 7p 코드는 Sequential에 합성곱층을 쌓되, 합성곱층마다 LeakyReLU(alpha=0.2)와 Dropout(0.25)을 붙이고, 중간에 ZeroPadding2D · BatchNormalization(momentum=0.8)을 두며, 마지막에 Flatten → Dense(1, activation='sigmoid')로 진짜일 확률 하나를 낸다.

교안생성자 모델 (8p)

생성자는 무작위 데이터를 받아 훈련 데이터를 흉내 낸 가짜 이미지를 만든다. 목표: 판별자가 진짜라고 판정할 만큼 훈련 데이터와 완벽하게 비슷한 이미지를 만드는 것. 8p 코드는 노이즈를 Dense(128*7*7)로 키운 뒤 Reshape((7, 7, 128))로 특징 맵 모양을 만들고, 그다음 업샘플링과 합성곱을 반복해 7×7 → 14×14 → 28×28 이미지로 키운다.

교안판별자 학습 — 평범한 지도 학습 (10 · 12p)

  • 일반적인 지도 학습 모델의 학습 과정이다 — 생성자가 만든 가짜 이미지와 훈련 데이터에서 뽑은 진짜 이미지를 레이블과 함께 입력한다(진짜 = 1, 가짜 = 0)
  • 진짜인지 여부를 시그모이드 함수로 확률 값으로 예측한다
  • 12p 코드: discriminator = Discriminator_Model()로 만들고, binary_crossentropy 손실 · Adam 최적화 · metrics=['accuracy']로 컴파일
noise = np.random.normal(0, 1, (batch_size, 100))     # 노이즈 데이터 생성

# 판별자 모델 학습(진짜 이미지는 1, 가짜 이미지는 0)

교안생성자 학습 — 판별자를 붙인 통합 신경망 (10 · 11 · 14p)

생성자를 학습하려면 만든 가짜 이미지가 얼마나 진짜 같았는지 알려 줄 판별자가 필요하다. 그래서 판별자와 생성자를 합친 통합 신경망을 만들어 생성자를 학습한다.

병렬 학습 (11p)오차가 고치는 가중치
판별자 모델의 오차역전파 → 판별자 가중치 수정
통합 신경망의 오차역전파 → 생성자 가중치 수정
 
discriminator.trainable = False             # 판별자 가중치 고정
z = Input(shape=(100,))                     # 생성자 입력: 노이즈
img = generator(z)                          # 노이즈 → 가짜 이미지
valid = discriminator(img)                  # 가짜 이미지 → 판별자의 판정
combined = Model(inputs=z, outputs=valid)   # 통합 신경망
combined.compile(loss='binary_crossentropy', optimizer=optimizer)
g_loss = combined.train_on_batch(noise, valid)   # 노이즈 → '진짜(1)'라고 답하게

14p 아래 그림은 학습 에포크별 생성 이미지 — 처음엔 잡음이던 것이 에포크가 늘수록 숫자 모양이 된다.

교안왜 판별자 가중치를 고정하나 (13p)

  • 생성자를 학습할 때는 판별자 모델의 가중치를 고정해야 한다
  • 이유: 생성자와 판별자의 손실 함수가 서로 달라 가중치 수정 방향도 서로 다르기 때문
  • 고정하지 않으면 생성자의 손실 함수가 이끄는 방향으로 판별자 가중치가 수정되어, 판별자가 가짜 이미지를 진짜로 판정하는 경향을 보이게 된다

보충설명한 번의 반복(iteration)을 순서대로 — 같은 가짜 이미지에 정답이 두 번 다르다

① 진짜 배치 뽑기훈련 데이터에서 무작위 32장 → imgs, 정답 valid = 1
② 가짜 배치 만들기노이즈 32개 → generator.predict → gen_imgs, 정답 fake = 0
③ 판별자 학습진짜엔 1, 가짜엔 0이라고 답하도록 — 판별자만 바뀐다. d_loss = 0.5 × (real + fake)
④ 생성자 학습 (통합 신경망)새 노이즈를 넣고 정답을 1(진짜)로 — 판별자는 얼어 있으니 생성자만 바뀐다

③에서는 가짜에 0을, ④에서는 가짜에 1을 정답으로 준다 — 같은 가짜를 두고 경찰은 ‘가짜다’를, 위조범은 ‘진짜로 보이게’를 배운다. 이것이 적대적 훈련이다. ④에서 판별자를 고정하지 않으면 ‘가짜에 1’이라는 정답이 판별자까지 고쳐 버려, 경찰이 위조범 편을 들게 된다(13p의 경고).

Keras 주의: trainable = False는 compile 시점에 적용된다. 판별자 자체는 그 전에 따로 compile해 두었으므로 ③에서는 여전히 학습되고, 통합 신경망 안에서만 얼어 있다 — 그래서 코드 순서가 ‘판별자 compile → trainable=False → combined compile’이다.

교안제로섬 게임과 미니맥스 (15p)

  • GAN의 학습은 최적화 문제보다 제로섬 게임에 가깝다 — 참가자들이 총합이 정해진 점수를 나눠 가지므로 한 참가자의 득점이 다른 참가자의 실점이 된다
  • 이를 인공지능에서는 미니맥스 게임 이론(mini-max game theory)이라 한다. 미니맥스는 의사 결정 알고리즘의 한 종류로, 두 참가자가 순서대로 행동하는 게임의 의사 결정에 주로 쓰인다
  • 목표는 최적의 다음 수를 예측하는 것 — 최대화 참가자(maximizer)는 자기 점수가 최대가 되게, 최소화 참가자(minimizer)는 최대화 참가자의 수에 대응하면서 그 점수가 최소가 되게 한다
왜 ‘최적화’가 아니라 ‘제로섬 게임’인가 — 내리막을 찾는 게 아니라 균형점을 찾는다

맞다. GAN의 학습은 손실 함수 하나를 최소화하는 전통적인 최적화 문제보다, 두 네트워크가 경쟁하며 균형점을 찾는 제로섬 게임에 가깝다.

  • 두 신경망의 경쟁 구조 — 생성자는 판별자를 속이려고 가짜를 진짜처럼 만들고, 판별자는 그것을 가려내려고 애쓴다
  • 상반된 목적 함수 — 둘이 같은 값 V(D, G)를 두고 판별자는 키우고 생성자는 줄인다. 한쪽의 이득(손실 감소)이 곧 다른 쪽의 손실(손실 증가)인 미니맥스 게임이다(아래 가치 함수 카드)
  • 내쉬 균형(Nash Equilibrium) 추구 — 일반 딥러닝은 경사 하강법으로 손실의 최솟값을 찾지만, GAN은 두 플레이어 모두 혼자서 전략을 바꿔도 이득이 없는 균형 상태를 목표로 한다

내쉬 균형을 비유로 — 가위바위보에서 두 사람이 가위 · 바위 · 보를 1/3씩 낸다면, 어느 한 사람이 혼자 전략을 바꿔도(바위만 낸다 등) 이길 확률이 오르지 않는다. 이 상태가 내쉬 균형이다. GAN에서는 생성자가 실제와 똑같은 분포로 만들고 판별자가 늘 0.5라고 답하는 상태 — 판별자가 더 열심히 해도 가려낼 단서가 없고, 생성자가 바꿔 봐야 더 진짜 같아질 수 없다.

그래서 GAN 학습이 어렵다 — 최솟값 찾기와 달리 균형점 주변에서 빙빙 돌기 쉽다. 간단한 예: 생성자는 V=x\cdot y를 줄이려고 x를, 판별자는 키우려고 y를 움직인다고 하자. 균형점은 (0, 0)이다. 그런데 둘이 동시에 기울기만큼 움직이면 x가 줄 때 y가 따라 움직이고, 그러면 다시 x의 방향이 바뀌어 (0, 0) 주위를 원을 그리며 돌다가 오히려 멀어지기도 한다. 실제 GAN에서 손실이 출렁이고, 생성자가 판별자를 잘 속이는 몇 종류만 반복해 만드는 모드 붕괴(13.5)가 생기는 이유다. 13.6에서 학습률을 0.0002로 낮추고(5단계) d_loss · g_loss가 0.69 근처에서 오르내리는지 보는 것(6 · 7단계)도 이 때문이다.

교안가치 함수 V(D, G) (16 · 17p)

\min_G\max_D V(D,G)=\mathbb{E}_{x\sim p_{\text{data}}(x)}\big[\log D(x)\big]+\mathbb{E}_{z\sim p_z(z)}\big[\log\big(1-D(G(z))\big)\big]

앞 항 = 실제 데이터 x에 대한 판별자의 출력, 뒤 항 = 생성자가 만든 가짜 이미지에 대한 판별자의 출력.

기호의미

  • D의 목표 — 이미지 레이블을 정확히 예측할 확률을 최대로. 실제와 가짜를 모두 정확히 분류하도록 학습한다. 단독 학습에서는 \log D(x)의 D(x)가 1에 가까워지도록 해 미니맥스 함숫값을 최대로
  • G의 목표 — 생성 이미지의 레이블이 정확히 예측될 확률을 최소로. \log(1-D(G(z)))가 최소가 되도록(=D(G(z))를 1 쪽으로) 학습한다
  • 두 부분은 서로 다른 오차 함수를 쓴다. 결론: 진짜에 대한 D(x)는 최대로, 가짜에 대한 D는 최소로(판별자 입장). 로그를 씌운 이유 — 원하는 값과 차이가 날수록 벌점이 커지도록

보충설명숫자로 보는 ‘로그는 틀릴수록 벌점을 키운다’

판별자는 두 항을 모두 0 쪽(최댓값)으로 올리려 하고, 생성자는 뒤 항을 −∞ 쪽(최솟값)으로 끌어내리려 한다 — 같은 V를 하나는 키우고 하나는 줄이니 ‘min max’다. 확률을 그대로 쓰면 0.1과 0.01의 차이가 0.09지만, 로그로는 −2.3과 −4.6으로 크게 벌어져 ‘많이 틀린 것’을 강하게 꾸짖는다. 이 식은 판별자의 이진 교차 엔트로피와 같은 꼴이다(정답 1에는 \log D, 정답 0에는 \log(1-D)).

(교안 밖) 이론상 둘이 끝까지 균형을 이루면 생성 분포가 실제 분포와 같아지고 판별자는 무엇을 넣든 D = 0.5(반반 찍기)가 된다. 또 13.3 코드처럼 생성자를 ‘정답 1’로 학습하면 실제로는 -\log D(G(z))를 줄이는 셈인데, 학습 초반 기울기가 더 커서 실무에서 흔히 쓰는 변형이다.

교안미니맥스의 이론적 성질과 비포화 손실 (대면 14p · 개정 17p)

  • 생성자를 고정했을 때 최적 판별자: D^*(x)=\dfrac{p_{\text{data}}(x)}{p_{\text{data}}(x)+p_g(x)}
  • D*를 넣으면 C(G)=-\log 4+2\cdot\mathrm{JSD}(p_{\text{data}}\,\|\,p_g) → 전역 최적은 p_g=p_{\text{data}}, 이때 D^*(x)=\tfrac12
  • 실전 팁: 학습 초기에는 판별자가 쉽게 이겨 \log(1-D(G(z)))의 기울기가 거의 0이다. 그래서 대신 -\log D(G(z))를 최소화하는 비포화(non-saturating) 손실을 쓴다 — 케라스 구현의 ‘가짜에 1 레이블’이 바로 이것이다

보충설명숫자로 — D*가 0.5가 되는 이유와 ‘포화’의 뜻

  • 어떤 이미지 x가 실제 데이터에서 나올 확률 밀도가 0.6, 생성자에서 나올 밀도가 0.2라면 D^*=0.6/(0.6+0.2)=0.75 — ‘진짜일 가능성이 더 크다’. 생성자가 완벽해져 둘 다 0.4가 되면 0.4/0.8=0.5, 판별자는 동전 던지기밖에 못 한다
  • 학습 초반 D(G(z)) = 0.01(판별자가 가짜를 쉽게 알아봄)이라 하자. \log(1-D)를 D로 미분하면 -1/(1-D)=-1.01로 작지만, -\log D의 미분은 -1/D=-100이다. 생성자가 가장 못할 때 100배 큰 신호를 받는 쪽이 비포화 손실이다

좋은 쪽클수록작을수록(실제와 가깝다)

결론(30p): 실제로는 생성 이미지의 품질을 사람이 직접 평가하는 방식이 주로 쓰이고, 인셉션 점수 · 인셉션 거리가 함께 쓰인다.

보충설명두 기준을 예로 — 그리고 FID가 더 많이 쓰이는 이유

  • 신발만 아주 선명하게 만드는 생성자 — 인셉션이 ‘신발!’이라고 확신하니 ①은 높지만, 한 클래스에 몰려 ②가 낮다. 생성자가 진짜 같아 보이는 몇 종류만 반복해 만드는 이 현상을 모드 붕괴(mode collapse)라고 한다
  • 흐릿한 이미지 — 인셉션이 무엇인지 확신하지 못해 ①이 낮다
  • FID는 실제 이미지 분포와 직접 비교하므로, 인셉션 점수가 놓치는 ‘실제 데이터와 얼마나 닮았나’를 본다. 두 분포의 평균 차이와 퍼짐(공분산) 차이를 함께 재므로 품질과 다양성을 한 숫자로 본다 — 0이면 두 분포가 같다
대면수업 필기 — 13.4 GAN 모델 평가 방법
  • IS(인셉션 점수) — 높을수록 좋다
  • FID — 낮을수록 좋다
  • GAN 초반에는 성능이 매우 낮았고(필기: “Tensorflow 0점대 수준”), 이후 계속 발전했다

필기의 ‘Tensorflow 0점대’가 어떤 지표를 가리킨 말인지는 교안에 없어 그대로 옮겼다 — 확인이 필요하다. 교안에서 확인되는 ‘발전’의 크기: 2014년 첫 GAN은 MLP로 작은 흑백 · 저해상도 이미지를 만들었고, 개정 43p 기준 ImageNet 256² FID는 BigGAN-deep 6.95 → DiT-XL/2 2.27 → VAR 1.73까지 내려왔다(낮을수록 좋다).

교안IS와 FID를 식으로 (대면 16p · 개정 52p)

사람의 육안 평가는 주관적이고 비용이 크므로 자동 지표를 함께 쓴다.

\mathrm{IS}=\exp\Big(\mathbb E_x\,\mathrm{KL}\big(p(y\mid x)\,\|\,p(y)\big)\Big)\qquad(\uparrow\ \text{좋음})

품질 = 이미지 하나의 분류가 확신에 차 있다(p(y\mid x)의 엔트로피가 낮다). 다양성 = 전체로 보면 클래스가 고르다(p(y)의 엔트로피가 높다). 둘이 다를수록 KL이 크다. 한계: 실제 데이터와 비교하지 않고, 클래스 안의 다양성은 못 보며, ImageNet이 아닌 영역(의료 등)에는 맞지 않는다.

\mathrm{FID}=\lVert\mu_r-\mu_g\rVert^2+\mathrm{Tr}\big(\Sigma_r+\Sigma_g-2(\Sigma_r\Sigma_g)^{1/2}\big)\qquad(\downarrow\ \text{좋음})

실제 · 생성 이미지를 Inception-v3에 넣어 2,048차원 특징을 모으고, 각각을 다변량 가우시안 N(\mu_r,\Sigma_r) · N(\mu_g,\Sigma_g)로 근사한 뒤 둘 사이의 프레셰 거리를 잰다. 표본 수에 민감(보통 5만 장), 다양성 붕괴도 잡아내 GAN · 확산 모두의 표준 지표다.

보충설명숫자로 — 클래스 2개짜리 IS, 1차원 FID

클래스가 2개면 IS의 최댓값은 2(완벽히 또렷 + 완벽히 고름)다. B는 이미지마다 또렷해도 다양성이 없어 최저점이다. 1차원 FID: 실제 특징이 N(0, 1²), 생성 특징이 N(0.5, 0.8²)이면 (0-0.5)^2+1+0.64-2\cdot\sqrt{1\cdot0.64}=0.25+0.04=0.29. 평균이 어긋난 몫(0.25)과 퍼짐이 어긋난 몫(0.04)이 더해진다 — 둘 다 같으면 0.

11주차 분류는 /255로 [0, 1]이었다. GAN 예제가 [−1, 1]로 바꾸는 것은 진짜 이미지와 가짜 이미지의 값 범위를 맞추기 위해서다 — 범위가 다르면 판별자가 ‘모양’이 아니라 ‘값의 범위’만 보고도 진위를 가려 버린다. expand_dims(axis=3)은 흑백 이미지에 채널 축 1을 붙여 Conv2D가 받는 (28, 28, 1) 모양으로 맞춘다(11주차 채널).

교안 코드의 함정 — 진짜는 [−1, 1]인데 생성자 마지막 층은 relu — 24p 생성자의 마지막 층은 Conv2D(1, kernel_size=3, padding="same", activation="relu")라 출력이 0 이상뿐이다. 진짜 이미지에는 −1 ~ 0 값(어두운 픽셀)이 많은데 생성자는 그 값을 만들 수 없어, 판별자가 ‘음수가 있으면 진짜’로 쉽게 가려낼 수 있다. 범위를 맞추려면 마지막 활성화를 출력 범위 −1 ~ 1인 tanh로 두는 것이 원래 DCGAN의 방식이다. 시험에서는 교안 그대로(relu) 묻겠지만, 직접 돌려 본다면 이 한 줄을 바꿔야 결과가 제대로 나온다.

교안3단계 — 생성자 (24p)

def build_generator():
    generator = Sequential()
    generator.add(Dense(128 * 7 * 7, activation="relu", input_dim=100))   # 유닛 6,272개
    generator.add(Reshape((7, 7, 128)))                                   # 이미지 모양 7×7×128로
    generator.add(UpSampling2D())                                         # 14×14로 두 배
    generator.add(Conv2D(128, kernel_size=3, padding="same", activation="relu"))
    generator.add(BatchNormalization(momentum=0.8))
    generator.add(UpSampling2D())                                         # 28×28로 두 배
    generator.add(Conv2D(64, kernel_size=3, padding="same", activation="relu"))
    generator.add(BatchNormalization(momentum=0.8))
    generator.add(Conv2D(1, kernel_size=3, padding="same", activation="relu"))  # 필터 1개 → 28×28×1
    generator.summary()
    noise = Input(shape=(100,))                                           # 길이 100인 노이즈 벡터
    fake_image = generator(noise)
    return Model(inputs=noise, outputs=fake_image)

24p 그림: 100 z → 7×7×128 → 14×14×128 → 28×28×64 → 28×28×1. 데이터셋 이미지 크기(28×28)에 도달했으므로 업샘플링은 두 번으로 끝난다. UpSampling2D()의 기본 size가 (2, 2)다.

교안4단계 — 판별자 (25p)

입력 28×28×1 → Conv2D(32, 보폭 2) → 14×14×32 → Conv2D(64, 보폭 2) + ZeroPadding → 8×8×64 → Conv2D(128, 보폭 2) → 4×4×128 → Conv2D(256) → 4×4×256 → Flatten → Dense(1, sigmoid) → 값 1개(진짜일 확률). 층마다 LeakyReLU · Dropout · BatchNormalization.

def train(epochs, batch_size=128, save_interval=50):
    valid = np.ones((batch_size, 1))       # 진짜 정답 = 1
    fake  = np.zeros((batch_size, 1))      # 가짜 정답 = 0
    for epoch in range(epochs):
        # --- 판별자 학습 ---
        idx  = np.random.randint(0, X_train.shape[0], batch_size)   # 무작위 배치
        imgs = X_train[idx]
        noise = np.random.normal(0, 1, (batch_size, 100))
        gen_imgs = generator.predict(noise)
        d_loss_real = discriminator.train_on_batch(imgs, valid)
        d_loss_fake = discriminator.train_on_batch(gen_imgs, fake)
        d_loss = 0.5 * np.add(d_loss_real, d_loss_fake)              # 두 손실의 평균
        # --- 생성자 학습 ---
        g_loss = combined.train_on_batch(noise, valid)               # 가짜를 '진짜'로 판정하도록
        print("%d [D loss: %f, acc.: %.2f%%] [G loss: %f]" % (epoch, d_loss[0], 100*d_loss[1], g_loss))
        if epoch % save_interval == 0:
            plot_generated_images(epoch, generator)                  # 생성 이미지를 그려 파일로 저장

대면수업 필기 — VAE
  • VAE(Variational Autoencoder)는 2013년 Kingma & Welling이 제안한 생성 모델
  • 오토인코더 구조에 확률적 해석을 붙여서, 잠재 공간에서 샘플링해 새 데이터를 만들 수 있게 한 모델
  • 흐름: Image → encoder → decoder → Generated
  • z를 조금씩 바꾸면 결과도 부드럽게 변한다 → 새 샘플을 생성한다. 이게 보간?? (아래 풀이)
  • 한때 인기 있었던 알고리즘
강조 — VAE는 ‘구름(분포)’으로 저장된다 (대면 23p ‘VAE 쉽게 이해하기’)

오토인코더는 사진 한 장을 잠재 공간의 점 하나로 저장하지만, VAE는 구름 하나(평균 μ 둘레로 σ만큼 퍼진 정규분포)로 저장한다. 구름들이 원점 근처에 촘촘히 겹쳐 빈 땅이 없으니, 어디서 z를 뽑아도 그럴듯한 그림이 나온다 — 아래 점 대신 구름 표가 이 슬라이드의 정리다.

보간(interpolation)이 뭐냐 — 두 z 사이를 한 걸음씩 걸어 보는 것

맞다. ‘z를 조금씩 바꾸면 결과도 부드럽게 변한다’를 두 사진 사이에서 해 보는 것이 보간이다. 보간 = 이미 아는 두 값 사이의 값을 채워 넣는 것(1과 3 사이에 2를 넣듯이).

  • 웃는 얼굴 A를 인코더에 넣었더니 z_A=(1.0,\,-0.5), 무표정 B는 z_B=(-1.0,\,0.5)가 나왔다고 하자(잠재 2차원으로 단순화)
  • 둘 사이를 비율 λ로 섞는다: z(\lambda)=(1-\lambda)\,z_A+\lambda\,z_B. λ = 0.25면 (0.5,\,-0.25), λ = 0.5면 (0,\,0), λ = 0.75면 (-0.5,\,0.25)
  • 이 z들을 디코더에 하나씩 넣으면 활짝 웃음 → 살짝 웃음 → 무표정처럼 이어지는 그림 여러 장이 나온다. 그중 가운데 그림들은 학습 데이터에 없던 새 샘플이다 — 필기의 ‘새 샘플을 생성한다’

왜 VAE라서 되나 — 일반 오토인코더에서는 (0, 0) 같은 중간 지점이 아무 사진도 배정되지 않은 빈 땅일 수 있어 디코딩하면 깨진 그림이 나온다. VAE는 KL 항이 구름들을 원점 근처에 겹쳐 모아 두었기 때문에 중간 지점도 ‘누군가의 구름 속’이고, 그래서 결과가 매끄럽게 이어진다. 같은 이야기를 컴퓨터비전 14주차 VAE에서도 다뤘다.

교안왜 오토인코더로는 못 그리나 — 점 대신 구름 (대면 22 · 23p · 개정 9p)

오토인코더 (12주차)VAE
인코더 출력잠재 벡터 z 하나(점)분포 (μ, σ) — ‘이 근처 어딘가’(작은 구름)
손실재구성 \lVert x-\hat x\rVert^2만재구성 + KL 항(구름을 표준 정규분포 N(0, I) 근처로 모음)
잠재 공간점들이 흩어져 빈 곳이 많다 → 빈 곳의 z를 디코딩하면 이상한 이미지원점 근처가 구름으로 촘촘히 채워짐 → 아무 z나 뽑아도 그럴듯
생성불가(어디서 z를 뽑을지 모름)z\sim N(0,I)를 뽑아 디코더에 넣으면 끝 — 디코더가 ‘생성기’

비유(대면 23p) — 지도에 도시를 점으로만 찍으면 사이가 비지만, 도시 주변을 넓게 색칠하면 지도 전체가 의미 있는 땅이 된다. 두 점 사이를 이동하면 결과도 부드럽게 바뀐다(보간) — 웃는 얼굴 z와 무표정 z의 중간을 디코딩하면 살짝 웃는 얼굴.

장점: 학습이 안정적(경쟁 없음), 잠재 공간이 매끄럽다. 단점: 결과가 흐릿해지기 쉽다(픽셀 평균을 맞추는 재구성 손실 탓). 그래서 오늘날에는 그림을 직접 그리기보다 잠재 확산(Stable Diffusion · FLUX · Veo)의 압축기로 쓰인다 — ‘구식’이 아니라 현대 생성 모델의 기반 부품이다(13.8 잠재 확산).

교안손실 = 재구성 + KL — ELBO (개정 10p)

\log p_\theta(x)\ \ge\ \underbrace{\mathbb E_{q_\phi(z\mid x)}\big[\log p_\theta(x\mid z)\big]}_{\text{① 재구성}}-\underbrace{\mathrm{KL}\big(q_\phi(z\mid x)\,\|\,N(0,I)\big)}_{\text{② 규제}}=\mathrm{ELBO}

진짜 목표인 \log p(x)는 모든 z에 대한 적분이라 계산할 수 없다. 대신 그 아래쪽 경계(증거 하한, ELBO)를 키운다. 학습 손실은 −ELBO.

  • ① 재구성 항 — z에서 x를 얼마나 잘 복원하나. 가우시안 디코더면 MSE, 베르누이면 BCE를 최소화하는 것과 같다
  • ② KL 항 — 닫힌 형태 \mathrm{KL}=\tfrac12\sum_j(\mu_j^2+\sigma_j^2-\log\sigma_j^2-1). μ = 0, σ = 1이면 0이 된다 → 구름을 원점의 표준 정규분포 모양으로 정돈
  • β-VAE — KL에 β를 곱한다. β가 크면 흐릿해지고 사후분포 붕괴 위험, 작으면 잠재 공간이 사전분포와 어긋나 샘플링 품질이 떨어진다

교안재매개변수화 트릭과 VQ-VAE (개정 11p)

문제: z\sim N(\mu,\sigma^2)에서 ‘뽑는’ 연산은 미분할 수 없어 인코더로 기울기가 흐르지 않는다. 해결: 무작위성을 파라미터와 무관한 ε로 떼어 낸다.

z=\mu+\sigma\odot\epsilon,\qquad \epsilon\sim N(0,I),\qquad \frac{\partial z}{\partial\mu}=1,\ \ \frac{\partial z}{\partial\sigma}=\epsilon
mu, logvar = encoder(x)                 # 인코더는 σ 대신 log σ² 를 낸다(음수 걱정 없음)
std = torch.exp(0.5 * logvar)           # log σ² → σ
eps = torch.randn_like(std)
z   = mu + std * eps                    # 재매개변수화
x_hat = decoder(z)
recon = F.mse_loss(x_hat, x, reduction="sum")
kl    = -0.5 * torch.sum(1 + logvar - mu**2 - logvar.exp())
loss  = recon + beta * kl               # −ELBO

VQ-VAE(2017) — 잠재를 연속 벡터 대신 코드북의 가장 가까운 항목(이산 토큰)으로 바꾼다. 이미지가 정수 토큰 격자(예: 32×32)가 되어 트랜스포머가 ‘단어처럼’ 생성할 수 있다(DALL·E 1, VAR). VQGAN(2021)은 여기에 지각 손실 + GAN 판별자를 더한 고품질 토크나이저다.

보충설명숫자로 — z 하나 뽑기와 KL 한 칸

  • 인코더가 μ = 0.5, σ = 0.8을 냈고 이번에 ε = 1.2가 뽑혔다면 z=0.5+0.8\times1.2=1.46. 다음 반복에서 ε = −0.5면 z=0.1 — 같은 사진도 매번 구름 안의 다른 점이 된다
  • 이 한 차원의 KL: \tfrac12(0.5^2+0.8^2-\ln0.64-1)=\tfrac12(0.25+0.64+0.446-1)\approx0.168. μ = 0, σ = 1이면 \tfrac12(0+1-0-1)=0 — KL은 ‘표준 정규분포에서 얼마나 벗어났나’에 매기는 벌점이다
  • 기울기: \partial z/\partial\mu=1, \partial z/\partial\sigma=\epsilon=1.2 — ε를 상수로 보니 μ, σ로 그대로 역전파된다. 확산 모델의 x_t=\sqrt{\bar\alpha_t}x_0+\sqrt{1-\bar\alpha_t}\,\epsilon도 정확히 같은 꼴이다(13.8)

교안순방향 수식 — 한 번에 t단계로 점프 (개정 27p)

q(x_t\mid x_{t-1})=N\big(\sqrt{1-\beta_t}\,x_{t-1},\ \beta_t I\big),\qquad \alpha_t=1-\beta_t,\quad \bar\alpha_t=\prod_{s\le t}\alpha_s
x_t=\sqrt{\bar\alpha_t}\,x_0+\sqrt{1-\bar\alpha_t}\,\epsilon,\qquad \epsilon\sim N(0,I)

\beta_t는 노이즈 스케줄(예: 10⁻⁴ → 0.02 선형). \bar\alpha_t는 ‘원래 신호가 얼마나 남았나’의 누적곱. 덕분에 x₀에서 xt로 t번 반복하지 않고 한 번에 만든다(재매개변수화와 같은 꼴).

개정판의 핵심 메시지: 확산 모델의 ‘느림’은 모델의 본질이 아니라 적분 방법의 문제다. 같은 학습된 모델로 DDPM 1,000스텝 대신 DDIM 50스텝을 쓰면 신경망 호출이 1/20이다. 같은 아이디어의 다른 이름이 점수 기반 모델(밀도가 높아지는 방향 \nabla_x\log p(x)를 배운다 — 노이즈 예측과 같은 것, 개정 29p)이다.

보충설명확산 모델의 수학 — 수식 다섯 줄과 절차 한 장

대면 교안은 직관만 보여 주지만 DDPM 논문은 확률 수식으로 쌓여 있다. 뼈대는 ‘모든 단계가 정규분포(가우시안)’라는 가정 하나와, VAE에서 본 ELBO다. 순서대로 보면 다섯 단계다.

단계수식한 줄 뜻
① 한 걸음 망가뜨리기q(x_t\mid x_{t-1})=N\big(\sqrt{1-\beta_t}\,x_{t-1},\ \beta_t I\big)이전 그림을 살짝 줄이고(√(1−β)) 노이즈를 β만큼 더한다. 학습할 것 없음
② 한 번에 t걸음x_t=\sqrt{\bar\alpha_t}\,x_0+\sqrt{1-\bar\alpha_t}\,\epsilon가우시안을 여러 번 더해도 가우시안이라 한 줄로 접힌다(위 표)
③ 되돌리는 모델p_\theta(x_{t-1}\mid x_t)=N\big(\mu_\theta(x_t,t),\ \sigma_t^2 I\big)한 걸음 되돌리기도 가우시안이라고 놓고, 그 평균만 신경망이 맞힌다
④ 학습 목표 (ELBO)-\log p_\theta(x_0)\le\sum_t \mathrm{KL}\big(q(x_{t-1}\mid x_t,x_0)\,\|\,p_\theta(x_{t-1}\mid x_t)\big)+\cdotsVAE처럼 직접 못 구하는 우도 대신 상한을 줄인다. x₀를 알면 ‘정답 되돌리기’ q(xt−1 | xt, x₀)도 가우시안으로 계산된다
⑤ 단순화\mu_\theta=\tfrac{1}{\sqrt{\alpha_t}}\Big(x_t-\tfrac{\beta_t}{\sqrt{1-\bar\alpha_t}}\,\epsilon_\theta(x_t,t)\Big)\ \Rightarrow\ \lVert\epsilon-\epsilon_\theta\rVert^2두 가우시안의 KL은 ‘평균 차이의 제곱’이 되고, 평균을 이 꼴로 놓으면 결국 노이즈 맞히기 MSE만 남는다(Lsimple)
학습 절차사진 x₀ 뽑기 → t를 무작위로 → ε 뽑기 → ②로 xt 만들기 → 신경망이 ε 예측 → MSE로 갱신 (반복)
생성 절차xT ~ N(0, I)에서 출발 → 매 t마다 ε 예측 → ⑤의 μθ 계산 → 작은 노이즈 σtz 더해 xt−1 → … → x₀

‘정규화’라고 기억나는 것의 정체 — 확산에서 핵심 단어는 정규분포다. ① 매 단계 더하는 노이즈가 정규분포, ② 끝점 xT가 표준 정규분포 N(0, I), ③ 되돌리기도 정규분포로 놓는다. 여기에 ‘크기를 맞춘다’는 의미의 정규화가 하나 더 숨어 있다: ①에서 √(1−β)로 줄이고 β를 더하면 분산이 (1-\beta)\cdot1+\beta=1로 늘 1로 유지된다 — 아무리 노이즈를 더해도 값이 폭주하지 않는 이유다(위 표의 0.280² + 0.960² ≈ 1). 입력 이미지를 [−1, 1]로 맞추는 전처리도 같은 목적이다. 컴퓨터비전 14주차 정리(CV 14주차 확산 모델)에 같은 전방 · 역방 식이 있다 — CV에서 들은 ‘정규화’가 정확히 어느 대목이었는지는 그 페이지와 대조해 보면 된다.

교안텍스트로 조종하기 — 교차 주의와 CFG (대면 27~30p · 개정 31p)

교차 주의 (cross-attention)CFG (분류기 없는 가이던스)
비유화가가 캔버스의 각 부분을 칠할 때마다 주문서에서 해당 단어를 찾아보는 것‘그냥 그린 그림’과 ‘주문대로 그린 그림’의 차이를 찾아 그 차이를 과장해 그리는 것
왜노이즈를 지우는 신경망은 그림만 본다 → 어떤 단어를 어느 위치에 그릴지 연결이 필요텍스트를 넣어도 모델이 문장을 약하게 반영 → 프롬프트와 덜 맞고 흐릿
어떻게Q = 그림의 각 위치(패치), K · V = 문장의 단어 토큰. 위치마다 관련 단어에 가중치를 주고 그 의미(V)를 가져온다 — 계산은 자기 주의와 같다(12주차 자기 주의)학습 때 약 10~20% 확률로 텍스트를 빈칸 ∅로 바꿔 한 모델이 두 예측을 모두 익힘 → 생성 때 두 예측의 차이를 w배
효과단어별 주의 지도로 ‘어느 단어가 어디에 그려지는지’ 보인다 → 단어 하나만 바꿔 그 부분만 편집(Prompt-to-Prompt)w ↑ → 충실도 · 선명도 ↑, 다양성 ↓, 너무 크면 과포화 → 보통 3~8. 스텝마다 예측 2번 → 계산량 2배
\hat\epsilon=\epsilon_\theta(x_t,t,\varnothing)+w\cdot\big(\epsilon_\theta(x_t,t,c)-\epsilon_\theta(x_t,t,\varnothing)\big)

숫자 예: 어떤 픽셀에서 조건 없는 예측 ε(∅) = 0.2, ‘고양이’ 조건 예측 ε(c) = 0.5, w = 3이면 0.2+3\times(0.5-0.2)=1.1. 조건이 가리키는 방향(+0.3)을 3배로 밀어 0.5보다 더 ‘고양이 쪽’으로 간다. w = 1이면 그냥 ε(c) = 0.5, w = 0이면 조건을 무시한 0.2.

작은 잠재 공간에서 그리고, 마지막에 VAE 디코더로 크게 펼친다. 지각적으로 의미 없는 고주파 세부는 VAE에 맡기고, 확산은 의미 있는 구조에 집중한다. 학습 때는 이미지 → VAE 인코더 → z₀ → 노이즈 추가 → 백본이 ε(또는 v) 예측, 추론 때는 인코더가 필요 없고 디코더만 한 번 부른다.

DiT(확산 트랜스포머) — U-Net을 트랜스포머로 바꾼다. 잠재 32×32×4를 2×2 패치로 자르면 16×16 = 256 토큰. 모델과 데이터를 키울수록 FID가 꾸준히 내려가(스케일링) SD3 · FLUX · 영상 모델의 기본 골격이 됐다(13.9).

교안흐름 매칭 — 노이즈와 데이터를 직선으로 잇는다 (대면 32~34p · 개정 38p)

비유(대면 33p) — 꼬불꼬불한 산길(확산) 대신 직선 고속도로(흐름 매칭)를 타고 목적지까지 가는 것. 확산의 생성 경로는 구불구불해서 정확히 따라가려면 작은 걸음을 아주 많이 걸어야 한다. 경로가 곧으면 큰 걸음 몇 번으로 도착한다.

x_t=(1-t)\,x_0+t\,x_1,\qquad x_0\sim N(0,I)\ (\text{노이즈}),\ \ x_1\sim p_{\text{data}},\ \ t\sim U[0,1]
L_{\text{CFM}}=\mathbb E\,\big\lVert v_\theta(x_t,t)-(x_1-x_0)\big\rVert^2
학습생성
노이즈 x₀ · 데이터 x₁ · 시각 t로 중간점 xt를 만들고, 신경망이 그 자리의 정답 속도 x₁ − x₀를 맞힌다 — 노이즈 스케줄 없이 단순 회귀 노이즈에서 출발해 x\leftarrow x+\Delta t\cdot v_\theta(x,t)를 t = 0 → 1로 몇 번 반복(오일러 적분). 비유(대면 34p): 어디서든 ‘도착지 방향과 속력’을 알려 주는 내비게이션을 따라 몇 번만 이동

보충설명숫자로 — 1차원 점 하나를 직선으로 옮기기

  • 노이즈 x₀ = −1.0, 데이터 x₁ = 0.6이라 하자. 정답 속도는 v=x_1-x_0=1.6 — t와 상관없이 늘 같다(직선이니까)
  • t = 0.25의 중간점: x_{0.25}=0.75\times(-1.0)+0.25\times0.6=-0.6. 학습은 ‘x = −0.6, t = 0.25를 보고 1.6을 말하라’
  • 신경망이 완벽히 1.6을 낸다면 생성은 Δt = 0.5로 2스텝이면 충분: −1.0 → −1.0 + 0.5 × 1.6 = −0.2 → −0.2 + 0.8 = 0.6 도착. 경로가 휘어 있으면 큰 걸음이 길을 벗어나 많은 스텝이 필요하다 — 이것이 확산과의 차이

필기 속 질문: 확산과 흐름 매칭은 서로 반대 개념? — 아니다, 같은 목표 · 다른 길
  • 목표는 같다 — 둘 다 ‘노이즈 → 데이터’로 가는 길을 배운다. 확산이 반대(데이터 → 노이즈)를 배우는 것이 아니다. 확산도 노이즈를 더하는 과정은 학습 데이터 만들기용이고, 신경망이 배우는 건 되돌리는 쪽이다
  • 다른 것은 길의 모양과 맞히는 대상 — 확산은 굽은 길 위에서 ‘섞인 노이즈 ε’를, 흐름 매칭은 곧은 길 위에서 ‘속도 v’를 맞힌다. 개정 38p: 둘은 선형 변환으로 서로 바꿀 수 있고, 흐름 매칭은 ‘가장 단순한 경로 + 가장 단순한 손실’을 고른 더 일반적인 틀이다(확산을 포함)
  • 헷갈리는 이유 두 가지 — ① 기호: 확산 절에서는 x₀ = 데이터, 흐름 매칭 절에서는 x₀ = 노이즈다. ② 시간 방향: 확산의 생성은 t = T → 0으로 거꾸로 세고, 흐름 매칭은 t = 0 → 1로 앞으로 센다. 이름표가 반대일 뿐 하는 일은 같은 방향이다

교안자기회귀 생성 모델과 LLM (개정 PART 4 · 22~24p)

p_\theta(x)=\prod_i p_\theta(x_i\mid x_1,\dots,x_{i-1}),\qquad \text{손실}=-\sum_i\log p_\theta(x_i\mid x_{\lt i})

‘다음 토큰 예측’ = 최대 우도. 학습은 병렬(teacher forcing), 생성은 순차(토큰 수만큼 순전파).

  • LLM은 자기회귀 생성 모델이다 — 다음 단어 예측 하나로 언어 능력이 창발했고, 손실이 파라미터 · 데이터 · 연산량의 거듭제곱으로 줄어드는 스케일링 법칙이 규모 경쟁의 근거가 됐다. temperature · top-p 샘플링에도 ‘다양성 vs 품질’ 딜레마가 그대로 있다
  • 이미지에 쓰려면 픽셀 그대로는 너무 길다(256×256 컬러 = 196,608 스텝) → VQ-VAE/VQGAN으로 이산 토큰 격자로 줄인 뒤 생성(DALL·E 1, Parti). MaskGIT은 마스크된 토큰을 병렬로 8~16번에 채우고, VAR(2024)은 1×1 → 2×2 → … → 16×16 ‘다음 해상도’를 예측해 FID 1.73으로 당시 DiT를 넘었다
  • 확산 언어 모델(개정 47p): 반대로 텍스트에 확산을 쓴다 — 전부 [M]으로 가린 문장을 양방향으로 몇 번에 걸쳐 복원(LLaDA, Mercury, Gemini Diffusion) → 토큰 병렬 생성으로 빠르다

생성 모델 · GAN

없던 콘텐츠를 만드는 신경망. GAN = 적대적 훈련, 경쟁하는 두 신경망. 학습한 데이터와 비슷한 분포의 새 이미지를 만든다.

생성자 · 판별자

생성자(위조지폐범): 노이즈 → 이미지. 판별자(경찰): 이미지 → 진짜일 확률(0 가짜, 1 진짜) = 이미지 분류 신경망.

구조

판별자 = 출력 1차원까지 줄어드는 CNN(LeakyReLU · Dropout · sigmoid 1개). 생성자 = 1차원 입력을 이미지 크기까지 업샘플링(Dense → Reshape 7×7×128 → 14 → 28).

업샘플링

픽셀을 가로세로로 반복. (2, 2): 2×2 → 4×4, (3, 3): 2×2 → 6×6. 다운 샘플링 = 풀링으로 줄이기.

학습

판별자 = 진짜 1 · 가짜 0 지도 학습(sigmoid, binary_crossentropy, Adam). 생성자 = 통합 신경망(노이즈 → 정답 1), 판별자 고정. 둘을 교대로.

판별자 고정 이유

두 손실 함수가 달라 수정 방향이 다르다. 고정 안 하면 판별자가 가짜를 진짜로 판정하게 된다.

미니맥스

제로섬 게임. \min_G\max_D\,\mathbb E[\log D(x)]+\mathbb E[\log(1-D(G(z)))]. D는 최대, G는 최소. 로그 = 틀릴수록 큰 벌점.

평가

인셉션 점수: 예측 확신도 ↑ · 다양성 ↑(클수록 좋다). FID: 실제 · 생성 출력의 다변량 가우시안 사이 프레셰 거리(작을수록 좋다). 주로 사람이 직접 평가.

응용

StackGAN(문장 → 저해상도 형태 · 색 → 고해상도 세부), 이미지-이미지 번역, 초해상도.

프로젝트

패션 MNIST · /127.5 − 1 → [−1, 1] · expand_dims → (28, 28, 1) · 노이즈 100 · Adam(0.0002, 0.5) · train(1000, 32, 50) · d_loss = 평균.

판별 vs 생성

판별 = p(y|x)(경계). 생성 = p(x)(분포)를 배워 새 표본. 명시적 밀도(자기회귀 · VAE · 확산) vs 암시적 밀도(GAN).

발전 흐름

VAE(2013) · GAN(2014) → DCGAN · WGAN · StyleGAN → DDPM(2020) → Stable Diffusion(2022) → DiT · SDXL(2023) → SD3 · FLUX(흐름 매칭, 2024) → 멀티모달 · 소수 스텝(2025~26).

GAN 학습의 어려움

모드 붕괴 · 기울기 소실 · 진동. 해결: 비포화 손실 −log D(G(z)), WGAN-GP, 스펙트럴 정규화, TTUR. D* = pdata/(pdata+pg), 균형에서 ½. 손실보다 샘플을 보라.

평가 확장

IS = exp(E KL(p(y|x)‖p(y))) ↑, FID = ‖μr−μg‖² + Tr(…) ↓. 텍스트 → 이미지: CLIP 점수 · 아레나(사람 선호). 복원: PSNR · SSIM.

GAN 계보

안정 학습 → 조건 제어 → 고해상도 · 스타일 → 대규모. cGAN(조건 y를 G · D에) · Pix2Pix(짝) · CycleGAN(짝 없이 순환) · StyleGAN(해상도별 스타일) · StackGAN · SRGAN.

VAE

인코더가 분포(μ, σ) → z = μ + σε(재매개변수화). 손실 = 재구성 + KL(→N(0, I)) = −ELBO. 매끄러운 잠재 · 안정, 대신 흐림 → 잠재 확산의 압축기.

확산

순방향(노이즈 추가)은 고정, 역방향만 학습. xt = √ᾱ x₀ + √(1−ᾱ) ε, 손실 ‖ε − εθ‖². 안정 · 다양, 느림(T번) → DDIM 등. 2020 DDPM.

교차 주의 · CFG

교차 주의: Q = 그림 위치, K · V = 단어. CFG: ε̂ = ε(∅) + w(ε(c) − ε(∅)), 학습 때 10~20% ∅, w 3~8, 크면 과포화, 계산 2배.

잠재 확산 · SD

VAE로 압축(512²×3 → 64²×4, 약 48배) → 잠재에서 확산 → VAE 디코더. SD 1/2 U-Net → SDXL 큰 U-Net · 이중 인코더 → SD3 MMDiT + 흐름 매칭.

흐름 매칭 · 증류

xt = (1−t)x₀ + t x₁, 속도 v = x₁ − x₀ 회귀, 직선이라 적은 스텝. 증류: 점진적 · 일관성 · 적대적 → 1~4 스텝. MeanFlow 1스텝.

비교 · 삼중고

GAN 고품질 · 빠름(다양성 ↓), VAE 빠름 · 다양(품질 ↓), 확산 고품질 · 다양(느림). 최신 = DiT + 흐름 매칭 + VAE 잠재, 멀티모달 LLM 결합, 영상 + 음성.

응용 · 윤리 · 강조

편집 · 영상 · 증강 · 의료. 딥페이크 · 저작권 → SynthID · C2PA. ★ 프롬프트 능력 = 기획력, 트렌드를 계속 익히는 AI-Native scientist.
