2.1

확률의 기초표본공간 · 확률변수 · 조건부확률 · 베이즈 정리

왜 확률인가
  • 사람의 언어는 불확실한 현상으로 구성되어 있다 — “사과” 다음에 “맛있다”가 나올 가능성은? 같은 문장도 문맥에 따라 다르게 해석된다
  • 확률(probability) — 어떤 사건(event)이 발생할 가능성을 수치로 나타낸 것. 불확실한 자연어 현상을 정량적으로 분석 · 예측하게 해 주는 언어
  • 현대 자연어처리의 거의 모든 모델은 확률 모델이다
    · 언어모델 : 다음 단어의 확률분포를 예측  P(다음 단어 | 앞의 단어들)
    · 분류 · 번역 · 요약 : 가장 확률이 높은 출력을 선택

표본공간 · 사건 · 확률변수

  • 표본공간(sample space) Ω — 일어날 수 있는 모든 경우의 집합. 동전 두 개를 던지면 {HH, HT, TH, TT}
  • 사건(event) — 표본공간의 부분집합
  • 확률변수(random variable) — 표본공간의 각 표본점(결과)을 하나의 실수에 대응시키는 함수  X : Ω → ℝ
    · 예 : HH → 2, HT → 1, TH → 1, TT → 0 이므로 P({HH}) = P(X=2) = 1/4
    · 자연어처리에서의 확률변수 : 다음에 올 단어, 문장의 감성 레이블, 품사 태그 등

이산 확률변수 vs 연속 확률변수

구분이산 확률변수 (discrete)연속 확률변수 (continuous)
값의 성격취할 수 있는 값이 이산적으로 셀 수 있음연속적인 실수 값
분포 표현확률질량함수(PMF) P(X=x)확률밀도함수(PDF) f(x) — 특정 한 점의 확률은 0
확률 계산각 값의 확률을 그대로 사용구간의 넓이(적분), 전체 넓이는 1
NLP에서의 예단어, 품사 등 대부분의 언어 단위임베딩 값, 모델 파라미터 등

결합 · 주변 · 조건부 확률

  • 결합확률 P(X, Y) — 두 사건이 동시에 일어날 확률
  • 주변확률 P(X) — 다른 변수를 모두 합해서 얻는 확률 (marginalization)
  • 조건부확률 P(Y|X) — X가 일어났다는 조건 아래 Y가 일어날 확률

연쇄법칙과 문장의 확률, 그리고 마르코프 가정

  • 조건부확률을 반복 적용하면 연쇄법칙(chain rule)을 얻는다. 문장은 단어의 나열이므로 문장의 확률도 연쇄법칙으로 분해할 수 있다
  • 그러나 앞 단어 전체를 조건으로 하면 경우의 수가 폭발해 추정이 불가능해진다
  • 독립(independent) — 두 사건이 독립이면 P(A, B) = P(A) P(B)
  • 마르코프 가정 — 바로 앞의 n−1개 단어만 보면 충분하다고 가정
    · n=2 이면 bigram, n=3 이면 trigram 모델
    · 현실을 단순화한 가정이지만 계산 가능한 모델을 만들어 준다
참고 — Transformer 기반 언어모델은 이 마르코프 가정을 완화하여 긴 문맥을 직접 다룬다.

베이즈 정리

  • 관측된 증거(E)를 이용해 가설(H)에 대한 믿음을 갱신하는 규칙
  • 사전확률 P(H) → (우도 P(E|H) 반영) → 사후확률 P(H|E)
응용 — 나이브 베이즈(Naive Bayes) 문서 분류
  • 문서 d가 주어졌을 때 가장 확률이 높은 클래스 c를 선택
  • P(c|d) ∝ P(c) P(d|c) 이고, 단어들이 조건부 독립이라고 “순진하게(naive)” 가정한다

기댓값과 분산

  • 기댓값(expectation) — 확률변수의 평균과 같은 역할. 값과 그 값이 나올 확률의 가중평균
    · 주사위 한 개 : E(X) = 1·1/6 + 2·1/6 + … + 6·1/6 = 21/6 = 3.5
  • 분산(variance) — 값들이 평균에서 얼마나 흩어져 있는지를 나타냄

주요 확률분포

이항분포 B(n, p)Binomial

확률 p인 베르누이 시행을 n번 반복할 때 성공 횟수의 분포.

다항분포 Multi(P)Multinomial

이항분포의 일반화로 결과가 k가지인 경우. 평균 E(xi)=n pi, 분산 Var(xi)=n pi(1−pi). 문서의 단어 빈도 벡터, 언어모델의 출력 분포가 대표적.

정규분포Gaussian

연속 확률분포. 평균 μ와 표준편차 σ 두 파라미터로 결정. 신경망 가중치 초기화, 임베딩 값의 분포 등에 널리 사용.

참고 : 언어 데이터의 분포 — Zipf의 법칙
단어의 출현 빈도는 정규분포가 아니라 매우 치우친(long-tail) 분포를 따른다. 상위 소수 단어가 전체 출현의 대부분을 차지하고, 대부분의 단어는 매우 드물다. → 데이터 희소성(data sparsity) 문제의 근본 원인이며, 스무딩과 서브워드 분절의 배경이 된다.
2.2

MLE와 MAP파라미터 추정의 두 원리와 스무딩

MLE — 최대우도추정 (Maximum Likelihood Estimation)
  • 모델의 파라미터 θ를 데이터로부터 어떻게 정할 것인가?
  • 관측된 데이터가 나타날 확률(우도)을 가장 크게 만드는 θ를 선택
  • 곱셈은 값이 작아지므로 보통 로그를 취한 로그우도를 최대화한다
MLE로 n-gram 확률 추정하기
  • 코퍼스에서 세어본 빈도의 비율이 곧 MLE 추정값이 된다
  • 예 : C(“자연어 처리”) = 30, C(“자연어”) = 50 → P(처리 | 자연어) = 0.6
MLE의 한계 — 관측되지 않은 사건의 확률이 0이 되어 버린다. 한 번도 못 본 bigram이 하나라도 있으면 문장 전체의 확률이 0이 된다.
MAP — 최대사후확률추정 (Maximum A Posteriori)
  • 사전지식(prior)을 함께 고려하여 사후확률을 최대화하는 θ를 선택
  • 데이터가 적을 때 사전분포가 추정값을 안정적인 쪽으로 끌어당겨 준다
  • 데이터가 많아지면 우도가 지배적이 되어 MLE와 거의 같아진다
스무딩 — MAP의 실용적 형태
  • Add-k 스무딩 — 모든 사건에 가상의 빈도 k를 더해 준다 (k=1인 경우를 라플라스(add-one) 스무딩이라 함)
  • “모든 사건은 조금씩은 가능하다”는 사전 믿음을 반영한 것 → MAP 추정과 동치
  • 실무에서는 Kneser-Ney, Good-Turing 등 더 정교한 스무딩을 사용
  • 딥러닝에서의 대응 개념 : 가중치 감쇠(weight decay), 라벨 스무딩 등의 정규화

MLE vs MAP 한눈에 비교

구분MLE (최대우도추정)MAP (최대사후확률추정)
최대화 대상우도 P(데이터 | θ)사후확률 P(θ | 데이터) ∝ 우도 × 사전확률
사전지식사용하지 않음사전분포(prior)로 반영
데이터가 적을 때과적합 · 확률 0 문제 발생사전분포가 추정을 안정화
데이터가 많을 때—우도가 지배적 → MLE와 거의 같아짐
NLP에서의 형태빈도 비율로 n-gram 확률 추정Add-k(라플라스) 스무딩, Kneser-Ney 등
2.3

정보이론과 엔트로피정보량 · 엔트로피 · 교차엔트로피 · KL · Perplexity

  • 정보이론은 Shannon이 제안한 이론으로, 데이터의 압축률과 전송률을 최대화하는 수학적 모델에서 출발했다
  • 정보량(self-information) — 잘 일어나지 않는 사건일수록 정보량이 크다
    · “오늘 해가 떴다” → 정보량 낮음  /  “오늘 눈이 왔다(7월)” → 정보량 높음
  • 엔트로피 — 확률변수가 갖는 정보량의 평균적인 기댓값. 어떤 정보의 불확실성이 높은지 낮은지 평가하는 지표로, 값이 높을수록 불확실성이 높다
    · 분포가 균등할수록(예측하기 어려울수록) 엔트로피가 커진다
  • 결합 엔트로피 H(X,Y) — 두 확률변수를 함께 볼 때의 불확실성
  • 조건부 엔트로피 H(Y|X) — X를 알고 난 뒤에도 남아 있는 Y의 불확실성

상호정보량과 PMI

  • 상호정보량 I(X;Y) — X를 알게 되어 줄어드는 Y의 불확실성 = 두 변수의 의존성
  • PMI(점별 상호정보량) — 두 단어가 우연보다 얼마나 자주 함께 나타나는가
    · 연어(collocation) 추출, 단어 벡터(PPMI 행렬) 구성에 사용
    · 예 : “미역”-“국”의 PMI는 높고, “미역”-“컴퓨터”의 PMI는 낮다

교차 엔트로피 · KL-divergence · Perplexity

  • 교차 엔트로피 H(P,Q) — 참 분포 P를 모델 분포 Q로 표현할 때 필요한 평균 비트 수
    · H(P,Q) = H(P) + KL(P∥Q) 이고, P는 데이터가 정해 주는 고정 분포라 H(P)가 상수 → 교차 엔트로피를 줄이는 것 = KL을 줄이는 것
    · 딥러닝 분류 · 언어모델 학습의 표준 손실함수
  • KL-divergence — 두 분포 P와 Q가 서로 얼마나 다른지 측정
    · 값이 낮을수록 두 분포가 일치 (항상 0 이상)
    · 비대칭이므로 거리(distance)가 아니라 발산(divergence)이라 부른다
    · 지식 증류, 강화학습(PPO)의 정책 제약 등에 널리 사용
  • Perplexity — 언어모델의 표준 평가 지표로, 교차 엔트로피를 지수로 되돌린 값
    · 직관 : “모델이 다음 단어를 고를 때 평균 몇 개의 후보 사이에서 헷갈리는가”
    · 값이 낮을수록 좋은 모델
2.4

자연어처리를 위한 선형대수벡터 · 내적 · 코사인 유사도 · 행렬 · SVD

왜 벡터인가
  • 컴퓨터는 문자열을 그대로 계산할 수 없다 → 단어와 문장을 수치 벡터로 바꿔야 한다
  • 원-핫 표현은 단순하지만 차원이 크고 의미 정보를 담지 못한다
  • 분산 표현(임베딩)은 조밀한 저차원 벡터로 의미의 유사성을 기하 구조로 표현한다
벡터 · 노름 · 내적
  • 벡터 — 크기와 방향을 갖는 수의 나열. 단어 하나가 하나의 벡터
  • 노름(norm) — 벡터의 길이. 문서가 길수록 빈도 벡터의 노름이 커진다
  • 내적(dot product) — 두 벡터의 크기와 방향의 일치 정도를 함께 반영하는 스칼라 값 (방향만 보려면 노름으로 나눈 코사인 유사도를 쓴다)
코사인 유사도 — 내적을 두 벡터의 노름으로 나누면 각도만 남는다 → 길이의 영향을 제거. 문서 길이나 단어 빈도의 크기와 무관하게 ‘의미의 방향’만 비교할 수 있어, 검색 · 문서 유사도 · 임베딩 기반 추천에서 가장 널리 쓰이는 유사도다.
행렬과 선형변환
  • 행렬은 여러 벡터를 한꺼번에 다루거나, 벡터를 다른 공간으로 옮기는 변환
  • 임베딩 조회(lookup) — 원-핫 벡터에 임베딩 행렬을 곱하면 해당 행이 선택된다
  • 신경망의 한 층 = 행렬 곱 + 편향 + 비선형 함수
  • 배치 처리 — 여러 문장을 행렬로 쌓아 GPU에서 한 번에 계산
단어-문서 행렬과 TF-IDF, 그리고 SVD
  • 문서 집합을 단어 × 문서 행렬로 표현하면 텍스트가 선형대수의 대상이 된다
  • TF-IDF — 자주 나오지만 모든 문서에 흔한 단어의 가중치를 낮춘다
  • 단어-문서 행렬은 매우 크고 희소 → 핵심 의미 구조만 남기고 압축
  • SVD(특이값 분해)로 상위 k개의 특이값만 남기면 잠재 의미 분석(LSA)이 된다. 문맥이 비슷한 단어가 같은 축으로 모이므로 표면 형태가 달라도 유사도를 잡아낼 수 있다 (단, 동의어뿐 아니라 반의어도 함께 모이는 것이 한계)
참고 : 확률 · 선형대수가 만나는 지점 — 소프트맥스
벡터 내적으로 계산한 점수를 확률분포로 바꾸는 함수가 소프트맥스다.
· 분자 : 문맥 벡터와 단어 벡터의 내적 → 선형대수
· 분모 : 전체 어휘에 대한 정규화 → 확률의 합이 1
즉 언어모델 = 선형대수로 점수를 만들고, 확률로 해석하고, 교차 엔트로피로 학습하는 것.
2.5

언어학 개요언어의 층위와 대응 과제

  • 자연어처리를 연구하려면 자연어 자체의 원리를 이해할 필요가 있다
  • 언어는 소리에서 맥락까지 여러 층위로 이루어져 있다
  • 각 층위마다 대응되는 자연어처리 과제가 존재한다
음운론소리→ 형태론형태소 · 품사→ 통사론구구조 · 의존구조→ 의미론의미 · 의미역→ 화용론맥락 · 사용
2.6

음절, 형태소, 어절 그리고 품사형태론

음절 · 형태소 · 어절

음절 (syllable)최소 발화 단위

말하고 들을 때 하나의 덩어리로 여겨지는 최소 발화 단위. 한국어는 초성 · 중성 · 종성이 기본(초·종성은 자음 C, 중성은 모음 V, 모음 단독 음절도 가능). NLP에서는 “음”, “절”, “은” 같은 한 글자 단위를 음절이라 한다.

형태소 (morpheme)의미의 최소 단위

의미를 가지는 가장 작은 단위. 더 쪼개면 기능이나 의미를 갖지 않게 된다.

어절띄어쓰기 단위

한 개 이상의 형태소가 모여 구성된 단위. 발화할 때 끊어 말하는 단위이며, 글에서는 띄어쓰기 단위와 거의 일치한다.

형태소의 분류
  • 실질 형태소(어휘 형태소) — 실질적인 의미를 갖는 형태소 (명사 · 대명사 · 수사 · 관형사 · 부사 · 감탄사, 그리고 용언의 어간)
  • 형식 형태소(문법 형태소) — 문법적 기능을 하는 형태소 (조사 · 어미 · 접사)
  • 자립성 기준으로는 자립 형태소 / 의존 형태소로도 나눈다
  • 이형태 — 하나의 형태소가 환경에 따라 다른 모습으로 나타나는 것 (이/가, 을/를)
한국어는 교착어라서 어절 하나에 여러 형태소가 결합된다. 따라서 단순 띄어쓰기 분리만으로는 의미 단위를 얻을 수 없고, 형태소 분석이 선행되어야 한다.
“학교” + “에서” + “는” 처럼 조사가 계속 붙어 어절의 종류가 폭발적으로 많아지고, 어절을 그대로 어휘로 쓰면 미등록어(OOV)가 급증 → 형태소 분석 또는 서브워드 분절이 필요하다.
언어별 차이 — 영어는 굴절어이지만 굴절이 약화되어 분석적(analytic) 성격이 강하다. 기능어가 독립 단어로 분리되어 있어 공백 토큰화만으로도 상당 부분 처리가 가능하다.

품사 (Part-of-Speech)

품사 — 단어를 문법적 성질에 따라 분류한 갈래
  • 기능에 따라 — 체언 · 수식언 · 관계언 · 독립언 · 용언의 5언
  • 의미에 따라 — 명사 · 대명사 · 수사 · 관형사 · 부사 · 조사 · 감탄사 · 동사 · 형용사의 9품사
  • 형태에 따라 — 가변어와 불변어
5언설명세부
체언문장에서 주체가 되는 자리에 쓰임명사 · 대명사 · 수사
수식언다른 말을 꾸며 주는 단어관형사 — 체언 앞에서 체언을 꾸밈 (성상 · 지시 · 수 관형사)
부사 — 주로 용언이나 문장 전체를 꾸밈 (성상 · 지시 · 부정 · 양태 · 접속 부사)
관계언자립 형태소에 붙어 문법적 관계를 나타내는 의존 형태소 = 조사격조사(주격 · 목적격 · 관형격 · 부사격 · 호격 · 보격 · 서술격), 접속조사, 보조사
독립언다른 성분과 관계없이 독립적으로 쓰임감탄사
용언어미를 활용하여 서술어 기능을 하는 말동사 · 형용사
용언과 활용
  • 용언은 어간(변하지 않는 부분)과 어미(변하는 부분)로 이루어진다
  • 어말 어미 — 종결 어미 · 연결 어미 · 전성 어미
  • 선어말 어미 — 시제 선어말 어미(-았/었-, -겠-), 높임 선어말 어미(-시-)
  • 동사의 분류 — 자동사/타동사, 능동사/피동사, 주동사/사동사, 본동사/보조동사, 규칙/불규칙
  • 활용 때문에 한국어는 표면형의 종류가 매우 많다 → 형태소 분석기의 원형 복원 단계가 이를 처리 (영어의 lemmatization에 대응)
품사 태깅(POS tagging)과 중의성
  • 문맥을 보고 각 형태소에 올바른 품사를 부여하는 과제
  • 표기가 같아도 문맥에 따라 분석 결과가 달라진다 → 자동 분석이 필요한 이유
  • 대표 태그셋 — 세종 태그셋(Komoran · Mecab-ko 가 이를 따름)과 자체 태그셋을 쓰는 Okt
2.7

구구조와 의존구조통사론

구구조 (phrase structure)
  • 문장 요소들이 서로 결합하여 이루는 계층적 구조
  • 구성 요소들은 선행 관계와 지배 관계를 맺고 있다
  • 수형도(tree) 또는 괄호 표기로 나타낸다
  • 단어 배열이 비교적 고정된 영어와 같은 언어 분석에 많이 쓰인다
문맥자유문법 (CFG)
  • 구구조는 다시 쓰기 규칙(rewriting rule)의 집합으로 형식화할 수 있다
  • 유한한 규칙으로 무한한 문장을 생성할 수 있다 (생성 문법)
구조적 중의성 — 하나의 문장이 둘 이상의 구구조를 가질 수 있다.
“I saw the man with glasses” → 안경을 낀 남자를 보았다  /  안경을 끼고 남자를 보았다
의존구조 (dependency structure)
  • 문장에 포함된 단어들이 서로 의존 관계를 이루어 구문을 형성한다고 본다
  • 각 단어는 지배소(head)와 의존소(dependent)의 관계로 연결된다
  • 한국어는 어순이 비교적 자유롭기 때문에 구구조보다 의존 구문 분석이 주로 이용된다
  • 의존 구문 분석 방법 — 그래프 기반과 전이 기반의 두 가지 대표적 접근
구분구구조 분석의존 구문 분석
보는 방식요소들이 결합해 이루는 계층적 구조단어 간 지배소–의존소 관계
표현수형도(tree) · 괄호 표기단어를 잇는 의존 관계 그래프
형식화문맥자유문법(CFG)의 다시 쓰기 규칙그래프 기반 / 전이 기반 접근
적합한 언어어순이 고정된 언어(영어 등)어순이 자유로운 언어(한국어)
2.8

의미론과 화용론의미 · 의미역 · 중의성 해소 · 맥락

의미론 (Semantics)
  • 단어 · 문장 · 발화가 실제로 가리키는 의미와 그 관계를 다룬다
  • 문법적으로 옳아도 의미가 어색하면 자연스러운 언어라 할 수 없다
    · 예 : “사료가 개를 먹었습니다”는 문법적으로 완벽하지만 의미적으로 부자연스럽다
  • 어휘 의미 관계 — 동의 · 반의 · 상하위 · 부분 관계 (WordNet, KorLex 등의 자원)
의미역 (semantic role)
  • 서술어에 대해 각 명사구가 담당하는 의미적 역할 — 행위자 · 대상 · 수혜자 · 장소 · 도구 등
  • 의미역 결정(SRL)은 “누가 누구에게 무엇을 하였는가”를 밝히는 과제
중의성 해소와 분포 가설
  • 어휘 중의성 — 같은 단어가 문맥에 따라 다른 의미를 가짐 (“배” : 과일 / 신체 / 선박)
  • 단어 의미 중의성 해소(WSD) — 문맥을 이용해 올바른 의미를 고르는 과제
  • 분포 가설은 이 문제를 통계적으로 다루는 출발점이자 임베딩의 이론적 근거
화용론 (Pragmatics)
  • 언어 사용자와 발화 맥락을 고려하는 연구
  • 말하는 이 · 듣는 이 · 시간 · 장소로 구성되는 맥락 속에서 언어의 사용을 다룬다
  • 대화 시스템 · 챗봇에서 특히 중요 (의도 파악, 문맥 유지, 공손성)

한 줄로 꿰기
언어는 불확실하니까 → 확률로 모델링하고(2.1), 데이터에서 파라미터를 추정하며(2.2), 얼마나 잘 맞췄는지 정보이론으로 재고(2.3), 계산은 벡터 · 행렬로 한다(2.4). 그럼 무엇을 모델링하는가 → 언어의 층위(2.5)를 따라 형태소 · 품사(2.6) → 구조(2.7) → 의미와 맥락(2.8)이 그 대상이다.
