학습 흐름Learning Path

1~2주차 · 기초 — 자료구조와 알고리즘의 관계, 알고리즘 성능분석(점근 표기), 그리고 구현 언어인 Python 클래스 문법을 다집니다.
3~4주차 · 선형 자료구조 — 연결 리스트(단순·이중·원형)에서 시작해 스택·큐·데크로 확장합니다.
5~7주차 · 트리 — 이진트리와 이진힙, 이진탐색트리 연산, 균형을 유지하는 AVL 트리 회전까지 이어집니다.
8~10주차 · 정렬과 해싱 — O(n²) 정렬(선택·버블·삽입·쉘)과 O(n log n) 정렬(합병·퀵·기수)을 비교하고, 해시 테이블의 충돌 처리(선형조사·체이닝)를 다룹니다.
11~14주차 · 그래프 — 표현 방식(인접행렬·인접리스트)과 탐색(DFS·BFS)을 익힌 뒤 위상정렬·연결성분, 최소신장트리(Kruskal·Prim), 최단경로(Dijkstra·Floyd-Warshall)로 마무리합니다.
